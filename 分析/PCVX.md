# PCVX · Vaxcyte(肺炎球菌疫苗研发)

市值 88.5 亿美元 / 股价 59.47 美元 / 生物科技(临床阶段疫苗) / TTM 截止 2026-06-30 / 任务5 第 88 名

**先说结论性质:这是一家零收入、一年亏 10.6 亿的研发公司,全部身家押在一支疫苗上,三个月后开奖。** 下面的分析不是在算它赚多少钱,而是在算「它会不会死」和「赌赢了值多少」。

---

## 第一部分:它到底做几件事

**只做一件事:研发一支覆盖更多血清型的肺炎球菌结合疫苗,目前一分钱收入都没有。**

### 这件事是什么

肺炎球菌是一种细菌,会引起肺炎、脑膜炎、败血症,老人和婴儿最容易中招。它有一百多种「血清型」(可以理解为一百多个变种),疫苗只能挑一部分来防。辉瑞的 Prevnar(沛儿)是这个领域的霸主:从 7 价、13 价做到现在的 20 价,意思是防 20 种变种,一年卖 60 多亿美元,是全世界最赚钱的疫苗之一。默沙东 2024 年推出的 Capvaxive 防 21 种,专攻成人市场。

为什么不干脆做个防 50 种的?因为传统工艺有个天花板。结合疫苗的做法是把每种血清型的糖分子「挂」在一个载体蛋白上,免疫系统认出载体蛋白才会产生反应。挂的种类越多,载体蛋白就被稀释得越厉害,免疫反应反而下降,行话叫「载体抑制」。所以辉瑞从 13 价到 20 价花了十年,再往上加就加不动了。

Vaxcyte 的办法是换掉整个制造工艺。它从 Sutro Biopharma 授权了一套「无细胞蛋白合成」技术,可以在试管里精确合成载体蛋白,并且在指定位置放上非天然氨基酸当「挂钩」,糖分子只能挂在挂钩上,不会乱挂。这样每种血清型用的载体量可以减到传统工艺的一小部分,同样的载体总量能挂 31 种而不是 20 种。公司管这个叫「载体节约型」(carrier-sparing)。

它的主打产品 **VAX-31** 防 31 种血清型,比 Prevnar 20 多 11 种。公司的说法是能覆盖美国 50 岁以上成人侵袭性肺炎球菌病病例的九成以上,而现有疫苗只能覆盖一半多。2024 年的一/二期数据显示,VAX-31 在 20 种共有血清型上的免疫反应不输 Prevnar 20,多出来的 11 种也都有效——这是股价当年翻倍的原因。

### 现在做到哪一步

- **成人项目(主线)**:三个三期试验 OPUS-1、OPUS-2、OPUS-3 已全部入组完毕。OPUS-1 是关键的「非劣效」试验(证明 VAX-31 不比 Prevnar 20 差),**顶线数据预计 2026 年四季度出**,OPUS-2/3 在 2027 年上半年出。三期全过之后申报 FDA,顺利的话 2028 年前后上市。
- **婴儿项目**:婴儿是肺炎球菌疫苗最大的市场(美国婴儿要打四针,联邦儿童疫苗计划买走一半),但婴儿的免疫系统对结合疫苗更挑剔。2025 年 3 月 VAX-24 婴儿二期数据不够漂亮,股价当天腰斩。现在婴儿项目改推 VAX-31,进度落后成人两三年。
- **后面排队的**:A 组链球菌疫苗、牙周炎疫苗、志贺菌疫苗,全在临床前或一期,眼下不值钱。

### 赌赢了怎么赚钱

疫苗跟药不一样,卖的是「渠道 + 官方推荐」。美国 CDC 下属的免疫实践咨询委员会(ACIP)开会说「50 岁以上成人推荐打 VAX-31」,医保和商保就得付钱,CVS、Walgreens 的药房就会进货。成人一针 Prevnar 20 私立市场标价约 280 美元。一年美国 50 岁以上人口有几千万没打过新一代疫苗,加上婴儿每年 370 万新生儿 × 4 针。整个肺炎球菌疫苗市场一年约 80 亿美元,还在涨。

生产外包给龙沙(Lonza),自己不建厂,资产负债表上 3.7 亿的固定资产主要是龙沙那边的专用产线投入。

## 第二部分:把会计障眼法剥掉

- **股权激励(SBC)**:TTM 1.5 亿,占经营亏损的 13%。零收入公司用股票发工资是常态,这 1.5 亿已经在 GAAP 亏损里扣了,不需要再调。真正要看的是它带来的稀释(下面说)。
- **一次性项目**:没有。亏损全是研发和管理费,没有减值、没有诉讼。
- **资本化的支出**:没有。研发费全部当期费用化,3.7 亿固定资产是真实的产线设备,没有把研发藏进资产。
- **回购与稀释**:TTM 回购 1,630 万(只是代员工缴税的股票回收,不算回购),增发 6.22 亿。股本一年膨胀 4.9%(1.42 亿股→1.49 亿股)。**这家公司的商业模式就是隔一两年增发一次**:2022 年增发 8.6 亿、2023 年 6.4 亿、2024 年 24.6 亿、2026 年上半年 6.2 亿。从 2021 年到现在股本翻了 2.6 倍。
- **利润和现金流的差**:净亏 10.64 亿,经营现金流 −8.81 亿,差 1.8 亿——全是 SBC(1.5 亿)和折旧(0.27 亿)这类非现金项。现金比利润「好看」一点,但都是亏。

**烧钱速度和续命时间(全篇最重要的一张表):**

| 项目 | 数字 |
|---|---|
| 现金 + 短期投资 | 14.87 亿 |
| 长期投资(国债之类,能变现) | 10.21 亿 |
| 有息负债(全是租赁) | −1.15 亿 |
| **净可用资金** | **约 23.9 亿** |
| TTM 自由现金流 | −9.21 亿 |
| 最近半年折年的烧钱速度(估算) | 约 10 亿/年 |
| **按现在速度还能烧** | **约 2.4 年,到 2028 年底** |

2.4 年刚好覆盖三期出数据(2026 Q4–2027 H1)、申报、审批。**但覆盖不了上市推广**——建销售队伍、备货、婴儿三期,这些都在 2028 年之后,而且每年还要多烧。所以几乎可以肯定还会再增发至少一次,大概率选在三期数据好、股价高的时候。

## 第三部分:亏损公司的口径

| 项目 | 数字 | 说明 |
|---|---|---|
| TTM 营收、同比增速 | 0 | 没有营收,连「唯一硬的东西」都没有 |
| TTM 经营亏损 | −11.65 亿 | |
| TTM 经营现金流 / 自由现金流 | −8.81 亿 / −9.21 亿 | |
| 一年净烧多少 | 9.2 亿(最近半年折年约 10 亿) | |
| 账上现金 − 有息负债 | 23.9 亿(含长期投资) | |
| 还能烧几年 | 2.4 年 | 够到审批,不够到上市推广 |
| SBC 占营收 / 股本膨胀 | 营收为零无法算;股本一年 +4.9%,五年 2.6 倍 | |
| **做到成熟利润率能赚多少** | 见下 | |

**假想市盈率怎么算:** 拿辉瑞 Prevnar 系列当参照——单一疫苗产品线的经营利润率在 50% 上下(生产外包给龙沙,成本约 15–20%,销售队伍 15%,持续研发 15%),税后净利率按 40% 算。

- **保守情形**:VAX-31 只拿下成人市场的一块,年销售 20 亿美元 → 净利 8 亿 → 假想市盈率 88.5 ÷ 8 = **11 倍**,投 100 块一年赚 9 块。
- **乐观情形**:成人 + 婴儿都成,年销售 40 亿(抢走辉瑞一大半) → 净利 16 亿 → **5.5 倍**,投 100 块赚 18 块。

**大白话:假设它明天就做到成熟利润率,你投 100 块一年赚 9 到 18 块——这个数字本身相当便宜。但它离那一天差得远:**营收要从 0 做到 20 亿,最早也是 2030 年前后;这期间至少再增发一到两次,你手里的份额还要被稀释两三成;而且以上全部建立在三期试验成功的前提上。

三期成功的概率有多大?非劣效免疫原性试验,二期数据已经很强,这类疫苗三期通过率历史上在七八成。**但「七八成」的另一面是两三成的概率归零**——2025 年 3 月婴儿数据一出来股价一天跌一半,就是预演。

**失败了剩什么:** 账上 23.9 亿,每股约 16 美元,股价 59 美元。也就是说,现在的价格里有 16 美元是现金、43 美元是对 VAX-31 的赌注。

## 第四部分:一句话结论

**这不是一家公司,是一张三个月后开奖的彩票,赔率还算公道。** 赌赢了,你是用 6–11 倍的假想市盈率买了辉瑞最赚钱疫苗的挑战者,四五年后兑现;赌输了,59 美元的股票剩 16 美元现金加一堆早期管线。88 亿市值对这个赌局不算贵也不算便宜——它是一个 2.4 年不会死、但一定还要再向你伸手要钱的公司。想参与就等 OPUS-1 数据,不想参与就别看它。
