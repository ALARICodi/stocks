## 第一部分：它到底做几件事

先讲清楚 Organon 是怎么来的，不然后面的报表全看不懂。

**2021 年 6 月，默沙东（Merck）把自己不想要的东西打包成一家公司扔了出来，这家公司就是 Organon。** 装进去的是三类资产：过了专利期、还能卖但年年掉价的老药；女性健康产品线；以及一堆生物类似药。默沙东留下的是 Keytruda 这种正在爆发的新药。

分拆不是白送。翻 2021 年的现金流量表能看得一清二楚：那一年 Organon **发了 94.70 亿美元的长期债**，同时"其他融资活动"流出 **90.34 亿**——这 90 亿就是转给默沙东的钱。**换句话说，Organon 是背着 90 亿美元的债务出生的**，而它出生那年的净利润是 13.51 亿。这笔债是理解这家公司此后五年一切行为的唯一钥匙。

现在它做四件事：

### 生意一：卖过期老药（Established Brands），TTM 营收 36.79 亿，占 60.0%

这是营收最大的一块，也是**注定要慢慢死掉**的一块。

具体是什么：默沙东三四十年间开发的、专利已经到期的品牌药。名字都是医生和药剂师耳熟能详的——**顺尔宁**（Singulair，孟鲁司特，治哮喘和过敏性鼻炎的口服片）、**内舒拿**（Nasonex，鼻喷激素）、**益适纯**（Zetia，依折麦布，降胆固醇）和它的复方 Vytorin/Atozet、**安康信**（Arcoxia，依托考昔，止痛消炎）、**福善美**（Fosamax，阿仑膦酸钠，治骨质疏松）、**科素亚**（Cozaar，氯沙坦，降血压）、**保法止/保列治**（Propecia/Proscar，非那雄胺）。

**它怎么还能赚钱？** 专利过期意味着任何一家仿制药厂都能生产同样的分子，价格通常只有原研的十分之一。在美国这些药基本已经卖不动了。但 Organon 的营收大头不在美国——在中国、日本、韩国、巴西、俄罗斯、东南亚。这些市场有一个美国没有的现象：**医生和患者信品牌**。中国的心内科医生开"科素亚"和开"氯沙坦钾片"，患者的接受度不一样；日本的处方习惯更是牢牢绑定原研厂。所以同一个分子，Organon 能比仿制药多卖两三倍的价钱。

举个具体的运作方式：Organon 在中国不自建销售队伍全覆盖，而是把一部分产品交给本地的商业化伙伴，按扣点分成；在日本通过传统的医药经销体系铺进医院。它的核心资产不是分子专利（早没了），而是**注册批文 + 生产质量记录 + 几十年的医生认知**。

**但这块每年都在往下走。** FY2021 40.68 亿 → FY2022 38.74 亿 → FY2023 38.47 亿 → FY2024 38.49 亿 → FY2025 36.91 亿 → TTM 36.79 亿。五年掉了 9.6%。掉的原因是结构性的：中国的带量采购（VBP）把中标品种的价格砍掉 70%–90%，一个品种一进集采，Organon 的定价溢价当场归零。这个过程不会停，只会一个品种一个品种地轮到。

### 生意二：女性健康（Women's Health），TTM 营收 16.35 亿，占 26.7%

**这是 Organon 唯一有护城河的生意，也是整个投资逻辑的支点。**

核心产品是 **Nexplanon（依伴依，依托孕烯植入剂）**，这块里最大的单品，规模在十亿美元级别。它是一根火柴棍大小（4 厘米长、2 毫米粗）的塑料棒，医生用一次性推注器打进上臂内侧皮下，之后持续缓释孕激素避孕。

具体怎么收钱：在美国，一支 Nexplanon 的挂牌价约 1,300–1,400 美元，走的是"buy and bill"模式——诊所先自掏腰包把货买进来，给患者植入之后再向保险公司或者政府项目（Medicaid、Title X 计划生育资助）报销，报销价加上一笔植入操作费。所以 Organon 的直接客户不是患者，是诊所和采购集团。

**它的护城河比"药品专利"更结实，是操作手法：** 植入要在皮下找到正确的层次，取出更麻烦——三年后那根棒子周围长了纤维包膜，取的时候要精确定位、局麻、小切口挑出来，取不干净是真实的临床风险。Organon 免费给医生做培训和认证，一家妇科诊所把整个团队培训到熟练要花几个月。让这家诊所换一个竞品，等于让所有人重学一遍手法，还要重新踩一遍并发症的坑。这种"肌肉记忆型"的转换成本，比一纸专利难攻破得多。

近年 FDA 把它的适用期从 3 年延长到 5 年。这件事对使用者是纯好处（少挨两次操作），对 Organon 则是把双刃剑：单支能提价，但每个用户的更换频次从 3 年一次降到 5 年一次，长期看是**用降低周转换取单价**，净效果不见得是正的。

这块里还有 **NuvaRing**（阴道避孕环，每月放一个）、**Follistim AQ**（试管婴儿促排卵用的注射液，卖给生殖中心，一个促排周期用掉几千美元）、**Jada System**（产后大出血止血装置，一根带真空吸引的管子伸进子宫，靠负压让子宫收缩止血，一次性使用，卖给产科）、以及一系列口服避孕药。

**但整块在下滑：** TTM 16.35 亿 vs FY2025 全年 17.52 亿。这是个警告信号——Organon 的整个多头论点建立在"Nexplanon 撑得住"上，而这块已经开始掉了。

### 生意三：生物类似药（Biosimilars），TTM 营收 7.45 亿，占 12.2%

**唯一在长的一块**：FY2021 4.24 亿 → FY2022 4.81 亿 → FY2023 5.93 亿 → FY2024 6.62 亿 → FY2025 6.91 亿 → TTM **7.45 亿**。五年翻了 76%。

生物类似药是什么：像修美乐（Humira）、赫赛汀（Herceptin）、类克（Remicade）这类由活细胞生产的大分子蛋白药，专利到期后没法像化学药那样简单仿制（蛋白结构复杂到无法做到完全一致），只能做"高度相似"版本，还得做临床试验证明疗效等效。门槛高，所以竞争者少、价格只比原研低 20%–50%，不像化学仿制药那样跌到脚踝。

Organon 的做法很聪明：**它自己不研发也不生产**，而是跟三星生物制剂（Samsung Bioepis）这类专门做生物类似药的公司签商业化协议——对方负责研发、临床、生产，Organon 负责在美欧市场卖，双方分成。它出的是几十年积累的销售渠道和跟大型采购组织（PBM、GPO）打交道的能力。

主要产品：**Hadlima**（修美乐的类似药，治类风湿关节炎和银屑病，一支预充针几千美元，患者一年打 26 针）、**Renflexis**（类克的类似药，医院静脉输注）、**Ontruzant**（赫赛汀的类似药，HER2 阳性乳腺癌）、**Brenzys**（恩利的类似药）。

这块的天花板也很明确：它是分成生意，Organon 拿的是渠道费，不是产品的全部利润，所以毛利率结构性低于自有产品。

### 生意四：其他（皮肤科等），TTM 营收 0.68 亿，占 1.1%

规模上可以忽略，但战略上不能——这里装的是 Organon 用收购买来的新品种（2024 年花了 0.75 亿现金收购、2023 年 1.66 亿）。这是它试图跳出"卖老药"命运的努力。TTM 0.68 亿，比 FY2025 的 0.82 亿还少。**目前这些努力没有产生可见的财务效果。**

## 第二部分：把会计障眼法剥掉

**Organon 的 GAAP 报表被三样东西压垮了：无形资产摊销、连年的"重组"减值、以及一个荒谬的税率。逐项拆开。**

**股权激励（SBC）：** TTM **7,500 万美元**，占净利润 2.09 亿的 **35.9%**。这个比例很高。GAAP 已经把它扣掉了，我不加回——员工拿走的股票是真实的成本，它稀释你的股份。

**回购与稀释——这一项非常难看：**

| 项目 | TTM |
|---|---|
| 股权激励 SBC | 7,500 万 |
| 回购股票 | **900 万** |
| **回购 ÷ SBC** | **0.12** |
| 股本变化（同比） | +1.39% |
| 股本变化（环比一个季度） | **+2.87%** |

**员工每拿走 8 块钱的股票，公司只回购 1 块钱。** 这不是回馈股东，连堵漏都算不上。更值得警惕的是环比：最近一个季度股本增加了 2.87%，如果按这个速度年化就是 12%——**稀释在加速**。

**一次性项目——最大的疑点在这里：**

| 财年 | 资产减值与重组费用 |
|---|---|
| FY2021 | 1.11 亿 |
| FY2022 | 1.16 亿 |
| FY2023 | 0.08 亿 |
| FY2024 | 0.81 亿 |
| FY2025 | **3.16 亿** |
| **TTM** | **3.02 亿** |

**连续两年 3 亿以上，占营收的 4.9%。** 单看 TTM 这一期，我无法判断这到底是"真一次性"还是"年年都要发生的一次性"——但把五年序列摆出来，答案已经很明显了：**这家公司每年都在减值，只是最近两年的规模是历史常态的四倍。** 前三年的平均是 6,800 万，现在是 3.02 亿。

我的处理方式：把 6,800 万当作常态化的经营成本**不加回**，把超出常态的 2.34 亿视为可以剔除的一次性损失，按约 21% 的税率还原，**加回约 1.85 亿**。这个处理在第三部分的"剔除障眼法后的真实市盈率"里用。

**资本化的支出：** TTM **购买无形资产 1.33 亿**（FY2025 1.54 亿、FY2024 1.76 亿、FY2022 2.31 亿）。这是买产品授权、付里程碑款、买注册批文的钱——花出去是真金白银，但不进利润表，而是计入资产，之后慢慢摊销。**每年都要花 1.3–1.8 亿，这实质上是维持营收所必需的开支，不是可选的投资。** 算真实自由现金流时应该把它当成资本开支的一部分。

**荒谬的税率：** TTM 税前利润 4.91 亿，交税 **2.82 亿**，有效税率 **57.43%**。一家跨国药企的正常有效税率应该在 15%–20%（药企普遍把知识产权放在低税率地区）。57% 意味着账上有大量不可抵扣的减值损失，或者某个海外税务安排出了问题。**这一条单独就吃掉了 Organon 超过一半的税前利润。**

**利息在吞噬利润：** 经营利润 12.10 亿，税前利润只剩 4.91 亿，中间蒸发了 **7.19 亿**。按利息保障倍数 2.59 倍倒推，利息费用约 **4.67 亿**（85.53 亿的债务，综合成本约 5.5%）。剩下约 2.52 亿是其他非经营性损失——**这四页财报页拆不开这 2.52 亿的明细**，多半是债务提前偿还的损失和汇兑，我只能标明它存在，不能编出构成。

**利润和现金流的差——这是全篇含金量最高的一张表：**

净利润 2.09 亿，经营现金流 7.37 亿，**相差 5.28 亿，是净利润的 2.5 倍**。逐项对账（单位百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 209 | GAAP 起点 |
| + 折旧摊销 | +354 | **大头是分拆时分配来的无形资产摊销，不花钱** |
| + 资产减值与重组 | +302 | 账面减记，不花钱 |
| + 股权激励 SBC | +75 | 非现金，但真实稀释你 |
| + 其他经营活动 | +22 | |
| − 应收账款增加 | −21 | |
| − 存货增加 | −6 | |
| − 应付账款减少 | −2 | 没有靠拖欠供应商 |
| − 所得税相关变化 | −104 | 补缴以前年度的税 |
| − 其他净经营资产变化 | −11 | |
| （小计） | **818** | |
| 未列示科目（推测为递延所得税） | **−81** | **这四页拆不出来，如实标注** |
| **= 经营现金流** | **737** | |

**结论很清楚：Organon 的 GAAP 利润严重低估了它的现金创造能力。** 7.31 亿的差额里，有 3.54 亿是无形资产摊销（默沙东分拆时把产品线按公允价值记成资产，之后每年摊销，但这些老药的实际维护成本远低于摊销额）、3.02 亿是减值（账面数字游戏）。**这些都不花钱。** 而营运资金变动合计只有 −1.44 亿，占比很小，说明现金流的质量是干净的——没有靠拖账或压库存粉饰。

自由现金流 = 7.37 亿 − 资本开支 1.70 亿 = **5.67 亿**。如果再把那 1.33 亿"购买无形资产"也算成必要开支（我认为应该算），**真实自由现金流约 4.34 亿**。

**最后一件必须看的事：钱到哪去了。**

| TTM 现金去向 | 金额 |
|---|---|
| 分红 | 1,800 万 |
| 回购 | 900 万 |
| **净还债** | **2.86 亿** |
| 资本开支 + 买无形资产 | 3.03 亿 |

**这家公司在 2025 年 5 月把季度股息从 $0.28 砍到 $0.02，砍掉 93%。** 数字在现金流表上一目了然：分红从 FY2024 的 2.97 亿、FY2025 的 0.88 亿，掉到 TTM 的 **0.18 亿**。每股分红从 $1.12 变成 $0.069，股息率从 8% 变成 **0.5%**。省下来的钱全部拿去还债。

净债务从 FY2025 的 82.26 亿降到现在的 **74.21 亿，一年减少 8.05 亿**，相当于市值的 22.4%。**但这里有一个必须说破的细节**：这 8.05 亿里，只有 2.47 亿是总债务的真实下降（88.00 亿 → 85.53 亿），另外 5.58 亿是账上现金变多了（5.74 亿 → 11.32 亿）。而现金变多的主因是 TTM 的**投资活动净流入 1.30 亿**（往年都是净流出 3–5 亿）——资本开支 1.70 亿加买无形资产 1.33 亿本该是 3.03 亿的流出，却录得 1.30 亿的流入，**中间约 4.33 亿的流入项这四页没有列示**，最可能是卖掉了某条产品线或某项资产。**这意味着"一年去杠杆 8 亿"这个故事，有一半是卖资产换来的，不是经营赚来的。**

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 35.92 亿 ÷ 2.09 亿 | 17.2 倍 | $5.82 |
| 公司自己吹的 Non-GAAP | 这四页不披露 | — | — |
| **剔除障眼法后的真实市盈率** | 35.92 亿 ÷ 3.94 亿（净利润 2.09 亿 + 超额减值税后 1.85 亿） | **9.1 倍** | **$10.97** |
| 自由现金流口径 P/FCF | 35.92 亿 ÷ 5.67 亿 | 6.3 倍 | $15.77 |
| 严格自由现金流（再扣买无形资产） | 35.92 亿 ÷ 4.34 亿 | 8.3 倍 | $12.08 |
| **企业价值口径 EV/EBIT** | 110.10 亿 ÷ 12.10 亿 | **9.1 倍** | $10.99 |
| 企业价值 / 自由现金流 EV/FCF | 110.10 亿 ÷ 5.67 亿 | 19.4 倍 | $5.15 |
| **三年平均利润口径** | 35.92 亿 ÷ 4.20 亿（TTM 2.09 + FY25 1.87 + FY24 8.64 的均值） | **8.6 倍** | **$11.69** |

（企业价值 110.10 亿 = 市值 35.92 亿 + 净负债 74.21 亿。EV/EBITDA 7.04 倍。）

### 这张表里最重要的两件事

**第一，三年平均口径 8.6 倍比当期 17.2 倍便宜一半——方向和绝大多数公司相反。** 通常"三年平均"这一行是用来揭穿"当期利润处在高点"的，NVDA 那次当期 34 倍、三年平均 73.5 倍，差一倍多。Organon 反过来：**当期利润是被压到谷底的**（FY2024 还有 8.64 亿净利润，现在只剩 2.09 亿），压它的是减值、是 57% 的税率、是分拆遗留的无形资产摊销——三样都是账面项目，都不花钱。所以这一次，"当期市盈率高"不代表贵。

**第二，市值只有 35.92 亿，企业价值却是 110.10 亿。** 这是全篇必须记住的一句话：**你买的是一家 110 亿的公司，其中 67% 属于债主，你只占 33%。** 因此所有以"市值"为分母的比率都会显得很便宜（P/FCF 6.3 倍！），而所有以"企业价值"为分母的比率才是真相（EV/FCF 19.4 倍）。这两个数字差三倍，就是杠杆在放大。

### 说人话：你投 100 块进去，一年拿回多少

**按最保守的真实口径（三年平均利润 8.6 倍 / EV/EBIT 9.1 倍），公司一年替你赚约 11 元。**

这 11 元的去向，是这只股票最反直觉的地方：

- **只有 0.5 元以分红的形式打到你账上**（股息率 0.5%，砍完之后基本等于没有）。
- **只有 0.25 元用于回购**（TTM 900 万，相对 35.92 亿市值是 0.25%），而且被 7,500 万的股权激励反向吞掉，**你的股份数实际上还在变多**。
- **剩下约 10 元，全部拿去还债和维持产品线。**

**还债对股东有没有价值？有，而且很大。** 一家企业价值 110 亿的公司，如果每年从债主手里赎回 8 亿的权益，理论上这 8 亿全部转移到剩下那 35.92 亿市值的股东身上——相当于每年 22% 的隐含回报。这正是这只股票过去 52 周涨了 44.92% 的全部原因。

**但要打两个折扣。** 一是上面说破的：这 8 亿里有一半是卖资产换来的，不是经营赚来的，卖资产是一次性的、不可持续的。二是营收在萎缩——TTM 营收同比 −2.45%，三条主力产品线里两条在跌。**债在减少的同时，还债的能力也在减少。** 分母和分子在赛跑。

**这个 11 元未来会变大还是变小？** 中期会变大：无形资产摊销会随着时间递减（分拆记的那批资产在按年摊完），57% 的税率是异常值不会长期维持，利息负担随债务下降而下降。这也是市场给出 **3.83 倍远期市盈率**（对应约 9.4 亿的预期净利润，是 TTM 的 4.5 倍）的原因。长期会变小：老药一个品种一个品种地进集采、Nexplanon 已经开始下滑、生物类似药只是分成生意撑不起大局。

---

## 第四部分：一句话结论

**便宜是真的便宜，但便宜的名字叫 74 亿净债。**

把账算清楚：EV/EBIT 9.1 倍、EV/EBITDA 7.0 倍、三年平均市盈率 8.6 倍、真实自由现金流 4.34 亿对 35.92 亿市值。这些数字放在任何一家制药公司身上都算便宜。17.2 倍的 GAAP 市盈率是假象——它是被 3.54 亿不花钱的无形资产摊销、3.02 亿账面减值和一个 57% 的荒谬税率一起压出来的。

但你必须清楚自己在买什么：

**你买的不是一家制药公司，你买的是一份高杠杆的去杠杆赌注。** 市值 35.92 亿是站在 74.21 亿净债之上的那一层薄薄的权益。债务是 EBITDA 的 5.23 倍、是自由现金流的 15.08 倍，利息保障倍数只有 2.59 倍——这个杠杆水平在利率下行时是印钞机，在经营稍有闪失时是绞索。管理层已经用行动承认了这一点：2025 年 5 月砍掉 93% 的股息，把股东的钱全部转去还债，股价当天崩了近三成。

三个具体的风险，按严重程度排：

1. **60% 的营收来自年年萎缩的老药。** 中国带量采购这个绞肉机每年吃掉几个品种，这个过程不可逆、不可谈判。
2. **唯一的护城河 Nexplanon 已经开始下滑**（女性健康 TTM 16.35 亿 vs FY2025 17.52 亿）。整个多头论点建立在这一条产品线上，它一垮，"去杠杆"就变成"还不起"。
3. **回购 ÷ SBC = 0.12，最近一个季度股本还增加了 2.87%。** 在还债的同时你还在被稀释。

我的判断：**这是个统计上便宜、商业上可疑的标的，属于"雪茄烟蒂"那一类**——还能免费吸一口，但你得盯着它什么时候烧到手。股价过去一年已经涨了 44.92%，最容易赚的那段（市场意识到它不会破产）已经过去了。真正想赚剩下这段，你需要相信 Nexplanon 撑得住，而 TTM 的数字正在说它撑不太住。

如果你是冲着 8% 的股息来的，那个 Organon 已经在 2025 年 5 月死了。
