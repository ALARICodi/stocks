# CDE · Coeur Mining（科尔黛伦矿业）

市值 193.4 亿美元 / 股价约 18.78 美元 / 行业：非能源矿产（金银开采）/ 数据口径：TTM 截止 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

**Coeur 只做一件事：从北美六座露天/地下矿里把含金银的石头挖出来，磨碎，用化学方法把金和银提出来，铸成金锭银锭，卖给精炼厂。** 卖价它一分钱说了不算——伦敦金银市场每天报什么价，它就收什么价。

所以严格讲这不是"几门生意"，而是**六个成本结构完全不同的采矿现场，共用一个不受它控制的售价**。这六个现场值得一个个讲清楚，因为它们之间的差别，决定了金价跌下来的时候谁先死。

### 关键背景：2026 年 3 月，这家公司变了一半

2026 年 3 月，Coeur 完成了对加拿大 New Gold 公司的**全股票收购**——不花现金，直接印新股换。按 1 股 New Gold 换 0.4959 股 Coeur 的比例，**新发行了约 3.93 亿股，公司总股本从约 6.4 亿股膨胀到 10.34 亿股，一年内增加 53%。** 换来的是加拿大安大略的 Rainy River 金矿和不列颠哥伦比亚的 New Afton 金铜矿，公司自己说这让年黄金产量提高约 80%。

**这件事对下面所有的财务数字都是决定性的**——TTM 这四个季度里，只有最后约 4 个月带着 New Gold，但股本已经全额稀释完了。这是本篇最大的会计陷阱，第二部分会算给你看。

### 六个矿，六种生意

**1. Las Chispas（墨西哥索诺拉州，高品位银金矿）— TTM 营收 6.41 亿**

这是 Coeur 2025 年 2 月吞掉 SilverCrest 拿到的资产，也是它现在最赚钱的一块。它是**地下坑道开采的高品位矿脉**——矿石里每吨含银 400 克以上，而行业里 100 克/吨就算不错了。品位高意味着同样挖一吨石头，出的银多好几倍，单位成本极低。这座矿基本上是全公司的现金奶牛。

**2. Palmarejo（墨西哥奇瓦瓦州，银金矿）— TTM 营收 6.12 亿**

Coeur 的老资产，地下+露天混合。这座矿有一个特殊安排：**它的一部分黄金产量被"卖断"给了 Franco-Nevada（一家特许权公司）**——当年 Coeur 缺钱建矿，Franco-Nevada 先付一笔钱，条件是以后每产一盎司金，Franco-Nevada 有权按远低于市价的固定价格（大约 800 美元/盎司）买走一部分。**所以 Palmarejo 的黄金，有一块是永远吃不到金价上涨红利的。** 这是典型的"当年缺钱时卖掉的未来"。

**3. Rochester（美国内华达州，露天堆浸银金矿）— TTM 营收 6.03 亿**

这是最能体现采矿业本质的一座矿。**堆浸**的意思是：把矿石爆破挖出来，粗碎后堆成一个几十米高的大堆，从顶上不停喷氰化钠溶液，溶液渗下去把金银溶解带走，在底部收集起来再提纯。这种方式适合品位极低的矿石（每吨含银十几克就能做），成本低，但周期长——喷淋一堆矿要一两年才能把金属提完。

Coeur 从 2020 年起在 Rochester 砸了 7 亿多美元做扩产（业内叫 POA 11），2024 年才完全达产。**这也是为什么 2022–2024 年这家公司连年亏损——钱全砸进 Rochester 了。** 现在这笔投资终于开始回本，Rochester 营收从 FY2024 的 2.16 亿涨到 TTM 的 6.03 亿。

**4. Kensington（美国阿拉斯加，地下金矿）— TTM 营收 4.19 亿**

阿拉斯加朱诺附近的地下金矿，只能坐船和飞机进出，成本高、天气影响大。这是 Coeur 成本最高的矿之一，历史上多次被市场认为该关掉。**金价高的时候它是印钞机，金价一跌它第一个变成负担。**

**5. Wharf（美国南达科他州，露天堆浸金矿）— TTM 营收 3.24 亿**

小而稳的老矿，堆浸，成本低，运营了几十年。这是六个矿里唯一 TTM 营收比上一财年**下滑**的（−4.3%），说明矿体在贫化——好挖的部分挖完了。

**6. New Gold 资产包（Rainy River + New Afton，加拿大）— TTM 营收约 5.72 亿（倒算）**

**注意：财报的分部表还没有更新，只列了前五座矿，加起来 25.99 亿，而总营收是 31.71 亿，差额 5.72 亿就是 New Gold 并入后约 4 个月的贡献。这个数是我倒算出来的，不是财报直接披露的。**

- **Rainy River**（安大略）：大型露天+地下金矿，规模大但品位一般，成本处在行业中位。
- **New Afton**（不列颠哥伦比亚）：金铜矿，用**块崩落法**开采——在矿体底下掏空，让上面的矿石靠自重塌下来，是全世界成本最低的地下采矿方式之一。而且它产铜，这给 Coeur 带来了第一块非贵金属收入，等于多了一个不同步的价格敞口。

对比列为 FY2025 全年（分部数据只有年度和 TTM 两栏）。

**财报只披露到分部营收，不披露分部利润。** 全公司经营利润率 35.19%，毛利率 56.64%。按常识，Las Chispas 和 New Afton 的利润率明显高于全公司平均，Kensington 明显低于平均——但**这是基于开采方式和品位的估算，不是财报数字**，不采信任何具体百分比。

### 这 117% 的营收增长，有多少是"价"、多少是"量"？

这是全篇最值得算的一笔账。**用两座既没扩产、也不涉及并购的矿做对照组：**

- **Palmarejo**：FY2024 营收 3.79 亿 → TTM 6.12 亿，**+61%**。这座矿的产能这一年半没有实质变化。
- **Kensington**：FY2024 营收 2.25 亿 → TTM 4.19 亿，**+86%**。同样没有扩产项目。

**这两个数字里几乎没有"量"，全是"价"。** 也就是说，过去一年半金银价格的涨幅，大致就在 60%–85% 这个量级。

**结论很清楚：Coeur 这一轮从连年亏损变成年赚 8.5 亿，主要不是因为它经营得更好了，而是因为金银价格涨了一大截**（Rochester 扩产达产和两笔并购是次要贡献）。这个判断会直接决定第三部分里"三年平均口径"那一行的分量。

## 第二部分：把会计障眼法剥掉

### ⚠️ 最大的障眼法：网站上那个 16.9 倍市盈率是假的

各大财经网站显示 Coeur 的滚动市盈率是 **16.89 倍**。算法是：股价 18.78 ÷ TTM 每股收益 1.11 = 16.9。

**问题出在分母的"每股"上。** 每股收益用的是这四个季度的**加权平均股本**——因为 3.93 亿新股是 2026 年 3 月才发的，加权下来只算了约 **7.66 亿股**（850.41 ÷ 1.11 = 766）。但**今天你买这只股票，面对的是 10.34 亿股的全额稀释股本。**

用市值直接除净利润，才是你真正付的价：

**193.4 亿市值 ÷ 8.504 亿净利润 = 22.7 倍**，不是 16.9 倍。

**这两个数字差了 35%，而它不是任何人在造假——它是股本在期中大幅膨胀时，"每股收益"这个指标的结构性失真。** 凡是刚做完大额换股并购的公司，滚动市盈率都会系统性偏低，看到就要警惕。

公平地说，这个失真是双向的：TTM 净利润里也只含了 4 个月的 New Gold 利润。等 New Gold 满 12 个月并表，分母会变大，市盈率会掉下来——市场给的 **10.93 倍前瞻市盈率**就是在算这笔账。所以真实答案在 22.7 和 10.9 之间，而这个区间**完全取决于金价能不能守住**。

### 股权激励（SBC）

TTM 2,773 万美元，占净利润 **3.3%**。矿业公司不需要用股票抢人，这个比例很健康。按规矩当真实成本扣掉，GAAP 已扣，不加回。

### 一次性项目

TTM 这一期非常干净：资产减值 0、资产出售损益 0、重组费用 0。前几年（FY2023 减值 4,025 万、FY2022 资产出售收益 6,225 万）都有，本期没有。

但有一项要点名：**"其他经营活动" TTM 是 +1.128 亿美元，而 FY2025 是 −1.043 亿，FY2024 是 −5,780 万。** 一个平时是负数、金额几千万的科目，突然变成正的一个多亿，方向和量级都反转了。这大概率与 New Gold 并购的收购会计处理有关（比如存货公允价值重估的转回）。**单期口径无法判断这是不是年年都会发生的项目，也无法拆出它对利润的具体影响——这里明确标注为不确定项。** 它占经营现金流的 7.7%，不算小。

### 税

TTM 所得税 2.11 亿，有效税率 **19.87%**。矿业公司在墨西哥还要交特别采矿权使用费。这个税率正常，**没有障眼法**。

### 资本化的支出：这里有真问题

**TTM 资本开支只有 3.10 亿美元，占营收 9.8%。** 对比一下历史：

| | 资本开支 | 占营收 |
|---|---|---|
| FY2022 | 3.52 亿 | 44.8% |
| FY2023 | 3.65 亿 | 44.4% |
| FY2024 | 1.83 亿 | 17.4% |
| FY2025 | 2.21 亿 | 10.7% |
| **TTM** | **3.10 亿** | **9.8%** |

**采矿业和别的行业有一个根本不同：矿是消耗品。** 你今年挖走的每一吨矿石，就是永远少掉的一吨。要维持产量，必须持续花钱勘探、开新采区、剥离表土。Coeur 现在的资本开支占营收比例掉到了历史最低——**这不是效率提升，一部分是 Rochester 那个大工程建完了（正常），一部分是把维持性投入往后推（不正常）。**

**当期漂亮的 11.56 亿自由现金流里，有一块是"欠矿的债"。** 这笔钱迟早要还，要么是未来资本开支跳升，要么是产量下滑。财报页上看不出具体欠了多少，但从 Wharf 营收已经开始下滑这个信号看，矿体贫化是真实存在的。

### 回购与稀释：这个比值在这里会骗人

- TTM 回购金额：**1.648 亿美元**
- TTM 股权激励：**2,773 万美元**
- **回购 ÷ SBC = 5.94 倍**

按常规判断标准（大于 3 才算真回购），5.94 是个很漂亮的数字，说明这不是在给员工发股票擦屁股，是真金白银在回购。

**但把它放在股本变化旁边，这个漂亮就没了：股本一年增加 53.29%。**

Coeur 一边花 1.65 亿回购股票，一边为了买 New Gold 印了 3.93 亿股（按当时股价算价值几十亿美元）。**回购的规模，相对于并购稀释的规模，是零头的零头。** 你作为老股东，手里的股份被稀释了三分之一还多，公司花的那 1.65 亿连塞牙缝都不够。

这不是说这笔并购不该做——用高估的股票去换真实的矿产资源，如果换得便宜，是聪明的资本运作。**但"回购/SBC = 5.94"这个指标在这里完全失效，不能拿它说"公司在回馈股东"。**

现金流量表上**没有支付普通股股利这一行，TTM 分红为 0**（统计页列了一个 2026 年 5 月 22 日的除息日，但现金流量表上找不到对应的付款，单期口径无法确认，按 0 处理）。

### 利润和现金流的差：逐项对账

| 项目 | 金额（百万美元） |
|---|---|
| 净利润 | 850.41 |
| + 折旧摊销 | 523.39 |
| + 股权激励 | 27.73 |
| + 其他经营活动（性质不明，见上） | 112.81 |
| + 应收账款减少 | 7.29 |
| − 存货增加 | −80.59 |
| + 应付账款增加 | 60.56 |
| − 其他净经营资产变化 | −35.23 |
| **= 经营现金流** | **1,466** |
| − 资本开支 | −310.14 |
| **= 自由现金流** | **1,156** |

**这张表最值得看的一行是折旧摊销 5.23 亿——占净利润的 62%。** 采矿业的折旧不是电脑折旧那种"东西会旧"，而是**耗竭摊销**：你花 7 亿建的 Rochester，按预计能挖出的总矿量分摊，每挖走一吨就摊掉一点。

**所以对矿业公司，"经营现金流远高于净利润"绝不能理解为"利润被低估了"。** 那 5.23 亿的耗竭摊销对应的是**真实消失的矿产资源**——它不是纸面数字，它是这家公司在把自己的存货（地下的矿）卖掉。这也是为什么资本开支砍到 9.8% 是个危险信号：矿在减少，而补矿的钱没在花。

资产负债表倒是干净得让人放心：**现金 10.52 亿，总债务 7.13 亿，净现金 +3.39 亿**，从一年前的净负债 5.61 亿翻了过来。债务/EBITDA 只有 0.43 倍，利息保障 37.6 倍。**这家公司现在没有任何财务风险。**

### 大白话说清楚

**你现在投 100 块进 Coeur，按当期真实口径（市值 ÷ 全额稀释后的 TTM 净利润）算，公司一年替你赚 4.40 块。**

这 4.40 块里，**一分钱都不会以分红的形式回到你口袋**——TTM 没有分红。回购花了 1.65 亿，摊到 193 亿市值上是 0.85%，而同期股本增加了 53%，所以**净回到股东手里的现金是负的**。全部利润都留在公司里：还债（净还了 0.96 亿）、堆现金（现金从 5.54 亿涨到 10.52 亿）、买矿（New Gold 是换股，没花现金，还倒带进来 1.18 亿现金）。

**现在看那一行最关键的数字：三年平均利润口径 38.8 倍。**

这个表里，当期口径 22.7 倍和三年平均口径 38.8 倍差了 **71%**。原因很直白：

| | 净利润 |
|---|---|
| FY2023 | **−1.04 亿（亏损）** |
| FY2024 | +0.59 亿 |
| FY2025 | +5.86 亿 |
| TTM | +8.50 亿 |

**三年前这家公司还在亏钱。** 而第一部分已经用 Palmarejo（+61%）和 Kensington（+86%）这两座没扩产的矿证明了：这轮利润爆发的主因是**金银价格**，不是经营改善。

**所以 22.7 倍这个数字，是建立在"金价永远停在历史高位"这个假设上的。** 如果金银价格回到两年前的水平，Coeur 的营收会掉三成以上，而它的成本（人工、柴油、氰化钠、折旧）基本不会跟着掉——利润会以数倍于营收的速度蒸发，重新回到微利甚至亏损。**这就是采矿业的经营杠杆：赚钱时惊人，亏钱时也惊人。**

**这个 4.40 块未来是变大还是变小，取决于一件你我都控制不了的事：金银铜的价格。** 除此之外，有三个可控因素：

1. **New Gold 满 12 个月并表**，会实打实地把利润推上去（这是前瞻 10.9 倍的主要依据），这一块是确定的。
2. **Rochester 达产后的现金回收**，也是确定的正向贡献。
3. **矿体贫化和被压低的资本开支**，是确定的负向拖累，只是时间点不确定。

还有一个必须点出的数字：**ROIC 8.76%，而 WACC 是 11.34%。** 在金价创历史新高、公司净利润率高达 26.8% 的情况下，它的投资回报率**仍然低于它的资金成本**。这不是暂时的——这就是采矿业的长期真相：**它是一个持续毁灭资本的行业，只在价格周期顶部的少数几年看起来很赚钱。**

## 第四部分：一句话结论

**Coeur Mining 不是一门生意，是一张有杠杆的金银价格看涨期权，而你现在为它付的价格，反映的是金价永远不跌。**

财务状况确实脱胎换骨了：从三年前亏钱、背 5.6 亿净债，变成现在年赚 8.5 亿、手握 3.4 亿净现金、11.6 亿自由现金流。这是真的。New Gold 的加入让它从一家中型银矿公司变成北美一线金矿商，规模效应也是真的。

但三个数字把故事讲完了：**市场看到的 16.9 倍是股本膨胀造成的失真，真实是 22.7 倍；三年平均口径是 38.8 倍；ROIC 8.76% 低于 WACC 11.34%。** 翻译成人话就是——**在这一轮金价的绝对高点上，用最有利的当期口径算，它也只值 22.7 倍；而它长期是个不赚钱的行业。**

买它的唯一理由是：你认为金银价格还要继续往上走，而且你明确知道自己在做的是价格投机，不是在买一门好生意。**如果你是冲着"矿业公司现在赚大钱了"去的，你买的是后视镜。**
