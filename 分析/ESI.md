# ESI · 元素解决方案（Element Solutions Inc）

市值 $88.7 亿 ｜ 股价 $36.41（2026-08-19 盘中）｜ 企业价值 $108.0 亿 ｜ 行业：特种化学品（电子材料）｜ TTM 截止 **2026-06-30**

---

## 第一部分：它到底做几件事

这家公司名字听着像咨询公司，其实是**卖化学品的**——而且是那种一瓶几百美元、你一辈子不会见到、但你手上每一部手机里都有的化学品。它 1785 年就有了前身（MacDermid），2019 年才改成现在这个名字。

财报上报两个大段（MacDermid Alpha 电子解决方案、Element 特种品），底下拆成五门具体生意。按 TTM 营收从大到小：

### 生意一：焊膏和封装材料（Assembly Solutions）—— 全公司最大的一门，也是最容易被误读的一门

**这是什么**：你打开任何一块电路板，上面那些芯片、电阻、电容是怎么固定在板子上的？靠焊锡。工厂的做法是先用钢网把一层灰色的膏体（焊膏）刮到电路板的焊盘上，再把元件贴上去，整块板送进回流焊炉，膏体一熔化就把元件焊死了。这个灰色膏体就是 ESI 卖的东西——锡粉 + 助焊剂调成的浆。

**怎么收钱**：按公斤卖，一桶 500 克装的焊膏大概 30–80 美元，高端的（低温焊膏、给汽车电子用的高可靠性焊膏）能到几百美元一公斤。一家像富士康那样的代工厂，一条 SMT 产线一天能刷掉几十公斤焊膏，一个大厂一年买几千万美元很正常。

**客户为什么非买不可**：因为**换供应商要重新做认证**。焊膏的配方直接决定焊点会不会有空洞、会不会在汽车引擎盖底下震三年后开裂。一家做车规电子的厂子，把某个牌号的焊膏塞进产线，要跑几个月的可靠性测试（热循环、盐雾、振动），拿到 IATF 16949 的过程认证。为了每公斤省 5 美元去换供应商，赌的是整批车召回。所以一旦进去，黏性极强。

**同时也做导热材料**：CPU 和散热片之间那层灰色的膏、功率半导体底下的银烧结材料——AI 服务器功耗越高，这块越值钱，这是 ESI 现在最想让市场看到的故事。

**⚠️ 这门生意的营收有一半是"过路钱"**：焊膏里 90% 的重量是锡。锡价涨，ESI 的售价就照抬，营收跟着涨，但**赚的钱一分没多**——锡是按市价转嫁给客户的。TTM 这门生意营收从 907 涨到 1,187（+31%），**其中相当一部分就是锡价和收购带进来的，不是它多卖了多少膏**。看营收增速会被骗，这一点后面还要提。

### 生意二：电路板金属化（Circuitry Solutions）

**这是什么**：一块多层电路板，层与层之间要用一个个小孔（过孔）导通。孔是钻出来的，孔壁是绝缘的环氧树脂，怎么让它导电？把板子泡进一缸化学药水里，让铜从溶液里析出来、均匀镀满孔壁——这缸药水就是 ESI 卖的。还有板子最外层那圈金色的镀层（沉金/OSP），防止铜氧化。

**怎么收钱**：卖化学药剂 + 卖"缸子的管理服务"。典型模式是 ESI 派工程师常驻客户工厂，负责监控药水浓度、定期补加、处理镀层不良的工艺问题，客户按消耗量付费。一个中型 PCB 厂一年花几百万美元，一个大厂（比如给英伟达做 AI 加速卡基板的那几家）能花上千万。

**为什么黏**：镀液是活的化学系统，浓度、温度、电流密度全部要调，换一家供应商等于把整条产线的良率重新赌一遍。AI 服务器用的高层数板（20 层以上）对孔壁镀铜的均匀性要求极高，能做的供应商全球就那么几家。TTM 576.5，+9.2%。

### 生意三：半导体封装材料（Semiconductor Solutions）

**这是什么**：芯片从晶圆上切下来之后要"封装"——把它接到能焊到电路板上的引脚上。现在先进封装（把好几颗芯片叠在一起、用微凸块连接）用的电镀液、光刻胶剥离液、晶圆级封装材料，就是这块。**HBM 内存堆叠、CoWoS 这些 AI 芯片的封装工艺都要用**。

**怎么收钱**：卖到台积电、日月光、安靠这类封装厂，也直接卖给存储厂。单价比前两门高，量小。TTM 396.6，+12.9%——**这是全公司最有价值的一门，但它只占 12.6%**。

### 生意四：工业镀层（Industrial Solutions）—— 老本行，也是拖后腿的那门

**这是什么**：给金属零件镀一层保护膜。最典型的是**化学镀镍**：一个汽车刹车卡钳、一根液压杆，泡进药水里就自动镀上一层均匀的镍磷合金，不用通电、不管形状多复杂角落都镀得到，防锈耐磨。汽车厂、建筑五金、航空零件都用。

**怎么收钱**：论桶卖药水，一桶几百到上千美元，配套卖前处理清洗剂。客户是汽车零部件厂、五金厂。

**问题**：这门生意跟全球汽车产量和工业开工率绑死，五年前 599.7，现在 668.4，**五年只涨了 11%**，基本原地踏步。TTM 同比 +2.6%，就是通胀而已。

### 生意五：海上钻井液（Energy Solutions）—— 94.1，占 3%，可以忽略

给海上油气钻井用的完井液（一种高密度盐水，用来压住井底压力）。TTM 94.1，+5.3%。规模太小，不影响判断。

2. **227.4M 对不上。** 五门生意加起来 2,922.6，总营收 3,150，差 227.4M（占 7.2%）。FY2025 是能对上的（2,551.2 vs 2,551）。这 227.4M 极可能是 TTM 期内那笔 **8.66 亿美元现金收购**买回来的业务，还没归进现有分部。财报页没写标的名字，我不编。
3. **焊膏那 +30.9% 含金量存疑**——锡价上涨的转嫁 + 收购并表，两样都不代表它多卖了货。

## 第二部分：把会计障眼法剥掉

### 股权激励（SBC）：一年之内翻了 4.6 倍，这是最刺眼的一项

| | TTM | FY2025 | FY2024 | FY2023 |
|---|---|---|---|---|
| SBC | **68.5** | 59.1 | 14.8 | 9.4 |
| 占净利润 | **38.4%** | 31.0% | 6.1% | 8.0% |

FY2024 还只有 1,480 万，TTM 变成 6,850 万——**两年涨了 6.3 倍，而同期净利润是往下走的**。这不是"业务扩张带来的正常增长"，这是管理层给自己和员工发股票的力度突然加大。

**我一律把它当真金白银的成本扣掉**，因为它确实稀释你的股份。GAAP 里已经扣了（净利润 178.6 是扣完的），所以下面第三部分的"真实市盈率"里我不会把它加回来。ESI 自己报的调整后利润是加回去的——那是骗人的。

### 一次性项目

- TTM 有一笔 **资产处置损失 7.6M**（FY2025 是 +59M 的收益，来自卖掉 Graphics 制版业务，那笔 3.212 亿的处置款也在 FY2025 的投资现金流里）。金额不大。
- **单期口径无法判断"收购相关费用"这一项是不是年年发生**——但从历史看，ESI 是个连环收购者（FY2021 花 5.365 亿、FY2023 花 2.148 亿、TTM 花 8.658 亿），**所谓"一次性的并购费用"对这家公司来说基本是每年都有的固定开销**，不该当一次性剔除。
- **收购形成的无形资产摊销我也不加回。** ESI 的折旧摊销 163M 里有相当一部分是历年收购留下的客户关系、技术摊销。华尔街习惯把它加回去算"调整后利润"，理由是"非现金"。对一家刚又花 8.66 亿买公司的连环收购者来说，这个理由不成立——**买公司的钱是真花出去的现金，只是记账时被摊到了后面几年**。加回去等于假装收购不花钱。

### 资本化的支出

没有。ESI 不资本化软件或内容，研发费用化。资本开支 86.5M，占营收 2.7%，是典型的化学品行业水平（建反应釜、扩产线）。

### 回购与稀释：**这一项直接判死刑**

| | TTM |
|---|---|
| 回购金额 | **5.6** |
| SBC | **68.5** |
| 回购 ÷ SBC | **0.08** |
| 股本变化（同比） | **+0.14%（不减反增）** |

**回购只相当于 SBC 的 8%。** 也就是说：公司一年发给员工 6,850 万美元的股票，只花 560 万买回来一点点，剩下 6,290 万的稀释**全部由你这个股东承担**。股本还净增加了 0.14%。

这个比值大于 3 才叫真回购，接近 1 叫"原地踏步"，0.08 叫**"员工在分你的公司，你连意思一下的对冲都没有"**。同期公司却花了 7,850 万分红——**分红 78.5M vs 回购 5.6M**，一个正常的资本配置不该长这样：分红是要交税的现金流出，回购是免税的每股价值提升，在股价没有明显高估时优先回购才对。当然，也可能管理层自己知道 50 倍市盈率买不下手。

### 利润和现金流的差：**这是全篇最重要的一张表**

净利润 178.6，经营现金流只有 224.2，自由现金流跌到 **137.7**（上一年 295.2，**腰斩**）。钱去哪了：

| 项目 | 金额 | 说明 |
|---|---|---|
| GAAP 净利润 | **178.6** | 起点 |
| ＋ 折旧摊销 | +163.0 | 不花钱的账面费用，加回 |
| ＋ 股权激励 SBC | +68.5 | 发股票不花现金，加回（但它稀释你） |
| ＋ 资产处置损失 | +7.6 | 一次性 |
| ＋ 其他经营调整 | +17.8 | |
| **－ 应收账款增加** | **-131.5** | **货发出去了，钱还没收回来** |
| **－ 存货增加** | **-102.3** | **原材料和成品压在仓库里** |
| ＋ 应付账款增加 | +27.3 | 欠供应商的钱多了，等于占用别人资金 |
| － 其他经营资产变化 | -4.8 | |
| **= 经营现金流** | **224.2** | |
| － 资本开支 | -86.5 | 建产线 |
| **= 自由现金流** | **137.7** | |

**看那两行加粗的：应收 -131.5、存货 -102.3，两项合计 2.34 亿美元被营运资金吸走了。** 这跟前面说的锡价是同一件事的两面——锡贵了，同样多的焊膏要占更多的存货金额，卖出去后应收账款金额也更大。**营收账面上涨 26.6% 看着热闹，实际是把 2.34 亿现金押进了库存和账期里。**

结果：自由现金流利润率从 12.02%（FY2024）掉到 **4.37%**。这是一家把"增长"做成了"占用现金"的公司。

分红 78.5M ÷ FCF 137.7M = **57%**。还盖得住，但空间不大了；如果 FCF 再掉一截，分红就要靠借钱。

### 债务

净负债从 FY2025 的 10.96 亿涨到 **19.27 亿**——那笔 8.66 亿的收购基本是借钱买的（TTM 新发债 4.994 亿 + 烧掉 4.33 亿现金）。净负债/EBITDA 从 2.22 跳到 **3.42**，Debt/EBITDA 3.76。利息保障倍数 5.59，还没到危险区，但**杠杆在明显加码，而收购的回报还没兑现**。

## 第三部分：市盈率，多口径

市值 8,872M，企业价值 10,798M（含净负债 1,927M）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| **GAAP TTM 市盈率** | 8,872 ÷ 178.6 | **49.7 倍** | **$2.01** |
| 公司自己吹的 Non-GAAP（**估算**） | 加回无形摊销 + 一次性，约 292M | ~30.4 倍 | ~$3.29 |
| **剔除障眼法后的真实市盈率** | 8,872 ÷（178.6 + 7.6×0.647 = 183.5）<br>SBC 已按 GAAP 扣除，不加回；摊销不加回 | **48.3 倍** | **$2.07** |
| 自由现金流口径 | 8,872 ÷ 137.7 | **64.4 倍** | **$1.55** |
| 自由现金流（用 FY2025 的正常年份 227.6） | 8,872 ÷ 227.6 | 39.0 倍 | $2.56 |
| 企业价值口径 EV/EBIT | 10,798 ÷ 401 | **26.9 倍** | $3.72（对应全部投入资本） |
| **三年平均利润口径** | 8,872 ÷ [(178.6+190.8+244.2)/3 = 204.5] | **43.4 倍** | **$2.30** |

（Non-GAAP 那一行标了估算：ESI 只公布调整后 EBITDA 和调整后 EPS，财报页拿不到精确的调整后净利润，我按"加回约 1.1 亿无形资产摊销 + 一次性项目、按正常税率还原"倒推，**别当精确数字用**。有效税率 TTM 高达 35.29%，本身也偏高。）

### 说人话

**你现在投 100 块进去，按最保守的真实口径（剔除障眼法后的 48.3 倍）算，公司一年替你赚 2 块 7 毛……不对，是 2 块 0 毛 7。** 用自由现金流算更惨，只有 1 块 5。

这 2 块钱里，有多少真回到你口袋？

- **分红**：股息率 0.86%，也就是每 100 块给你 **8 毛 6**。
- **回购**：TTM 回购 560 万，占市值 0.06%，股本还净增加了 0.14%——**回购贡献是负的，倒扣你 1 毛 4**。
- **留在公司里再投资**：剩下的一块多，加上新借的 5 亿债，全砸进了那笔 8.66 亿的收购。

也就是说，**你拿到手的现金回报大约每 100 块 7 毛 2（8 毛 6 分红减掉 1 毛 4 稀释）**，剩下的钱管理层拿去买别的公司了。这笔买卖划不划算，取决于你信不信管理层的收购眼光。

**看看历史成绩单**：ESI 的投入资本回报率（ROIC）五年分别是 6.45%、5.43%、5.97%、7.33%、6.37%，TTM **5.47%**。而它的加权平均资本成本（WACC）是 **9.52%**。

**这是全篇最要命的一个数字对比：这家公司每投一块钱进去，赚回来 5.5 分，而这一块钱本身的成本是 9.5 分。它每做一笔收购、每扩一条产线，都在毁灭价值。** 连续五年，一年没例外。

**这个 X 未来会变大还是变小？**

变大的理由：半导体封装那门生意（占 12.6%）确实踩在 AI 先进封装的风口上，导热材料也是；新收购的业务如果整合顺利，227M 营收会转化成利润；forward PE 19.35 说明卖方普遍预期未来 12 个月利润要翻一倍多。

变小的理由：占 37.7% 的焊膏生意的增长有相当部分是锡价转嫁，锡价一回落营收就掉；占 21.2% 的工业镀层五年没长；SBC 两年涨 6.3 倍还在往上走；杠杆刚从 2.2 倍加到 3.4 倍；营运资金还在吸血；**而 ROIC 低于 WACC 已经连续五年**。

**过去 52 周股价涨了 49.5%，而同期 EPS 从 1.01 跌到 0.74（-26%）。市盈率从 31.7 倍涨到 50.65 倍——这一年的涨幅，100% 是估值扩张，一分钱不是利润涨出来的。**

## 第四部分：一句话结论

**贵得没道理。** 一家 ROIC 5.5% 打不过 9.5% 资本成本、连续五年在毁灭价值的化学品公司，营收增长里掺着锡价水分，自由现金流一年腰斩，员工每年拿走 6,850 万股票而公司只回购 560 万，股本不减反增——这些事实配的不是 50 倍市盈率，配的是 15 倍。

市场付的是"AI 先进封装材料"的估值，买到的是"37% 焊膏 + 21% 汽车镀镍 + 12.6% 真正的半导体材料"的业务组合。**要么等那 12.6% 长到 40%，要么等股价跌一半，现在这个价格是替别人的乐观买单。**
