# SPXC · SPX Technologies(SPX 科技)

市值 $105.3 亿 / 股价约 $210 / 行业:工业制造(暖通冷却 + 检测测量) / TTM 截止 2026-06-27

---

## 第一部分:它到底做几件事

SPX Technologies 是老牌工业集团 SPX 拆分瘦身后剩下的精华,现在就做两件事:**给大型设施散热/供暖,和卖各种"探测"设备**。两件事都靠不停收购小公司往上垒。

### 生意一:HVAC 暖通(TTM 营收 $16.9 亿,占 68%,较上财年 +12%)

核心是**散热**。旗下 Marley 是北美冷却塔的百年老牌:一座数据中心或天然气电厂运转时产生巨量废热,要靠楼顶或场边一排排冷却塔用蒸发原理把热排进大气。典型一单:一家云厂商在弗吉尼亚建 AI 数据中心,采购几十套 Marley 冷却塔加变频风机,连设备带服务一单几百万到上千万美元;塔用二十年,风机、填料、维修配件持续回购——设备是入口,售后是年金。**AI 数据中心建设潮正好撞在它枪口上**,公司正在扩产能,资本开支从两年前的 $3800 万干到 TTM $1.19 亿,翻了三倍。

围着"管空气"这个主题,它这几年买了一圈:ASPEQ(工业电加热元件)、TAMCO(风阀)、Ingenia(医院级定制空气处理机组)。供暖+制冷+风控打包,卖给数据中心、医院、电厂、工厂。

### 生意二:检测与测量 D&M(TTM 营收 $7.8 亿,占 32%,较上财年 +5%)

一个高毛利的小众设备杂货铺,每样东西都在自己的缝隙市场里数一数二:
- **Radiodetection 地下管线探测仪**:施工队开挖前先扫一遍地下,别把光纤和燃气管挖断——美国每个州都立法要求"挖前先探",这是刚需;
- **Genfare 公交收费系统**:城市公交的投币机、刷卡闸机和后台;
- **Sealite 航标灯、通信塔障碍灯**:塔上闪的红灯就是这类产品,受法规强制;
- **KTS/CommTech 军用通信侦测**:2025 年买的 KTS 做的是机密级国防电子对抗接口设备,搭上国防预算的车。

项目制、有波动,但法规驱动的需求死不了。

分部经营利润公司未按渠道细拆到本口径,按整体 15.8% 经营利润率和历史披露估算,两个分部利润率都在 20% 上下(分部口径,估算),HVAC 贡献约三分之二利润。

**要点:TTM 营收 +20.6% 里,大约一半是买来的**——TTM 又花了 $4.4 亿收购,过去四年年年花 $3-5.5 亿买公司,这是一台"收购机器"。

## 第二部分:把会计障眼法剥掉

- **股权激励(SBC)**:TTM 仅 $1710 万,占净利润 6%,很轻,难得。
- **一次性项目**:TTM 有 $1850 万投资出售收益(真一次性,算真实利润时要剔掉);"其他经营调整"高达 +$7960 万,主要是递延税和养老金类非现金项,单期口径无法判断是否年年发生,存疑。
- **资本化的支出**:无软件资本化动作,但注意 CapEx 三年翻了三倍到 $1.19 亿——扩产能是为数据中心需求下注,短期压自由现金流。
- **回购与稀释**:TTM 回购只有 $1290 万,连 SBC 都盖不住(比值 0.75);更重要的是 **2025 年增发了 $5.75 亿新股,股本一年膨胀 +6.19%**。人家回购注销,它反向操作——发股票筹钱去买公司。你的股份在被稀释,赌的是买来的生意比稀释更值。
- **利润和现金流的差**:净利润 $2.79 亿 vs 经营现金流 $4.22 亿 vs FCF $3.03 亿:

| 净利润 → 经营现金流对账(TTM,百万美元) | 金额 |
|---|---|
| 净利润 | 279 |
| + 折旧摊销(大头是收购来的无形资产摊销) | 131 |
| + 股权激励 | 17 |
| + 其他非现金调整(递延税/养老金类) | 80 |
| − 投资出售收益(非经营) | -19 |
| − 应收款大增(生意扩张垫出去的钱) | -89 |
| − 存货增加 | -48 |
| + 应付款增加 | 69 |
| = 经营现金流 | 422 |

现金流质量中规中矩:多出来的主要是收购摊销(纸面费用),但被应收和存货的扩张吃回去一截,再扣掉翻三倍的 CapEx,**FCF $3.03 亿只比净利润多 9%**,不像前两家那样有现金流惊喜。

- **账上钱**:净负债 $4.5 亿,负债/EBITDA 1.1 倍,不重。P/TBV 高达 110 倍——净资产几乎全是商誉和收购无形资产,连环收购的常态,哪年买砸了会以减值爆出来。

## 第三部分:市盈率,多口径

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 105.3 亿 ÷ 2.79 亿 | 37.9 | ¥2.6 |
| 公司自己吹的 Non-GAAP | 加回收购摊销,调整后 EPS 约 $7 | 约 30 | ¥3.3 |
| **剔除障眼法后的真实市盈率** | 剔 $1850 万一次性投资收益(税后) | **约 40** | **¥2.5** |
| 自由现金流口径 | 105.3 亿 ÷ 3.03 亿 | 35.9 | ¥2.8 |
| 企业价值口径 EV/EBIT | 109.7 亿 ÷ 3.92 亿 | 29.0 | ¥3.4 |
| 三年平均利润口径 | 105.3 亿 ÷ 1.78 亿(FY23-25 均值) | 59.1 | ¥1.7 |

大白话:**你现在投 100 块,按真实口径公司一年替你赚 2.5 块**——这 2.5 块里,通过分红回购回到你口袋的是 **0**(不分红,回购连发股都盖不住,你的持股比例还在被增发稀释),全部利润都被拿去买下一家公司和扩产能了。这是纯粹的"信管理层再投资"模式。

三年平均口径 59 倍值得多看一眼:当前利润确实处在爬坡后的高位,而且爬坡有一半是花钱买出来的。X 未来会不会变大?**大概率会**——数据中心散热是真需求,扩产完成后放量,收购的生意也都不差。但市场早就知道这一点:37.9 倍 GAAP、36 倍 FCF,已经把未来三四年的增长预付了。华尔街看的 23 倍"远期市盈率"用的是公司调整后口径加乐观指引,拿它安慰自己之前记得那是加回了收购摊销的数字。

## 第四部分:一句话结论

生意是好生意——数据中心散热的风口是真的、缝隙市场的地位是真的、杠杆也不重;但 38 倍 GAAP、36 倍现金流、股东回报为零还在增发稀释,**这是把"好故事"按"完美执行"定的价,现在买等于替过去四年的涨幅买单**——好公司,坏价格,等它跌。
