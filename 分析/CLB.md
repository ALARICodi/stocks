# CLB · 核心实验室（Core Laboratories）

市值 $5.67 亿 / 股价 $12.36 / 能源矿产—油田服务 / TTM 截止 2026-06-30

---

## 第一部分：它到底做几件事

这家公司名字里带"实验室"，做的确实是实验室生意——**给全世界的石油公司化验石头和油**。它不钻井、不采油、不拥有一滴油，它是油田行业里的"检验科"。财报分两个分部。

### 生意一：油藏描述（Reservoir Description）——化验岩芯和油样

石油公司花几千万美元钻一口井之前和之后，最想知道的是：**这块地下岩层里到底有多少油、油能不能流得动、用什么方法采最划算。** 这些问题只有一个办法回答——把地下的岩石取出来化验。

具体流程是这样：钻井时用特殊钻头切下一根根圆柱形的岩芯（core，公司名字就从这来的），长度可能有几百米，连同井里取的原油、天然气、地层水样本，一起送进 Core Lab 在全球 50 多个国家的实验室。实验室测岩石的孔隙度（石头里有多少空隙能装油）、渗透率（油在石头里流得动流不动）、油的黏度和成分，最后给石油公司一份报告：这个油藏值不值得开发、往哪个方向打水平井、注水还是注气驱油效率最高。

举个具体例子：中东某国家石油公司要开发一个新海上油田，把 300 米岩芯和几十桶油样送到 Core Lab 在阿布扎比的实验室，化验周期几个月，一个项目收几百万美元。客户为什么非用它不可？因为这是全球唯一一家**独立的**、覆盖全球的岩芯化验网络——斯伦贝谢等大型油服也能做类似分析，但它们同时卖钻井服务，既当运动员又当裁判；Core Lab 不卖井，报告没有利益冲突，而且它有 90 年积累的全球油藏数据库做对比基准。

这门生意的关键特征：**跟着国际（尤其中东、海上）勘探开发预算走，不太跟美国页岩油走**。项目周期长，收入相对稳。

### 生意二：增产服务（Production Enhancement）——射孔弹和示踪剂

井钻好后，井壁有钢套管，油进不来，得**用聚能炸药在套管上炸出孔**让油流进井筒。Core Lab 卖这种射孔弹（shaped charge，原理和穿甲弹一样），一口美国页岩井压裂时要打几千发，单发几十美元，一口井的射孔弹加起来几万到十几万美元。它的高端产品能把孔炸得更深、形状更利于油流动，页岩油公司为了多产 1% 的油愿意买贵的。

另一块是**示踪剂诊断**：往压裂液里掺化学示踪剂，之后检测各段返排液里的示踪剂浓度，告诉客户"你压的 40 段里第 12 段根本没起作用"——一次诊断服务几万美元，帮客户省下次压裂的百万级成本。

这门生意主要跟美国页岩油活跃度走，波动比生意一大。

> 财报只披露分部营收到 stockanalysis 这一层，分部利润按整体经营利润率 8.1% 和两个分部的历史相对盈利水平估算，油藏描述略高、增产略低。

**全公司画面：TTM 营收 $5.19 亿，五年几乎没长（2021 年 $4.70 亿，年化约 2%），经营利润率只有 8%。** 这是一家有真手艺、但整个行业不给它增长的公司——全球上游勘探开发预算就那么多，化验预算是里面的零头。

## 第二部分：把会计障眼法剥掉

- **股权激励（SBC）**：TTM $837 万，**占净利润 $2435 万的 34%**——比例不小。GAAP 已扣，不加回。
- **一次性项目**：TTM 资产减值与重组仅 $3 万，可忽略。往年有 FX 损失和小额重组，属于"年年都有的一次性"，本次金额小，不构成障眼法。
- **资本化支出**：无软件/内容资本化问题，CapEx $1734 万全是实验设备和厂房，正常。
- **回购与稀释**：TTM 回购 $1435 万 ÷ SBC $837 万 = **1.7 倍**——刚过"抵消员工发股"的线，不算真回购。股本一年只减 1.8%，且**最近一个季度股本反而增加了 1.75%**（发股节奏快于回购），回馈力度很弱。股息一年只付 $185 万，股息率 0.3%，聊胜于无。
- **利润和现金流的差**：这是本篇最要紧的一张表。净利润 $2435 万，但自由现金流只有 $1088 万：

| 逐项对账（TTM，百万美元） | 金额 |
|---|---|
| 净利润 | 24.4 |
| + 折旧摊销 | 14.9 |
| + 股权激励 | 8.4 |
| + 坏账计提 | 1.9 |
| − 其他经营调整 | -1.4 |
| − 营运资金变化（应收+存货+其他净占用） | -19.9 |
| **= 经营现金流** | **28.2** |
| − 资本开支 | -17.3 |
| **= 自由现金流** | **10.9** |

  营运资金一年吃掉近 $2000 万——主要是"其他净经营资产"占用 $1704 万。油服行业客户（尤其国家石油公司）付款慢是老毛病，这不是造假，但意味着**账面利润变成真现金的效率很低**：赚 100 块利润，落袋只有 45 块自由现金。
- **另一个要点：还债中**。净负债 $1.42 亿（相当于市值的 25%），过去五年从 $2.38 亿降下来，每年的现金优先拿去还债了——这解释了为什么分红回购都这么抠。方向是对的，但股东这几年基本没分到钱。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 567 ÷ 24.4 | 23.3 倍 | ¥4.3 |
| 公司口径 Non-GAAP | 剔 FX/重组后约 | ≈22 倍 | ¥4.5 |
| **剔除障眼法后的真实市盈率** | 一次性项目可忽略，≈GAAP | **23.3 倍** | **¥4.3** |
| 自由现金流口径 | 567 ÷ 10.9 | 52.1 倍 | ¥1.9 |
| 企业价值口径 EV/EBIT | 710 ÷ 42.3 | 16.8 倍 | ¥6.0（对全体出资人） |
| 三年平均利润口径 | 567 ÷ 32.6（25/24/23 年均值） | 17.4 倍 | ¥5.7 |

三年平均口径**比当期便宜**（17.4 vs 23.3）——说明现在的利润不是周期高点反而是近三年低点（2023 年赚 $3668 万，TTM 只剩 $2435 万，一路下滑）。这一点对它有利。

但大白话算总账：**你投 100 块进去，按 GAAP 算公司一年替你赚 4.3 块；按真金白银的自由现金流算只有 1.9 块。** 这 4.3 块里，以分红+回购形式真回到你口袋的约 2.8 块（其中一多半只是对冲发股），剩下的在还债和垫营运资金。而且 ROIC 只有 6.75%，低于它自己 8.81% 的资金成本——**这家公司每投一块钱进自己的生意，创造的回报还不够本**，这是营收五年不涨的财务注脚。未来这个 4.3 块会不会变大？要赌国际油气勘探预算持续上行，它自己没有把营收做大的抓手。

## 第四部分：一句话结论

手艺是真的、垄断地位是真的，但这是一门**不增长、赚不回资金成本、利润变现金还打五五折**的生意——23 倍买它没有便宜可占，自由现金流口径 52 倍更是明白告诉你：现在的价格在为"油气景气持续+利润率修复"预付钱。想要油服敞口有更便宜的选择，想要好生意这里没有增长。**偏贵，不值得为它守着。**
