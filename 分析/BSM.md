# BSM · 黑石矿产合伙企业（Black Stone Minerals, L.P.）

市值 31.37 亿美元 · 单位价格 $14.75 · 行业：油气矿权（有限合伙企业 MLP，NYSE） · TTM 截止 2026-06-30

---

## 第一部分：它到底做几件事

先说清楚这家公司的身份，因为它跟绝大多数石油公司**完全不是一回事**。

美国的地下矿产权是私有的。你家院子底下如果有油，那油是你的。石油公司要来开采，得先跟你签租约（lease），这份租约通常包含两笔钱：

1. **签字费（lease bonus）**：签合同当场给你的一笔现金，"允许我在你这块地上钻井"的入场费；
2. **矿区使用费（royalty）**：井打出来之后，卖油卖气的收入里，直接给你切一刀，一般是 20%–25%。**注意是从"收入"里切，不是从"利润"里切。**

第二点是这门生意的全部秘密。石油公司要花几百万美元打一口井，要付钻机租金、压裂砂、水处理费、人工、维修，油价跌了它可能亏得裤子都没有——但你作为矿权持有人，**从收入的第一块钱开始分成，一分钱成本都不摊**。井打得好你多拿，井打亏了你照样拿，只是拿得少一点。

Black Stone Minerals 就是把这件事做到了极致规模：它是全美最大的独立矿权持有者之一，手里握着分布在四十多个州、约两千万英亩毛面积的矿产权和特许权益，重点集中在路易斯安那/得州东部的**海恩斯维尔页岩气区（Haynesville）和谢尔比槽（Shelby Trough）**，另外在二叠盆地、巴肯、鹰滩也有零散头寸。它自己一口井都不打（后面会说这句话现在有点变了），只是坐在地契上收钱。

它的报表也因此长得很怪：**毛利率 89.59%**。一家"能源公司"的毛利率接近九成，因为它根本没有开采成本，成本项只有折耗、管理费和一点点税。

TTM 的钱从四个地方来：

| 生意 | TTM 营收（百万美元） | 上年同期 | 增速 | 占比 | 说明 |
|---|---|---|---|---|---|
| 石油与凝析油矿权费 | 232.73 | 209.36（FY25） | +11.2% | 50.6% | 从原油销售收入中按比例分成 |
| 天然气与 NGL 矿权费 | 190.88 | 191.62（FY25） | −0.4% | 41.5% | 海恩斯维尔干气为主，NGL 少量 |
| 签字费及其他收入 | 22.80 | 21.35（FY25） | +6.8% | 5.0% | 新租约入场费、地面使用费 |
| 商品衍生品损益 | +13.11 | +47.59（FY25） | — | 2.9% | 套保合约的公允价值变动，**不是现金业务** |
| **合计** | **459.52** | 469.92 | −2.2% | 100% | |

有一处要说明：利润表上写的"Revenue"是 **423.60**，正好等于石油 232.73 + 天然气 190.88。也就是说标准化报表把签字费和衍生品损益归到了别处，只把矿权费本身算作营收。这两个口径都在这份报表里，我下面凡是提"营收"一律用 459.5 的完整口径，提"利润"一律用净利润 254.12（那里面签字费和衍生品损益都已经含进去了）。

**分部利润财报没有单独披露**，因为对矿权公司来说没有意义——所有收入共用同一个折耗和同一套管理费用，整体经营利润率 69.80% 就是全部答案。

### 这门生意最近变了一件重要的事

2021 年、2022 年，BSM 的资本开支分别只有 1464 万和 1256 万美元——几乎为零，完全符合"躺着收钱"的经典模型。但 TTM 的资本开支是 **1.29 亿美元**，是四年前的**九倍**。

这笔钱去了哪里？主要是两件事：买入新的矿权资产（拿现金换未来的现金流），以及在谢尔比槽的开发上**自己出钱参与工作权益**——也就是说，为了让运营商愿意在自己的地里加快钻井，BSM 开始自掏腰包分担钻井成本。

这件事必须看明白：**它正在从"纯收租"往"半个开发商"漂移**。收租的生意零成本、零风险；出钱打井是有成本、有风险的。这是本篇后面所有结论的根子——1.29 亿的资本开支，正好是它自由现金流盖不住分红的那个缺口的主要来源。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 1064 万美元，占净利润 4.2%。金额不大，而且 GAAP 已经扣过了，不需要额外调整。合伙单位数 TTM 增加了 0.50%——员工发的单位比回购的多，你的份额被稀释了一点点。

**一次性项目**：没有大额重组、减值或诉讼和解。这家公司的报表在这方面很干净。

**资本化支出**：不适用（没有软件或内容资本化）。1.29 亿的资本开支是实打实买资产和打井，不是把费用藏起来。

**衍生品损益——这是本篇最重要的一项调整**。BSM 用天然气和原油的期货、领口期权对冲价格，会计上每个季度按公允价值重估，赚了记收入、亏了记支出，**但这笔钱在合约到期之前一分现金都没进出**。TTM 它记了 **+1311 万美元**的衍生品收益，FY2025 记了 +4759 万，FY2024 记了 −573 万，FY2022 记了 **−1.21 亿**。这条线的波动幅度接近净利润的一半，而它跟公司当年到底赚了多少钱毫无关系。**算真实盈利必须把它剥掉。**

**回购与稀释**：TTM 回购 282 万美元，同期 SBC 是 1064 万。**回购/SBC = 0.27**。这个比值远低于 1，意味着回购连抵消员工发单位都不够，更谈不上回馈持有人。单位数净增 0.50% 印证了这一点。BSM 回馈持有人的方式是分红，不是回购——这在 MLP 里是常态，但数字该说清楚。

**优先级单位——这一项被市场公开的市盈率完全忽略了**。BSM 有一层优先级单位，TTM 支付了 **2947 万美元**的优先级分配。这笔钱在到达普通单位持有人之前就被拿走了。任何算给你（普通单位持有人）的回报，都必须先扣掉它：

- 净利润 254.12 − 优先级分配 29.47 = **归属普通单位 224.65 百万美元**
- 每单位 224.65 / 212.71 = **$1.056**，不是财经网站上写的 $1.20

**利润和现金流的差**——这一段做一张逐项对账表，因为差额很大且信息量很足：

| 项目 | 金额（百万美元） | 这是什么 |
|---|---|---|
| 净利润 | 254.12 | 起点 |
| ＋ 折旧摊销/折耗 | +39.24 | 矿权按产量摊销，不花现金 |
| ＋ 其他摊销 | +1.06 | |
| ＋ 股权激励 | +10.64 | 发的是单位不是现金 |
| ＋ 应收账款减少 | +8.98 | 客户回款比记账快 |
| − 应付账款减少 | −1.97 | |
| ＋ 其他经营性净资产变动 | +1.52 | |
| − 其他经营活动（主要是未实现衍生品收益的冲回） | −22.67 | **把没收到现金的衍生品收益扣回去** |
| **＝ 经营活动现金流** | **320.38** | 比净利润高 26% |
| − 资本开支 | −128.92 | 买矿权 + 参与开发出资 |
| ＋ 出售资产收回 | +0.56 | |
| **＝ 自由现金流** | **191.46** | **比净利润低 25%** |

看清楚这条链：净利润 2.54 亿 → 经营现金流 3.20 亿（因为折耗是假支出，现金流更高）→ 自由现金流 1.91 亿（因为 1.29 亿资本开支把它砍掉了四成）。

**然后是全篇最刺眼的一组数字**：

- TTM 自由现金流：**191.46**
- TTM 支付的优先级分配：**29.47**
- TTM 支付的普通单位分配：**254.56**
- 分配合计：**284.03**

**它发出去的钱，比它挣到的自由现金流多了 9257 万美元。** 缺口靠什么补？TTM 净借款 **+9700 万美元**。数字对得严丝合缝——**这一年的分红，是借来发的**。

对应的资产负债表变化也印证了：总债务从 FY2024 年底的 **2500 万**，涨到 FY2025 的 1.54 亿，再到现在的 **1.96 亿**。两年翻了近八倍。绝对值仍然不高（债务/EBITDA 只有 0.59，利息保障倍数 23.77，离危险还很远），但方向是清楚的。

同时它已经在砍分红了：每单位年度分配从 FY2023 的 $1.90 → FY2024 $1.60 → FY2025 $1.275 → 现在 $1.20。**连续三年下调，累计砍掉 37%。**

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率（网站口径） | 31.37 亿 ÷ 2.541 亿 | **12.34 倍** | 8.10 元 |
| 扣掉优先级分配后（归属普通单位） | 31.37 亿 ÷ 2.247 亿 | **13.96 倍** | 7.16 元 |
| **剔除障眼法后的真实市盈率** | 31.37 亿 ÷（2.541 − 衍生品收益 0.131 − 优先级 0.295）= 2.115 亿 | **14.83 倍** | **6.74 元** |
| 自由现金流口径（扣优先级后） | 31.37 亿 ÷（1.915 − 0.295）= 1.620 亿 | **19.37 倍** | 5.16 元 |
| 企业价值口径 EV/EBIT | 33.32 亿 ÷ 2.957 亿 | **11.27 倍** | 8.87 元 |
| 三年平均利润口径（剔衍生品、扣优先级） | 31.37 亿 ÷ 2.340 亿 | **13.41 倍** | 7.46 元 |

最后一行是唯一的历史口径，这里它说了一件**反直觉的好消息**：BSM 现在的利润**不在高点**。FY2023 剔除衍生品后的真实净利是 3.10 亿，FY2024 是 2.48 亿，FY2025 是 2.23 亿，TTM 是 2.41 亿——过去三年是**下坡然后企稳**，不是冲顶。所以 13.41 倍的三年平均口径跟 14.83 倍的当期口径差别不大，说明"你买在利润高点"的风险在这家公司身上不成立。这跟大多数能源股不一样，值得记一笔。

### 说人话

**你现在投 100 块进去，按最保守的真实口径（剔掉衍生品的纸面收益、扣掉优先级单位先拿走的那份），公司一年替你赚 6 块 7 毛 4。**

这 6.74 块里，有多少真的回到你口袋？

按当前每单位 $1.20 的年度分配、$14.75 的价格算，**账面派息率 8.14%**，也就是投 100 块每年打给你 8.14 元现金。**这个数字比公司真实赚到的 6.74 元还高**——多出来的 1.4 元，是从借款里挤出来的。

看它自己的对账：支付比率（分红/利润）**101.86%**，分红/自由现金流约 **157%**（254.56 ÷ 161.99）。这两个数都在告诉你同一件事：**当前的 8.14% 收益率不是可持续的**。它已经连续三年下调分红了，市场共识的远期市盈率 **14.75 倍高于当期的 12.34 倍**——分析师也在预期利润继续下滑。

留在公司里的部分呢？1.29 亿资本开支，买了新矿权、参与了开发井。这笔钱理论上会在未来变成更多的矿权费收入，但它把这家公司从"零风险收租"变成了"要承担一部分钻井风险"。ROIC 14.72%、WACC 4.42%，投出去的钱回报率还是显著高于资金成本的，这一点没问题。

**这 6.74 元未来大概率变大还是变小？** 取决于一件事：**天然气价格**。BSM 一半的营收来自海恩斯维尔的干气，而海恩斯维尔是美国最靠近墨西哥湾 LNG 出口终端的产气区。未来几年美国 LNG 出口产能大幅扩张、叠加数据中心的用电（进而燃气）需求，是这家公司唯一的多头逻辑，也是它股价过去 52 周涨 22.2%、逼近区间上沿的原因。如果这个逻辑兑现，收入端会明显上台阶；如果气价回落到 2024 年那种水平，分红还得继续砍。

**顺带一句必须提醒的事**：BSM 是有限合伙企业（L.P.），不是普通公司。持有人拿到的是"单位"不是"股票"，报税拿的是 K-1 表不是 1099。对非美国投资者，MLP 分配适用美国税法第 1446 条的预提，实际到手会比 8.14% 的名义收益率低相当一截。买之前必须先搞清楚自己的账户能不能持有 MLP、预提多少——这不是小事，能吃掉三分之一的收益。

## 第四部分：一句话结论

**这门生意是真好，但这个价格上没有便宜可占。**

矿权收租的商业模式几乎无可挑剔——89.6% 的毛利率、14.7% 的 ROIC、4.4% 的资本成本、0.59 倍的债务/EBITDA，账干净得像模板。而且难得的是，它当前的利润不在周期高点，三年平均口径反而比当期口径更便宜，没有"买在山顶"的风险。

但摆在你面前的 12.3 倍市盈率是修饰过的：它没扣优先级单位先拿走的那 2947 万，也没剥掉 1311 万纯纸面的衍生品收益。**扣完是 14.8 倍，年回报 6.74 元，而它派给你 8.14 元——多出来的部分是借的。**债务两年从 2500 万涨到 1.96 亿，分红连砍三年累计 37%，远期市盈率还比当期高。

真正的赌注是海恩斯维尔的气价。你不是在买一个 8% 的稳定收益，你是在用 14.8 倍的价格买一张"美国 LNG 出口 + 数据中心用气"的看涨票据，而这张票据在你等待期间会付给你逐年递减的现金。愿意赌这个方向的人可以买；冲着 8% 高息来的人会被砍到。
