# TSSI · TSS 公司

**市值** 2.30 亿美元 | **股价** 约 8.15 美元 | **行业** 科技服务（数据中心机柜集成） | **TTM 截止** 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

TSS 是一家给数据中心「攒机柜」的公司——注意，不是攒电脑，是攒**整个机柜**。全公司只有 286 个人，年收入 1.93 亿美元。财报把生意分成三块，但这三块的性质差得非常远，必须分开看。

### 生意一：Procurement（代采购）—— 占收入 68.6%，但基本不是生意

这块是全公司收入的大头，1.325 亿美元，也是最容易看错的一块。

具体是这么运作的：客户（几乎全是戴尔，以及戴尔背后的最终客户）要建一个 AI 数据中心，需要采购一大堆硬件——GPU 服务器、交换机、电源分配单元、光模块、线缆、机架导轨。客户不想自己一家一家去谈，就委托 TSS 去下单。TSS 用自己的名义向各家厂商买货，货到自己仓库，然后开票给客户。

**关键在于：这笔钱在会计上是「全额」计入收入的。** 假设一批 GPU 服务器的进价是 1000 万美元，TSS 加价 70 万卖给客户，收入表上记的是 1070 万，不是 70 万。所以你看到的「1.93 亿收入」里，有 1.32 亿其实只是货物过了一趟手。

这块的毛利率极低。整体毛利率 19.02%，倒推回去，代采购业务的毛利率大约在 **5%–8% 之间（估算，财报只披露到分部收入，不披露分部利润）**。做一亿三千万的流水，赚八百万到一千万的毛利，扣掉人工和仓储，净下来的利润薄得几乎看不见。

更麻烦的是它的波动。这块业务 FY2025 全年做了 1.975 亿，最近十二个月只剩 1.325 亿，掉了三分之一。因为它完全跟着客户的采购节奏走——客户这个季度要建两个数据中心就有单，下个季度不建就没有。TSS 对此没有任何控制力。

**为什么这块要单独拎出来说：它把整个公司的收入曲线搞得面目全非。** 全公司 TTM 收入同比掉了 26.52%，看上去像业务塌了；但塌的主要是这块「过手费」业务，真正的核心业务其实在涨。

### 生意二：System Integration（系统集成）—— 占收入 26.7%，这才是真正的公司

5161 万美元，这块是 TSS 存在的理由。

做的事情很具体：戴尔（或者亚马逊、微软这类最终客户）要往数据中心里塞一批 AI 训练集群。GPU 服务器、交换机、电源、液冷分配器分别从不同厂商发出来，如果直接运到数据中心现场组装，需要在机房里干几天活——而现代数据中心的机房是无尘、恒温、带电运行的，在里面拧螺丝是灾难。

所以行业做法是「工厂预集成」：把空机柜运到 TSS 在德州和佐治亚的车间，工人把 8 台 GPU 服务器一台台推进机柜滑轨，接上 48 根电源线和 32 根 400G 光纤，装上液冷歧管和快接头，走线捆扎，贴标签，然后**通电跑压力测试**——满负载跑 24 到 72 小时，看有没有内存报错、有没有漏液、散热够不够。测完断电，整个机柜用防震包装装车，运到数据中心，现场只需要推进去、接电、接水、接网，两小时就能上线。

**收费是按机柜算的。** 一个装满 GPU 的高密度机柜，集成加测试的服务费大概在**一到三万美元**之间（视复杂度，尤其是液冷比风冷贵得多）。5161 万的收入，对应大概两千到三千个机柜。

客户为什么非用不可：一是数据中心现场没有做这件事的场地和人；二是液冷机柜必须在受控环境下做水路密封性测试，漏一滴水就是几百万美元的 GPU 报废；三是戴尔这类整机厂自己不想养这条产线，外包更划算。

这块的毛利率**估算在 40%–45%（财报不披露分部利润，此为按整体毛利倒推）**。而且它在涨：FY2025 全年 4034 万，最近十二个月 5161 万，涨了约 28%。AI 数据中心还在建，这块的需求是真的。

### 生意三：Facilities Management（设施管理）—— 占收入 4.7%，小但稳

914 万美元，最小的一块，但性质最好。

TSS 帮客户运维模块化数据中心：派几个技术员常驻在客户的机房里，负责监控温湿度、换故障硬盘、处理告警、做巡检和季度保养。按月收管理费，合同一签几年。这是唯一一块「不用等订单、每个月自动进账」的收入。

毛利率**估算 35%–40%**。规模太小，撑不起公司，但它是收入曲线里唯一不抖的那条线。

| 生意 | TTM 收入（百万美元） | 对比 FY2025 全年 | 占总收入 | 毛利率（估算） | 毛利贡献（估算） |
|---|---|---|---|---|---|
| Procurement 代采购 | 132.53 | −32.9% | 68.6% | 5%–8% | 约 900 万 |
| System Integration 系统集成 | 51.61 | +27.9% | 26.7% | 40%–45% | 约 2200 万 |
| Facilities Management 设施管理 | 9.14 | +15.6% | 4.7% | 35%–40% | 约 350 万 |

**一句话总结这家公司：一家真正的机柜集成商（5000 万收入），外面套了一层代采购的壳（1.3 亿流水）。看收入会被壳骗，要看毛利。**

还有一件必须说的事：**客户高度集中**。TSS 的绝大部分收入来自戴尔一家（作为戴尔的授权集成合作伙伴）。这不是一家有几百个客户的公司，它是一家给一个客户干活的公司。戴尔换供应商、或者戴尔的 AI 服务器订单节奏一变，TSS 的报表立刻塌。

## 第二部分：把会计障眼法剥掉

这一部分是这篇分析的重点，因为 TSSI 的报表上藏着一个**足以让市盈率翻两倍半**的东西。

### 一、那笔 691 万美元的「所得税优惠」——本篇最重要的发现

看这三个数：

| 项目 | 金额（百万美元） |
|---|---|
| 税前利润 | **7.47** |
| 所得税 | **−6.91**（是优惠，不是缴税） |
| 净利润 | **14.37** |

**净利润几乎是税前利润的两倍。** 正常公司交完税，净利润应该比税前利润少 20%–25%；TSS 反而多了 92%。多出来的 690 万，一分钱不是经营赚的，是会计上「退」给它的。

这笔钱是怎么来的：TSS 过去很多年是亏损的（看 FY2021 净利润 −130 万、FY2022 −7 万），亏损累积出一大笔「递延所得税资产」——通俗说就是「以后赚钱了可以抵税的额度」。但因为公司一直不赚钱，会计上不确定这些额度将来用不用得上，就计提了「估值备抵」把它冲掉、不体现在账上。等到 AI 机柜生意起来、公司连续盈利之后，审计师认可「以后确实能赚钱、能用上这些额度」，于是把估值备抵**释放**掉，这一大笔递延所得税资产就一次性回到利润表里，变成一笔巨额的所得税优惠。

三个要点：
1. **它是一次性的。** 备抵只能释放一次，释放完就没有了。
2. **它不是现金。** 公司账上没有多出 690 万，这就是为什么现金流量表里要把它冲回去（见下面的对账表）。
3. **它会让市盈率严重失真。** 用这个净利润算出来的 16 倍市盈率，是全篇最不能信的数字。

### 二、股权激励（SBC）：420 万美元，相当于真实利润的四分之三

TTM 股权激励 420 万美元。

- 占 GAAP 净利润 1437 万的 **29.2%**
- 占「剥掉税收优惠后的真实净利润」约 568 万的 **74%**

这是个非常刺眼的比例。一家真实利润只有五百多万的公司，一年给管理层和员工发了四百多万的股票。这些股票稀释你的股份，是实打实的成本，本篇一律按现金成本对待、不加回。

### 三、回购与稀释：这是本篇第二个大问题

| 项目 | TTM 金额 |
|---|---|
| 回购股票 | 320 万美元 |
| 股权激励 SBC | 420 万美元 |
| **回购 ÷ SBC** | **0.76 倍** |
| **发行新股** | **5539 万美元** |
| **股本变化（同比）** | **+9.13%** |

回购 320 万，还不够抵消 420 万的员工发股——**回购比值 0.76 倍，连稀释都没堵住，更谈不上回馈股东**（这个比值要大于 3 才算真回购）。

更关键的是那 5539 万的「发行普通股」。公司在 FY2025 股价高的时候做了一次大额增发（或 ATM 持续售股），一口气融了五千五百万。这就是为什么账上现在躺着 6768 万现金——**那笔现金不是赚来的，是卖股票卖来的**。

结果就是：过去一年股东手里的股份被稀释了 9.13%，而股价跌了 47.76%。

### 四、利润和现金流的差：全篇含金量最高的一张表

净利润 1437 万，经营现金流 **−941 万**，自由现金流 **−2098 万**。一家「盈利一千四百万」的公司，一年烧掉两千万现金。差额 2378 万，逐项对账：

| 项目 | 金额（百万美元） | 说明 |
|---|---|---|
| 净利润 | **14.37** | 起点 |
| ＋ 折旧摊销 | +5.35 | 非现金 |
| ＋ 股权激励 SBC | +4.20 | 非现金（但是真成本） |
| ＋ 资产处置损失 | +0.68 | 非现金 |
| ＋ 其他经营项 | +1.65 | |
| **− 递延所得税等非现金项** | **−7.26** | **就是那笔税收优惠被冲回去了** |
| 小计（营运资金变动前） | 18.99 | |
| ＋ 应收账款减少 | +3.89 | 收入下滑，收回了钱 |
| − 存货增加 | −2.37 | |
| **− 应付账款减少** | **−33.61** | **本表的核心** |
| − 预收账款减少 | −0.78 | |
| ＋ 其他经营性资产 | +4.47 | |
| **＝ 经营现金流** | **−9.41** | |
| − 资本开支 | −11.57 | 佐治亚新集成厂房 |
| **＝ 自由现金流** | **−20.98** | |

**这张表说了两件事。**

第一，那 726 万的递延所得税冲回，**从现金流量表这一侧证明了「690 万的所得税优惠不是现金」**。会计上加进净利润，现金流上原样减掉。

第二，应付账款一年减少 3361 万，这是烧钱的主因，而它的成因是代采购业务在收缩。展开说：代采购业务扩张时，TSS 先向供应商拿货（记应付账款）、后向客户收钱，供应商的账期等于给了它一笔无息贷款——FY2024 应付账款增加了 3898 万，那年经营现金流是正的 1530 万，大部分是这么来的。现在代采购收入掉了三分之一，欠供应商的货款要一笔笔还掉，而新的欠款跟不上，这笔无息贷款就在往外倒吐。

**这不是造假，是过手型生意的物理规律：涨的时候现金比利润多，跌的时候现金比利润少。** 但它意味着，这家公司报表上的现金流，在业务收缩期会持续为负，而且跟利润好坏没什么关系。

### 五、一次性项目与资本化

除了上面那笔所得税优惠，TTM 内没有大额诉讼、重组或减值。资本开支 1157 万主要是佐治亚州新集成厂房和产线设备，是真机器不是软件资本化，这一项干净。

## 第三部分：市盈率，多口径

市值 2.2999 亿美元，企业价值 2.0107 亿美元（净现金 2891 万）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 230.0 ÷ 14.37 | **16.0 倍** | **6.25 元** |
| 公司口径（调整后 EBITDA） | 公司不披露调整后净利润，只报调整后 EBITDA 约 1466 万 | 不适用 | — |
| **剔除障眼法后的真实市盈率** | 230.0 ÷ 5.68（税前 7.47 × 按 24% 正常税率） | **40.5 倍** | **2.47 元** |
| 自由现金流口径 | 自由现金流为 −2098 万 | **不适用（为负）** | **−9.12 元** |
| 企业价值口径 EV/EBIT | 201.1 ÷ 9.40 | **21.4 倍** | **4.67 元** |
| 三年平均利润口径 | 230.0 ÷ 6.19（FY24 598 万、FY25 约 690 万、TTM 568 万，均按正常税率还原） | **37.2 倍** | **2.69 元** |

**这张表里最重要的一行是第三行。**

筛选器上写的 16 倍，是拿一笔一次性的、不是现金的所得税优惠算出来的。把这笔优惠拿掉、按正常公司该交的税还原，真实市盈率是 **40.5 倍**——不是便宜了一点点，是**贵了两倍半**。

三年平均口径 37.2 倍进一步确认：这不是「今年有个一次性因素、明年就正常」，而是这家公司在正常税率下本来就只能赚五六百万，过去三年一直如此。它没有一个被压低的利润高点等着回归。

**说人话：你现在投 100 块进去，按最保守的真实口径算，公司一年替你赚 2 块 4 毛 7。**

这 2 块 4 毛 7 里，回到你口袋的部分是**负的**。公司不分红；回购只有 320 万，还不够抵消 420 万的员工发股；同时它一年增发了 5539 万新股，股本涨了 9.13%。也就是说，扣掉稀释之后，**作为老股东，你在过去一年不但没拿到一分钱，手里的股份还缩水了近一成**。

这 2 块 4 毛 7 未来是变大还是变小？两股力量在拧：
- **变大的力量**：系统集成业务同比涨 28%，毛利率是代采购的六到八倍，佐治亚新厂投产后产能翻倍，AI 数据中心的建设周期还没走完。如果三年后集成收入翻倍到一亿、代采购归零，公司的毛利结构会好看得多。
- **变小的力量**：代采购收入还在往下掉，每掉一块钱就带走一块钱应付账款的现金；客户集中在戴尔一家，议价权全在对方；这门手艺（把服务器推进机柜、接线、通电测试）的技术壁垒并不高，戴尔随时可以再找一家或者自己干；13.53% 的流通股被卖空，市场对它的看法很清楚。
- **最重要的是**：那笔所得税优惠明年不会再有。就算经营层面一切照旧，明年的 GAAP 净利润也会从 1437 万掉到五六百万，账面「市盈率」会自己从 16 倍跳到 40 倍——**什么都不用发生，只需要日历翻一页**。

## 第四部分：一句话结论

**16 倍市盈率是假的，真实是 40 倍，而且这个真相明年会自己暴露出来。**

TSSI 里面确实藏着一门好生意——那个 5000 万收入、四成毛利、还在涨 28% 的机柜集成业务，是 AI 数据中心建设链条上一个真实的位置。但你为它付的价格，是按一个被一次性税收优惠吹大了一倍半的净利润定的，外面还包着一层 1.3 亿的代采购流水在制造「这是家两亿收入的公司」的错觉。

剥干净之后是这样一家公司：真实年利润五百多万，市值两亿三，一年烧掉两千万现金，靠增发五千五百万补血，股东被稀释 9%，客户只有一个，管理层拿走的股权激励相当于真实利润的四分之三。

股价过去一年跌了 47.76%，跌成这样仍然是 40 倍。**这不是被错杀，是杀得还不够。**
