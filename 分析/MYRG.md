## 第一部分：它到底做几件事

MYR Group 是**电工包工头**——一家 1891 年成立、干了 135 年的电力工程承包商。它不生产任何东西，不拥有任何电网，不卖电。它做的事是：**电力公司和大楼业主要拉电线、建变电站、装配电盘，MYR 派工人去干，按合同收工钱。**

全公司 9,000 名员工，一年做 40.06 亿美元营收，人均创收 44.5 万美元——这是典型的**人力密集型**生意，跟上面两家（墨菲石油人均 368 万、CNO 保险人均 141 万）完全不同。它的核心资产不是设备也不是专利，是**那 9,000 个能爬上高压铁塔干活的电工**。

它分两个分部，客户完全不同、干法也完全不同。

### 生意一：输配电（T&D）—— 20.99 亿美元，占 52%

**客户是电力公司**（大型上市电力集团、农村电力合作社、市政电力局）。用的是老牌子 **The L.E. Myers Co.**——就是 1891 年那个公司的原名。

具体在干什么，举一个真实典型的活：

> 某州的电力公司要把一条 60 英里长的老旧 138 千伏输电线升级成 345 千伏。公开招标，MYR 报价 1.2 亿美元中标。接下来 14 个月里，MYR 要做这些事：沿线路走廊清障（砍树、修便道）、用大型钻机在每个塔基位置打混凝土基础、把几十米高的钢管塔或格构塔一段段吊装起来、然后**架线**——用绞磨机把几十吨重的导线从一座塔"放"到下一座塔，一路张紧到规定弧垂，再装绝缘子串、避雷线、金具。全程线路带电区段要停电或带电作业。干完调试，交给电力公司。

线路之外还有三类活：
- **变电站建设**：在一块地上建起变压器、断路器、母线、继电保护室，把高压变成中压。一座中型变电站合同额 2,000 万到 8,000 万美元。
- **配电网**：城市和乡镇的低压线路、电线杆、地埋电缆、路灯，这类活单笔金额小（几十万到几百万），但量大且持续。
- **抢修（storm restoration）**：飓风、冰暴、野火过后，电力公司发出互助请求，MYR 连夜派几百名电工带着车队开过去，**按人工小时 + 设备台班计价，费率是平时的两三倍，且不封顶**。这是行业里利润率最高的活，但完全靠天吃饭——哪一年飓风多，哪一年利润好看。

**怎么签合同、怎么收钱？** 主要三种：
- **主服务协议（MSA）**：跟一家电力公司签三到五年的框架协议，对方随时派活，MYR 按事先谈好的单价干。这是最好的一类合同——不用一次次投标、收入可预测、客户黏性极高。
- **单价合同**：按"每英里线路多少钱""每根杆多少钱"结算，工程量增加了钱就增加，MYR 不承担工程量风险。
- **固定总价合同**：报一个总价包干。**这是危险的那一类**——如果遇到地质超预期、征地拖延、材料涨价、工人不够，超出的成本全部由 MYR 自己吞。后面第二部分要讲的 2024 年那场事故，就出在这类合同上。

### 生意二：商业与工业（C&I）—— 19.07 亿美元，占 48%

**客户是盖楼的人**——总承包商、地产开发商、数据中心运营商、机场管理局、医院、市政。用的牌子是 **Sturgeon Electric**，主要在美国西部（科罗拉多、加州、亚利桑那、内华达）和加拿大不列颠哥伦比亚省。

这块干的是**建筑物内部和周边的一切电气活**：从进楼的高压开关柜、配电室、母线槽，到每一层的桥架、穿线、插座、照明、消防联动、弱电和安防，再到室外的变压器、发电机、路灯、停车场充电桩。

典型的活长这样：

> 一个 60 万平方英尺的数据中心在凤凰城开工，总承包商把电气分包给 Sturgeon，合同 8,000 万美元。Sturgeon 要装 4 台备用柴油发电机、两套不间断电源系统、几十面配电柜、以及机房里成千上万条给服务器机柜供电的支路。工期 18 个月，按月按完工进度开票（percentage-of-completion），业主扣留 5%–10% 的质保金到竣工验收后再付。

C&I 的其他典型项目：机场航站楼扩建的全部电气、轻轨和高速公路照明系统、污水处理厂的电控、医院手术室的双路供电、酒店赌场、以及**电动车充电站**（这几年新增的一块）。

**T&D 和 C&I 的关键差别**：T&D 的客户是受监管的电力公司，钱多、付款准、有 MSA 长约、活是刚需（电网不修不行）；C&I 的客户是地产和建筑市场，跟着经济周期走，竞争更激烈（每个城市都有一堆电气承包商），**固定总价合同的比例更高、风险更大**。

### 两个分部的钱（TTM，单位百万美元）

| 分部 | TTM 营收 | 占比 | vs FY2025（半年错位） | FY25 vs FY24 真实同比 |
|---|---|---|---|---|
| 输配电 T&D | 2,099 | 52.4% | +4.8% | +6.4% |
| 商业与工业 C&I | 1,907 | 47.6% | **+15.2%** | +11.7% |
| **合计** | **4,006** | 100% | **+9.5%** | **+8.8%** |

全公司 TTM 营收同比 **+16.06%**，是三家里增长最快的。C&I 增长明显快于 T&D——这背后是数据中心建设潮。

**财报没有按分部披露利润。** 只能按整体口径估算：TTM 毛利 5.003 亿 ÷ 营收 40.06 亿 = **12.5% 的毛利率**；经营利润 2.211 亿 = **5.52% 的经营利润率**。行业常识是 T&D（有 MSA、单价合同多）的利润率通常高于 C&I（竞标激烈、固定总价多），但**这只是常识推断，不是财报数字**。

**必须记住这个 5.52%**——它是理解这家公司的全部关键。**每 100 块营收，只剩 5 块 5 毛的经营利润。** 这意味着：任何一个大项目上出 10% 的成本超支，就能吃掉这个项目全部利润还倒亏；一年里有两三个这样的项目出问题，全公司的利润就没了。这不是假设，这是 2024 年真实发生过的事。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：TTM 1,796 万美元，占净利润 1.653 亿的 10.9%。** 金额不大，GAAP 已经扣了，不加回。但要注意 SBC 在快速上涨：FY2023 是 838 万、FY2024 是 853 万、FY2025 是 1,483 万、TTM 是 1,796 万——**两年翻了一倍多**，比营收增长快得多。

**一次性项目：TTM 这一期干净，没有减值、没有重组、没有诉讼和解。** 但**这家公司最重要的历史事件恰恰是一笔"一次性"**，而且它就发生在两年前：

| 财年 | 营收（百万） | 经营利润 | 经营利润率 | 净利润 |
|---|---|---|---|---|
| FY2023 | 3,644 | 124.88 | 3.43% | 90.99 |
| **FY2024** | **3,362** | **57.53** | **1.71%** | **30.26** |
| FY2025 | 3,658 | 162.61 | 4.45% | 118.42 |
| **TTM** | **4,006** | **221.09** | **5.52%** | **165.29** |

**FY2024 的利润只有 3,026 万——比 FY2023 掉了 67%，比现在的 TTM 少了 82%。** 原因是几个大型清洁能源固定总价项目严重超支，MYR 一次性把预计亏损全部计提。这笔损失当时被称作"一次性"，但**从这张表看，它更像是这门生意的固有属性周期性发作**：低毛利 + 固定总价 + 大型复杂项目 = 每隔几年出一次事故。

**只看当期 TTM，你看到的是一家利润率 5.52% 的优秀承包商；把镜头拉到三年，你看到的是一家利润率在 1.71% 到 5.52% 之间来回摆动的公司。** 这个区别在第三部分会变成三倍的估值差。

**资本化的支出：没有值得注意的。** 承包商的资本开支主要是买卡车、吊车、绞磨机这类施工设备，TTM 资本开支 1.051 亿，折旧摊销 6,975 万。资本开支高于折旧 50%，说明在扩充设备队伍——跟营收增长 16% 是匹配的，合理。没有软件资本化、没有开发费资本化这类粉饰空间。

**回购与稀释：TTM 这一期不好看，但要看上下文。**

| 项目 | TTM | FY2025 | FY2024 |
|---|---|---|---|
| 回购股票 | **729 万** | 7,765 万 | 8,087 万 |
| 股权激励 SBC | 1,796 万 | 1,483 万 | 853 万 |
| **回购 ÷ SBC** | **0.41 倍** | 5.2 倍 | 9.5 倍 |
| 股本一年变化 | −2.15% | | |
| 股本最近一季变化 | **+0.35%** | | |
| 分红 | **无** | 无 | 无 |

**TTM 的 0.41 倍意味着这一年公司买回来的股票，还不到发给员工那部分的一半。** 但前两年回购是 5.2 倍和 9.5 倍，非常慷慨。为什么突然停了？**几乎肯定是因为股价。** 股价过去 52 周涨了 78.94%，管理层在 $170 的时候大手笔回购，涨到 $400 就不买了——**这是一个理性管理层该有的样子，值得加分**，但对现在的股东来说意味着：那条每年缩 5% 股本的顺风，现在停了。

公司不发股息。

**利润和现金流的差：这一项 MYR 是三家里最漂亮的。**

| 项目 | TTM（百万美元） |
|---|---|
| 净利润 | 165.29 |
| + 折旧摊销 | +69.75 |
| − 出售资产收益 | −4.37 |
| + 股权激励 | +17.96 |
| + 其他经营活动 | −6.52 |
| − 应收账款增加 | −25.51 |
| + 应付账款增加 | +34.78 |
| **+ 预收账款增加（客户先付钱）** | **+50.37** |
| + 其他经营性资产变动 | −3.25 |
| **= 经营现金流** | **298.50**（报表 298.49）✅ |
| − 资本开支 | −105.13 |
| **= 自由现金流** | **193.36** |

**逐笔对得上，一分不差。** 而且结论很好看：

**自由现金流 1.934 亿 ÷ 净利润 1.653 亿 = 1.17 倍。** 也就是说 **MYR 报出来的每一块钱利润，背后有 1.17 块钱的真现金**。这在承包行业里不常见——承包商的经典毛病是"账面赚钱、现金全压在应收款和未结算工程量里"，很多同行的自由现金流只有利润的一半。

关键在那笔 **+5,037 万的预收账款增加**：MYR 的客户在活干完之前就先付了钱。这说明它在合同谈判里有议价权（尤其在 T&D 那边，电力公司愿意预付以锁定施工队），而且**这笔钱是免费的营运资金**——用客户的钱垫付工资和材料。

再看资产负债表：**现金 1.379 亿、有息负债 6,710 万、净现金 7,077 万。** 一家零负债、账上有净现金的公司。利息覆盖倍数 59.85（利息支出小到可以忽略）。

**账是干净的。这一部分我找不到什么障眼法。**

### 全篇最重要的一行：当期 30.5 倍 vs 三年平均 48.2 倍

**这两个数字之间 58% 的差距，就是这份分析的全部结论。**

当期市盈率 30.5 倍已经不便宜了。但当期利润 1.653 亿是**这家公司历史上最好的一年**——它建立在 5.52% 的经营利润率上，而这个利润率是过去六年的最高值（FY2021 是 4.62%、FY2022 是 3.74%、FY2023 是 3.43%、FY2024 是 1.71%、FY2025 是 4.45%）。

**六年平均的经营利润率大约是 3.9%。如果 MYR 回到这个正常水平，同样 40 亿的营收只能产出约 1.17 亿的净利润，市盈率立刻变成 43 倍。**

三年平均口径给出的 **48.2 倍**，就是把 FY2024 那个 3,026 万的灾难年算进去后的结果。你可以说 FY2024 是意外、不该算——**但一家六年里出过一次这种事故的公司，凭什么假设未来六年不再出一次？** 承包行业没有护城河能挡住"某个大项目干砸了"这件事。

### 一个必须承认的漂亮数字：ROIC 25.6%

| 指标 | 数值 |
|---|---|
| 净资产收益率 ROE | **24.71%** |
| 投入资本回报率 ROIC | **25.59%** |
| 加权平均资本成本 WACC | 11.50% |
| **ROIC − WACC** | **+14.1 个百分点** |
| 资产周转率 | 2.46 次 |

**这是三家公司里唯一一个投入资本回报率大幅高于资本成本的。**（墨菲石油是 5.36% vs 5.83%，负的。）

为什么一个毛利率只有 12.5% 的包工头能有 25% 的投入资本回报率？因为**它几乎不需要投入资本**：没有工厂、没有存货、没有专利，主要资产就是卡车和应收账款，而客户还预付钱。资产周转率 2.46 次意味着**每一块钱资产一年能转出 2.46 块钱营收**——薄利多销的极致。**利润率低不等于生意差，关键看周转。**

### 大白话总结

**你现在投 100 块进 MYR Group，按当期利润算，公司一年替你赚 3.3 块；按自由现金流算 3.8 块；按最保守的三年平均口径算，只有 2.1 块。**

这 3.3 块里，回到你口袋的是：
- **分红：0 块**（公司不发股息）
- **回购：0.14 块**（TTM 回购 729 万 ÷ 市值 50.44 亿），基本等于零

**也就是说，这一年公司几乎一分钱都没还给股东。** 钱去哪了？看现金流：资本开支 1.051 亿（买施工设备）、还债 7,761 万，剩下的 1.149 亿留在账上当现金。这是**全额留存再投资**的模式——对一家 ROIC 25% 的公司来说，把钱留在公司里再投资**理论上是正确的选择**（留在公司能赚 25%，发给你只能赚存款利息）。前提是它真能把这些钱以 25% 的回报再投出去，而承包生意的规模扩张受限于**能招到多少合格电工**，不是受限于钱。

**这个 3.3 块未来会变大还是变小？**

**往大的方向，理由是实打实的，而且是这几年最硬的产业趋势之一：**
- **美国电网到了必须大修的时候。** 大量输电线路是 1960–70 年代建的，早已过设计寿命。同时可再生能源要并网（风电光伏在偏远地区，电得输过来）、电动车要充电、工厂在回流——所有这些都要求电网扩容。这不是一年的事，是十年的事。
- **数据中心。** 这是过去两年最猛的增量。一座 AI 数据中心的用电量相当于一座小城市，它要新的输电线、新的变电站、新的厂内配电——T&D 和 C&I **两个分部同时吃到这块肉**。C&I 营收 TTM 增长 15.2%，主要就是这个。
- **抢修需求在变多。** 极端天气频率上升，飓风冰暴野火过后的抢修是最高利润率的活。
- **电工短缺是 MYR 的朋友不是敌人。** 合格的高压线路电工要经过三到四年的学徒期，全美总量有限。谁手里有队伍谁就能挑活、谈价——这是 MYR 真正的护城河，而且比"品牌"或"专利"结实。

**往小的方向，理由同样硬：**
- **利润率已经在历史最高点。** 5.52% 的经营利润率是六年最高，而六年平均只有 3.9%。均值回归的力量很难对抗，尤其在一个竞争充分、没有定价权的行业里。
- **固定总价合同的地雷没有拆除。** FY2024 那次 67% 的利润塌方就是最好的证据。行业繁荣时，承包商为了抢单会接更激进的固定价合同——**现在正是繁荣期，也就正是种下下一颗雷的时候**。
- **股价已经跑在前面。** 52 周涨 78.94%。而且注意一个细节：**当前股价 $323.7，低于 50 日均线 $401.5，高于 200 日均线 $318.2**——股票在最近这段时间已经从高点跌了约 20%（相对强弱指标 RSI 只有 34.45，处在超卖区）。市场已经开始怀疑这个故事了。
- **6.68 倍市净率、8.82 倍有形账面市净率**，给一个包工头这个价格，是把它当成长股在定价。

## 第四部分：一句话结论

**生意是真的好，价格是真的贵。这是典型的「好公司，坏价格」。**

好在哪里，说清楚：**投入资本回报率 25.6%、远高于 11.5% 的资本成本；账上有净现金、零负债压力；自由现金流是净利润的 1.17 倍，利润全是真钱；客户预付款还在替它垫资；护城河是 9,000 名训练有素的电工和跟电力公司的长期框架协议，这东西砸钱砸不出来，只能靠时间攒；面对的是美国电网大修 + 数据中心建设这两条十年级别的产业顺风。** 这些都不是故事，是财报上能验证的事实。

**问题只有一个，但足够大：你要为这一切付 30.5 倍当期利润、48.2 倍三年平均利润、6.7 倍账面净资产，换回来一年 2.1 到 3.3 块。而且这一年一分钱分红没有、回购基本停了——你拿到手的现金是零，全部靠股价上涨兑现。**

更要命的是，那个 30.5 倍是拿**历史最高的利润率**做分母算出来的。这家公司两年前刚刚因为几个固定总价合同干砸，利润掉了 67%。**低毛利承包生意的规律就是：好年份看起来像成长股，坏年份现出包工头的原形。** 用成长股的价格去买一家周期波动的承包商，赌的是"这次不一样"。

**值得放进观察名单，但不是现在的价格。股价从 $400 跌到 $324 已经跌了两成，还得再跌一大截——大概在 20 倍当期利润、也就是 $210 上下，这门生意的质量才配得上这个价钱。**
