# RH · RH（原 Restoration Hardware，高端家居零售）

**市值** 33.3 亿美元 ｜ **股价** 约 $176.10 ｜ **股数** 1,893 万股 ｜ **行业** 零售 / 家居 ｜ **交易所** NYSE
**TTM 截止日** 2026 年 5 月 2 日（公司财年 1 月底结束）

---

## 第一部分：它到底做几件事

RH 卖沙发、床、餐桌、灯具和床品。就这么简单。但它卖得跟所有人都不一样，所以先得说清楚它到底在干什么。

### 它的商业模式：把家具店做成博物馆

普通家具店（比如宜家、Wayfair）的逻辑是「货架 + 价格」。RH 的逻辑是**「你先在一个漂亮到不像话的地方待一下午，然后顺便买张一万五的沙发」**。

具体是这样的：RH 在纽约 Meatpacking、旧金山、芝加哥这些地方，把整栋历史建筑买下来或长租下来，改造成 5,000–10,000 平米的「**Gallery**」（它坚决不叫「店」）。里面没有货架、没有价签牌子，是按「一间客厅」「一间卧室」这样布置成一整套完整的家，天花板挂着水晶灯、地上铺着地毯、墙上挂着画。顶层通常有一个**餐厅**（RH Rooftop Restaurant），供应松露披萨和香槟，很多是当地要提前几周订位的网红餐厅。有的 Gallery 还有酒吧、咖啡厅、甚至一个小型艺术展区。

一个客户带着家人来吃个午饭，从餐厅下楼，穿过样板间，看到一张 Cloud Sofa（RH 的招牌产品，一张羽绒填充的巨大沙发，售价 $8,000–$15,000），坐上去陷进去，服务员过来说「您可以先带布料样品回家试试」。三周后这单成了。

**这套模式的经济学是**：Gallery 的坪效比传统家具店高好几倍，但前期投入巨大（改造一栋楼要几千万美元），而且**这些楼绝大多数是租的**——这就是后面所有财务问题的根源。

### 它卖的具体是什么、怎么收钱

- **软体家具**：Cloud Sofa 系列、Modena、Maxwell 这些皮沙发，单价 $6,000–$20,000。这是最赚钱的品类，毛利率最高，因为「设计感」的溢价全在这里。
- **床和床垫**：一张四柱床 $4,000 起。
- **餐桌椅**：一张实木大餐桌 $5,000–$12,000。
- **照明**：水晶吊灯、落地灯，$500–$5,000。
- **纺织品**：床品、地毯、窗帘。这是复购品类，客单价低但频次高。
- **户外家具（RH Outdoor）**：柚木和藤编的庭院家具，美国郊区大宅的标配，单套 $10,000+。

**收钱方式**：绝大部分是**先收钱后交货**。客户下单付全款或大额定金，RH 从越南、中国、意大利的代工厂订货，6–12 周后送到家并安装。所以 RH 的资产负债表上有一笔不小的「预收账款（Unearned Revenue）」——**这是客户在给它免息贷款**，TTM 还增加了 3,194 万，是个正面信号。

另外有一个会员制：**RH Members Program**，年费 $175，会员买东西打七五折。这个设计很聪明——它把「打折促销」变成了「入会费」，既锁定复购，又不用在店里挂「五折」的牌子破坏品牌调性。RH 的绝大部分销售额来自会员。

### 它还在做几件「不像家具店」的事

- **RH Guesthouse**（纽约的一家精品酒店）
- **RH Interior Design**（免费的室内设计服务，本质是导购）
- **两架私人飞机和一艘游艇**用于客户体验（是的，写在 10-K 里的）
- **正在往欧洲扩张**：伦敦、巴黎、慕尼黑、布鲁塞尔陆续开 Gallery

CEO Gary Friedman 是这家公司的灵魂，也是一个极具争议的人物——他把 RH 当作一个「设计品牌」而非零售商在经营，坚持不打折、坚持烧钱盖 Gallery、坚持扩张到欧洲。**他持有约 18% 的股份**（内部人持股 18.15%），所以他跟股东是绑在一起的；但他也是那个决定借 40 亿美元回购自家股票的人。

### 分部数据（TTM 截止 2026-05-02，单位百万美元）

RH 只披露两个分部，而且第二个小到可以忽略：

| 分部 | TTM 营收 | 占比 | vs FY2026（1月底结束） | 经营利润率（估算） | 贡献利润（估算） |
|---|---|---|---|---|---|
| **RH 主品牌**（家具、照明、纺织、户外、餐厅） | 3,229 | 94.2% | −0.4% | ~10% | ~323 |
| **Waterworks**（高端卫浴五金） | 197.3 | 5.8% | −0.4% | ~8% | ~16 |
| **合计** | **3,426** | 100% | **+4.84%（同比）** | **9.88%（实际）** | **338.5（实际）** |

> **财报不披露分部经营利润**，上表分部利润率是按整体 9.88% 结合业务性质估算的，不是财报数字。合计栏的 9.88% 和 338.5 是实际数。

**Waterworks** 是 RH 2016 年收购的一个高端卫浴品牌，卖 $3,000 一个的水龙头和 $10,000 一个的浴缸，客户是高端住宅的建筑师和设计师。它规模小、增长停滞（五年营收从 1.65 亿到 1.97 亿），本质上是个附属品。

**所以：RH 实质上就是一门生意——用博物馆式的门店卖高端家具。**

营收轨迹值得看一眼：FY2022 37.59 亿 → FY2023 35.90 亿 → FY2024 30.29 亿 → FY2025 31.81 亿 → FY2026 34.40 亿 → TTM 34.26 亿。**从 2022 年的高点跌了 12%，最近两年在回升，但还没回到 2022 年的水平。** 而且 TTM（截止 5 月）比刚结束的整个 FY2026 财年还略低 0.4%，说明最新一个季度的势头在减弱。

毛利率也在阴跌：50.47%（FY2023）→ 45.86% → 44.48% → 44.07% → **43.54%（TTM）**。四年掉了 7 个百分点。对一个「靠品牌溢价」的公司，这是个不好的信号——**要么在降价，要么成本（关税、运费）在涨而它转嫁不出去。**

## 第二部分：把会计障眼法剥掉

RH 的财报本身没有明显造假，但它的**资本结构**制造了这批公司里最大的一个陷阱，请看完这一部分。

**股权激励（SBC）——占比很高**：TTM **4,343 万美元**，占净利润 1.031 亿的 **42.1%**。这是个很大的比例：**公司报出来的每 100 块利润里，有 42 块是「已经用股票付给员工、但记账时被加回来当利润看」的争议地带。** GAAP 口径已经扣掉了，我们不加回——但要记住，如果哪天 RH 想学 Non-GAAP 那套把 SBC 加回去吹利润，那 42% 的水分就出来了。

**一次性项目**：TTM 只有 464 万美元的资产减值/重组，金额很小，可以忽略。这一项干净。

**资本化的支出**：RH 每年 1.865 亿的资本开支主要是改造 Gallery（装修、家具、设备）。折旧摊销 1.52 亿。资本开支略高于折旧，正常（还在扩张期）。**没有软件资本化之类的操作。**

**回购与稀释——这里有一个必须说清楚的历史**：

| 项目 | TTM | FY2025 | FY2024 | FY2023 |
|---|---|---|---|---|
| 回购普通股 | **0** | −1,199 万 | **−12.53 亿** | **−10.01 亿** |
| 股权激励（SBC） | 4,343 万 | 4,419 万 | 3,938 万 | 4,355 万 |
| 长期债务净增减 | −1.935 亿 | +1.123 亿 | −4,067 万 | +6,230 万 |

**FY2023 和 FY2024 两年，RH 花了 22.54 亿美元回购自己的股票，而这笔钱基本是借来的。** 它在 2021–2022 年发行了 20 亿美元的可转债（利率极低甚至零息，因为当时利率环境好），拿这笔钱把股本从 2,800 万股买到不到 1,900 万股。

**这个操作的后果，就写在今天的资产负债表上：**

| 项目 | 金额 |
|---|---|
| 现金 | **5,380 万美元** |
| 总债务 | **40.19 亿美元** |
| 净债务 | **−39.65 亿美元**（每股 −$209.51，**比股价 $176.10 还高**） |
| **账面股东权益** | **仅 5,693 万美元**（每股 $3.01） |
| PB 市净率 | **56.79 倍** |
| Debt / EBITDA | 6.04 倍 |
| 利息保障倍数 | **1.52** |
| **Altman Z-Score** | **1.26**（低于 1.81 即属破产风险区） |

**一家 33 亿市值的公司，账面净资产只剩 5,693 万美元——基本被回购掏空了。** 它现在有 40 亿债务、5,380 万现金。这不是「杠杆偏高」，这是「几乎全部资产由债主拥有」。

TTM 回购金额为 **0**，回购/SBC 比值 = **0**。也就是说：**员工每年拿走 4,343 万的股权，公司一分钱都没回购来对冲这个稀释。** （统计口径显示流通股同比减少 4.24%，但 TTM 现金流量表上找不到对应的回购支出，这个差额来自更早期回购股份的注销时点，不代表本期有真实回购。）RH 不发股息。

**利润和现金流的差——RH 最迷惑人的地方在这里**：净利润 1.031 亿，经营现金流 4.181 亿，差了 4 倍。逐项对账（单位百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 103.05 | |
| ＋ 折旧摊销 | +152.01 | 主要是 Gallery 的装修摊销 |
| ＋ 资产减值/重组 | +4.64 | |
| ＋ 权益投资损失 | +3.64 | |
| ＋ 股权激励（非现金） | +43.43 | |
| ＋ 其他经营活动 | **+184.42** | **主要是租赁使用权资产摊销**（非现金） |
| − 应收账款增加 | −8.55 | |
| **＋ 存货减少** | **+211.13** | **⚠️ 本期最大的单一现金来源** |
| ＋ 应付账款增加 | +13.33 | |
| ＋ 预收账款增加 | +31.94 | 客户提前付款 |
| − 其他经营性资产变动 | **−320.94** | **主要是租赁负债的实际现金支付** |
| **＝ 经营现金流** | **418.10** | |
| − 资本开支 | −186.50 | |
| **＝ 自由现金流** | **231.60** | |

**这张表里有两件事必须挑出来讲：**

**第一件事：那个 +18,442 万和 −32,094 万是一对。** 前者是「租来的 Gallery 按会计准则记的非现金摊销」，后者是「实际付给房东的租金现金」。两者相抵，**净流出约 1.365 亿美元**。RH 的 Gallery 几乎全是长租的历史建筑，这笔租金是刚性成本，永远跑不掉。任何只看「经营现金流 4.18 亿」而不看这一对的人，都会高估 RH 的造血能力。

**第二件事，也是最关键的一件：那 2.111 亿的存货释放是一次性的。**

看历史：FY2025 存货变动是 **−2.686 亿**（大量囤货，现金流出），FY2026 是 **+2.138 亿**（去库存，现金流入）。RH 在 2024–2025 年因为担心关税和供应链，提前囤了一大批货，那一年经营现金流被压到只剩 **1,710 万美元**；现在把这批货卖掉，现金回来了。

**这意味着：TTM 那 2.316 亿「自由现金流」里，有 2.111 亿是卖光了仓库里的存货换来的，不是今年的生意赚来的。** 剔掉这一笔：

> 真实可持续自由现金流 ≈ 2.316 − 2.111 = **约 2,050 万美元**

**而 RH 每年要付 2.171 亿美元的现金利息。**

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 33.3 亿 ÷ 1.031 亿 | **32.3 倍** | **$3.10** |
| 公司自己吹的 Non-GAAP | RH 报「调整后经营利润率」，不报调整后净利 | n/a | n/a |
| **剔除障眼法后的真实市盈率** | 33.3 亿 ÷（1.031 + 0.046×0.73 减值 = **1.065 亿**） | **31.3 倍** | **$3.19** |
| 自由现金流口径（表面） | 33.3 亿 ÷ 2.316 亿 | **14.4 倍** | **$6.95** |
| **自由现金流口径（剔除一次性去库存 2.111 亿）** | 33.3 亿 ÷ **0.205 亿** | **162 倍** | **$0.62** |
| 企业价值口径 EV/EBIT | **73.0 亿** ÷ 3.385 亿 | **21.6 倍** | **$4.64** |
| 三年平均利润口径 | 33.3 亿 ÷ [(1.276 + 0.724 + 1.248) ÷ 3 = **1.083 亿**] | **30.8 倍** | **$3.25** |

**这张表里最重要的是第四行和第五行的对比。**

市场上看多 RH 的人会说「P/FCF 只有 14 倍，很便宜」。**但那 14 倍里，91% 的自由现金流来自把仓库清空这一笔一次性动作。** 存货只能卖一次；明年要恢复库存，这笔钱还得还回去。按可持续口径算，是 162 倍，等于没有自由现金流。

**第二重要的是 EV/EBIT 那一行。** 市值 33.3 亿，但**企业价值 73.0 亿**——因为要买下整家 RH，你除了付 33.3 亿给股东，还得接手 39.65 亿的净债务。**债务比股权市值还大。**

而这 73 亿买到的是什么？一年 3.385 亿的经营利润。**这 3.385 亿的去向是这样的：**

| 经营利润 3.385 亿 | 分给谁 | 占比 |
|---|---|---|
| **现金利息** | **债主** | **2.171 亿 → 64%** |
| 所得税 | 政府 | 0.381 亿 → 11% |
| **剩下的净利润** | **股东** | **1.031 亿 → 30%** |

**RH 每挣 3 块钱经营利润，就有近 2 块钱直接付给债主。** 利息保障倍数 1.52 的意思是：经营利润只够付 1.5 倍的利息——**再跌三成，就付不起了。**

**说人话：你现在投 100 块进 RH，按最保守的真实口径（可持续自由现金流）算，公司一年替你赚 0.62 块。** 按三年平均利润算，是 3.25 块。哪个口径都不好看。

**这 3.25 块里，有多少真的回到你口袋？答案是零。** RH 不发股息，TTM 回购为零。全部留在公司里，去向是：资本开支 1.865 亿（继续盖 Gallery、往欧洲扩张）和净还债 1.935 亿。**你拿到手的现金回报是 0%，全部押在「Gary Friedman 把留存收益投出更高价值」这个赌注上。**

**这个数未来会变大还是变小？**

**变大的理由**（分析师 EPS 三年增速预测 +28.14%，Forward PE 26.86）：

1. **利率下行是 RH 的最大杠杆**。40 亿债务，利率每降 1 个百分点，一年省下 4,000 万，直接是净利润 +39%。这是所有看多逻辑的核心——**RH 现在与其说是家具股，不如说是一张利率期权。**
2. **房地产成交量回暖会直接拉动**。人搬家才买家具。美国二手房成交量还在历史低位，一旦解冻，RH 的客群（换大房子的高收入家庭）弹性最大。
3. **欧洲扩张的期权价值**。伦敦、巴黎的 Gallery 如果跑通，是一个全新的增长曲线。
4. **品牌是真的**。43.5% 的毛利率在家具零售里非常高（Wayfair 约 30%，宜家更低），说明客户确实愿意为设计付钱。

**变小的理由**：

1. **毛利率四年从 50.5% 掉到 43.5%**，说明品牌溢价在被侵蚀（关税、运费、以及被迫促销）。
2. **TTM 营收比刚结束的财年还低 0.4%**，最新的势头在转弱，而不是在加速。
3. **账面净资产只剩 5,693 万，Altman Z-Score 1.26 落在破产风险区。** 这不代表它明天就破产（它还在盈利、还在产生现金），但它没有任何缓冲——**一次严重的消费衰退就可能让它付不起利息。**
4. **27.34% 的流通股被做空**（占自由流通股 37.56%）。这是全市场做空比例最高的股票之一，一群专业机构在赌它撑不住。当然，这也意味着任何好消息都可能引发轧空——**这只股票的价格在很大程度上是空头和多头的拉锯，不是基本面的定价。**
5. **股价过去一年跌了 26.8%**，而分析师目标价 $177.18 只比现价高 0.61%——**华尔街 20 位分析师的共识是「Hold」，没有人认为它现在便宜。**

## 第四部分：一句话结论

**不值。这是一个好品牌被塞进了一个可能撑不住的资本结构里。**

RH 的生意本身有真东西：把家具店做成能吃饭的博物馆、用会员制代替打折、43.5% 的毛利率在家具零售业里遥遥领先——这些都不是幻觉。

但 2022–2023 年那个决定毁掉了它的财务安全：**借了 40 亿美元回购自家股票，把账面净资产从几十亿掏到只剩 5,693 万。** 今天的结果是：企业价值 73 亿里有 39.65 亿是债务（**债比股权市值还大**），每年 2.171 亿现金利息**吃掉经营利润的 64%**，利息保障倍数 1.52，Altman Z-Score 1.26 落在破产风险区。

看多的人拿「P/FCF 14 倍」说事，但那 2.316 亿自由现金流里有 2.111 亿是**把仓库清空换来的一次性现金**——存货只能卖一次，按可持续口径算是 162 倍，约等于没有。三年平均利润口径 30.8 倍，投 100 块一年赚 3.25 块，而且**一分钱都不会回到你口袋**（不分红、不回购），全部拿去盖新店和还债。

同时毛利率四年从 50.5% 掉到 43.5%、TTM 营收比上一财年还低 0.4%、股权激励占净利 42% 却零回购对冲。

它唯一真正的看多逻辑不是家具，是**利率**——40 亿债务，降息 1 个百分点就多出 4,000 万利润。这是一张标着「家具零售」的利率期权，而你要用 30 倍市盈率去买它。37.56% 的流通股被做空不是没有道理的。
