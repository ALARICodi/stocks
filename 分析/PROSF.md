# PROSF · Prosus

市值 886 亿美元（阿姆斯特丹主板 784.5 亿欧元，按 1 欧元 = 1.13 美元）/ 37.13 欧元/股 / 互联网控股公司 / TTM 截止 2026-03-31（财年 4 月–3 月，半年报，**财报本身用美元编制**，全文用美元）

> 任务4 海外巨头第 41 名。荷兰公司，南非 Naspers 的国际业务平台，全球最大的腾讯股东。stockanalysis 场外代号 PROSF 没有财报页，数据取自阿姆斯特丹 PRX 页面。

## 第一部分：它到底做几件事

**先说最重要的一句话：Prosus 是一家「壳里装着腾讯」的公司。** 它持有腾讯约 23% 的股份，按腾讯当前 5028 亿美元市值算，这一块值约 1160 亿美元——**比 Prosus 自己 886 亿美元的市值还高 30%**。也就是说，你花 886 亿买下整个 Prosus，拿到 1160 亿的腾讯股票，然后下面这一大堆自营生意（一年 97 亿美元营收）是白送的，还倒找你 270 亿。这个「折价」已经存在十年了，本篇要回答的是：折价为什么存在、会不会收窄。

财报把自营生意分成七个分部，我按性质归成四门：

### 生意 A：腾讯持股——真正的资产

**这是什么：** 2001 年 Naspers 花 3200 万美元买了腾讯 46.5% 的股份，这是人类商业史上回报最高的一笔投资。Prosus 现在还持有约 23%（一路减持：2018 年卖 2%、2021 年卖 2%、2022 年起「每天卖一点」用来回购自己的股票）。腾讯本身是微信、王者荣耀、微信支付、腾讯云，任务4 第 1 名已单独分析。

**怎么收钱：** 两条路。一是腾讯分红，Prosus 一年收到约 11–12 亿美元现金；二是卖腾讯股票——TTM 卖了约 139 亿美元的证券（投资活动里的「Investment in Securities +138.7 亿」），账面确认 48 亿美元「出售投资收益」。这笔钱大部分拿去回购 Prosus 自己的股票（74 亿）和买 Just Eat Takeaway（41 亿欧元）、Despegar（17 亿美元）。

**会计上怎么记：** 腾讯按权益法核算，Prosus 把腾讯净利润的 23% 记进自己的净利润，大约一年 65–75 亿美元——这就是为什么 Prosus 营收只有 97 亿、经营利润只有 3.2 亿，净利润却有 116 亿。

### 生意 B：外卖平台（iFood、Just Eat Takeaway、Delivery Hero 持股、Swiggy 持股）——自营里最大的一块

**这是什么：** iFood 是巴西的美团，在巴西外卖市场份额 80% 以上，一单 40 雷亚尔（约 7 美元）的外卖抽商家 12%–27% 佣金、再收用户几雷亚尔配送费，一个月 1 亿单。TTM 营收 23.7 亿美元，比上一财年增长 27%，已经盈利。Just Eat Takeaway 是 2025 年花 41 亿欧元收购的欧洲外卖平台（英国、荷兰、德国），营收规模跟 iFood 差不多但利润薄，Prosus 的算盘是用 iFood 的经验把它做赚钱。另外还持有 Delivery Hero（德国）约 27%、Swiggy（印度）约 12%，这两个是少数股权，不并表。

| 外卖 | 数字 |
|---|---|
| TTM 营收（iFood 23.7 亿 + JET 并表部分 19.2 亿） | 约 43 亿美元 |
| 占自营营收 | 44% |
| 经营利润（估算） | iFood 约盈利 3–4 亿；JET 约盈亏平衡 |

### 生意 C：分类信息 + 电商零售（OLX、eMAG）

**OLX** 是东欧的 58 同城：波兰、罗马尼亚、乌克兰、巴西、南非的二手车、房产、招聘分类广告，卖家发帖免费、想置顶付费，车商和房产中介按月付几百欧元套餐。这是自营里**最赚钱的生意**——营收 9.9 亿美元、增长 28%，经营利润率 40% 以上（估算约 4 亿美元）。**eMAG** 是罗马尼亚的亚马逊，自营卖货加第三方平台，营收 25.4 亿美元、自营里最大的单一分部，但零售的毛利薄、刚做到微利。

| 分类信息 + 电商 | 数字 |
|---|---|
| TTM 营收（OLX 9.9 亿 + eMAG 25.4 亿） | 35.3 亿美元 |
| 占自营营收 | 36% |
| 经营利润（估算） | OLX 约 4 亿；eMAG 约 0.5 亿 |

### 生意 D：支付、旅游和其他（PayU、iyzico、Despegar、Udemy、Remitly 等持股）

**PayU** 是印度的支付网关，商户在网站上接一个 PayU 收款按钮，每笔交易抽 1%–2%，营收 7.8 亿美元；**iyzico** 是土耳其版的 PayU，4.2 亿美元、增长 46%；**Despegar** 是 2025 年花 17 亿美元买的拉美最大在线旅行社（机票酒店），营收 8 亿美元。「其他」3.8 亿美元是教育（Udemy、Skillsoft 持股）和各种小项目。

| 支付 + 旅游 + 其他 | 数字 |
|---|---|
| TTM 营收 | 23.9 亿美元 |
| 占自营营收 | 25% |
| 经营利润（估算） | 微利到微亏 |

### 自营生意合起来

| 合计（TTM 截止 2026-03-31） | 数字 |
|---|---|
| 自营营收 | 97.1 亿美元（+49%，含 JET 和 Despegar 并表） |
| 毛利率 | 46.4% |
| 自营经营利润 | 3.2 亿美元，利润率 3.3% |
| 集团净利润（含腾讯权益法 + 投资收益） | 116.4 亿美元 |

**要点：** 自营生意 2023 财年还亏 3 亿、2022 财年亏 7.5 亿，2024 年新 CEO Fabricio Bloisi（iFood 创始人）上任后砍掉烧钱项目，两年内扭亏到赚 3.2 亿。方向对了，但相对 886 亿市值，3.2 亿仍然可以忽略不计——**Prosus 的估值 95% 是腾讯，自营生意是「折价能不能收窄」的筹码**。

## 第二部分：把会计障眼法剥掉

**这家公司的利润表要反着读。** 净利润 116 亿美元里，只有 3.2 亿是自己做生意赚的，其余全是腾讯和投资：

| TTM 净利润 116.4 亿的构成 | 金额 | 性质 |
|---|---|---|
| 自营生意经营利润 | 3.2 亿 | 真的 |
| 腾讯权益法利润（约 23% × 腾讯净利润） | 约 70 亿（估算） | 真的，但钱在腾讯账上，Prosus 只拿到 11–12 亿分红 |
| 出售腾讯等股票的收益 | 48.0 亿 | 卖资产，卖一次少一次 |
| 持股公允价值变动（Delivery Hero、Swiggy、Udemy 等涨跌） | 68.7 亿 | 纸面浮盈，去年是 57 亿，前年 28 亿，随股市波动 |
| 利息、税、减值、其他 | 约 −73 亿 | 含 4.8 亿减值和约 10 亿利息 |

**股权激励（SBC）：** TTM 1.73 亿美元，占自营经营利润的 54%——自营生意「赚的」3.2 亿里有一半多是靠发股票省出来的。占集团净利润则不到 2%。

**一次性项目：** 48 亿出售收益和 69 亿公允价值变动都不是经营所得，但也不是「一次性」——Prosus 每年都在卖腾讯、每年都有浮盈浮亏（2022 年 118 亿、2023 年 56 亿、2024 年 43 亿、2025 年 60 亿、2026 年 48 亿）。真实市盈率里这两项全部剔除。另有 4.8 亿减值。

**资本化的支出：** 没有值得说的。

**回购与稀释：** TTM 回购 74 亿美元，SBC 1.7 亿，回购 ÷ SBC = 43 倍，是**真回购、大回购**——相当于市值的 8.4%。stockanalysis 显示股本一年减少 39%，那是 Naspers/Prosus 交叉持股结构调整注销的股份加上回购的合计，真金白银买回来的按 74 亿算。分红只有 5 亿。

**利润和现金流的差：** 净利润 116 亿，经营现金流只有 16 亿——差 100 亿。这是控股公司的正常现象，但必须对账：

| 从净利润到经营现金流（TTM，亿美元） | 金额 | 说明 |
|---|---|---|
| 净利润 | 116.4 | |
| − 出售投资收益 | −48.0 | 现金记在投资活动 |
| − 公允价值变动 | −68.7 | 纸面浮盈，没有现金 |
| − 腾讯权益法利润 + 腾讯分红 | 约 −58 | 权益法利润约 70 亿不是现金，只收到约 12 亿分红（估算） |
| + 折旧摊销、减值、SBC | 11.8 | |
| + 其他（递延税等） | 10.2 | |
| − 营运资金变化 | −5.7 | |
| **= 经营现金流** | **16.1** | |
| − 资本开支 | −1.0 | 平台公司几乎不需要资本开支 |
| **= 自由现金流** | **15.1** | |

**大白话：** Prosus 一年真正流进口袋的现金约 15 亿美元，其中 11–12 亿是腾讯分红，自营生意的现金贡献只有三四亿。它花的钱（74 亿回购 + 71 亿收购 + 5 亿分红 = 150 亿）是自由现金流的十倍，差额全靠卖腾讯股票（139 亿）。**这是一台把腾讯股票换成 Prosus 回购和欧洲外卖公司的机器。**

## 第三部分：市盈率，多口径

市值 886 亿美元。净负债 20 亿（现金 157 亿、有息负债 177 亿），忽略不计。

**这是控股公司，市盈率之外还要看「分部加总」。** 先按规格做市盈率表：

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 886 ÷ 116.4 | 7.6 倍 | 13.1 元（假的，含浮盈和卖资产） |
| 公司自己吹的口径 | Prosus 用「核心每股收益」（剔除公允价值变动和出售收益，保留腾讯权益法），TTM 约 73 亿 | 12.1 倍 | 8.3 元 |
| **剔除障眼法后的真实市盈率** | 886 ÷（自营 3.2 + 腾讯权益法约 70 − 利息和总部约 12）≈ 61 | **14.5 倍** | **6.9 元** |
| 自由现金流口径 | 886 ÷ 15.1 | 58.7 倍 | 1.7 元（腾讯利润留在腾讯，不算现金） |
| 企业价值口径 EV/EBIT | 只对自营生意有意义：（886 + 20 − 腾讯 1160）为负数 | 无意义 | — |
| 三年平均利润口径 | 886 ÷ 三年平均净利润 102（2024 财年 66、2025 财年 124、2026 财年 116） | 8.7 倍 | 11.5 元（同样含浮盈） |

**然后看分部加总，这才是 Prosus 的定价方式：**

| 资产 | 价值（亿美元） | 依据 |
|---|---|---|
| 腾讯约 23% | 约 1160 | 腾讯市值 5028 亿 × 23% |
| Delivery Hero 约 27%、Swiggy 约 12%、Remitly、Udemy、Trip.com 等上市持股 | 约 80–100 | 按各自市值粗估 |
| iFood + JET + OLX + eMAG + PayU + iyzico + Despegar（自营） | 约 150–200 | iFood 单独就有人出价 100 亿以上；OLX 4 亿利润 × 15 倍 = 60 亿 |
| − 净负债 | −20 | |
| **加总** | **约 1370–1440** | |
| **Prosus 市值** | **886** | **折价 35%–38%** |

**大白话：你现在投 100 块进去，按剔除浮盈的真实口径算，公司（主要是腾讯）一年替你赚 6.9 块；但按资产算，你付 100 块拿到的是 155–163 块的东西。**

这 6.9 块里，只有约 1.3 块（腾讯分红）真正变成 Prosus 的现金，Prosus 再通过卖腾讯股票，一年把相当于你本金 8.4% 的钱以回购形式还给你。分红 0.6 块。剩下的 5.6 块留在腾讯账上再投资（腾讯自己也在大回购）。

**折价为什么存在、会不会收窄：** 三个原因。一是双层控股（Naspers 控制 Prosus，Prosus 持有腾讯），每一层都要打折；二是历史上管理层拿腾讯的钱乱投（教育、电商烧了上百亿美元，2022 财年自营亏 7.5 亿）；三是荷兰公司卖腾讯要交税的疑虑。新 CEO 上任两年自营扭亏、回购加码，折价从 2022 年的 50% 以上收窄到现在的 35%——**方向在收窄，但要收到 15% 以下需要自营生意证明自己每年能赚 10 亿以上，这至少还要三年。** 腾讯本身（任务4 第 1 名已分析）是这笔投资的底盘，腾讯涨 Prosus 跟着涨、腾讯跌折价还可能再扩。

## 第四部分：一句话结论

**便宜，是「用 65 块钱买 100 块钱腾讯」的便宜，但要接受这 35% 的折扣可能长期存在。** 真实口径 14.5 倍买腾讯的权益（腾讯自己是 16 倍左右），外加每年 8% 的回购和一堆正在扭亏的新兴市场平台白送。它不是一门好生意——它是一个装着好生意的、管理层过去十年口碑不佳的壳，最近两年壳在变好。适合的买法是：看好腾讯、又想要一个安全垫，同时接受回报大部分来自「折价收窄」而不是「生意变好」。折价不收窄，你拿到的就是腾讯的回报减去一点点摩擦。
