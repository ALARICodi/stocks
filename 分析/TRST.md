# TRST · TrustCo Bank Corp NY（纽约信托储蓄银行）

市值 $9.73亿 / 股价约 $57.1 / 行业：储蓄银行 / TTM 截止 2026-06-30（数据来源 stockanalysis.com，S&P Global）

**这是银行，下面用市净率（PB）+ 净资产收益率（ROE）口径，不用市盈率那套**——银行的「营收」和「利润」都是杠杆放出来的，PE 单独看会骗人，得看它用多少本钱、加了多少杠杆、赚出多少回报。

---

## 第一部分：它到底做几件事

一门生意，而且是全美国最老派的那种：**吸储蓄存款 → 放住宅按揭 → 赚利差**。1902年成立，总部在纽约州奥尔巴尼（Albany），140家左右分行铺在纽约上州、纽约市郊区和佛罗里达中部（佛州占了约三分之一，是过去二十年慢慢开出来的退休人口市场）。

具体怎么运转：奥尔巴尼一对夫妻买35万美元的房子，到楼下的 Trustco 分行贷28万、30年期按揭。跟绝大多数美国银行不一样的是——**Trustco 不把这笔贷款卖给房利美，而是自己留在账上收30年利息**。资金哪来？同一家分行里街坊存的储蓄存款，付给储户的利息低，收借款人的利息高，中间约3个点的利差就是它的收入。全行约64亿美元资产里，绝大部分就是这样一笔笔本地住宅按揭。

它的风格在业内是出了名的「抠」和「保守」：不做信用卡、不做投行、不碰商业地产大项目、不买花哨的衍生品；放贷只放它派人看过房子的本地按揭，所以坏账率常年趴在地板上，2008年金融危机都没伤到筋骨。分行装修朴素、人手精简，成本控制是它的看家本领。另外挂着一个小的财富管理部门，替客户管着约10亿美元的信托资产，收点手续费，占收入的零头。

这门生意的天花板同样明摆着：**它不增长**。存款规模、分行数量十年没有大变化，赚多赚少全看利率周期给不给利差——利率快速上升时存款成本先涨、按揭收益后涨，利润被挤（FY2024 净利掉到 $48.8M）；利率企稳回落后利差修复，利润回来（TTM $65.1M，同比+33%）。它做的从来不是把饼做大，是把同一张饼烤好。

## 第二部分：把会计障眼法剥掉（银行版）

**一次性项目**：无。利润逐季平稳，TTM 的增长是利差修复的周期性恢复，不是一次性收益堆的。

**股权激励（SBC）**：极小（这家银行以吝啬著称，历史上每年不到 $2M，占净利润约2%，估算口径），可忽略。

**拨备与资产质量**：具体拨备数汇总页未披露，但该行的招牌就是几乎为零的坏账核销率和远超监管线的资本充足率（历史常年如此，估算口径）。账是干净的，这点不用怀疑。

**回购与稀释（这家的亮点）**：股本一年 **-4.91%**——约88万股被真金白银买回注销，按均价估算花了约 $44M；加上派息约 $27M（每股 $1.60，股息率2.8%，派息率44%），一年合计还给股东约 $71M，**相当于市值的7.3%、净利润的109%**。发得比赚得多一点，动用的是它过剩的资本——对一家资本常年过剩、又不需要增长投入的银行，这是把多余的本钱退给股东，是好事而不是危险信号。

**杠杆（回报的真实来源）**：总资产约 $64亿 ÷ 股东权益约 $6.7亿 ≈ **9.6倍杠杆**。ROA 只有 1.01%，乘上9.6倍杠杆才变成 9.65% 的 ROE。净息差按净利息收入/总资产估算约 2.8-2.9%（估算）。记住：这个回报建立在杠杆之上，经济严重下行、房价崩塌时会剧烈缩水——只是这家银行的按揭组合是全美最保守的那一档。

## 第三部分：银行口径的估值

| 指标 | 数值 | 说明 |
|---|---|---|
| 市净率 PB | **1.48** | 有形市净率同为1.48（几乎没商誉，账实相符） |
| ROE | 9.65% | ROA 1.01% × 9.6倍杠杆 |
| **投100块年回报 = ROE ÷ PB** | **¥6.5** | 花148块买100块净资产，净资产一年赚9.65块 |
| 市盈率（参考） | 15.9 | 它自己过去五年常年只有 **9.5~13倍** |
| 股息率 | 2.8% | FY2023-24 时是 4.6%~5.2% |
| 股东实得（股息+回购） | ~7.3%/年 | 略超当年利润，退还过剩资本 |
| 三年平均利润口径（参考） | 972.79 ÷ 56.2M = 17.3倍 | TTM利润处在周期回升段，三年平均更实 |

说人话：投100块，买到的是148块换100块账面的银行股权，一年替你赚6.5块，其中约7块多通过分红+回购真的回到你口袋（动用了一点家底）。这个6.5未来变大还是变小：利差修复还有一点尾声红利，但**这家银行的长期形态就是不增长**——十年前它赚这个数，十年后大概率还是赚这个数上下，赚的是周期钱不是成长钱。

关键在价格史：过去五年市场给它的定价常年是 10~13 倍利润、1倍出头的净资产。现在 15.9 倍、1.48 倍——**过去一年+45%的涨幅里，利润只贡献了三分之一，剩下全是估值抬升**。等周期热度退掉，它有的是时间跌回老家。

---

## 第四部分：一句话结论

账本干净得像标本、管理层抠门利落、还在真金白银回购——但 9.65% 的 ROE 是门平庸生意，配 1.48 倍 PB 和它自己历史上从没站稳过的 16 倍 PE，现在买等于在周期高点为「保守」二字付成长股的溢价；喜欢它就等它跌回 1.1 倍 PB 的常态再说。
