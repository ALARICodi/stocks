## 第一部分：它到底做几件事

Interface 卖的东西说穿了很土：**地板**。但它卖的是一种很特别的地板，而且这个特别之处就是它全部的商业模式。

### 核心产品：方块地毯（carpet tile）

传统商用地毯是**卷材**——4 米宽的一大卷，铺的时候要拼缝、要满涂胶水粘死在地上。这有三个致命麻烦：拼缝处永远看得出来；办公室咖啡机旁边那块地毯三年就磨秃了，但你没法只换那一块，得整层撕掉重铺；撕掉的时候整卷废掉，还得停业几天。

Interface 干的事，是把地毯做成 **50cm × 50cm 的方块**，背面用点胶或者互扣结构松铺在地上，不满涂胶。

**举个具体例子**：一家律所要重新装修 5000 平方米的办公层。设计师在图纸上指定 Interface 的某个花色，Interface 的方块地毯单价大约每平米 40–55 美元，这单货值 20 万到 27 万美元。铺装比卷材快一半，因为不用满涂胶、不用等胶干、不用精确裁边。三年后，咖啡机周围那 20 块磨秃了——**保洁自己就能换**：撬起来，从库房拿 20 块同批次的新的按上去，十分钟搞定，花几百美元，办公室照常上班。这就是这个产品在客户端的全部说服力。

而且它还有个隐藏优势：**方块地毯不需要对花**。Interface 有一整套刻意设计成"随机纹理、任意方向铺都对得上"的花色系列，所以铺装工人不用管方向，损耗率从卷材的 10%–15% 降到 3%–5%。

### 真正的护城河：它不卖给用地板的人

这是理解这家公司最关键的一点。**Interface 的销售员不去找律所老板，也不去找物业公司。他们去找室内设计师和建筑师。**

商用装修的流程是：业主雇设计事务所 → 设计师出图，在施工文件里写明"地面材料：Interface [某系列][某色号]" → 总包按图去找地材承包商 → 承包商向 Interface 的经销商下单。**真正决定买谁的是那个写图纸的设计师**，而设计师关心的是花色库够不够大、样品能不能三天寄到、这个牌子在同行里体不体面、以及——

### 可持续性：一家地毯公司凭什么有 40% 毛利率

Interface 从 1990 年代起就是全行业的环保标杆（创始人 Ray Anderson 的"零使命"是商学院案例）。它的方块地毯做到了**全生命周期碳负值**——回收渔网做尼龙纱线、生物基背衬、工厂用可再生电力。

这件事在商业上非常值钱，原因很具体：一栋要拿 LEED 认证的写字楼、一家承诺 2030 年净零的跨国公司总部，**在施工文件里是硬性要求低隐含碳材料的**。而能同时提供 EPD 环境产品声明、碳足迹第三方核证、又有设计师看得上的花色库的地材厂商，全球没几家。这就是为什么一家做地毯的公司能有 **40.48% 的毛利率**——同行里普通地毯厂 25%–30% 就到顶了。

### 另外两条产品线

**nora 橡胶地板**（2018 年花约 4.2 亿美元收购的德国品牌）：卖给**医院和实验室**。手术室地面要求无缝（缝隙藏细菌）、耐消毒剂腐蚀、吸音（推车轮子不吵）、还要有一定弹性（医护人员站十二小时）。橡胶地板是这个场景的标准答案，nora 是这个细分里的第一品牌。这门生意毛利率比地毯更高，但**这笔收购的历史很难看**——2020 年之后 Interface 为 nora 计提过上亿美元的商誉减值，买贵了是公认的。

**LVT 高级乙烯基地板**：木纹、石纹的塑胶板材。毛利率明显低于方块地毯，Interface 做它的理由不是赚钱，是**让设计师能在一家买齐一整层楼的地面**——办公区铺地毯、走廊和茶水间铺 LVT、医疗区铺橡胶，一个供应商、一套样品册、一张订单。这是防守，不是进攻。

**FLOR**：面向消费者的零售品牌，规模很小，可以忽略。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 1711 万美元，占净利润 1.456 亿的 **11.8%**。中等水平，五年里从 547 万涨到 1711 万，涨了两倍多，比营收涨得快得多——这一项在变贵，值得盯。按规矩它已经按 GAAP 扣掉了，我不加回。

**一次性项目**：TTM 财报上**没有**列出重组、减值科目（FY2022 有 3618 万的资产减值，是 nora 相关的，已经翻篇）。

**但有一项必须单独拎出来，是全篇最重要的会计发现：TTM 实际税率只有 16.95%。**

拆一下：税前利润 = 1441 × 12.17% = 1.754 亿；所得税 2971 万；净利润 1.456 亿。**2971 ÷ 17,540 = 16.95%。** 一家美国联邦税率 21%、总部在乔治亚州（州税 5.39%）、另有欧洲业务的制造企业，正常的实际税率应该在 **23%–26%**。16.95% 意味着本期有一笔可观的税务收益。

这类收益通常来自：递延所得税资产的估值备抵转回（以前亏损时计提的"这些税务亏损可能用不上了"的减值，现在盈利了转回来）、境外税收抵免的一次性确认、或不确定税务头寸的时效到期释放。**只看 TTM 一期，我无法确定这具体是哪一种、也无法判断它明年还在不在**——但有一条旁证：现金流量表里"其他经营活动"是 **−1983 万**（一个反向的非现金调整），规模跟这笔税务收益的量级吻合，说明**利润表上确认的这笔税收好处并没有对应的现金流入**。

把税率正常化到 25% 重算：真实净利润 = 1.754 亿 × 75% = **1.315 亿**，比账面的 1.456 亿低 **9.7%**。下面第三部分我按这个口径单列一行。

**资本化的支出**：这是家制造企业，没有软件/内容资本化的花招。

**回购与稀释**：

| 项目 | TTM 金额 |
|---|---|
| 回购股票 | −4931 万 |
| 同期 SBC | 1711 万 |
| **回购 ÷ SBC** | **2.9 倍** |
| 实际股本变化（一年） | **−0.26%** |
| 实际股本变化（一个季度） | **−1.21%** |
| 现金分红 | −595 万（每股 $0.12，股息率 0.31%，派息率 4.45%） |

2.9 倍**刚好卡在"真回购"门槛（3 倍）的下沿**。年度股本只减了 0.26%，但**最近一个季度减了 1.21%**——回购是最近才明显加速的（TTM 4931 万 vs FY2025 全年 2655 万 vs FY2024 只有 477 万）。这是个正面信号：管理层刚还完债，现在开始把钱转向股东。但目前累计的效果还很小，别把年报里那个"0.26%"当成什么了不起的回馈。分红等于没有。

**利润和现金流的差**：净利润 1.456 亿，经营现金流 1.779 亿，自由现金流 1.240 亿。逐项对账：

| 步骤 | 金额（百万美元） |
|---|---|
| 净利润 | 145.55 |
| ＋ 折旧摊销 | +39.95 |
| ＋ 股权激励（非现金） | +17.11 |
| ＋ 坏账计提 | +1.44 |
| **− 其他经营活动（非现金反向调整，疑与低税率有关）** | **−19.83** |
| − 应收账款增加 | −17.17 |
| − 存货增加 | −5.12 |
| ＋ 应付账款增加 | +19.78 |
| − 其他经营性资产净变化 | −3.77 |
| **＝ 经营现金流** | **177.93** |
| **− 资本开支** | **−53.90** |
| **＝ 自由现金流** | **124.03** |

这张表说明三件事：

1. **营运资金几乎不占钱**（应收 −17.17、存货 −5.12、应付 +19.78，净额只有 −2.5 百万）。生意在长，但没有靠压货或者放账把利润做出来。这一项健康。
2. **那 −1983 万的"其他经营活动"是本期利润里没有现金支撑的部分**，跟上面 16.95% 的税率是同一件事的两面。
3. **资本开支已经超过折旧 35%，而且在急剧上升**：FY2022 只花 1844 万，FY2023 2611 万，FY2024 3379 万，FY2025 4619 万，TTM **5390 万**，四年翻了近三倍，同期折旧从 4538 万一路降到 3995 万。**这就是为什么 P/FCF（18.15 倍）比市盈率（15.77 倍）还高**——账上的利润有一部分正在被投回工厂。这跟大多数公司相反，也跟同批次的 MCRI 正好相反（那家资本开支只有折旧的 40%，自由现金流被虚增）。

这笔钱花在哪没有明说，合理推测是产能自动化和满足关税环境下的本地化生产。**这是好是坏取决于回报**：如果这些投入能把毛利率再推上去，那是划算的；如果只是维持竞争位置的军备开支，那自由现金流的真实水位就是 1.24 亿，对应 5.5% 的收益率，不算高。

**资产负债表 —— 过去五年真正的故事在这里**：

| 财年 | 总债务 | 净负债 | 净利润 |
|---|---|---|---|
| FY2021 | 6.16 亿 | −5.18 亿 | 5523 万 |
| FY2023 | 5.15 亿 | −4.05 亿 | 4452 万 |
| FY2025 | 2.75 亿 | −2.03 亿 | 1.161 亿 |
| **当前** | **2.90 亿** | **−2.09 亿** | **1.456 亿（TTM）** |

五年还掉一半以上的债。这是 EPS 从 0.94 涨到 2.47（涨 163%）的重要来源之一——利息支出大降。现在利息覆盖倍数 12.11、债务/EBITDA 只有 1.14、Altman Z 分 4.29，资产负债表已经修好了。

但反过来说：**这根杠杆已经拉完了**。从 6.16 亿还到 2.9 亿能省下的利息，未来五年不可能再省一遍。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 22.5 亿 ÷ 1.456 亿 | **15.8 倍** | **6.34 元** |
| 公司自己吹的 Non-GAAP | 公司主推调整后 EPS 和调整后 EBITDA（TTM 约 2.30 亿），取数页不提供对应市盈率 | — | — |
| **剔除障眼法后的真实市盈率**（税率正常化到 25%） | 22.5 亿 ÷ 1.315 亿 | **17.1 倍** | **5.85 元** |
| 自由现金流口径 | 22.5 亿 ÷ 1.240 亿 | **18.2 倍** | **5.51 元** |
| 企业价值口径 EV/EBIT | 24.6 亿 ÷ 1.904 亿 | **12.9 倍** | **7.75 元** |
| 三年平均利润口径 | 22.5 亿 ÷ [(1.456 + 1.161 + 0.870) ÷ 3 = 1.162 亿] | **19.4 倍** | **5.16 元** |

**大白话**：你现在投 100 块进 Interface，按**最保守的三年平均利润口径**算，公司一年替你赚 **5.16 元**；按当期 GAAP 口径算，赚 **6.34 元**。

**这张表里差距最大的是第一行和最后一行：15.8 倍 vs 19.4 倍，差 23%。** 而且如果把窗口再往前拉一年，差距会大得吓人——**FY2022 这家公司的净利润只有 1956 万**（当年有 3618 万减值），FY2023 是 4452 万。也就是说：

> **Interface 的净利润在四年里从 1956 万涨到 1.456 亿，涨了 7.4 倍，而同期营收只涨了 11%。**

营收从 12.98 亿到 14.41 亿，涨 11%；净利润涨 644%。这个反差就是理解这家公司当前估值的全部要点：**过去四年赚的钱，绝大部分不是卖出去更多地毯赚的，是三件事叠出来的——毛利率从 33.5% 修到 40.5%、还债省下的利息、以及本期这个 16.95% 的低税率。**

前两件是真本事（提价能力 + 财务纪律），但**三件都是一次性的、不可重复的**。毛利率不可能再修 7 个点，债不可能再还一遍，税率不可能再降。

一个直接的印证：**远期市盈率 16.20 倍，高于当前的 15.77 倍**。市场明确预期未来 12 个月每股利润会**下降**，尽管三家分析师给的评级是"强烈买入"、目标价 45.25 美元（比现价高 16%）。这两件事同时成立，说明卖方认为下降是暂时的（大概率就是税率回归正常）。

**这 6.34 元里有多少真回到你口袋**：分红 595 万 + 回购 4931 万 = 5526 万，除以市值 = **2.5%**。剩下的钱去了哪？**5390 万去了资本开支、1.06 亿去了还债**。所以现阶段这家公司的现金分配次序是：还债 > 建厂 > 回购 > 分红。债已经还得差不多了，接下来这 1.06 亿会转向哪里，是判断未来股东回报的关键——如果转成回购，2.5% 会变成 5% 以上。

**这个 X 未来会变大还是变小**：分析师预测未来三年营收年增 6.60%、EPS 年增 12.33%。我认为**EPS 那个数字偏乐观**，因为三根杠杆都拉到头了，12% 的 EPS 增长得靠营收和利润率同时再往上走。营收端确实有支撑：办公楼回归率在恢复、教育和医疗的地材更新周期是刚性的、方块地毯对卷材的替代还在继续。但要留意——

**风险集中在一个词：周期。Beta 1.91**（是全市场平均波动的近两倍），空头持股占流通股 7.43%。这是一家**商业装修**公司，收入直接绑定写字楼、学校、医院的翻新预算，而这些预算是经济一转弱最先被砍的。历史清清楚楚地演示过这一点：

- FY2023 营收只跌了 2.81%（12.98 亿 → 12.61 亿），**净利润却从 1956 万起步、在低位挣扎了整整两年**。
- 一家固定成本占比高的制造企业，营收跌 10%，经营利润可能跌 40%。13.22% 的经营利润率经不起太大的营收下滑。

再叠加一个当下的事实：**股价过去 52 周涨了 47.22%**，RSI 67，200 日均线 30.14 而现价 38.9——现在的价格比过去一年的平均水平高了近 30%。

## 第四部分：一句话结论

**好公司，好生意，但这个 15.8 倍不像看上去那么便宜——现在是在为一个周期的好时候付全价，值得放进名单但不值得追。**

先说它确实好在哪，这几点是真的：**ROIC 18.12% 对 WACC 13.59%，利差 4.5 个百分点**，是一门真正在创造价值的生意；40.48% 的毛利率对一家做地板的公司来说是异常优秀的成绩，来源是"设计师指定 + 可持续性认证"这个双重壁垒——竞争对手要复制的不是产线，是三十年的品牌积累和一整套第三方碳核证；营运资金零占用、账面清爽、五年还掉一半债务、最近开始加速回购。管理层做的每一件事都做对了。

但要打折的地方也很清楚，三条：

第一，**15.77 倍这个数字被一个 16.95% 的税率美化了。** 正常化到 25% 就是 17.1 倍，而三年平均口径是 19.4 倍。远期市盈率 16.20 倍高于当前市盈率，市场自己就在说这个利润水平不可持续。

第二，**过去四年利润涨 7.4 倍而营收只涨 11%，这三根撬棍都已经拉到头了。** 毛利率修完了、债还完了、税率没法更低了。往后想涨利润，只能靠真正卖出去更多地毯，而营收五年复合增速只有 3.7%。

第三，**这是 Beta 1.91 的强周期股，而现在处在周期的好位置，股价一年涨了 47%。** 这家公司四年前的净利润是 1956 万——不是 1.456 亿，是 1956 万。同一批楼、同一批设计师、同一个产品，只是那年商业装修不景气加上一笔减值。**买这家公司真正的问题不是"15.8 倍贵不贵"，而是"1.456 亿这个分母能撑几年"。**

**该怎么对待它**：适合放进观察名单，等一个更差的宏观时点。两个具体的买点信号：一是**下个财年税率回归正常后市盈率自然抬到 17–18 倍，股价却没跌**——那说明市场认账了这个利润水平；二是**商业装修数据转弱把股价打回 200 日均线（约 30 美元）附近**——那时候你买的是同样一门 18% ROIC 的生意，价格便宜 23%。现在这个位置，向上的空间是分析师那 16% 的目标价，向下的空间是这门生意四年前证明过的样子，赔率不对称。
