# KYMR · Kymera Therapeutics（凯梅拉制药）

市值 95.6 亿美元 · 股价 116.47 美元（2026-09-11 收盘）· 生物科技（口服蛋白降解药）· TTM 截止 2026-06-30 · **亏损公司，第三部分用亏损口径**

## 第一部分：它到底做几件事

说到底就一件事：**用能口服的小分子药，把细胞里某一个特定的蛋白「拆掉」**，做成可以替代打针的免疫病药。财报上的两条线——合作收入和自家管线——是同一件事的两种变现方式。

### 先讲清楚这门技术

传统药物的思路是「堵」：找到坏蛋白上的一个口袋，用分子把它塞住，蛋白还在，只是干不了活。问题是很多关键蛋白身上根本没有可以塞的口袋，几十年来被称为「无法成药」。Kymera 的办法是「拆」：它的分子一头抓住目标蛋白，另一头抓住细胞自带的垃圾回收系统（泛素-蛋白酶体），把两者拉到一起，回收系统就把目标蛋白当垃圾处理掉了。一个药物分子拆完一个还能接着拆下一个，所以剂量很低、效果很彻底，而且不需要口袋，只要能碰上就行。这就是「靶向蛋白降解」，Kymera 是这个领域做免疫病最靠前的公司。

### A. 自家主打：KT-621，口服版的 Dupixent

Dupixent（度普利尤单抗）是赛诺菲和再生元的注射剂，治特应性皮炎、哮喘、鼻息肉、慢阻肺，一年卖 140 亿美元以上，是全球最赚钱的免疫药之一。它的原理是在细胞外面拦住 IL-4 和 IL-13 两个炎症信号。这两个信号进入细胞后，最终都要靠一个叫 STAT6 的蛋白去「开灯」——STAT6 是转录因子，身上没有口袋，抗体进不了细胞，所以以前没人能直接对付它。KT-621 干的就是把 STAT6 拆掉，等于从屋里拔了灯的总闸，理论上跟 Dupixent 一样堵死了这条通路，但形式是每天一粒药。

具体到病人：一个中重度特应性皮炎患者，现在每两周打一针 Dupixent，美国标价约 3,800 美元一个月，一年 4.6 万美元，要冷藏、要扎针。如果 KT-621 上市，他改成每天吃一粒；对公司来说，就算定价打 Dupixent 的六折，每人每年也是两三万美元。

进度：2025 年 6 月健康人一期数据显示血液里 STAT6 降解超过 90%，炎症指标（TARC、嗜酸粒细胞趋化因子）下降幅度跟 Dupixent 打针的历史数据相当，没有明显安全问题——股价一年涨 168%，主要就是这一条。之后在特应性皮炎病人身上做了一期 b（BroADen），现在同时跑特应性皮炎和哮喘的二期 b。乐观估计 2028–2029 年上市，中间还要过二期 b、三期两道关，任何一道关的数据不如预期，这个故事就要重新定价。

### B. 后面排队的：KT-579（IRF5）和 KT-295（TYK2）

同一套技术换靶点。IRF5 是狼疮、类风湿、干燥综合征里的核心开关，也是「无法成药」名单上的老面孔；TYK2 对应银屑病和银屑病关节炎，走的是 BMS 口服药 Sotyktu 同一条路，Kymera 的说法是降解比抑制更彻底。两个都在一期，离收钱至少五年。2025 年公司把肿瘤方向（MDM2、STAT3 降解剂）全砍了，把钱集中到免疫病上。

### C. 合作收入：把早期项目卖给大药企

- **赛诺菲**：2020 年拿了 1.5 亿美元首付，把 IRAK4 降解剂（KT-474）交给赛诺菲做二期（化脓性汗腺炎、特应性皮炎）。后续开发费用赛诺菲出，Kymera 等里程碑款和上市后的销售提成。
- **吉利德**：2025 年 1 月，把 CDK2 降解剂（肿瘤）授权出去，首付 8,500 万美元，总额最高 7.5 亿。

TTM 营收 1.05 亿美元全是这类合作收入，比 2025 全年的 0.39 亿翻了一倍多。看现金流量表能猜出发生了什么：递延收入这一年减了 4,000 万（把以前收的首付款按进度确认成收入），另外新冒出 2,000 万应收账款，说明上半年触发了一笔里程碑。**这种收入不是生意，是一次性的**——单期口径判断不了明年还有没有，也判断不了赛诺菲那个项目最终会不会推进。

## 第二部分：把会计障眼法剥掉

- **股权激励（SBC）**：TTM 6,520 万美元，占经营亏损的 19%、占营收的 62%——每收 100 块合作款，就发 62 块股票给员工。当真实成本扣，它已经在 GAAP 亏损里。
- **一次性项目**：资产减值 386 万，忽略不计。要警惕的反而在收入端：那 1.05 亿里有多少是里程碑款，单期口径分不清。
- **资本化的支出**：没有。资本开支只有 119 万美元，实验室早就建好了。
- **回购与稀释**：零回购。TTM 增发 8.32 亿美元，2025 全年 10.44 亿，2024 年 6.39 亿——三年从股东口袋里拿了 25 亿。股本一年膨胀 17.7%：你去年持有公司的 1%，今年只剩 0.85%。趁高位增发是正确的做法，但代价是你出的。
- **利润和现金流的差**：净亏 3.00 亿，经营现金流 −2.37 亿，差 6,300 万，逐项对账：

| 项目 | 金额（亿美元） |
|---|---|
| 净亏损 | −3.00 |
| + 折旧摊销 | +0.08 |
| + 股权激励（不花现金） | +0.65 |
| + 减值 | +0.04 |
| − 投资收益（归投资活动） | −0.09 |
| + 收回应收账款 | +0.20 |
| + 应付款增加 | +0.03 |
| − 递延收入减少（以前收的钱现在才算收入，没有新现金） | −0.40 |
| + 其他经营资产变动 | +0.12 |
| **= 经营现金流** | **−2.37** |

真实烧钱速度是每年 2.4 亿美元。另外有约 4,700 万利息收入（15 亿现金存着生的利息）在帮忙填坑，利率一降这块就缩。

大白话：假设它明天就做到成熟药企的利润率，你投 100 块一年赚不到 4 毛钱。反过来算，95.6 亿市值要值 20 倍市盈率，得每年净赚 4.8 亿，按 35% 净利率要 13.7 亿美元营收——也就是 KT-621 得成为一个年销十几亿美元的药。而它现在在二期 b，离上市至少 3 年，这期间你每年还要被稀释 10–18%。

这个价在赌什么：Dupixent 一年 140 多亿美元，口服版哪怕抢 10% 就是 14 亿。市场现在是按「KT-621 大概率成功、并且能拿到 Dupixent 一成以上份额」定价的。可以对照一个先例：BMS 的 Sotyktu 2022 年上市，当年被吹成「口服替代注射」的标杆，上市头几年销售也只有几亿美元——口服替代注射的故事，落地比讲的慢，医生和保险公司换药都不快。

## 第四部分：一句话结论

**它会不会死**：不会。账上 14 亿净现金，按现在的速度烧到 2030 年都不用再融资，只是中间大概率还会趁高位增发。

**活成了值不值**：不值。95.6 亿是在为一个二期 b 阶段的药预支「口服 Dupixent」的全部愿景，假想市盈率 260 倍，从现在到上市至少三年、两道临床关。技术是真的、团队是行内前排，但这个价格没给失败留任何余地。想买的，等二期 b 数据（2027 年前后）出来再看，那时候要么便宜一半，要么贵一倍但确定性高得多。
