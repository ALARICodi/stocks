# HQI · HireQuest 公司

**市值** 2.275 亿美元 | **股价** 约 16.38 美元 | **行业** 商业服务（人力派遣特许经营） | **TTM 截止** 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

这家公司最容易被看错的地方是：**它看起来是一家人力派遣公司，实际上是一家收加盟费的特许经营商。** 搞不清这个区别，后面所有数字都会读错。

一个数字先摆在这里：**全公司只有 88 个员工，年收入 3015 万美元，毛利率 100%。** 一家「人力公司」怎么可能毛利率 100%？因为它根本不发工人的工资——它收的是抽成。

### 生意一：加盟royalty（特许经营抽成）—— 占收入约 90%，是这家公司的全部

**先讲一遍钱是怎么流动的，这是理解这家公司唯一需要搞懂的事。**

老王在一家全国性劳务派遣公司当了十年分公司经理，攒了本地的客户关系，想自己单干。他找到 HireQuest 买一个加盟权。

开张之后，老王每天干这些事：附近一个仓库明天早上需要 12 个理货工，一个屋顶工程队后天需要 4 个壮工，一家会展中心周末需要 30 个搭台工。老王去谈这些单子，去招这些工人（美国日结劳务市场，很多是当天到店、当天派活、当天拿钱）。

**关键在这里：这些工人在法律上不是老王的员工，是 HireQuest 总部的员工。**

- 工人的工资，由 HireQuest 总部垫资发放（每天）；
- 工人的工伤保险（workers' compensation），由 HireQuest 总部投保和承担；
- 工资税、W-2 报税表、劳动合规，全部由 HireQuest 总部处理；
- 给仓库开的发票，抬头也是 HireQuest，钱先进总部账户。

仓库付了 1 万美元的账单，总部收到之后：扣下大约 **6% 的抽成（600 美元）**归自己，剩下的 9400 美元划给老王，老王用这笔钱付工人工资、付自己的房租和自己的收入。

**所以 HireQuest 的收入表上只记那 600 美元，不记那 1 万美元。**

这就解释了三个乍看很怪的数字：
- **毛利率 100%**：抽成没有对应成本，工人工资根本不进它的损益表；
- **人均收入 34.26 万美元**：88 个总部员工，撑起全系统超过 6 亿美元的开票流水；
- **资本开支一年 3 万美元**：字面意思，一年花三万块买办公设备，这家公司几乎不需要资产。

**加盟商为什么愿意交这 6%？** 因为他自己干不了那三件事：垫付日结工资需要几百万的周转金；工伤保险单独去买，一家小公司拿不到费率也可能被拒保（屋顶工、拆除工的工伤费率极高）；五十个州的劳动合规和报税，一个人搞不定。他交 6%，买的是「我只管跑客户和招人，剩下的总部包了」。

**旗下的品牌（不同品牌抽成比例不同）：**
- **HireQuest Direct** —— 日结体力工，建筑、仓储、活动搭建。这是收入的基本盘，也是抽成比例最高的。
- **Snelling / LINK Staffing** —— 商务和文职临时工，前台、客服、会计助理。
- **DriverQuest** —— 持商用驾照的卡车司机派遣。
- **HireQuest Health** —— 护士、医技人员。
- **MRINetwork** —— 2023 年收购来的高管猎头网络，按录用者年薪的百分比收费，抽成模式和日结完全不同。
- **TEC Staffing / Northbound** —— 区域性商务派遣。

### 生意二：服务收入（利息和后台费）—— 占收入约 10%

两部分。一是**资金占用的利息**：总部每天垫钱发工资，但客户的账单要 30 到 60 天才收得回来，这中间的垫资总部要向加盟商收利息。二是**后台服务费**：用总部的工资系统、保险平台、合规支持，按使用量另外收一小笔。

这部分毛利也接近 100%，本质上是把「总部垫资」这件事变现了两次——一次收抽成，一次收利息。

### 这两块生意的钱

| 生意 | TTM 收入（百万美元，估算拆分） | 占比 | 毛利率 | 说明 |
|---|---|---|---|---|
| 加盟抽成 royalty | 约 27 | 约 90% | 100% | 按加盟商开票流水的约 6% 抽 |
| 服务收入（利息 + 后台费） | 约 3 | 约 10% | 100% | 垫资利息和系统使用费 |
| **合计（实际数）** | **30.15** | 100% | **100%（实际）** | |

> 说明：财报不按分部披露，**上表拆分为估算**。总收入 3015 万、毛利 3015 万、经营利润 925 万（利润率 30.68%）、净利润 816 万为实际数。

### 这个模式好在哪、坏在哪

**好：** 总部几乎没有固定成本（88 人），没有资本开支（一年 3 万），没有存货，没有债务。加盟商自己承担跑客户和招人的成本和风险。总部躺着收全系统流水的过路费，经营利润率 30.68%，投入资本回报率 12.62%。这是一个结构上很干净的收租模式。

**坏——而且这个「坏」正在发生：**

第一，**日结体力工是经济周期里最先被砍掉的东西**。仓库订单少了，第一个动作就是不叫临时工。看收入曲线：

| 财年 | 收入（百万） | 同比 |
|---|---|---|
| FY2022 | 30.95 | +37.4% |
| FY2023 | 37.88 | +22.4% |
| FY2024 | 34.60 | −8.7% |
| FY2025 | 30.64 | −11.4% |
| **TTM（2026年6月）** | **30.15** | **−7.5%** |

**从 FY2023 的峰值 3788 万，连跌三期到 3015 万，累计下滑 20.4%。** 而且 FY2023 那个峰值本身还是靠收购（MRINetwork、Dubin）堆出来的，内生下滑更陡。这不是一个季度的波动，是连续三年的收缩。

第二，**工伤保险的尾巴挂在总部身上**。总部是所有派遣工人法律上的雇主，屋顶工、拆除工、仓储工的工伤索赔全部由总部承担。公司自留了第一层风险、账上计提工伤准备金——这个准备金是一个**会计估计**，往低了估当期利润就好看，几年后索赔陆续了结时再补提。这是这个商业模式里最大的一块隐藏负债，也是外部投资者最难验证的一项。

第三，**收购没有全部成功**。FY2024 有 **604 万美元的资产减值**，把当年净利润砸到只剩 367 万；TTM 内又减了 67 万。他们在 2021–2023 年花了大约 7500 万现金做了一串收购（Snelling、LINK、Dubin、MRINetwork），现在在陆续给其中一部分做减值。P/TBV（有形账面市净率）5.12 倍 vs PB 3.30 倍，这个差距就是账上还挂着的商誉和无形资产。

## 第二部分：把会计障眼法剥掉

这家公司的账整体是干净的，但有一项需要特别拎出来，因为它直接影响你该给这家公司多少倍市盈率。

### 一、8.91% 的所得税率 —— 本篇最需要警惕的一项

TTM 税前利润 925 万，缴税 **82.4 万**，实际税率 **8.91%**。

正常美国公司联邦加州的综合税率在 22%–26%。这家公司只交了不到 9%，差额去哪了？答案是 **WOTC（工作机会税收抵免）**——联邦政府为了鼓励企业雇佣特定群体（退伍军人、长期失业者、有前科人员、领食品券家庭成员），给雇主按每人几千美元的抵免额。

日结劳务派遣公司恰恰是这类人群最大的雇主之一。HireQuest 作为几万名派遣工的法定雇主，能大规模申报这项抵免。

**该怎么看这一项：**
- 它是**真实的、可持续的**——只要商业模式不变，这个抵免年年都有，不是一次性的；
- 但它**不是经营能力**，是税收政策补贴。WOTC 需要国会定期重新授权（历史上曾多次接近失效再被延期），政策一变，利润立刻少一截；
- 所以估值时应该**按正常税率还原来看**：925 万税前，按 24% 正常税率算，净利润应该是 703 万，而不是报出来的 816 万。**报表净利润被税收政策垫高了约 16%。**

### 二、股权激励（SBC）：82 万美元，克制

TTM 股权激励 82 万，占净利润 816 万的 **10.0%**。这是个很低的比例，管理层没有借股票给自己发钱。内部人持股 44.57%——他们本来就是大股东，靠股价而不是靠发股赚钱。这一项干净。

### 三、回购与稀释

| 项目 | TTM 金额 |
|---|---|
| 回购股票 | 280 万美元 |
| 股权激励 SBC | 82 万美元 |
| **回购 ÷ SBC** | **3.4 倍** |
| 分红 | 336 万美元（每股 0.24 美元） |
| 股本变化（同比） | **−0.50%** |

回购 3.4 倍于 SBC，刚刚够到「真回购」的门槛线。但注意股本只减少了 0.50%——因为回购的大部分被员工发股和加盟交易中的发股抵消掉了。

分红 336 万 + 回购 280 万 = **616 万**，占净利润 816 万的 **75.5%**，占市值的 **2.7%**。这是本批三家里唯一真金白银往股东口袋里放钱的公司。

### 四、一次性项目

- **资产减值 67 万（TTM）**：FY2024 是 604 万，FY2025 是 67 万，TTM 是 67 万。**这就是典型的「年年都有的一次性」**——连续三年都在减值收购来的资产。单期口径下无法判断明年还有没有，但从三年的记录看，把它当成经常性费用更安全。
- **资产处置收益 −25 万（即收益 25 万）**：公司会定期把自营的分支机构卖给加盟商，卖的时候确认一笔收益。FY2023 是 203 万损失，FY2022 是 223 万损失，TTM 是 25 万收益。这项在损益表上跳来跳去，也属于「年年都有的一次性」。
- 没有诉讼和解，没有重组费用，没有税务一次性调整。

### 五、资本化的支出：没有

不资本化软件开发费，不资本化内容成本。资本开支一年 3 万美元。这一项干净得不能再干净。

### 六、利润和现金流的差：几乎没有差，这是它最大的优点

净利润 816 万，经营现金流 949 万，自由现金流 **945 万**。**自由现金流比净利润还高 16%。**

| 项目 | 金额（百万美元） |
|---|---|
| 净利润 | **8.16** |
| ＋ 折旧摊销 | +3.08 |
| ＋ 股权激励 SBC | +0.82 |
| ＋ 资产减值 | +0.67 |
| ＋ 坏账计提 | +0.68 |
| − 资产处置收益 | −0.25 |
| ＋ 其他经营项 | +0.52 |
| 小计（营运资金变动前） | 13.68 |
| − 应收账款增加 | −6.10 |
| ＋ 应付账款增加 | +0.11 |
| ＋ 其他经营性资产 | +1.82 |
| **＝ 经营现金流** | **9.49** |
| − 资本开支 | −0.03 |
| **＝ 自由现金流** | **9.45** |

这张表很短，因为没什么可对账的。**利润就是现金，现金就是利润**，这是特许经营模式的天然优点。唯一值得注意的是应收账款增加了 610 万——在收入下滑 7.5% 的情况下应收还在涨，这是垫付给加盟商的工资款在变多，需要盯着（回款周期变长通常是加盟商经营吃紧的早期信号）。

**这一项和本批另外两家形成了强烈对比：TSSI 报了 1437 万利润却烧掉 2098 万现金，HDSN 报了 902 万利润却烧掉 3451 万现金，HQI 报 816 万利润、真收到 945 万现金。**

## 第三部分：市盈率，多口径

市值 2.2753 亿美元，企业价值 2.2589 亿美元（净现金仅 164 万），账面价值 6886 万美元。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 227.5 ÷ 8.16 | **27.9 倍** | **3.59 元** |
| 公司口径（调整后 EBITDA） | 公司不披露调整后净利润，调整后 EBITDA 约 1233 万 | 不适用 | — |
| **剔除障眼法后的真实市盈率** | 227.5 ÷ 7.54（税前 925 万 ＋ 减值 67 万，按 24% 正常税率还原） | **30.2 倍** | **3.31 元** |
| 自由现金流口径 | 227.5 ÷ 9.45 | **24.1 倍** | **4.15 元** |
| 企业价值口径 EV/EBIT | 225.9 ÷ 9.25 | **24.4 倍** | **4.10 元** |
| **三年平均利润口径** | 227.5 ÷ 6.05（FY24 367 万、FY25 633 万、TTM 816 万） | **37.6 倍** | **2.66 元** |
| 市净率（参考） | 227.5 ÷ 68.9 | 3.30 倍（有形 5.12 倍） | |

**这张表里最要命的是最后一行。**

三年平均市盈率 **37.6 倍**，比当期的 27.9 倍**高出三分之一**。这说明当前这 816 万净利润，是过去三年里**最好的一年**，不是最差的一年。你不是在周期底部买它——恰恰相反，你是在它这三年的利润高点上，付了 28 倍。

（这里可以和本批的 HDSN 直接对照：HDSN 当期 25.3 倍、三年平均 13.7 倍，是利润被砸在底部；HQI 当期 27.9 倍、三年平均 37.6 倍，是利润在近三年的顶部。两家的当期市盈率看起来差不多，含义完全相反。）

再把税收优惠还原掉，真实倍数是 **30.2 倍**。

而这 30 倍买的是一家**收入连续三年下滑、累计下滑 20.4%** 的公司。

**说人话：你现在投 100 块进去，按最保守的真实口径算，公司一年替你赚 3 块 3 毛 1。**

这 3 块 3 里，有多少真正回到你口袋：**大约 2 块 7**（分红 336 万 + 回购 280 万 = 616 万，占市值 2.7%）。这是本批三家里唯一一家真正把钱还给股东的——比例高达净利润的 75.5%。剩下的留在公司里，但公司几乎不需要资本开支（一年 3 万），所以留存的部分主要是在补账上那 164 万可怜的现金余额和还债（TTM 还了 433 万债，现在零负债）。

这个 3 块 3 未来变大还是变小：

- **变大的理由**：模式本身没有问题——30.68% 的经营利润率、零资本开支、零负债、ROIC 12.62%，如果劳务市场回暖，收入回到 FY2023 的 3788 万，利润率不变的话经营利润是 1163 万，按正常税率净利润约 884 万。**注意：即使完整恢复到三年前的最好水平，市盈率也还有 25.7 倍。** 另外前瞻市盈率 21.84 倍显示卖方预期明年会回升。
- **变小的理由**：收入还在跌（TTM −7.5%），没有见底信号；应收账款在收入下滑时反而增加 610 万，加盟商的资金状况值得警惕；WOTC 税收抵免是政策，不是能力；工伤准备金是估计，不是事实；连续三年在给收购资产减值。
- **还有一个不能忽略的技术因素**：**流通股只有 518 万股，日均成交量 31755 股**——按这个成交量，把流通股换一遍手需要 163 个交易日。内部人持股 44.57%。股价过去 52 周涨了 **71.16%**，但在一个每天只成交三万股的池子里，几笔买单就能把价格推上去。**这 71% 的涨幅里，有多少是基本面、有多少是没货可买，是分不清的**——而且它在下跌时同样没有承接。

## 第四部分：一句话结论

**模式是真好，账是真干净，价格是真不合适——好公司，坏价格。**

先把好话说完：这是本批三家里商业模式最优的一家。88 个人收全系统 6 亿流水的过路费，30.68% 的经营利润率，一年 3 万块的资本开支，零负债，利润百分之百转化成现金（自由现金流 945 万还高于净利润 816 万），内部人持股 44.57%，一年把 75.5% 的利润以分红加回购的形式还给股东。这些都是真的，没有一项需要打折。

但价格不成立：

**27.9 倍 GAAP，还原税收优惠后 30.2 倍，三年平均口径 37.6 倍——而收入已经连续三年下滑，累计跌了 20.4%，至今没有见底信号。** 三年平均口径比当期还高，明确告诉你现在这个利润是近三年最好的，不是最差的。

更要命的是算一下最好的情况：即使劳务周期完全反转、收入回到三年前的峰值 3788 万，按正常税率算的市盈率也还有 **25.7 倍**。也就是说，**这个价格里已经把完整的周期复苏预期计价进去了，而复苏还一点没发生**。买它你既没有安全边际，也没有赔率。

最后，股价一年涨了 71.16%，但日均成交只有 3 万股、流通盘只有 518 万股。在这么薄的池子里，**价格能被少量资金推上去，也能被少量资金砸下来**。这不是一个可以按基本面从容进出的标的。

**结论：把它放进「等」的名单，不是「买」的名单。等两个信号——收入同比转正、股价回到 12 美元以下（对应还原税率后约 22 倍）。现在 16.38 美元不值。**
