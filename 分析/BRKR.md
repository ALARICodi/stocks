# BRKR · 布鲁克（Bruker）

市值 81.4 亿美元 · 股价 53.43 美元 · 医疗科技 / 科学仪器 · TTM 截止 2026-06-30（任务5 亏损榜第 96 名，2026-09-12）

> 这是一家「账面亏」的公司：TTM 报亏 1.07 亿，但经营利润 3.11 亿为正、经营现金流 1.9 亿为正。亏损来自约 2.5 亿的减值（2024 年花 16 亿买的几家公司开始认亏）加上一年 3200 万的优先股股息。第三部分照常做市盈率表，GAAP 那行写「无意义」，主角是剔除减值后的真实口径。

## 一、它到底做几件事

布鲁克是德国物理学家 Günther Laukien 1960 年创办的，现在由他儿子 Frank Laukien 当 CEO，家族持股约 32%。它做的是**科学家用的高端仪器**——大学、药企、医院检验科、半导体厂、军队都是客户。财报分四个分部，实际上前三个（合称 BSI）是一套仪器生意，第四个（BEST）是超导线材，两门。

### 生意 A：科学仪器 BSI（约 92% 营收），三个分部

**BioSpin（25%）——核磁共振波谱仪 NMR。**大白话：把一个分子放进超强磁场里，用射频「敲」它，听它回响，就能知道分子的结构。药企用它确认合成出来的分子对不对，大学用它研究蛋白质。布鲁克是这个领域**近乎垄断**的厂商——2014 年安捷伦退出后，高场 NMR 全世界只有它一家能做。一台最顶级的 1.2 GHz 系统一千五百万到两千万美元，磁体要用液氦冷却、占一间屋子。客户主要是大学和国家实验室，钱来自政府科研预算，所以这块生意的问题是**看政府脸色**：美国 NIH 削经费、欧洲财政紧、中国反腐加关税，订单就断档。这个分部营收从 2024 年的 9.06 亿掉到 TTM 的 8.69 亿，连跌两年。也做临床前小动物 MRI 和台式 NMR。

**CALID（36%，最大、增长最好）——质谱、光谱、探测器、诊断。**几样东西：
- **MALDI Biotyper**：医院微生物实验室的标配。以前鉴定病人感染的是哪种细菌要培养两三天，用它把菌落抹在靶板上，几分钟出结果。全球装了六千多台，每台每天消耗靶板和试剂——**仪器卖一次，耗材卖十年**，这是布鲁克最像「好生意」的一块。
- **timsTOF 质谱仪**：做蛋白质组学研究的旗舰，一台一百万美元上下，卖给研究所和药企。
- **红外/拉曼光谱仪**：化工、制药质检、半导体用。
- **CBRNE 探测器**：给军队和第一响应者用的化学、生物、核辐射、爆炸物探测设备，跟着国防预算涨。
- **ELITech**（2024 年收购）：分子诊断和生化分析仪，让 CALID 更偏向医院端。

**Nano（31%）——X 射线、原子力显微镜、半导体量测、空间生物学。**X 射线衍射/荧光仪（材料、矿业、半导体），原子力显微镜（纳米级表面），**半导体 X 射线量测**（芯片厂用来检查 HBM 高带宽内存和先进封装，这是跟着 AI 芯片涨的一块，也是 Nano 里唯一的亮点），荧光显微镜。还有 2024 年从破产清算里买来的 **NanoString**（空间生物学：在一片组织切片上原位看每个细胞的基因表达）——技术很好，但一直亏钱，是拖累 Nano 利润率的主因。Nano 营收 TTM 10.83 亿，两年没动。

### 生意 B：超导线材 BEST（约 8% 营收）

大白话：医院里的 MRI 机器靠超导磁体，磁体要用铌钛、铌三锡超导线绕成。布鲁克是西门子、GE、飞利浦这三家 MRI 巨头的主要线材供应商，也给 ITER 核聚变项目和私营聚变公司供货。**低毛利的材料生意**（估算经营利润率 5% 上下），但随核聚变热潮在涨，TTM +5.7%。

### 四个分部的钱

财报只披露到分部营收，经营利润按公司非 GAAP 口径**估算**：

| 分部 | TTM 营收 | 同比（vs FY2025） | 占比 | 估算经营利润率 | 估算贡献利润 |
|---|---|---|---|---|---|
| BioSpin 核磁 | 8.69 亿美元 | −1.1% | 25% | ≈15% | ≈1.3 亿 |
| CALID 质谱/诊断 | 12.71 亿美元 | +5.0% | 36% | ≈17% | ≈2.2 亿 |
| Nano X 射线/显微 | 10.83 亿美元 | −0.1% | 31% | ≈8%（NanoString 拖累） | ≈0.9 亿 |
| BEST 超导线 | 2.86 亿美元 | +5.7% | 8% | ≈5% | ≈0.1 亿 |
| 合计 | 35.0 亿美元 | +1.65% | | GAAP 8.9% | 3.11 亿 |

**要看趋势**：2021–2023 年是好日子，营收 24 亿涨到 30 亿、经营利润率 17–18%。2024 年花 16 亿一口气买了 NanoString、ELITech、Chemspeed 等好几家，营收冲到 34 亿，但利润率掉到 12%；2025 年市场转冷（学术经费、中国、关税），利润率掉到 8%。**营收还是 35 亿，利润却只有 2023 年的六成**——买来的东西没赚钱，买的钱（10 亿债 + 4 亿发股）还得付利息。现在开始减值，等于承认买贵了。

## 二、把会计障眼法剥掉

- **股权激励（SBC）**：TTM 2020 万美元，占营收 0.6%。德国家族企业的风格，非常克制。已按 GAAP 扣除。
- **一次性项目**：**减值与重组 2.8 亿**——从经营利润 3.11 亿到税前 −0.24 亿之间少了 3.35 亿，其中利息约 6000 万、投资损失 2000 万，剩下约 2.5 亿是减值（2024 年收购留下的商誉和无形资产）；另有约 3000 万重组费用在经营费用里。减值本身是一次性的，但**这家公司 FY2025 就有 1.32 亿减值重组、TTM 又有 2.8 亿，连着两年**——单期口径无法判断明年是否还有。另外所得税 4040 万是在税前亏损上交的，因为减值不能抵税。
- **资本化的支出**：没有值得一提的。
- **回购与稀释**：TTM 回购 1000 万 ÷ SBC 2020 万 = 0.5 倍，股本一年 +0.13%——基本不稀释也不回购。派普通股股息 2260 万（股息率 0.37%）。**2025 年发了优先股，一年付 3200 万优先股息**，排在你前面拿钱。
- **利润和现金流的差**：净亏 −1.07 亿，经营现金流 +1.90 亿，对账：

| 项目 | TTM 金额（百万美元） | 说明 |
|---|---|---|
| GAAP 净利润 | −107 | |
| + 折旧摊销 | +230 | 2023 年才 115，翻倍——是买来公司的无形资产摊销 |
| + 减值与重组 | +280 | 非现金 |
| + 股权激励 + 投资损失 | +40 | |
| − 其他非现金调整 | −74 | |
| − 营运资金变化 | **−215** | 应付款还了 8200 万、税付了 3500 万、其他占用 1.28 亿 |
| = 经营现金流 | 190 | |
| − 资本开支 | −97 | |
| = 自由现金流 | **94** | |

自由现金流 9400 万，是 2023 年 2.43 亿的四成。这两年的现金都被并购整合和营运资金吃掉了。**债**：有息负债 18.6 亿，净负债 16.7 亿，净负债/EBITDA 3.1 倍——对一家周期性仪器公司来说不轻，2021 年这个数还是 0.5 倍。

## 三、市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 81.4 亿 ÷ −1.07 亿 | 亏损 | 无意义 |
| 公司自己吹的 Non-GAAP | 再加回无形资产摊销约 1.3 亿和 SBC，估算调整后归母净利润约 2.7 亿 | ≈30 倍 | 3.3 元 |
| **剔除障眼法后的真实市盈率** | 税前 −0.24 + 2.8 减值重组 = 2.56 亿，按 25% 税 = 1.92 亿，减优先股息 0.32 亿 = 1.6 亿 | **51 倍** | **2.0 元** |
| 自由现金流口径 | 81.4 亿 ÷ 0.94 亿 | 87 倍 | 1.2 元 |
| 企业价值口径 EV/EBIT | 98.1 亿 ÷ 3.11 亿 | 31.5 倍 | 3.2 元（未扣利息和税） |
| 三年平均利润口径 | FY2023 4.27 亿、FY2024 1.13 亿、FY2025 −0.23 亿，平均 1.73 亿 | 47 倍 | 2.1 元 |
| 分析师明年预期（参考） | 远期市盈率 23.5 倍，隐含明年非 GAAP 每股赚 2.27 美元 | 23.5 倍 | 4.3 元 |

真实口径和非 GAAP 口径差在 1.3 亿的收购无形资产摊销——这是 2024 年那 16 亿并购的成本在利润表里分期确认。你可以说它不出现金，但你不能说它不是成本：那 16 亿是真花了的，而且现在正在减值。

**大白话：你现在投 100 块进去，按剔除减值后的真实利润算，公司一年替你赚 2 块；按现金算只有 1.2 块。**这 2 块里回到你口袋的是 0.37 块股息，回购几乎没有，剩下的在还债和付优先股息。这个 2 块未来会不会变大？取决于两件事：学术经费和中国市场回不回暖（管不了），以及 NanoString 和 ELITech 能不能从拖累变成贡献（2025 年起的裁员重组就是在干这个）。如果利润率回到 2023 年的 16%，真实市盈率能降到 23 倍左右——远期 23.5 倍就是市场在赌这个。

## 四、一句话结论

核磁共振近乎垄断、MALDI Biotyper 是耗材型好生意、半导体量测和超导线沾着 AI 和聚变的光——**布鲁克的底子是真的**。但 2024 年那 16 亿并购把一家 17% 利润率、几乎没债的公司变成了 9% 利润率、3.1 倍杠杆、正在减值的公司，营收两年不涨，自由现金流只剩巅峰的四成。现在 51 倍真实市盈率、87 倍自由现金流、31 倍 EV/EBIT，全部押在「利润率能修回去」上。**好公司，但不便宜——等减值出完、利润率站回 13% 以上再看。**
