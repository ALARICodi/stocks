# SMERY · 西门子能源（Siemens Energy AG）

市值 1,456 亿美元 ≈ **1,278 亿欧元**（按 1 欧元 = 1.14 美元）｜ADR 价约 35 美元｜行业：发电设备 / 电网设备 / 风机｜TTM 截止 2026-06-30（财年 10 月–9 月）｜财报货币：欧元，**全文数字统一用欧元**

> 这是一家 2023 年差点倒掉、要德国政府出 75 亿欧元担保才保住信用的公司。三年后它成了「AI 电荒」最大的欧洲受益者，股价从 2022 年低点涨了 18 倍。这篇的重点就是：涨出来的这 1,278 亿，有多少是它真赚出来的。

---

## 第一部分：它到底做几件事

西门子能源 2020 年从西门子集团拆出来独立上市，把西门子所有跟「发电和输电」有关的家当打包带走。财报按四个分部披露营收，实质上是四门生意。

### 生意一：燃气轮机（Gas Services）——占 32%，现在的印钞机

**这件事是什么**：造大型燃气轮机，就是天然气电厂里那台把天然气烧成电的核心机器。一台最大号的 HL 级燃机重 500 多吨，发电能力 5 亿多瓦，够一座 50 万人口的城市用。全世界能造这种大机器的只有三家：美国 GE Vernova、日本三菱重工、西门子能源。一台机器连带发电机和辅机卖 1.5–3 亿欧元，一座大电厂通常一次买两到四台。

**怎么收钱，为什么现在火**：卖机器只是第一笔钱。燃机每跑两三万小时要大修一次，热端叶片要换、涂层要重做——这活只有原厂能干，因为叶片是单晶合金加特殊冷却孔，别人仿不了。所以一台燃机卖出去，后面 25 年的服务合同（长期服务协议，LTSA）才是大头，毛利率是新机的两倍以上。西门子能源全球装机 1 亿多千瓦在跑，每年服务收入稳定进账。

2024 年起微软、谷歌、亚马逊在美国狂建 AI 数据中心，一个大型数据中心吃电相当于一座中等城市，电网供不上，只能自己建气电厂。燃机订单从「几年一台」变成「排队排到 2029 年」。三家厂商产能都锁死了，价格一路往上抬。**这就是这家公司股价 18 倍的核心原因。**

### 生意二：电网技术（Grid Technologies）——占 31%，同样缺货

**这件事是什么**：变压器、高压直流换流站、开关设备。电从电厂出来是几万伏，要升到几十万伏才能远距离送，到了城市再降回来——每次升降都要过一台变压器。一台特高压变压器重几百吨、卖几千万欧元，交货期现在排到两三年后。高压直流换流站更贵，一个海上风电送岸工程的换流站是十几亿欧元的单子，西门子能源在北海接了一串这种项目。

**为什么缺货**：全球电网都老了（美国变压器平均年龄 40 年），风光电场、数据中心、电动车充电桩全要接网，变压器需求突然翻倍，而全球产能过去二十年没怎么扩。西门子能源、日立能源、GE Vernova 三家分这块蛋糕。这一块比燃机的周期性弱，因为电网改造是十年级的持续开支。

### 生意三：工业转型（Transformation of Industry）——占 14%

**这件事是什么**：给钢铁厂、化工厂、油气田卖压缩机、工业汽轮机、电解槽（制氢设备）。比如一家 LNG 液化厂要把天然气压到零下 162 度变液体，用的大型压缩机就是他们的。电解制氢是讲给资本市场的新故事，目前还很小。这块生意平稳、利润率一般，跟油气资本开支周期走。

### 生意四：西门子歌美飒（Siemens Gamesa）——占 25%，还在亏

**这件事是什么**：造风力发电机，尤其是海上大风机（单机 1,400 万瓦、叶片 100 多米长）。这是 2017 年西门子风电和西班牙歌美飒合并来的，2023 年出了大事：陆上风机的 4.X 和 5.X 机型叶片和轴承有设计缺陷，装出去几千台要陆续返修，一次计提了 16 亿欧元质保损失，加上海上风机项目成本失控，**FY2023 全公司亏 45 亿欧元**，信用评级要塌，德国政府出面担保 75 亿欧元才让银行继续给它开保函。

现在的状态：陆上新机型停售、只做海上风机和老机型服务，亏损从 FY2024 的约 18 亿收窄到现在的几亿，公司目标 FY2026 做到盈亏平衡。营收 104 亿在原地踏步。

| 占总营收 | 25% | | |

**分部利润说明**：数据源只披露分部营收。上表分部利润率按公司过往披露的分部利润水平（燃机和电网双位数、歌美飒亏损收窄）估算，四块加总再扣约 1.7 亿集团费用，凑到 TTM 经营利润 36.86 亿欧元。**标注为估算，不是财报数字。**

**整体**：TTM 营收 418.44 亿欧元（+9%），毛利率 20.8%，经营利润率 8.8%，净利润 26.92 亿（净利率 6.4%）。**三门赚钱的生意合起来利润率 14% 左右，被歌美飒拖到 8.8%。**

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：数据源的现金流量表没有单列 SBC 一行（IFRS 公司常见）。西门子能源的股份支付费用按其年报口径约每年 1 亿欧元上下，占净利润不到 4%，**不是问题**。GAAP（IFRS）利润里已经扣了，不加回。

**一次性项目**：TTM 里资产减值加重组费用 0.88 亿、资产出售损失 0.62 亿，合计 1.5 亿，占净利润 5.6%，小。**但往前看两年就不小了**：FY2024 有 21.8 亿资产出售收益（卖了西门子印度公司的股权），FY2025 有 5.4 亿出售收益——那两年的净利润 11.84 亿和 14.14 亿里，**一大半是卖资产卖出来的**，剔掉之后 FY2024 其实是亏的。这直接影响第三部分的「三年平均」。单看 TTM 这一期判断不了这类出售是否年年发生，但从数字看，FY2024–25 是在靠卖资产撑利润表，TTM 这一年才是第一年靠主业赚出净利润。

**资本化的支出**：研发全部费用化，没有资本化的软件或开发支出。没有。

**回购与稀释**：TTM 回购 22.88 亿欧元，同期 SBC 约 1 亿，**比值 20 倍以上，是真回购**。但股本 YoY 只减少 0.28%、QoQ 减少 1.27%——说明这笔回购是最近一个季度才开始的，之前公司根本没钱回购（2023 年还在被政府担保）。另外 TTM 派息 6.01 亿（每股 0.70 欧元，FY2025 恢复分红），偿债 15.82 亿。

**利润和现金流的差——这是全篇最重要的一张表**：

净利润 26.92 亿，经营现金流 96.01 亿，自由现金流 77.91 亿。**现金流是利润的 3.6 倍**，这个差距太大，必须拆开看每一分钱从哪来：

| TTM 项目 | 亿欧元 | 说明 |
|---|---|---|
| 净利润 | 26.92 | |
| + 折旧摊销 | 13.44 | 正常 |
| + 其他摊销 | 1.58 | |
| + 资产出售损失 + 减值重组 | 1.50 | 非现金 |
| + 其他经营调整 | 9.23 | 主要是质保拨备计提（歌美飒缺陷的准备金，还没真花钱） |
| − 应收账款增加 | −22.25 | 卖得多、收得慢 |
| − 存货增加 | −10.37 | 为排队的订单备料 |
| + 应付账款增加 | 5.39 | |
| **+ 预收款增加（合同负债）** | **+60.66** | **客户为排队订单付的预付款** |
| + 其他营运资本 | 9.91 | |
| = 经营现金流 | 96.01 | |
| − 资本开支 | −18.10 | |
| = 自由现金流 | 77.91 | |

看到那行 **60.66 亿预收款**了吗。燃机和变压器现在要排队两三年，客户下单要先付 10–30% 定金。这 60 亿是客户提前交的钱，**是欠客户的货，不是赚的钱**——设备交付时这些现金要变成成本花出去。FY2025 同一行是 39.76 亿，FY2024 是 32.16 亿，年年都靠它。

**把预收款剔掉，真实自由现金流 = 77.91 − 60.66 ≈ 17 亿欧元**，跟净利润 26.92 亿在一个量级（再考虑应收和存货占用，其实比净利润还低）。所以 statistics 页上「P/FCF 16 倍、FCF 收益率 6.1%」这两个数字是**假便宜**，真实的现金回报只有它的四分之一。

预收款这件事有两面：好的一面是它证明订单是真的、客户急到愿意先付钱，公司拿着 111 亿现金、净现金 81 亿，再也不用求政府担保了；坏的一面是等交付高峰到来，这个数字会从正变负，那时候现金流会难看得吓人，到时候别惊讶。

## 第三部分：市盈率，多口径

市值按 1,278 亿欧元算。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP（IFRS）TTM 市盈率 | 1,278 亿 ÷ 26.92 亿 | **47.5 倍** | 2.1 元 |
| 公司自己吹的「特殊项目前利润」 | 经营利润 36.86 亿加回 1.5 亿重组减值 ≈ 税前 38.4 亿，税后约 29 亿（估算） | 44 倍 | 2.3 元 |
| **剔除障眼法后的真实市盈率** | 净利润加回真一次性损失 1.5 亿 ≈ 28.4 亿；SBC 不加回 | **45 倍** | **2.2 元** |
| 自由现金流口径（报表） | 1,278 亿 ÷ 77.91 亿 | 16.4 倍 | 6.1 元 |
| 自由现金流口径（剔除预收款） | 1,278 亿 ÷ 约 17 亿 | **75 倍** | 1.3 元 |
| 企业价值口径 EV/EBIT | (1,278 − 81 净现金) ÷ 36.86 亿 | 32.5 倍 | 3.1 元 |
| 三年平均利润口径 | FY2024 剔除 21.8 亿出售收益后约 −10 亿、FY2025 剔除 5.4 亿后约 8.8 亿、TTM 28.4 亿，三年平均 **约 9 亿** | **约 140 倍** | 0.7 元 |

三年平均那一行是全表最刺眼的：**当期 45 倍，三年平均 140 倍**，而且这还是把 FY2023 那笔 45 亿亏损排除在外算的。这家公司从 2020 年拆出来到 2025 年，五个财年里四个亏损或靠卖资产盈利，**TTM 这一年是它历史上第一次靠主业赚出像样的净利润**。市场用 47 倍买的不是过去，是「利润率从 8.8% 涨到 14–16%」的未来——那是公司自己定的 2028 年目标。

**大白话说：你现在投 100 块进去，按剔除障眼法的真实口径算，公司一年替你赚 2.2 块。** 这 2.2 块里，TTM 期间以分红回到你口袋的约 0.5 块（派息 6 亿）、以回购回来的约 1.8 块（回购 22.9 亿，刚开始）——加起来比利润还多，因为公司在花预收款堆出来的现金。留在公司里的：资本开支 18 亿主要是扩燃机和变压器产能（柏林、北卡罗来纳、印度建新厂）。

**这 2.2 块未来大概率会变大**：燃机订单排到 2029 年，价格还在涨；电网设备同样缺货；歌美飒亏损收窄到盈亏平衡还能再贡献 6 亿。如果利润率真做到 14%，净利润能翻倍到 55–60 亿，对应现在市值 22 倍，投 100 块赚 4.5 块。这是市场买的剧本。**风险在于**：燃机是周期品，上一轮景气 2015 年见顶后西门子燃机部门裁了三分之一的人；AI 电力需求如果 2028 年放缓，排队订单会被取消（定金退还，预收款倒转）；歌美飒的质保黑洞过去三年每次都说「差不多计提完了」，每次都还有。

## 第四部分：一句话结论

**好赛道、好时点、坏价格。** 燃气轮机和电网设备是三家分天下的真寡头生意，AI 电荒把它推到了十年一遇的顺风口，账上净现金 81 亿、开始回购，这些都是真的。但 47 倍市盈率买的是「2028 年利润翻倍」这个已经写在公司目标里的剧本，没有安全边际；报表上 16 倍的 P/FCF 是 60 亿客户预付款堆出来的假象，真实现金回报只有 1.3%；三年平均口径 140 倍，说明这个利润刚从谷底爬出来、还没证明能持续。投 100 块一年赚 2.2 块，比 GE Vernova 便宜不了多少，比五年前的自己贵了 18 倍。**这家公司值得盯，但现在这个价是为完美剧本付的钱——等下一次燃机订单不及预期、股价砍三成的时候再看。**

**归篮：很贵 / 一般**（生意周期性强、歌美飒还在亏、三年里两年靠卖资产盈利，够不上「好生意」；但也没有硬伤，主业真的在赚钱）。
