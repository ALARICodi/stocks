# MEDP · Medpace Holdings, Inc.（美迪派思）

市值 $161.5 亿 / 股价约 $579 / 行业：商业服务（临床试验外包 CRO，NASDAQ）/ TTM 截止日期：2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

**答案是：只做一门生意——替小型生物科技公司跑完整个临床试验。财报上那六个"分部"不是六门生意，只是把同一门生意按疾病领域切开报的营收，这一点必须先说清楚。**

### 这门生意到底是什么

先讲一个具体场景，这是理解 Medpace 的关键。

假设有一家叫 XYZ 的生物科技公司，总部在波士顿，**全公司只有 28 个人**——12 个科学家、5 个高管、几个行政。他们手上有一个减肥药分子，动物实验做完了，一期人体安全性试验也做完了，现在要做二期：需要找 **400 个 BMI 超过 30 的患者**，分散在美国、加拿大、波兰、澳大利亚的 **45 家医院**，连续给药 **52 周**，每 4 周抽一次血、量一次体重、做一次心电图，全程记录每一个不良反应。

这 28 个人**根本做不了这件事**。他们需要：跟 45 家医院一家一家谈合同、培训每家医院的护士怎么按方案取样、把全球几千份血样运到同一个实验室做统一检测、把几万条数据录入符合 FDA 21 CFR Part 11 规范的数据库、雇几十个监查员定期飞到每家医院核对原始病历、处理各国药监局的伦理审批、最后把所有东西整理成一份能提交给 FDA 的文件。

这套活儿雇人自己干，需要养两百号人、三年时间、上千万美元的固定成本——**而这个试验一旦失败，这两百号人立刻就是纯亏损**。所以他们不自己干，他们找 Medpace。

**Medpace 的做法是"一站式打包"**：签一份 **4,000 万美元、为期三年**的合同，把上面所有事情全包了。而且——这是它区别于同行的核心——**它不外包给别人**，它自己有中央实验室（做血样检测）、自己有影像判读中心（做 CT/MRI 的中心化阅片）、自己有生物分析实验室、自己有数据管理团队、自己有医学写作团队。客户只需要对接**一个项目经理**。

对比一下同行的做法：IQVIA、ICON 这些巨头做大药企的三期试验，一个项目下面挂着七八个供应商，实验室外包给 A、数据外包给 B、监查外包给 C，客户要开七八个协调会。对于有几千人临床团队的辉瑞来说这没问题，**但对于只有 28 个人的 XYZ 公司，这是灾难**。

### 它为什么只服务小公司

**这是 Medpace 最重要的战略选择，也是它利润率远高于同行的原因。**

大药企（辉瑞、默沙东）做三期试验，一单十几亿美元，但它们有专业采购部门，会把 CRO 压到 5%–8% 的利润率，还要求各种付款账期。**Medpace 基本不接这种活。**

它接的是**中小型生物科技公司**的二期、三期试验，单笔合同两千万到一亿美元。这类客户的特点是：

- **没有议价能力**——它们没有专业采购团队，也没有备选方案（能一站式打包的就那么几家）；
- **极度看重速度**——它们的钱是 VC 给的，烧完就死，试验早半年出结果就意味着早半年融下一轮，为此愿意多付钱；
- **极度看重"不出错"**——一个 28 人的公司如果试验设计出问题被 FDA 打回，公司就没了。

所以 Medpace 能收更高的价，还能拿到 **21% 的经营利润率**——这在 CRO 行业是顶尖水平。

另外还有一个别人学不来的东西：**Medpace 的创始人兼 CEO August Troendle 本人是医生**（前 FDA 医学审评官出身），公司内部有一支真正的医生团队参与试验方案设计，而不只是执行客户给的方案。对一个刚从大学实验室出来、根本不知道 FDA 想看什么的创始人来说，这个价值极大。**内部人持股 19.75%**——创始人的钱和你的钱在同一条船上。

### 收钱的方式：先收钱后干活

这一点后面第二部分会展开，先在这里点一下：**Medpace 是按里程碑预收款的**。签下 4,000 万的合同后，往往先收 15%–20% 的预付款，然后按"入组第 100 个患者""完成第 26 周随访"这样的节点收款，**收款通常跑在成本发生的前面**。所以它的账上永远躺着一大笔"客户已经付了但活还没干完"的钱（会计上叫"预收账款/合同负债"）。

**这张表里唯一真正要紧的一行是"代谢类"。**

它从 2022 年的 2.45 亿，一路涨到 2024 年 4.58 亿、2025 年 7.45 亿、TTM 9.06 亿——**四年翻了 3.7 倍，现在占总营收的三分之一，是公司最大的单一板块。**

这就是 GLP-1（司美格鲁肽那一类减肥药）浪潮的直接体现。全球现在有几百家生物科技公司在做减肥药和代谢病相关的分子，每一家都要做临床试验，Medpace 是这波浪潮最大的收费站之一。

**这是这家公司最大的增长引擎，也是它最大的单点风险。** 如果 GLP-1 的投资热潮退去（比如几个大药厂的产品先后上市把市场吃完、VC 不再给这个赛道砸钱），这 9 亿美元的营收会以肉眼可见的速度萎缩。而且注意：**"其他"和"心血管"两块已经在下滑**（其他从 4.31 亿降到 3.86 亿），说明公司的增长现在高度依赖代谢和 CNS 这两个热门赛道，并不是全面开花。

## 第二部分：把会计障眼法剥掉

### 股权激励（SBC）

TTM **2,121 万美元**，占净利润 **4.3%**，占营收 0.76%。

**极低。** 而且注意它是**下降的**：2025 全年 3,479 万，TTM 只有 2,121 万。这是一家 6,200 人的公司，绝大多数是临床监查员和数据管理员——拿工资的，不是拿期权的。这一项在 Medpace 身上完全不构成问题，按规矩当现金成本扣掉，扣完利润几乎没动。

### 一次性项目：没有

翻遍现金流量表，**没有重组费用、没有资产减值、没有诉讼和解、没有并购费用、没有税务一次性调整。** 这是一张干净得罕见的表。

唯一需要打问号的是"其他经营活动 **+9,187 万**"这一行：2024 年是 −752 万，2025 年跳到 +1.03 亿，TTM 是 +9,187 万。**连续两年出现约 1 亿美元的正向非现金调整，而 2021–2024 年这一项基本是零。** 财报页不提供明细，我无法判断这是什么（最可能是递延所得税的变动，见下）。**单期口径无法判断这是否会年年发生**，但它对经营现金流的贡献接近 20%，是这份财报里我唯一说不清楚的地方。

### 资本化的支出：几乎没有

资本开支 TTM 只有 **4,597 万**，占营收 **1.65%**。折旧摊销 **2,780 万**，占营收 1%。

**这是一门几乎不需要重资产的生意。** 它的"工厂"是 6,200 个员工的脑子和一套软件系统，最大的实物资产是辛辛那提的总部园区和几个实验室。没有软件资本化的痕迹（研发费用在这个行业本来就不存在——研发是客户的事）。

### 回购与稀释：真回购

| 项目（TTM，百万美元） | 金额 |
|---|---|
| 回购股份 | **−299.3** |
| 发行股份（期权行权） | +49.8 |
| 分红 | **0（不分红）** |
| 股权激励 SBC | 21.2 |

**回购 ÷ SBC = 299.3 / 21.2 = 14.1 倍。** 远超"大于 3 才算真回购"的标准。

**流通股一年减少 7.24%**，季度环比减少 1.41%。而且这不是新现象：2025 年回购了 **9.17 亿**（那一年回购力度是 TTM 的三倍），2022 年回购 8.48 亿。**公司一分钱不分红，把所有能用的现金都拿去注销股份。**

这带来一个副作用，你在数据上会看到两个吓人的数字：**市净率 37.2 倍、ROE 162%**。这两个数字完全没有意义——**因为账面净资产只剩 4.34 亿了，被回购吃掉了。** 一家公司如果把自己的股本回购到接近于零，ROE 就会趋向无穷大。看到 162% 的 ROE 不要以为这是什么神仙生意，它只是会计恒等式的产物。

### 利润和现金流的差：这张表是本篇最重要的东西

净利润 4.915 亿，经营现金流 7.527 亿，**现金流是利润的 1.53 倍**。差在哪：

| 项目（TTM，百万美元） | 金额 | 是什么 |
|---|---|---|
| GAAP 净利润 | 491.5 | |
| ＋ 折旧与摊销 | +27.8 | 真实但不花现金的成本 |
| ＋ 股权激励（非现金） | +21.2 | 真实但不花现金的成本 |
| ＋ 其他经营活动 | +91.9 | **说不清是什么，见上文** |
| − 应收账款增加 | −63.6 | 客户欠的钱变多了 |
| − 应付账款减少 | −9.4 | 还给供应商的钱变多了 |
| **＋ 预收账款增加** | **+95.9** | **客户预付但活还没干的钱** |
| ＋ 其他经营性资产净变动 | +97.4 | 主要也是合同负债类 |
| **＝ 经营活动现金流** | **752.7** | |
| − 资本开支 | −46.0 | |
| **＝ 自由现金流** | **706.7** | |

**关键在"预收账款 +9,590 万"和"其他经营性资产净变动 +9,740 万"这两行，合计约 1.93 亿。** 加上应收和应付的负向影响，净的营运资金流入是 **+1.203 亿美元**。

**这 1.2 亿是"客户提前付给你、但你还没干活"的钱。它是真金白银躺在你账上，但它不是利润——它是负债。** 未来你必须用人力成本把这笔活干出来。

**这意味着什么：Medpace 报出来的 7.07 亿自由现金流里，有 1.2 亿（17%）不是赚来的，是"客户垫的"。** 而这笔垫款能持续增加的唯一前提是**新签合同持续增长**。一旦新签订单增速放缓——不是下滑，只是放缓——这个正向的营运资金流入会立刻归零甚至转负，自由现金流会在利润没变的情况下凭空缩水一两亿。

**这是所有"预收款生意"（CRO、SaaS、健身房、教培）共有的特征：增长期现金流看起来比利润好得多，一旦停止增长，现金流会先于利润恶化。** 剔掉这部分，"真实的"自由现金流大约是 **5.86 亿**，而不是 7.07 亿。

### 税：现金税只交了账面税的三分之一

| 项目（TTM，百万美元） | 金额 |
|---|---|
| 利润表上的所得税费用 | 107.4 |
| **实际付出去的现金税** | **39.7** |
| 差额 | 67.7 |
| 有效税率 | 17.94% |

**实付税只有账面税的 37%。** 这 6,770 万的差额，最可能的来源是**股票期权行权带来的税务扣除**——员工行权时公司可以按行权当日的市价（而不是授予时的价格）抵扣，股价涨得越猛、抵扣越多。

**这是一笔隐藏的、依赖股价上涨的现金补贴。** 过去一年股价涨了 23.6%，所以这笔补贴很厚。**如果股价横盘或下跌，这 6,770 万会大幅缩水，现金流又要少一块。** 顺带一提，2024 年实付现金税是 8,357 万，2025 年降到 3,972 万——已经能看出这笔钱在剧烈波动。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 161.5 ÷ 4.915 | **32.9 倍** | **$3.04** |
| 公司自己吹的 Non-GAAP（加回 SBC，税后） | 161.5 ÷ 约 5.09 | 31.7 倍 | $3.15 |
| **剔除障眼法后的真实市盈率** | 无重大一次性项目可剔，SBC 按 GAAP 保持扣除 | **32.9 倍** | **$3.04** |
| 自由现金流口径（公司报的） | 161.5 ÷ 7.067 | 22.9 倍 | $4.38 |
| **自由现金流口径（剔掉客户垫款）** | 161.5 ÷ 5.864 | **27.5 倍** | **$3.63** |
| 企业价值口径 EV / EBIT | 157.9 ÷ 5.834 | 27.1 倍 | $3.69 |
| **三年平均利润口径** | 161.5 ÷ 三年均值 3.794 | **42.6 倍** | **$2.35** |

三年平均的算法：2023 年 2.826 亿、2024 年 4.043 亿、2025 年 4.511 亿，平均 **3.794 亿**。

**最后一行是全表最有价值的一句话：当期 32.9 倍，三年平均 42.6 倍，差了 30%。**

这个差距的含义是：**Medpace 的利润这三年在快速爬坡**（2.83 亿 → 4.04 亿 → 4.51 亿 → TTM 4.92 亿，四年增长 74%），所以用最新一年算出来的市盈率显得便宜。如果这个增长能继续，32.9 倍是合理的；**如果增长停在这里，你实际上买的是一个 40 倍以上的东西。**

而且要注意 EV/EBIT 27.1 倍**几乎等于**市盈率 32.9 倍打个折——因为公司账上净现金只有 3.59 亿（占市值 2.2%），资产负债表对估值几乎没有缓冲作用。这一点和百胜中国那种净现金公司很不一样。

### 说人话：你投 100 块，一年能拿回多少

**按最保守的三年平均口径，你投 100 块，公司一年替你赚 2.35 块。按当期口径是 3.04 块。按剔掉客户垫款的现金流口径是 3.63 块。**

这 3 块钱的去向非常单一：

| 去向 | 金额（TTM，百万） | 折算到你的 100 块 |
|---|---|---|
| **回购注销股份** | 299.3 | **$1.85** |
| 现金分红 | 0 | $0 |
| 留在公司里（现金余额增加） | 456.4 | $2.83 |
| 用于扩张的投资 | 46.0（资本开支） | $0.28 |

**注意这个特点：Medpace 不分红，一分钱都不分。** 它把钱分成两半——一半回购股份（等于变相把钱还给愿意卖的股东，同时提高留下来的人的每股含金量），一半就**堆在账上**（TTM 现金净增加 4.56 亿）。

它**几乎不需要投钱扩张**：资本开支只占营收 1.65%。它扩张的方式是**招人**——而招人的成本是当期费用，直接体现在利润里了。所以对 Medpace 来说"留存利润再投资"这个概念本身就不太成立，它赚的钱要么回购、要么躺着。

**这个 3 块钱未来大概率变大还是变小？**

**变大的力量（很强）**：营收 TTM 同比 +24.67%，是这三家公司里增长最快的；股本每年缩 7.2%，光这一项每股利润就自动涨 7%；经营利润率稳定在 21%，没有恶化的迹象；生物科技融资环境如果回暖，新签订单会加速。

**变小的力量（也很实在）**：
1. **代谢类占了三分之一营收，全押在 GLP-1 这一个赛道上**，热潮退去就是硬着陆；
2. **"其他"和"心血管"两块已经在萎缩**，说明基本盘并没有全面增长；
3. **1.2 亿的客户垫款红利在增长放缓时会立刻消失**；
4. **6,770 万的期权税务抵扣依赖股价继续上涨**，这是个自我强化也自我毁灭的循环；
5. **客户是烧 VC 的钱的生物科技公司**——这是全市场对利率和风险偏好最敏感的一群客户。2022 年加息周期里，整个生物科技融资市场腰斩，CRO 的新签订单集体崩过一次。这件事会再发生。

## 第四部分：一句话结论

**这是一门真正优秀的生意——几乎不用资本、21% 的经营利润率、创始人持股两成、一年注销 7% 的股份、财报干净得挑不出毛病——但你要付 32.9 倍当期利润（三年平均口径 42.6 倍）去买它，而它三分之一的营收押在减肥药这一个正在最高点的赛道上，客户全是靠 VC 输血活着的小生物科技公司。**

**换句话说：好公司，贵价格，而且贵的那部分完全建立在"增长不会停"这个假设上。** 你投 100 块，最保守口径下一年赚 2.35 块——这个回报率要成立，它必须再高速增长三到五年。它做得到的概率不小，但这不是一笔有安全边际的投资，而是一笔押注生物科技融资周期不会转向的投资。

生物科技融资周期一定会转向，只是不知道哪一年。**下一次它转向的时候，Medpace 的股价大概率会先跌一半，然后你再回来看这份分析。**
