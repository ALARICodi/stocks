# DOLE · 都乐（Dole plc）

市值 12.81 亿美元 / 股价约 $13.56 / 行业：分销服务（新鲜果蔬）/ TTM 截止：2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

Dole 现在这家公司是 2021 年 7 月拼起来的：爱尔兰的果蔬分销商 Total Produce 和美国那个卖香菠萝的 Dole Food 合并，在纽交所上市，注册地留在爱尔兰。所以它体内其实住着两种完全不同的生意——**一种是"我自己种"，一种是"我帮别人搬"**。财报按三个分部披露。

### 生意一：Fresh Fruit（自种自运的香蕉和菠萝）—— 营收 36.75 亿，占 39%

这是老 Dole，也是大多数人听到"Dole"想到的那个蓝色标签。

它具体是这么运作的：Dole 在厄瓜多尔、哥斯达黎加、洪都拉斯、危地马拉、菲律宾拥有或长期租用大片种植园，自己雇工人种香蕉和菠萝。香蕉从种下一株小苗到能砍下来，要 9 个月左右。砍下来当天就得进冷库降到 13.5 摄氏度——低于 13 度香蕉会冻伤发黑，高于 15 度会在船上熟透变烂，这个温度窗口只有两度多。降完温装进纸箱，每箱 18.14 公斤（40 磅，这是全球香蕉贸易的标准箱），拉到港口装上 Dole 自己的冷藏船队（十几条船），跨太平洋或加勒比海运到北美的圣地亚哥、威尔明顿港，或者欧洲的鹿特丹。船上全程恒温恒湿，还要通氮气把箱内氧气浓度压下去，让香蕉"睡着"不继续成熟。

到港卸货后进 Dole 自己的催熟房——用乙烯气体，四到七天把还是深绿色的香蕉催成你在超市看到的那种黄。什么时候催、催几天，是根据超市的订单排的，因为催熟完只有一周左右的货架寿命。最后贴上蓝色 Dole 标签，配送到沃尔玛、Kroger、Costco、Aldi 的门店。

**钱怎么收**：跟超市签的是**年度合同价**。比如沃尔玛跟 Dole 谈定，未来一年北美区域每箱 18.14 公斤的香蕉，Dole 交到配送中心的价格是 $15.50，全年不变，沃尔玛保证每周至少提多少箱。一家像沃尔玛这样的大客户一年能提上千万箱。

**这门生意的要害在于：成本全是浮动的，售价却是锁死的。** 厄瓜多尔政府今年把香蕉最低收购价从每箱 $6.50 调到 $7.00，Dole 得认；巴拿马运河因为干旱限流，绕道多烧的油钱，Dole 得认；一场飓风扫过洪都拉斯毁掉三千公顷种植园，Dole 得认；还有 TR4（黄叶病，一种能让整片香蕉园绝收且土壤十年不能再种香蕉的真菌）在东南亚扩散，得花钱做隔离和抗病品种。而对沃尔玛的售价，白纸黑字写着一年不动。所以这门生意在成本上行年份会被挤得很难看。

好的一面是壁垒真实：全世界能同时拥有几万公顷热带种植园、十几条专用冷藏船、几十个催熟中心、并且在美欧两地都进得了主流超市货架的，只有 Dole、金吉达（Chiquita）、都乐蒙特（Fresh Del Monte）这三家。新来的人不可能三年内复制这套东西。

### 生意二：Diversified Fresh Produce – EMEA（欧洲果蔬批发）—— 营收 41.57 亿，占 44%

这是老 Total Produce，营收最大的一块，但**它一棵树都不种**。

它做的是搬运和撮合：在爱尔兰、英国、荷兰、瑞典、丹麦、西班牙、捷克有几十个分销中心和分拣厂。每天从全世界的种植者手里买货——摩洛哥的西红柿、秘鲁的牛油果、西班牙的草莓、荷兰自己的甜椒、爱尔兰的土豆和蘑菇——运到分销中心，按超市的要求重新分级、清洗、切分、装进带超市自有品牌 logo 的小盒里（超市不希望顾客看到"Dole"，他们要卖 Tesco 自家的草莓），然后隔夜配送到门店。

**举个具体的**：都柏林一家 Dunnes Stores 连锁在周二下午下单，说周四早上要 8000 盒 250 克装的西班牙草莓。Total Produce 的爱尔兰仓库周二晚上把整托盘的散装草莓拆开、挑掉压坏的、按 250 克称重装盒、贴 Dunnes 标签、周三夜里装冷藏车、周四清早卡车停在门店后门。这单从头到尾的价值，就是**"让草莓在 36 小时内从西班牙的冷库变成货架上不烂的一盒"**，Dunnes 为这个服务付的钱，也就每盒几十欧分。

**这门生意的毛利极薄**——它本质上是一个带冷链的物流公司加一个风险承担者（货烂了算它的）。财报没有按分部披露经营利润，但从全公司 1.98% 的经营利润率和这块 44% 的营收占比反推，**这块的经营利润率大概只有 1.3%–1.7%（估算，财报只披露到营收层面）**。也就是说，卖 100 块钱的西红柿，扣完采购成本、冷库电费、卡车油钱、分拣工人工资、烂掉的损耗，剩一块五。

它的价值不在利润率，在于**它是不需要资本的**——不用买种植园，不用买船。而且欧洲的超市集中度极高（前五大占一半以上），能同时服务 Tesco、Lidl、Albert Heijn、ICA 这个级别客户并保证从不断货的分销商没几家，客户换供应商的动力也不强。

### 生意三：Diversified Fresh Produce – Americas & ROW（美洲及其他分销）—— 营收 17.67 亿，占 19%

一样是分销，但在西半球。两件事：一是把智利、秘鲁、阿根廷的葡萄、蓝莓、樱桃收上来出口到北美和亚洲（南半球的收获季正好是北半球的冬天，这是季节套利）；二是在北美境内做进口果蔬的批发分销。TTM 同比增长 6.7%，比 EMEA 那块稍好，利润率**估计在 2% 左右（估算）**，因为浆果和樱桃的单价高、损耗管理的溢价也高。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 只有 693 万美元，占 GAAP 归母净利 5972 万的 11.6%。这个数字小得让人舒服——它印证了一件事：这不是科技公司，是农业和物流公司，靠的是种植园和卡车，不是靠发股票留人。**已按 GAAP 全额当成本扣除，后文不加回。**

**一次性项目**：TTM 里有一堆，逐项列（单位百万美元）：

| 项目 | 金额 | 性质 |
|---|---|---|
| 出售资产收益 | +4.64 | 收益 |
| 出售投资收益 | +1.56 | 收益 |
| 资产减值 | -12.47 | 损失 |
| 其他非常项目 | -22.71 | 损失 |
| **净影响** | **-28.98** | **净损失** |

这些项目净扣掉税前 2898 万。要注意的是**"出售资产收益"这一项在 Dole 这里根本不是一次性的**：TTM +4.64、FY2025 +15.65、FY2024 +79.07、FY2023 +54.11——**连续四年都有，而且 2024 年那 7907 万几乎占了当年归母净利的一大半。** Dole 这几年一直在卖厂、卖地、卖非核心业务来"整理资产组合"，卖出的收益直接进了利润表。也就是说，**它过去几年报出来的漂亮利润里，有相当一部分是变卖家当变出来的，不是种香蕉种出来的。** 到 TTM 这一期这个来源基本枯竭了（只剩 464 万），利润立刻掉下来——这就是为什么归母净利从 FY2024 的 1.26 亿掉到 TTM 的 5972 万。

**"终止经营"的亏损，已经连续亏了五年**：TTM -1104 万、FY2025 -4596 万、FY2024 -2888 万、FY2023 -2182 万、FY2022 -5645 万。会计上"终止经营"（discontinued operations）的意思是"这块业务我要卖了/关了，跟主业无关，你别看"。但一个已经"终止"了五年、每年还在吞掉两千万到五千万的业务，实质上就是主业的一部分成本。**本文一律把它算进真实利润，不给它豁免。**

**少数股东权益吃掉三分之一**：这是 Dole 最容易被忽略的一件事。TTM 合并层面持续经营赚了 1.037 亿，但**少数股东拿走 3297 万**，剩给你这个二级市场股东的只有 7076 万，再减去终止经营的 1104 万，最后 5972 万。少数股东是谁？是 Dole 在南美种植园和欧洲各国分销公司里的当地合资方——Total Produce 当年就是靠一国一国收购当地分销商起家的，很多只买了 60%、70%，剩下的留给原老板。**所以你买 Dole 股票，买的是一个"合并报表好看、真正归你的那一半要打折"的结构。**

**资本化的支出**：没有软件或内容资本化的问题。资本开支 TTM 9185 万，全是实打实的种植园、冷库、船和卡车。

**回购与稀释**：TTM 回购 1802 万，SBC 693 万，**回购/SBC = 2.6 倍**。按这个标准算真回购——不只是抵消员工发股，还剩一多半在真减少股本。但股本实际上还是**增加了 0.19%**（94.46 百万股），说明回购是 TTM 后半段才开始的、还没体现出来。分红另付 3234 万，每股 $0.34，股息率约 2.5%。回购加分红一共 5036 万，占 TTM 自由现金流 7749 万的 65%——**这个派息水平是可持续的，但没什么余量。**

**利润和现金流的差**：TTM 归母净利 5972 万，经营现金流 1.693 亿，自由现金流 7749 万。逐项对账（单位百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 报表起点（合并净利减终止经营与少数股东分摊后倒算） | ~53.9 | 现金流表未单列起点，由调整项倒推 |
| + 折旧摊销 | +113.65 | 种植园、船、冷库、卡车的折旧，是真实的机器磨损 |
| + 其他摊销 | +3.04 | |
| + 资产减值与重组 | +12.47 | 上面剔过的非现金损失，这里加回 |
| + 股权激励 SBC | +6.93 | 非现金 |
| − 出售资产收益 | -4.64 | 这笔钱在投资活动里，不该算经营现金 |
| − 合营企业投资收益 | -24.58 | 权益法确认的利润，钱还在合营公司账上没分回来 |
| + 其他经营活动 | +49.85 | |
| − 应收账款增加 | -45.24 | 卖出去了但钱还没收回来 |
| − 存货增加 | -12.51 | |
| + 应付账款增加 | +28.45 | 欠供应商的钱多了，等于占用别人的资金 |
| − 其他净经营资产 | -12.00 | |
| **= 经营现金流** | **169.33** | |
| − 资本开支 | -91.85 | |
| **= 自由现金流** | **77.49** | |

这张表里最值得看的是**折旧 1.137 亿比整个归母净利还大**。Dole 是重资产：船、冷库、催熟房、种植园的地上附着物，每年都在磨损。折旧在现金流表里被加回来了（因为它不花钱），但**这些东西迟早要换**，而 TTM 的资本开支只有 9185 万——**低于折旧 1.137 亿**。连续低于折旧的资本开支意味着它在**吃老本**：船在变老，冷库在变旧，账面上的利润有一部分是"今年少修船省下来的"。这不能长期持续。

另一件事：**自由现金流极不稳定**。TTM 7749 万、FY2025 是 **-3283 万**、FY2024 是 1.896 亿、FY2023 是 1.895 亿。一个年年波动上亿的自由现金流，用任何单一年份去估值都会出错。

## 第三部分：市盈率，多口径

市值 12.81 亿美元，企业价值 24.30 亿美元（净债务 11.48 亿，接近市值的 90%）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 12.81 亿 ÷ 归母净利 5972 万 | **21.5 倍** | **$4.66** |
| 公司/网站常用口径（剔除终止经营） | 12.81 亿 ÷（持续经营 1.037 亿 − 少数股东 3297 万）= ÷ 7076 万 | 18.1 倍 | $5.52 |
| **剔除障眼法后的真实市盈率** | 剔除非常项目后税前 1.816 亿 ×(1−38.42%) − 少数股东 3297 万 − 终止经营亏损 1104 万 = 6782 万 | **18.9 倍** | **$5.29** |
| 自由现金流口径 | 12.81 亿 ÷ FCF 7749 万 | 16.5 倍 | $6.05 |
| 企业价值口径 EV/EBIT | 24.30 亿 ÷ 经营利润 1.878 亿 | 12.9 倍 | $7.74 |
| 企业价值口径 EV/FCF | 24.30 亿 ÷ FCF 7749 万 | 31.4 倍 | $3.18 |
| 三年平均利润口径（原始） | 12.81 亿 ÷ (TTM 5972 万 + FY25 5132 万 + FY24 1.255 亿)/3 = ÷ 7885 万 | 16.2 倍 | $6.16 |
| **三年平均利润口径（剔除卖资产收益后）** | 把 FY24 那 7907 万卖资产收益按税后剔掉，三年平均真实利润降至 6531 万 | **19.6 倍** | **$5.10** |

**最后两行是这张表里最要命的一对。** 原始三年平均看着 16.2 倍，好像比当期还便宜；但把每年靠变卖家当挣的那部分剔掉之后，变成 19.6 倍——**比当期 GAAP 还贵。** 这说明 Dole 过去三年报出来的利润是被资产处置垫高的，剥掉之后，**它真实的盈利水平不是在改善，是一直就这么低。**

### 用大白话说

**你现在投 100 块进 Dole，按最保守的真实口径（19.6 倍）算，公司一年替你赚 5.1 块。**

这 5.1 块里：
- 大约 **2.5 块**以现金分红的形式真的打进你账户（每股 $0.34，股息率 2.5%）；
- 大约 **1.4 块**通过回购变成你手里股份的增值（TTM 回购 1802 万，占市值 1.4%）；
- 剩下的 **1.2 块**留在公司里，主要去了两个地方：还债（TTM 净还债 7068 万）和资本开支（9185 万）。

**注意 EV/FCF 那一行的 31.4 倍、年回报 $3.18。** 这个数字才是最诚实的：因为 Dole 背着 11.48 亿的净债务——差不多等于它整个市值——所以你实际上是花 24.3 亿（自己掏 12.8 亿 + 承接 11.5 亿债务）买下一家一年产生 7749 万自由现金的公司。用这个角度看，年回报只有 3.2%，**比美国国债还低**。股权口径的 5.1% 之所以看起来高，全靠杠杆撑着。

**这个 5.1 块未来会变大还是变小？** 分析师明显押注变大——远期市盈率只有 9.35 倍，意味着市场预期未来一年利润接近翻倍。这个预期建立在三件事上：终止经营的那块亏损业务终于卖干净（每年少亏两三千万）、香蕉合同价在成本上涨后重新谈判上调、EMEA 的整合成本走完。**如果三件事都成，利润确实能回到一亿以上，那按当前市值就是 12 倍出头，那时候看现在的价格是便宜的。**

但要看清楚风险的形状：
- **ROIC 4.46%，WACC 4.97%**——投入的每一块钱资本，赚回来的回报低于它的资金成本。这个状态持续下去，公司规模越大，股东价值越少。
- **净债务是市值的 90%**，利息保障倍数只有 3.17 倍。经营利润下滑三分之一，利息就快付不起了。
- **有效税率 38.42%**，在多国经营被各国按各自税率征，压不下来。
- 卖资产垫利润这条路已经走到尽头了（TTM 只剩 464 万）。

## 第四部分：一句话结论

**不便宜。** 表面 18 倍是剔掉了那块已经"终止"了五年却还在年年亏钱的业务算出来的；把它和逐年枯竭的资产处置收益一起还原，真实市盈率接近 20 倍，年回报 5.1%——而这 5.1% 建立在一笔接近市值的净债务、一个低于资金成本的投入回报率、和一个已经在吃老本（资本开支低于折旧）的重资产盘子上。用企业价值口径看，自由现金流回报只有 3.2%，还不如国债。远期 9.35 倍的市场预期不是不可能实现，但那需要三件事同时办成，**你付的是"三件事都成"的价格，承担的是"一件都不成"的风险**。想清楚这个再动手。
