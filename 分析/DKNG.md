# DKNG · DraftKings（在线体育博彩）

市值 119 亿美元 · 股价 24.01 美元（2026-09-04 收盘，52 周跌了 50%）· 行业：在线博彩 · TTM 截止 2026-06-30 · 任务5 亏损口径

---

## 第一部分：它到底做几件事

财报分三块：体育博彩、在线赌场、其他。前两块是同一个 App 里的两个入口，用同一批用户、同一套获客，实质是两门生意加一个尾巴。

### 生意 A：体育博彩 Sportsbook（占 63%）

2018 年美国最高法院推翻联邦禁令，各州可以自己决定要不要开放体育博彩，到今天 30 多个州开了网上下注。DraftKings 和 FanDuel（Flutter 旗下）是这个市场的双寡头，合起来占七成以上份额。

怎么赚钱，讲透一点。你在 App 上押 100 美元「酋长队赢超过 3 分」，赔率是 −110，赢了拿回 190.9，输了 100 归 DraftKings。如果两边押的人一样多，DraftKings 稳赚 4.5%。现实里两边不平衡，所以它靠算法调赔率、靠「串关」（同时押三四个结果，赔率看着高实际抽水 20–30%）拉高毛利。**下注总额（handle）× 抽水率 = 营收**，TTM 抽水率大约 10% 出头。一个 NFL 赛季，一个活跃用户平均一年给它贡献一百多美元营收。

**这门生意最大的两笔成本在利润表上分别叫「其他运营费用」和「销售费用」**：一是各州的博彩税，从新泽西的 13% 到纽约的 51%，2025 年伊利诺伊还加了每注固定税，这是它营收和毛利之间的主要差额；二是拉新——2025 年广告费 11.3 亿，占营收 19%，新用户注册送几百美元「赠注」是行规。

### 生意 B：在线赌场 iGaming（占 30%）

老虎机、21 点、轮盘搬到手机上，只在 7 个州合法（新泽西、宾州、密歇根等）。**这是比体育博彩好得多的生意**：老虎机的数学期望是固定的（返还率 95% 左右），不像体育赛事结果会让庄家某个周末巨亏；用户全年 365 天都玩，没有赛季；不需要每场赛事另买数据。TTM 营收 18.8 亿，增速跟体育博彩差不多，但利润率高一截。问题只有一个：开放州太少，扩展速度取决于各州议会。

### 尾巴：其他（占 7%）

起家的梦幻体育（DFS，选球员组队比分数）、2024 年花 7.5 亿收购的 Jackpocket（帮人代买彩票的 App）、媒体和赛事数据。加起来 4.1 亿，不增长。

**数字**（TTM 截止 2026-06-30，百万美元）：

| 分部 | TTM 营收 | 2025 财年 | 2024 财年 | 占比 | 经营利润率（估） |
|---|---|---|---|---|---|
| 体育博彩 | 3,934 | 3,827 | 2,903 | 63% | 约 −5%（估，税+营销吃掉） |
| 在线赌场 | 1,875 | 1,805 | 1,508 | 30% | 约 +10%（估） |
| 其他 | 414 | 423 | 357 | 7% | 约 0 |
| **合计** | **6,223**（+15%） | 6,055 | 4,768 | 100% | **−2.7%** |

财报只披露到营收，分部利润按公司电话会里的方向估算。增速从 2023 年的 64%、2024 年的 30%、2025 年的 27% 一路降到 TTM 的 15%，新州开放放缓，老州渗透到顶。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 3.24 亿，占营收 5.2%，2021 年高峰时 6.83 亿，一路在降。当真实成本扣。

**一次性项目**：TTM 有 1300 万重组费和 4700 万其他特殊收益，净影响 +3400 万，剔掉后经营亏损约 2 亿，差别不大。

**资本化的支出**：**这是 DraftKings 最需要剥的一层。** 现金流量表里资本开支只有 2000 万，看着是零资产公司；但投资活动里另有一行「购买无形资产」1.54 亿，那是资本化的软件开发——App 是它的全部，开发 App 的工程师工资有一大块没进利润表，先记成资产分几年摊。**自由现金流要扣掉这 1.54 亿才是真的。**

**回购与稀释**：TTM 回购 6.82 亿，SBC 3.24 亿，**比值 2.1**，股本只涨了 1%。2025 年借了 6 亿定期贷款，其中一大半用来回购，这在股价腰斩的年份是聪明的（平均回购价远高于现在的 24 美元就不聪明了——2025 年回购 8.3 亿，均价约 40 美元，已经亏了 40%）。

**利润和现金流的差**：净亏损 1.67 亿，经营现金流 +6.71 亿，差 8.4 亿，对账：

| 项目 | 金额（百万美元） | 说明 |
|---|---|---|
| GAAP 净利润 | −167 | |
| + 折旧摊销 | +292 | 一半以上是资本化软件和收购无形资产的摊销 |
| + 股权激励 | +324 | |
| − 其他非现金 | −72 | |
| + 应付账款增加 | +135 | 欠供应商和各州的税款 |
| + 其他营运资金 | +160 | **主要是用户存在账户里还没下注的钱** |
| = 经营现金流 | 671 | |
| − 资本开支 | −20 | |
| = 自由现金流（财报口径） | 651 | |
| − 资本化软件开发 | −154 | |
| = **真实自由现金流** | **497** | |

再往下剥：那 2.95 亿营运资金流入（用户余额 + 欠款）是别人的钱暂时放在它账上，不是赚的。**扣掉后，DraftKings 一年靠经营真正留下的现金约 2 亿**，跟「净亏损 1.67 亿 + 加回 SBC 3.24 亿 ≈ +1.6 亿」对得上。**它基本是一家盈亏平衡的公司，不是亏损公司，也不是现金奶牛。**

## 第三部分：亏损口径

定性：**真亏边缘**。经营亏损 1.7 亿是真的，但现金流为正、账上不烧钱。2025 财年曾做到全年 GAAP 打平，TTM 又退回去了——2026 上半年比 2025 上半年差，原因是各州加税和拉新费用回升。

| 项目 | 数字 | 说明 |
|---|---|---|
| TTM 营收 / 同比 | 62.2 亿 / +15% | 增速三年腰斩再腰斩 |
| TTM 经营亏损（GAAP） | −1.69 亿（−2.7%） | 2025 财年 −0.03 亿，在恶化 |
| TTM 经营现金流 / 自由现金流 | +6.71 亿 / +6.51 亿（真实 +4.97 亿，剔用户余额后约 +2 亿） | |
| 一年净烧多少现金 | **不烧钱** | |
| 账上现金 − 有息负债 | 9.84 亿 − 19.16 亿 = **净负债 9.3 亿** | 12.5 亿可转债 2028 年到期 + 6 亿贷款 |
| 还能烧几年 | 不适用 | |
| SBC 占营收 / 股本膨胀 | 5.2% / +1% | 回购抵掉了 |
| **做到成熟利润率能赚多少** | 见下 | |

**假想利润**：拿两个对标。Flutter（FanDuel 母公司）集团层面经营利润率约 15%；欧洲成熟市场的 Bet365、Entain 在 15–20%。**取 15%**（美国州税比欧洲重，不敢取 20%）：

- 62.2 亿 × 15% = 9.3 亿经营利润，扣 25% 税 = **7.0 亿净利润**
- 市值 119 亿 ÷ 7.0 亿 = **假想市盈率 17 倍**
- 投 100 块一年回报 **5.9 块**

按现在的真实自由现金流 4.97 亿算是 24 倍（4.2 块）。

大白话：**假设它明天就做到 Flutter 的利润率，你投 100 块一年赚 5.9 块；它离那一天差的是利润率从 −3% 到 +15%，18 个百分点，主要靠两件事——广告费从营收的 19% 降到 10%（老用户占比上升自然会降）、在线赌场占比继续上升。这条路是看得见的，FanDuel 已经走通了（2025 年经营利润率两位数）。** 这期间几乎不稀释（回购抵消 SBC），也不烧钱。风险是路上的三个坑：各州继续加税（伊利诺伊开了头）、CFTC 监管下的预测市场（Kalshi、Polymarket）绕过州牌照全国卖体育合约、以及体育赛事结果偶尔集体对庄家不利。**52 周股价腰斩，就是市场在为前两个坑定价。**

三年平均口径：三年 GAAP 净利润 −5.1 亿、+0.04 亿、−1.7 亿，平均亏损，无意义；三年平均自由现金流（财报口径）5.7 亿，市值 ÷ 5.7 亿 = 21 倍。

## 第四部分：一句话结论

**会不会死**：不会。现金流为正，净负债 9 亿对 6 亿多经营现金流不算重，可转债 2028 年才到期。

**活成了值不值这个价**：**公道。** 119 亿买一个双寡头之一、76% 毛利、15% 增速、已经不烧钱的公司，假想市盈率 17 倍、真实现金流 24 倍，在腰斩之后不算贵，也谈不上便宜。**这门生意站得住**——牌照是壁垒，FanDuel 和它之外的第三名份额不到 10%——但它的利润率天花板由各州议会决定，不由它自己决定，这是它永远拿不到 Visa 那种估值的原因。如果你信「税不会无限加、预测市场抢不走主流用户」，这个价可以留着观察；下一次拉新费用和州税同时抬头、股价再跌一截时，就是便宜了。
