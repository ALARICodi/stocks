# MITSY · 三井物产（Mitsui & Co., Ltd.）

市值 905 亿美元 ≈ **14.23 万亿日元**（按 1 美元 = 157 日元）｜ADR 价 645.65 美元（1 ADR = 20 股，东证 5,019 日元）｜行业：综合商社（铁矿石 / LNG / 化工贸易 / 机械基建 / 医疗食品）｜TTM 截止 2026-06-30（财年 4 月–3 月）｜财报货币：日元，**全文数字统一用日元，「亿」= 1 亿日元**

> 说明：ADR 代号 MITSY 在数据源里没有财报页，本文数字取自东京证交所主上市线 8031.T 的页面，同一份财报。
>
> 三井物产是日本五大综合商社之一，2020 年巴菲特买入后出了名。综合商社这种东西西方没有对应物：**一半是贸易公司，一半是投资公司**——自己不采矿，但持有全球一堆矿山、气田、电厂、医院的股份，靠分红和贸易差价吃饭。理解它的关键是：财报上「营收 15 万亿」那个数几乎没意义，要看它持有的资产赚多少、分回来多少。

---

## 第一部分：它到底做几件事

财报按七个分部披露营收，按利润贡献实质上是三门大生意加几门小的。

### 生意一：矿产与金属资源——营收占 14%，利润占约 30%

**这件事是什么**：三井持有澳洲三大铁矿石产区的股份——跟力拓合作的 Robe River（33%）、跟必和必拓合作的 BHP Mitsui Coal、跟淡水河谷合资的巴西矿山，以及 2025 年花了 53 亿美元买下的 Rhodes Ridge 铁矿 40% 权益（西澳，储量 60 多亿吨，跟力拓合作开发）。合起来它每年有权分到 5,000 多万吨铁矿石，**是全球第五大铁矿石卖家**，但它一铲子矿都不挖——挖矿的是力拓和必和必拓，三井出钱占股、拿产量、卖给日本和中国的钢厂。

**怎么收钱**：两条。铁矿石按国际价（现在 100 美元/吨上下）卖给钢厂，赚贸易差价；合资矿山的利润按股比分给它，这部分在利润表里记成「权益法投资收益」（不是营收，是利润表下半截的一行）。**铁矿石价格每涨跌 10 美元，三井净利润变动约 400 亿日元。**

| 矿产与金属 | TTM | 上财年（2026-03） | 变化 |
|---|---|---|---|
| 营收 | 21,034 亿 | 19,216 亿 | +9% |
| 净利润贡献（估算） | **约 2,800 亿** | | |

### 生意二：能源——营收占 24%，利润占约 27%

**这件事是什么**：LNG（液化天然气）项目的股份——澳洲的 Browse 和 Ichthys、莫桑比克的 Area 1、卡塔尔、阿布扎比的 Ruwais（2024 年新签）、美国的 Cameron LNG；加上原油贸易和油气田权益。三井有权分到的 LNG 一年 1,000 多万吨，主要卖给日本电力公司和城市燃气。

**怎么收钱**：跟铁矿石一样——项目分红 + 贸易差价。LNG 长协价跟油价挂钩，油价 70 美元时一吨 LNG 约 500 美元。这一块 2022 年因为俄乌战争气价暴涨赚翻了，现在回落到正常水平。

| 能源 | TTM | 上财年 | 变化 |
|---|---|---|---|
| 营收 | 35,667 亿 | 32,307 亿 | +10% |
| 净利润贡献（估算） | **约 2,500 亿** | | |

### 生意三：机械与基础设施——营收占约 11%，利润占约 23%，增长最快

**这件事是什么**：三样。第一，海外发电厂和水务的股份（IPP，独立发电商，在美国、东南亚、中东持有几十座电厂），按发电量收固定电费，跟公用事业一样稳。第二，Penske 的合资——三井持有美国 Penske 汽车集团（卡车租赁、汽车经销）的股份，是它利润最稳的一块海外资产。第三，船舶和飞机租赁、铁路车辆、矿山机械（卡特彼勒的日本和亚洲代理是三井的）。这块不依赖大宗商品价格，是三井这几年刻意做大的「稳定器」。

| 机械与基建 | TTM | 上财年 | 变化 |
|---|---|---|---|
| 营收 | 约 17,130 亿（数据源 TTM 缺此项，按总营收倒推） | 15,232 亿 | +12% |
| 净利润贡献（估算） | **约 2,200 亿** | | |

### 其他四块：化工、健康、钢铁制品、创新

- **化工**（营收 31,842 亿，占 21%）：甲醇、盐、饲料添加剂、化肥的贸易和生产（美国的甲醇厂、澳洲的盐田）。营收大、利润薄，约 600 亿。
- **健康生态（Wellness）**（营收 34,840 亿，占 23%）：持有亚洲最大私立医院集团 IHH（马来西亚，2 万张床位）约 17% 股份，加上三井食品（日本第二大食品批发商）、水产、咖啡豆贸易。约 700 亿利润，医院那块在涨。
- **钢铁制品**（6,252 亿）：钢材贸易，约 250 亿。
- **创新与企业发展**（3,652 亿）：物流、房地产、风投，约 200 亿。

**分部利润说明**：数据源只披露分部营收，不披露分部利润。上表按公司过往披露的「各分部归属净利润」结构估算（矿产和能源合占约六成、机械基建两成多、其余分摊），加总凑到 TTM 净利润 9,364 亿。**标注为估算。**

**整体**：TTM 营收 15.04 万亿日元（+6.5%），毛利率 9.6%，**经营利润率 3.5%——但净利率 6.2%，净利润比经营利润还高**（第二部分拆）。净利润 9,364 亿，比 2023 财年高点的 11,306 亿低 17%，三年往下走。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：日本公司，几乎没有。

**一次性项目——商社的「一次性」是商业模式的一部分**：TTM 出售投资收益 1,186 亿 + 出售资产收益 530 亿 = 1,716 亿税前，占净利润 18%。数据源给了五年：每年都有 200–2,500 亿的出售收益。**商社就是「买资产、养几年、卖掉、再买」的循环，卖资产的利润年年有**。我的处理：单期算「真一次性」剔掉，但三年平均那一行不剔——因为它确实年年发生。

**经营利润和净利润倒挂——这是理解商社财报的核心**：TTM 经营利润只有 5,217 亿，税前利润却有 12,160 亿，多出的 7,000 亿是：**权益法投资收益 4,657 亿**（铁矿、LNG、Penske、IHH 这些合资公司按股比分给它的利润）+ 出售收益 1,716 亿 + 持股分红和利息约 600 亿。也就是说，**三井一半以上的利润来自它不并表的公司**。这不是障眼法，是它的商业模式，但要问一句：这些利润变成现金了吗——权益法收益是账面的，现金要等合资公司分红。看现金流量表「其他经营活动 +2,981 亿」，这大约就是合资公司实际分回来的钱，**账面记了 4,657 亿，现金收到约 3,000 亿，六成多**。剩下的留在矿山和气田里再投资，也算股东的，只是摸不着。

**资本化的支出**：油气和矿山的勘探开发按行业惯例资本化。正常。

**回购与稀释**：TTM 回购 1,996 亿日元（上财年 3,998 亿），SBC 约 0，**是真回购**，股本一年减少 1.79%。派息 3,282 亿，每股 140 日元，五年翻了 2.7 倍（52.5 → 140），派息率 35%。回购加分红一年约 5,300 亿，占市值 3.7%。这一点上它是老实的。

**利润和现金流的差——以及 1.1 万亿资本开支是怎么回事**：

| TTM 项目 | 亿日元 | 说明 |
|---|---|---|
| 净利润 | 9,364 | |
| + 折旧摊销 | 3,555 | |
| − 权益法收益（账面） | −4,657 | 没收到现金的部分先减掉 |
| + 合资公司分红等（其他经营） | 2,981 | 实际收到的 |
| − 出售投资和资产收益 | −1,716 | 现金进了投资活动 |
| − 应收款增加 | −3,358 | 贸易量涨、账期拉长 |
| + 应付款增加 | 1,831 | |
| − 其他营运资本 | −750 | |
| = 经营现金流 | 7,326 | 比去年的 10,175 亿少三成，主要是应收款 |
| − 资本开支 | **−11,205** | 上财年是 3,461 亿，**翻了三倍** |
| = 自由现金流 | **−3,878** | |

资本开支从 3,461 亿跳到 11,205 亿，多出的 7,700 亿主要是 **Rhodes Ridge 铁矿 40% 权益的 53 亿美元（约 8,000 亿日元）**——2025 年一次性付掉。这笔钱是三井历史上最大的一笔单项投资，赌的是铁矿石未来 30 年。剔掉它，正常资本开支约 3,200 亿，自由现金流约 +4,100 亿。**但它没用现金付，是借的**：TTM 净增债务 5,685 亿，有息负债从 4.84 万亿涨到 5.88 万亿，净负债 5.0 万亿，净负债/权益 0.54。利息一年 1,807 亿，比五年前翻了三倍半（日本加息 + 借得多）。

## 第三部分：市盈率，多口径

市值按 14.23 万亿日元算。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP（IFRS）TTM 市盈率 | 14.23 万亿 ÷ 9,364 亿 | **15.2 倍** | 6.6 元 |
| 公司自己吹的「基础营业现金流」 | 三井的核心 KPI，剔营运资本变动后的经营现金流，约 9,500 亿 | 15 倍 | 6.7 元 |
| **剔除障眼法后的真实市盈率** | 剔掉 1,716 亿出售收益的税后约 1,300 亿 → **约 8,060 亿** | **17.7 倍** | **5.7 元** |
| 自由现金流口径（报表） | −3,878 亿 | 负，无意义 | 0 |
| 自由现金流口径（剔 Rhodes Ridge 8,000 亿一次性） | 14.23 万亿 ÷ 约 4,100 亿 | 34.7 倍 | 2.9 元 |
| 企业价值口径 EV/EBIT | (14.23 + 5.0 净负债) ÷ 5,217 亿经营利润 | 36.9 倍（**失真**：经营利润不含权益法收益） | |
| 企业价值口径（加回权益法收益） | 19.23 万亿 ÷ (5,217 + 4,657) 亿 | 19.5 倍 | 5.1 元 |
| 三年平均利润口径 | FY2024–2026 净利润 10,637 / 9,003 / 8,340 亿，平均 **9,327 亿**（含年年有的出售收益） | **15.3 倍** | 6.6 元 |

三年平均和当期一样是 15 倍——**利润三年没涨（还在缓慢下滑），但市值从三年前的 6 万亿涨到 14 万亿**。也就是说，这三年股价翻倍，**全部是估值从 6 倍抬到 15 倍，不是生意变好**。抬估值的理由是巴菲特持股加日本企业治理改革；三井自己做的事——加分红、回购、砍低效资产——是真的，但利润没跟上。

**大白话说：你现在投 100 块进去，按真实口径算，公司一年替你赚 5.7 块。** 这 5.7 块里，以分红回到你口袋的 2.3 块、回购 1.4 块，合计 3.7 块——**这是这三家里回馈股东最实在的**。剩下的留在公司：正常年份 3,200 亿资本开支维持矿山气田，今年额外借了 8,000 亿买 Rhodes Ridge。

**这 5.7 块未来会变大还是变小**：它是铁矿石价和 LNG 价的函数。铁矿石现在 100 美元/吨，中国钢产量已经过了顶、房地产不会回来，中长期看跌方向的概率大；LNG 2026–2028 年全球新产能（卡塔尔、美国）集中投产，价格承压。机械基建和医院那两块在涨，但只占三成利润。Rhodes Ridge 要到 2030 年才出矿。**近三年往小的方向走的概率大于往大**——公司自己的指引也是 FY2027 净利润 9,000 亿上下，不增长。

## 第四部分：一句话结论

**生意没变，价格翻倍了。** 三井是一家老实的公司：真回购、分红五年涨 2.7 倍、账目透明、持有的铁矿和 LNG 资产是真的一流资产。但它本质上是一个用 0.54 倍杠杆持有大宗商品股份的投资组合，投入资本回报率 3%，利润三年下滑 17%，而市值三年翻了一倍多——从 6 倍市盈率到 15 倍，涨的全是「巴菲特买了」这个估值故事。15 倍买一门靠铁矿石和气价吃饭、利润不增长、刚借 8,000 亿押注铁矿的生意，投 100 块一年赚 5.7 块，分你 3.7 块，**不算离谱但没有便宜可占**。三年前 6 倍时它是全场最便宜的东西之一，现在是公道偏贵。**铁矿石跌回 80 美元、市盈率回到 10 倍以下再看。**

**归篮：偏贵 / 一般。**
