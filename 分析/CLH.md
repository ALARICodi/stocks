# CLH · 清洁港（Clean Harbors, Inc.）

市值 $170.0 亿 / 股价约 $322.0 / 行业：工业服务（危险废物处理与工业清洁）/ 数据口径：TTM，截至 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

Clean Harbors 是**北美最大的危险废物处理公司**。它的生意可以用一句话概括：**别人产生的、没人愿意碰的、法律规定不能随便扔的东西，交给它来收、来运、来烧、来埋，按吨收费。**

这门生意的本质不是技术，是**许可证**。在美国，建一座危险废物焚烧炉需要联邦 EPA 加州政府的层层审批，周期十年以上，选址要过环评和当地居民听证会——过去二十多年，美国**几乎没有新建成的商业危废焚烧炉**。Clean Harbors 手上握着北美最大的一张网：约十座危废焚烧炉、多个危废填埋场、几十个处理和转运站。这张网既建不出第二张，也拆不掉。

它对外报两个大部门，但里面装了五门客户和收费方式都不一样的生意。

### 生意一：技术服务（Technical Services）—— 烧和埋，最赚钱的核心

**TTM 营收 19.63 亿，占 31.4%。**

具体在干什么：一家化工厂生产过程中产生了 20 吨含氯有机废液，法律规定这东西不能倒、不能填，必须在 1,200℃ 以上的回转窑里焚烧，尾气还要洗涤。工厂打电话给 Clean Harbors，它派罐车来拉走，运到焚烧炉，烧掉，出具一份"废物处置证明"存档十年。**收费按吨算，含氯高、热值低、腐蚀性强的废物单价更高**，一吨从几百到几千美元不等。

这里面最赚钱的一块叫 **PFAS，"永远的化学品"**——就是不粘锅涂层、防水外套、消防泡沫里那类含氟化合物。它在自然界几乎不降解，正在被美国各州陆续列为强制清理对象。**目前公认能彻底销毁 PFAS 的方法只有超高温焚烧**，而北美有能力接这个活的炉子屈指可数。Clean Harbors 2022 年在内布拉斯加州 Kimball 新建的那座炉子，就是冲着这个来的。这是它未来十年最重要的一张牌。

**客户为什么非买不可**：这不是选择题。美国的《资源保护与回收法》规定，废物产生方对废物承担**"从摇篮到坟墓"的终身责任**——你把废物交给一家不合规的小公司，它半夜倒进河里，几年后被查出来，**罚的是你**，不是它。所以大企业只敢找有完整合规记录和保险的大公司。这就是为什么这门生意的利润率能维持在 20% 上下（估算），而且几乎不打价格战。

### 生意二：工业服务（Industrial Services and Other）—— 去客户厂里干脏活

**TTM 营收 13.05 亿，占 20.9%。**

炼油厂每隔几年要停产大修一次（业内叫 turnaround）。停产期间，几百个储罐、换热器、管道里结的油泥、焦炭、催化剂残渣得清出来。Clean Harbors 派几百号人带着高压水枪（压力能到 40,000 psi，切得动钢板）、真空罐车进厂，把这些东西掏出来、装罐、拉走处理。一次大修合同几百万到上千万美元。

**这门生意的问题**：它是纯粹的人力和设备出租，进入门槛远低于焚烧炉，竞争者多，利润率只有个位数（估算 8% 左右）。而且它跟着炼油厂的检修周期走——**TTM 营收是五门生意里唯一在下滑的（FY25 同比 −3.6%）**，因为炼厂延后了检修计划。

### 生意三：现场与应急响应（Field and Emergency Response）—— 出事了打的电话

**TTM 营收 9.59 亿，占 15.4%。**

火车脱轨、油罐车翻车、飓风过后化工厂泄漏、工厂着火——出这类事的时候，第一批赶到的除了消防队就是 Clean Harbors。它有全美最大的应急车队，24 小时待命，到现场堵漏、围控、把污染的土壤和水全挖走拉走。**2023 年俄亥俄州东巴勒斯坦那场著名的列车脱轨事故，清理工作就是 Clean Harbors 做的。**

**收费方式**：按人工时 + 设备台班 + 处置吨数计价，出了事的一方（铁路公司、化工厂、保险公司）付钱。这门生意**没法预测**——好年份靠几起大事故就能多赚几亿，风平浪静的年份就萎缩。但它有个隐性价值：应急现场挖出来的污染土壤，最后会拉进它自己的焚烧炉和填埋场，**给生意一送去了原料**。

### 生意四：Safety-Kleen 环境服务 —— 全美 20 万家汽修店的收废油生意

**TTM 营收 13.87 亿，占 22.2%，增长最快（FY25 同比 +10.8%）。**

这是全美最密集的一张小微客户网。想象一个街角的汽修店：修理工洗零件用的是一台绿色的"零件清洗槽"，里面装着溶剂。这台机器是 Safety-Kleen 的，每隔几周会有一辆蓝色的卡车开来，技师把脏溶剂抽走、换上干净的，顺手把店里换下来的废机油、废机油滤芯、防冻液、废电池也一并收走。**店主每月付几十到几百美元的服务费，一年一签。**

全美有 20 多万家这种小店，Safety-Kleen 跑着几千辆这样的车。**这门生意的护城河是路线密度**——一辆车一天能跑二十家店，成本就摊薄了；如果一个新对手只签下三家店，一天跑三家，怎么算都亏。这是典型的"最后一公里"生意，先到者通吃。

### 生意五：Safety-Kleen 油品 —— 把废机油炼回新机油

**TTM 营收 6.29 亿，占 10.1%，五门里唯一在明显萎缩的（FY25 同比 −15.1%）。**

生意四收上来的废机油，拉到自家的再炼厂，蒸馏、加氢，变回可以用的**基础油**，再调配成机油卖出去（自有品牌 Performance Plus，也卖给壳牌、嘉实多这类调配商）。

**为什么在萎缩**：这门生意的利润 = 基础油售价 − 收油成本。两头都由外部决定：基础油价格跟着原油走，收油成本跟着市场上抢油的人多不多走。原油一跌，卖价立刻跌，收油成本却因为竞争降不下来，利差就被挤扁。**这是全公司最像大宗商品、最没有定价权的一块**，营收从 FY2022 的 8.22 亿一路掉到 TTM 的 6.29 亿。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM **4,340 万美元**，占净利润 4.39 亿的 **9.9%**。中等偏低。GAAP 里已经扣了，我不加回。

**一次性项目**：TTM 干净得出奇——资产处置收益 78 万，坏账计提 1,078 万，就这些。**没有大额诉讼、重组或减值**。"其他经营调整 2,242 万"是递延税之类的零碎。**单看 TTM 一期，我判断不出这些小额调整是不是年年发生**，但金额只占净利润 5%，不影响任何结论。

**资本化的支出**：这家公司不做软件或内容资本化，但它有个**性质更重的东西：填埋场和焚烧炉的建设支出**。这些是实打实的重资产投入，走资本开支，然后按年折旧——**TTM 折旧摊销高达 4.55 亿，比净利润 4.39 亿还多**。这不是障眼法，是这门生意的本质：它靠钢铁和土地赚钱，不是靠代码。

**回购与稀释**：

| 项目 | TTM 金额（百万美元） |
|---|---|
| 回购股票 | 252.3 |
| 股权激励 SBC | 43.4 |
| **回购 ÷ SBC** | **5.8 倍** |
| 分红 | **0（不分红）** |
| 股本一年实际变化 | **−1.41%** |

5.8 倍，是真回购，远超"大于 3"的及格线。股本一年少 1.41%。但注意：**这家公司一分钱红都不分**，股东唯一拿到手的现金回报就是这 1.41% 的回购。

**利润和现金流的差 —— 这里有全篇最需要盯的一个数字。**

净利润 4.39 亿，经营现金流 9.03 亿，差了 4.64 亿。逐项对账（百万美元）：

| 步骤 | 金额 |
|---|---|
| GAAP 净利润 | 439.1 |
| ＋ **折旧与摊销** | **+455.4** |
| ＋ 其他摊销 | +5.6 |
| − 资产处置收益 | −0.8 |
| ＋ 股权激励（非现金） | +43.4 |
| ＋ 坏账计提 | +10.8 |
| ＋ 其他经营调整 | +22.4 |
| − **应收账款增加** | **−177.7** |
| − 存货增加 | −2.2 |
| ＋ 应付账款增加 | +68.3 |
| ＋ 其他净经营资产 | +38.4 |
| **＝ 经营现金流** | **902.6** |

**第一件事：4.55 亿的折旧撑起了大半个现金流。** 但这不是白送的钱——**同期资本开支 4.41 亿**，几乎跟折旧一样多。也就是说，公司每年赚回来的折旧，第二天就得原样投回去买新罐车、修炉子、开新填埋坑。**这跟前一家诺信（折旧 1.49 亿、资本开支只有 0.48 亿）是完全不同的物种**。

所以：**经营现金流 9.03 亿看着漂亮，减掉 4.41 亿资本开支之后，自由现金流只剩 4.62 亿**，FCF 利润率 7.4%。这才是这家公司真实的赚钱能力。

**第二件事，也是最刺眼的：应收账款一年增加了 1.78 亿。** 而同期营收只增加了约 3 亿（5.07%）。**收入涨 5%，客户欠的钱涨了这么多，比例明显失衡**。可能的解释有两种：一是 TTM 里那笔 3.58 亿现金收购并进来了一批应收账款（这是良性的）；二是回款在变慢，或者应急响应类项目的账期本来就长（这是需要警惕的）。**单看 TTM 一期的数据我无法区分这两者**——这是下个季度财报第一个该去核对的地方。如果没有这 1.78 亿的占用，自由现金流本该是 6.4 亿。

**债务**：净负债 **27.3 亿美元**，TTM 实付利息 1.56 亿。经营利润 7.41 亿 → 税前利润 5.97 亿，中间蒸发的 1.44 亿基本就是利息。Debt/EBITDA 2.19，利息保障 4.46——**不算轻松，但对一家重资产公司来说是可控的**，比上一家 Gen Digital（净负债 76 亿、吃掉三成经营利润）健康得多。

TTM 还花了 **3.58 亿现金做收购**，加上 4.41 亿资本开支——**这家公司把赚的钱几乎全投回去了**，这也解释了为什么现金从 9.54 亿降到 5.17 亿。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 170.0亿 ÷ 4.391亿 | **39.0 倍** | **$2.56** |
| 公司口径 Non-GAAP（估算） | 加回税后收购摊销与零星项目约 0.5亿 | ~34.7 倍 | $2.88 |
| **剔除障眼法后的真实市盈率** | TTM 几乎无一次性项目可剔，SBC 按 GAAP 扣 | **39.0 倍** | **$2.56** |
| 自由现金流口径 | 170.0亿 ÷ 4.617亿 | **36.8 倍** | **$2.72** |
| 企业价值口径 EV/EBIT | 197.3亿 ÷ 7.414亿 | **26.6 倍** | **$3.76** |
| 三年平均利润口径 | 170.0亿 ÷ 4.108亿（TTM/FY25/FY24 平均） | **41.4 倍** | **$2.42** |

**三年平均口径 41.4 倍，和当期的 39.0 倍几乎一样。** 这句话的意思是：**Clean Harbors 现在这个利润不是周期高点，但也不是低点——它就是这个水平。** FY2022 净利润 4.12 亿，四年过去 TTM 是 4.39 亿，**四年只涨了 6.6%**，而同期营收从 51.7 亿涨到 62.4 亿（+21%）。**营收在涨，利润几乎没动**——涨的收入被人工成本、燃油、保险和折旧吃掉了。

**说人话：你现在投 100 块进去。**

按最保守的真实口径，公司一年替你赚 **2.56 块**——2.6% 的收益率，**比美国国债还低**。按自由现金流口径也只有 2.72 块。这是全篇最需要停下来想一想的数字：**你花 100 块买下这门生意，它一年替你赚不到 3 块钱。**

这 2.56 块里，回到你口袋的是多少？**只有 1.41 块**（回购），因为**它不分红**。剩下的全部留在公司里——TTM 具体去了哪：4.41 亿修炉子买车（资本开支）、3.58 亿买别的公司、0.45 亿还债。

**关键问题是：这些留存的钱，创造了多少价值？** 看一个数字就够了：**ROIC 只有 9.91%，而它自己的加权平均资本成本 WACC 是 8.12%。** 差 1.8 个百分点。意思是——**这家公司每投入一块钱，创造的价值只比资金成本高一点点**。它不是不会赚钱，是**赚的钱刚好覆盖成本，几乎没有超额收益**。这跟诺信（ROIC 12.25% vs WACC 8.98%，差 3.3 个点）和 Gen Digital（ROIC 14.37% vs WACC 8.80%，差 5.6 个点）比，是三家里最差的。

**这个 2.56 块未来变大还是变小？我判断会慢慢变大，但速度撑不住 39 倍的估值。**

变大的理由：
1. **PFAS 是真实的、可能很大的增量**。全美各州陆续立法强制清理，而能烧的炉子极少，Clean Harbors 有定价权。这是唯一能让它从"稳健低增长"变成"高增长"的变量。
2. **焚烧和填埋的价格能持续涨**。产能建不出新的，需求只增不减，这门生意每年提价 4%–6% 客户只能接受。
3. **股本每年缩 1.4%**。
4. **Safety-Kleen 环境服务 +10.8%** 的增速稳定且高利润。

变小或走平的风险：
1. **工业服务（占 21%）在萎缩**，炼厂检修延后是行业性的。
2. **Safety-Kleen 油品（占 10%）是大宗商品生意**，原油一跌就亏，四年营收掉了 23%。
3. **人力成本**：22,591 名员工，人均创收只有 27.6 万美元、人均创利 1.94 万美元——**这是个高度依赖人工的行业**，工资每涨 5%，利润就被啃掉一大块。这也是为什么四年营收涨 21%、利润却纹丝不动。
4. **ROIC 只比资本成本高 1.8 个点**，意味着它的增长是"要花钱买的增长"，不是自动来的。

## 第四部分：一句话结论

**生意很好，护城河是真的，但 39 倍市盈率买一家四年利润零增长、ROIC 只比资本成本高 1.8 个点的重资产公司，这个价格没有道理。**

先说好的：危废焚烧许可证是这个国家最难拿的牌照之一，二十多年没有新炉子建成；Safety-Kleen 那张覆盖 20 万家汽修店的路线网也是买不来的；PFAS 这张牌确实可能很大。这是一门**几乎不可能被颠覆**的生意，五十年后它还在。

问题全在数字上：
- 净利率只有 **7%**（诺信 18%、Gen Digital 21%）
- ROIC **9.9%**，仅比资本成本高 1.8 个点
- 折旧 4.55 亿、资本开支 4.41 亿，**赚回来的钱要原样投回去**
- **四年营收 +21%，利润 +6.6%**——增长没有落到股东身上
- **不分红**，股东现金回报只有 1.41% 的回购
- 应收账款一年多占用 1.78 亿，需要下季财报确认原因
- 股价过去 52 周涨了 28.6%，估值是被市场情绪推上去的

39 倍这个价格，市场买的是"PFAS 故事"，不是现在的利润。**如果 PFAS 三年内没有变成实实在在的、每年几亿美元的高利润收入，那么现在买入的人，是在为一个还没发生的故事付 39 倍的钱。**

**判断：公司值得放进关注列表，价格明显偏贵。** 合理的买点应该在 22–26 倍附近，也就是股价 $180–$215 之间——那通常出现在应急响应业务淡季、或者油品业务被原油拖累的坏季度里。等它。
