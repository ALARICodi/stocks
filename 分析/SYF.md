# SYF · Synchrony Financial（同步金融）

市值 254 亿美元 / 股价约 78 美元 / 消费信贷 / TTM 截止 2026-06-30 / 排名第 60（任务2：市盈率 0–15 倍段）

> **这是消费信贷企业（本质是一家银行），第三部分用 PB / ROE / 拨备口径而不是普通市盈率**，原因是：放贷生意的利润建立在杠杆上，坏账拨备一个变量就能让利润翻倍或腰斩，市盈率必须和「现在处于信贷周期哪一段」一起看才有意义。

---

## 第一部分：它到底做几件事

**就一门生意：替商家发信用卡，赚穷人的高利息。** 美国最大的「商店信用卡」（private label / co-brand）发卡机构。

大白话讲透这门生意。你在 Lowe's 建材超市买 3,000 美元的地板，收银员说：「办一张我们的卡吧，今天这单立减 5%，而且 12 个月免息分期。」你办了。**这张印着 Lowe's 名字的卡其实是 Synchrony 发的**——Lowe's 一分钱贷款风险不担，得到的是你买得更多、更常回来；Synchrony 得到的是你的贷款余额。免息期一过（或者你只还最低额），年化利率直奔 **25%–30%**，比普通信用卡的 20% 狠得多——因为办商店卡的人群信用资质整体偏弱，正规银行白金卡不给他们额度。

它的合作名单基本覆盖美国人生活的每个角落：**Amazon**（亚马逊店卡）、**PayPal**、**Lowe's**、**Sam's Club**、**Verizon**，还有一块特别的 **CareCredit**——牙科、眼科、兽医诊所里的医疗分期卡：美国人镶一口牙 8,000 美元、给狗做十字韧带手术 5,000 美元，保险不赔，当场刷 CareCredit 分期。公司按五大平台报数（家居汽车、数字、多元零售、健康、生活方式），stockanalysis 不提供分部表，这里按整体讲。

**收钱的链条**（TTM，页面口径）：贷款组合收进来的利息和手续费是毛收入，扣掉三样大头——付给储户的资金成本（它靠自营的高息网络银行吸储放贷）、**分给商家的「零售商分成」**（合作协议里商家要分走一块利息收入，这是它锁住 Amazon 们的代价）、**坏账拨备 51.2 亿**——之后的净营收 99.1 亿，再扣运营费用和税，净利润 34.4 亿。

| | TTM | 上年同期比 |
|---|---|---|
| 净营收（扣资金成本、商家分成、拨备后） | 99.1 亿 | +7.9% |
| 信贷损失拨备（净营收前已扣） | 51.2 亿 | 前一年 52.3 亿，基本走平 |
| 净利润 | 34.4 亿 | 利润率 34.7% |

看清楚拨备的体量：**这门生意每年毛赚的钱里，先赔掉 50 亿坏账，剩下的才轮到股东**。客群偏弱 + 30% 利率，高坏账是商业模式的一部分，不是事故——只要收的利息足够覆盖。真正的风险是衰退时坏账从「高」变「失控」。

## 第二部分：把会计障眼法剥掉

- **股权激励（SBC）**：页面现金流表不单列（并在「其他经营活动」里），对 34 亿净利润成不了气候。
- **一次性项目**：TTM 干净。但注意 **FY2024 净利润 34.3 亿里含出售宠物保险业务 Pets Best 的一次性收益（税前 10.7 亿）**，那年的利润虚高，比较历史时要剔掉——TTM 里已经没有这块了。
- **资本化支出**：无。放贷生意没这个空间。
- **回购与稀释**：**这是全篇最凶的数字：TTM 回购 36.1 亿，股本一年实际减少 9.8%**。外加普通股股息 4.2 亿，一年合计回给股东 40 亿以上，等于市值的 16%。注意这超过了净利润（34.4 亿）——多出的部分靠出售资产和释放资本金撑着，**这个回购速度不可能永远持续**，但在 8 倍市盈率、1.67 倍账面的价位上回购，留下的股东每一股含金量实打实变厚。
- **利润和现金流的差**：经营现金流 96.9 亿远大于净利润 34.4 亿，差额主要是拨备 51.2 亿（先计提、后核销的非现金项）加折旧 5.2 亿。**但对放贷企业别看「自由现金流」流口水**——页面显示 P/FCF 只有 2.6 倍，是幻觉：投资现金流里每年有 70 多亿流出去放新贷款，那才是这门生意真正的「资本开支」。信贷公司只看利润和资本回报，现金流表没有意义。

## 第三部分：银行口径的估值

| 指标 | 数值 | 说明 |
|---|---|---|
| 市盈率（GAAP TTM） | 8.0 倍 | 投 100 块年赚 **12.5 块** |
| 市净率 PB | 1.67 倍 | 账面 169 亿 |
| 有形市净率 P/TBV | 2.02 倍 | |
| ROE | 20.8% | 顶级——但看下一行 |
| ROA | 2.9% | **20.8% 的 ROE = 2.9% 的资产回报 × 约 7 倍杠杆** |
| ROE ÷ PB 换算的真实回报 | 投 100 块年赚 **12.4 块** | 与市盈率口径互相印证 |
| 三年平均利润口径（剔除 Pets Best 一次性收益，估算） | 约 9.2 倍 | 投 100 块年赚 **10.9 块**——三年里含 2023 这个拨备大年，仍有两位数回报 |
| 资本充足率 CET1 | 页面不提供 | 不硬造数字 |

**大白话说回报**：你现在投 100 块进去，按最保守口径公司一年替你赚 11–12 块，而且**这两年它把赚的钱基本全数回给你**（回购+股息约等于甚至超过利润）。8 倍的意思是：市场认定下一次衰退坏账会飙、利润会腰斩——2008 年这类次级消费信贷坏账率确实翻过倍。所以你赚的 12 块里，有一部分是「衰退没来」的风险补偿，不是白给的。

还有两个结构性软肋要知道：**合作方集中**——前五大伙伴贡献大头，丢一个就伤筋动骨（2019 年它真丢过 Walmart，股价一天跌 10%；Amazon、PayPal 每次续约都是惊魂时刻）；**监管刀口**——消费者金融保护局盯着迟到费和高利率，2024 年的迟到费上限规则差点砍掉它一大块收入（后来法院废了，但刀一直悬着）。

## 第四部分：一句话结论

**便宜是真便宜——8 倍利润、每年 16% 现金回到股东口袋，全场少见；但你赚的每一块钱都是「经济不衰退、大伙伴不跑路」的对赌收益。** 生意本身谈不上伟大：7 倍杠杆放贷给次级客群，周期一来利润说没就没，护城河是合作协议而不是产品。价格给足了这些毛病的折扣，作为「便宜筐」里的标的合格，当传家宝不够格。
