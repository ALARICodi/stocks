# VSXY · Victoria's Secret & Co.（维多利亚的秘密）

市值 $66.7 亿（摊薄口径 $71.3 亿） | 股价 $83.93 | 行业：零售（内衣与美妆） | TTM 截止 2026 年 5 月 2 日

---

## 第一部分：它到底做几件事

财报把营收按**地理/渠道**拆成三块，但那只是收钱的窗口。按生意本身讲，它其实在做两件性质完全不同的事——**卖内衣**和**卖香水**——而后者才是真正的印钞机。

### 生意一：卖内衣（撑起营收，但不是利润核心）

主力是文胸。一件维密文胸标价大约 50–70 美元，是全店的锚定商品。逻辑是：女性买文胸需要试穿、需要有人量尺码，这件事线上做不了（这也是为什么它到今天还需要 1,300 多家实体店）。店员量完尺码推荐 2–3 款，客人试穿后往往买一件文胸，然后**顺手带走内裤和香氛**——这才是这门生意的真实结构。

内裤基本不指望赚钱，它是引流工具。维密最经典的打法是"**5 条 35 美元**"这类多件促销，把人拉进店里、拉上网站。单价低、复购快、退货率低。

旗下有三个牌子，打的是不同年龄段：
- **Victoria's Secret** 主品牌，面向 25–45 岁，文胸、睡衣、运动内衣；
- **PINK**，面向 15–22 岁的大学生，卖卫衣、瑜伽裤、休闲内衣，靠校园营销。**这是过去十年伤得最重的一块**，被 American Eagle 旗下的 Aerie 和 Lululemon 抢走了大量份额；
- **Adore Me**，2022 年买来的线上品牌，玩法是"寄一箱到家里试，留下想要的，其余寄回"，年营收约 2.5 亿美元级别，主要是补线上和大码这两块短板。

### 生意二：卖香水和身体乳（营收占比不到四分之一，但利润占比远高于此）

这才是维密最值钱的东西。Bombshell、Love Spell 这些香型的身体喷雾，一瓶 20–30 美元，成本大概只有售价的**一到两成**——一瓶香水的实际内容物值几美元，剩下的全是品牌溢价。而且它是**送礼刚需**：情人节、母亲节、圣诞节，一次买三四瓶。

这块生意的美妙之处在于：它**不受时尚周期影响**。文胸款式过时会滞销打折，香水不会——Love Spell 卖了二十多年还在卖。整体 37% 的毛利率里，美妆板块贡献的毛利率明显高于服装板块。**你可以粗暴地理解为：维密的服装业务在替美妆业务开门店、买流量。**

### 三个收钱窗口的钱

| 渠道 | TTM 营收（百万） | 对比上一整财年 | 占比 | 说明 |
|---|---|---|---|---|
| 北美门店 | 3,626 | +2.3% | 53.6% | 美加约 1,300+ 家店，正从商场往街边店迁移 |
| 直营线上 | 2,078 | +1.8% | 30.7% | 官网 + PINK + Adore Me |
| 国际 | 1,056 | +9.2% | 15.6% | 主要是**加盟批发**模式，增速最快 |
| **合计** | **6,760** | **+3.2%** | 100% | 经营利润率 6.49% |

> 上表的增速一列是 TTM 对上一整财年（口径差一个季度），**整体营收的真实同比是 +8.61%**。两个数字差得远，说明最近这个季度非常猛：TTM 比上一整财年多出的 2.07 亿营收，全部来自 2026 年 2–5 月这一个季度对上年同期的超出，倒推出来**最近一季的同比增速在 15% 上下**，而上一整财年才 5.18%。**增长在加速，这是真的。**

**国际这块的商业模式跟另外两块完全不同，值得单独说**：维密在海外大部分市场不自己开店，而是把货批发给当地合作伙伴，由对方在约 70 个国家开约 480 家店，维密收批发差价 + 品牌授权费。这种模式**几乎不占资本、不承担店铺租金和员工成本**，是三块里资本回报率最高的。中国市场走的是合资公司模式（维密控股、当地伙伴参股）——这就是下面利润表里那笔"少数股东权益"的来源。

## 第二部分：把会计障眼法剥掉

这一期的利润表里**塞了三笔一次性项目，方向还不一样**，不剥干净根本看不出真实盈利水平。完整的一段是这样（单位：百万美元）：

| 项目 | TTM |
|---|---|
| 经营利润 | 439 |
| − 利息支出 | −68 |
| + 其他非经营 | +7 |
| **= 剔除异常项前的税前利润** | **378** |
| − 并购与重组费用 | −61 |
| − 资产减值 | −120 |
| **+ 法律和解收益** | **+69** |
| = 报表税前利润 | 266 |
| − 所得税（实际税率仅 8.65%） | −23 |
| = 持续经营利润 | 243 |
| **− 少数股东分走** | **−32** |
| **= 归属股东净利润** | **211** |

逐项拆：

- **资产减值 1.2 亿**：这是**真一次性**——过去五年只有这一次。大概率是关店和商誉/无形资产（Adore Me 收购形成的）的计提。算真实利润时应该加回。

- **重组费用 6,100 万，这笔不能加回**。看历史：FY2026 是 6,200 万、FY2025 是 1,700 万、FY2024 是 1,100 万、FY2023 是 5,000 万——**五年里有四年在重组**。这是一家持续关店、持续调整门店组合的零售商，重组费用对它来说是**年年都有的经营成本**，不是一次性。公司自己的"调整后利润"里肯定会把这 6,100 万剔掉，那是化妆。

- **法律和解收益 +6,900 万，方向向上，很容易被忽略**。这是一笔**增加**利润的一次性项目——它让这一期的利润好看了。剔除障眼法时必须**减掉**它，很多人只记得加回损失、忘了减掉收益。

- **实际税率只有 8.65%，明显不正常**。前三年分别是 9.13%、23.53%、21.09%。一年交 2,300 万税，正常应该在 24% 上下。这里面很可能有递延所得税资产估值备抵的转回之类的一次性因素。算真实利润必须把税率归一化，否则等于白捡了一笔。

- **少数股东分走 3,200 万，而且在快速变大**（FY2025 才 400 万，FY2026 是 2,800 万）。这是海外合资公司里合作伙伴该拿的那份。**看"经营利润 4.39 亿"的人会忽略这笔**——它在 EPS 里已经扣了，但它意味着国际业务增长的果实有相当一部分不归你。

- **股权激励（SBC）**：TTM 5,400 万，占归母净利润 211 的 **25.6%**。按 GAAP 已扣，不加回。

- **回购与稀释——这一项是负分**：TTM 回购 1.33 亿美元，SBC 5,400 万，比值 2.46 倍，账面上看合格。**但股本不但没减，摊薄股数反而从 8,170 万涨到 8,500 万，一年增加 4.00%。** 原因是股价一年涨了 276%，大量原本"价外"的期权和限制性股票一夜之间变成"价内"，全部计入摊薄分母。这是真实的稀释——那些股份迟早会行权。回购 1.33 亿只买回约 250 万股，抵不过。**换句话说：公司花了 1.33 亿真金白银，股东手里的份额还是被稀释了。**

- **利润和现金流的差**：净利润 2.11 亿 → 经营现金流 5.12 亿，差 3.01 亿，来源清楚：

| 项目 | 金额（百万美元） |
|---|---|
| 净利润 | 211 |
| + 折旧摊销 | +230 |
| + 资产减值（非现金） | +120 |
| + 股权激励（非现金） | +54 |
| + 其他经营项 | −12 |
| − 应收账款增加 | −30 |
| − 存货增加 | −52 |
| + 应付账款增加 | +31 |
| + 税项往来 | +11 |
| − 其他往来 | −51 |
| **= 经营现金流** | **512** |
| − 资本开支 | −198 |
| **= 自由现金流** | **314** |

  **这张表是这家公司最好看的部分。** 折旧 2.3 亿远高于资本开支 1.98 亿，说明它现在花在门店上的钱比历史包袱的摊销还少（在关店、在收缩商场店）。存货只增加 5,200 万而营收涨了 8.6%，**库存管得很紧**（存货周转 3.98 次）。自由现金流 3.14 亿，是账面净利润 2.11 亿的 1.5 倍——**这是一家现金比利润多的公司**，跟同批的 PLXS 正好相反。

- **负债要看清楚**：报表"总债务 28.5 亿"吓人，但里面含**门店经营租赁负债**。按利息支出 6,800 万和 Debt/EBITDA 2.38 倍倒推，**真正的付息债务约 15–16 亿，平均利率约 4.3%**，杠杆属于正常水平。有形账面价值几乎为零（P/TBV 37.7 倍），但对一家轻资产零售商来说这不算硬伤。

## 第三部分：市盈率，多口径

用**摊薄市值 71.3 亿**（8,500 万摊薄股 × $83.93）作分母，比用 66.7 亿更诚实。

**先把"真实利润"算出来**：报表税前 266 + 加回真一次性减值 120 − 减掉一次性和解收益 69 = **317**（重组 6,100 万作为常态成本保留不加回），按归一化 24% 税率交税 → 240.9，再扣少数股东 32 → **归母真实利润 2.089 亿，摊薄 EPS $2.46**。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | $83.93 ÷ 摊薄EPS $2.48 | **33.8 倍** | **2.96 元** |
| 公司自己吹的 Non-GAAP（估算） | 把重组和减值全剔掉 → EPS 约 $3.00 | 28.0 倍 | 3.57 元 |
| **剔除障眼法后的真实市盈率** | 加回减值、减掉和解收益、重组按常态保留、税率归一到24% | **34.1 倍** | **2.93 元** |
| 自由现金流口径 | 71.3亿 ÷ 3.14亿 | **22.7 倍** | **4.40 元** |
| 企业价值口径 EV/EBIT | (71.3+26.4)亿 ÷ 4.39亿 | **22.3 倍** | 4.49 元 |
| **三年平均真实利润口径** | 71.3亿 ÷ 1.806亿 | **39.5 倍** | **2.53 元** |
| 参考：市场给的前瞻市盈率 | 按分析师一致预期 | 17.5 倍 | 5.71 元 |

**说人话：**

你现在投 100 块进去，按最保守的口径（三年平均真实利润）算，公司一年替你赚 **2.53 块**。按当期真实利润算是 2.93 块。按现金口径（自由现金流）算是 4.40 块——**这是全表最靠谱的一个数字**，因为它是真收到的钱，不受一次性项目和税率波动的干扰。

注意"公司自己吹的 28 倍"和"真实的 34.1 倍"之间的差距从哪来：公司会把每年都在发生的 6,100 万重组费用当成"一次性"剔掉，还会享受着 8.65% 的异常低税率不做调整。这两笔加起来，让它的调整后利润比真实值高出约 22%。

这 2.53–2.93 块里，回到你口袋的有多少？**基本没有。** 不发股息；回购 1.33 亿只占市值 2.0%，而且被 4% 的摊薄股本增加完全抵消掉了。留在公司里的钱去了哪：资本开支 1.98 亿（改造门店、往街边店迁移）、还债 9,400 万。**这是一家把钱全部投回自己身上的公司，短期内不要指望现金回报。**

这个 X 未来变大还是变小？**市场押的是大幅变大**：17.5 倍的前瞻市盈率意味着分析师预期调整后 EPS 从 $3.00 涨到约 $4.79，一年 **+60%**。要实现这个，经营利润率得从 6.49% 回到 8.4% 以上——那是 FY2023（三年前）的水平。往上的力量是真的：最近一季营收提速到 15%、毛利率从 35.8% 修到 37.0%、国际加盟这块高回报业务涨 9%。往下的力量也是真的：北美门店只涨 2.3%、线上只涨 1.8%、少数股东分走的比例在扩大、服装零售的时尚风险永远在。

## 第四部分：一句话结论

**转型是真的，价格是疯的。**

先给公司应有的肯定：这确实是一次像模像样的翻身。经营利润率从两年前的 4.16% 修到 6.49%，毛利率修回 37%，最近一个季度营收同比冲到 15% 上下，库存管得紧、自由现金流 3.14 亿是账面利润的 1.5 倍。国际加盟这条最赚钱的线在两位数增长。这些都不是化妆，是真的。

但把价格摆上来看：过去 52 周股价涨了 **275.69%**，同期归母利润从 1.65 亿涨到 2.11 亿，涨了 28%。**股价涨幅是利润涨幅的十倍。** 现在的 34 倍真实市盈率、39.5 倍三年平均市盈率，给的不是一家商场内衣零售商的估值，是给一家高增长消费品牌的估值。

而这门生意十年来的成绩单是：FY2022 营收 67.9 亿，FY2024 掉到 61.8 亿，现在 TTM 67.6 亿——**转了一大圈，回到十年前的原地**。它丢给 Aerie、Skims、Lululemon 的那些份额，到今天也没抢回来多少。真正在增长的是国际加盟和香水，北美门店和线上加起来占了 84% 的营收，同比只有 2% 上下。

更不舒服的三个细节：花了 1.33 亿回购，股东份额反而被稀释了 4%；公司口径的"调整后利润"比真实利润虚高 22%（靠把年年发生的重组说成一次性 + 享受 8.65% 的异常税率）；Beta 2.07、空头持股 13.79%，**这是一只已经完全被动量资金定价的股票**。

**结论：好转是真的，但你要在这个价位上买，等于赌利润在一年内再涨 60% 而且不出任何差错。买的人赚的不是公司的钱，是下一个买家的钱。** 如果这是一门 15 倍真实市盈率的生意，我会认真看；34 倍，不值。
