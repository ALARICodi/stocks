# SHOO · 史蒂夫马登（Steven Madden, Ltd.）

市值 34.5 亿美元 / 股价约 47 美元 / 行业：鞋类与配饰设计销售 / TTM 截止 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

财报分四个部门，实质上是**两门完全不同的生意**：一门是"快时尚批发"（把鞋卖给百货公司），一门是"自己开店零售"（Kurt Geiger 和自营店）。第三门"授权"小到可以忽略但白赚钱。

### 生意一：批发鞋类 —— 10.38 亿美元（37.9%），公司的老本行

**先说清楚这家公司真正的本事是什么：不是设计，不是制造，是速度。**

Steve Madden 本人 1990 年在纽约皇后区用 1,100 美元起家。三十多年下来这家公司**一间工厂都不拥有，也基本不做原创设计**。它的整套打法是这样的：

**第一步，抄。** 设计团队在纽约长岛市，每天盯三样东西：巴黎米兰的秀场、TikTok 上正在爆的短视频、以及苏荷区和首尔街头真人穿什么。看到 Prada 秀场上一双厚底乐福鞋要卖 900 美元、或者某个博主穿的一双方头长靴一夜之间点赞过百万，他们几天之内就画出一双"看起来是那个意思"的版本，定价九十几美元。

**第二步，找代工厂做。** 历史上九成产能在中国，这几轮关税之后大幅转到柬埔寨、越南、巴西、墨西哥。他们不投一分钱建厂，下单就走。

**第三步，也是全部竞争力所在：从画图到摆上货架，6 到 10 周。** 传统鞋品牌是提前 9 到 12 个月定死一整季的款和量，二月开会决定十月卖什么。Steve Madden 不需要——他们可以在这一季**中途**插进去。

**这就是百货公司非买不可的理由。** 举个具体的：DSW（美国最大的鞋类连锁）的采购员二月订货时押了尖头细跟鞋，四月发现完全卖不动，货架上全是死库存，而所有人都在买厚底玛丽珍。这时候他打给传统品牌，对方说"最快十月给你"；他打给 Steve Madden，六月货就到店了。**他买的不是鞋，是"猜错了还能改"的保险。**

**具体一单的钱**：一个百货采购员下单 4 万双某款靴子，批发价约 38 美元一双（零售挂 99 美元），Steve Madden 的到岸成本大概 22–24 美元，这一单营收 152 万美元，毛利约 60 万，毛利率 38%–40%。这一块 SG&A 极轻——没有店租、没有店员，一个销售对接一整家百货集团。

旗下的牌子：Steve Madden（主力）、Dolce Vita、Betsey Johnson、Blondo、Greats，另外还给 Anne Klein 和 DKNY 代工设计鞋子（授权生产）。

**但这块生意五年一动不动**，见下面的表——这是全篇最重要的一个事实。

### 生意二：批发配饰与服装 —— 6.893 亿美元（25.1%）

包子、腰带、冬季配饰，挂 Steve Madden 和 Betsey Johnson 的牌子，另外做授权手袋。

这块从 2021 年的 3.437 亿翻到现在的 6.893 亿，**翻倍的主要原因是 2023 年底收购了 Almost Famous**——一家做女装的**贴牌代工商**，给别人的品牌做衣服。

必须说清楚这件事的性质：**贴牌代工是一门明显更差的生意**。没有品牌溢价，毛利率薄，客户随时可以拿你的报价去压另一家工厂。用收购把营收做大，但把生意的质量做低了。

### 生意三：直营零售（DTC）—— 9.995 亿美元（36.5%），现在最大的一块

两部分：

**（a）自营的 Steve Madden 门店和官网**：全美约 250 家正价店和奥特莱斯店，加上 stevemadden.com。

**（b）Kurt Geiger —— 2025 年花约 3.72 亿美元现金买下来的英国品牌。** 这是理解这家公司这两年所有数字的钥匙。

Kurt Geiger 是英国的鞋履和手袋品牌，约 70 家独立门店，外加在 Harrods、Selfridges、John Lewis 这些英国顶级百货里的店中店专柜。它最出名的产品是"Kensington"手袋——就是那款镶满水晶、正面一个彩虹鹰头的包，在英国街头能见度极高，售价 229 英镑。**它的定位比 Steve Madden 高一档**：Steve Madden 的包卖 98 美元，Kensington 卖 229 英镑（约 290 美元）。

买它的逻辑是：Steve Madden 主品牌在美国已经封顶了，得往上走、往欧洲走。

**效果是营收立刻变大：DTC 从 FY2024 的 5.502 亿 → FY2025 的 8.457 亿 → 现在的 9.995 亿，两年多出 4.49 亿，基本全是 Kurt Geiger 带来的。**

**直营的账跟批发完全不一样**：你不用给百货公司分那一刀，毛利率大概 62%，但你要付伦敦和纽约的店租、付店员工资、付装修折旧。**毛利率高但经营利润率低**——这正是下面第二部分要讲的、公司整体利润率塌掉的原因。

### 生意四：品牌授权 —— 1,392 万美元（0.5%），白捡的钱

把 Steve Madden 这个名字租出去：眼镜、手表、童鞋、行李箱、袜子，别人生产别人卖，按销售额给他抽成。**成本接近于零，毛利率接近 100%。** 五年从 989 万涨到 1,392 万，慢慢涨。金额太小改变不了大局，但这是全公司质量最高的一块钱。

### 四门生意的钱

（百万美元。TTM = 2025年7月–2026年6月。同时列出五年前的 FY2021 是为了看清一件事，见下。）

| 生意 | TTM | FY2025 | vs FY2025 | FY2021 | **五年变化** | TTM 占比 |
|---|---|---|---|---|---|---|
| 批发鞋类 | 1,038 | 1,035 | +0.3% | 1,022 | **+1.6%** | 37.9% |
| 批发配饰/服装 | 689.28 | 640.66 | +7.6% | 343.68 | +100.6% | 25.1% |
| 直营零售 DTC | 999.52 | 845.67 | **+18.2%** | 487.91 | +104.9% | 36.5% |
| 品牌授权 | 13.92 | 12.59 | +10.6% | 9.89 | +40.7% | 0.5% |
| **合计** | **2,741** | **2,534** | +8.2% | 1,866 | **+46.9%** | 100% |

**利润：财报只披露到分部营收，不披露分部利润，下面按整体口径估算。** 全公司毛利率 46.9%、经营利润率 8.87%。估算的分部结构是：批发两块毛利率约 38%–40%、SG&A 很轻，经营利润率大概在 12%–14%；DTC 毛利率约 62%，但店租店员吃掉大半，经营利润率大概只有 5%–7%；授权接近 100%。

### 把上面这张表读出来，就是这家公司的全部问题

**看第一行和最后一行：**

> **五年里营收涨了 46.9%（18.66 亿 → 27.41 亿），但同期净利润从 1.907 亿跌到 1.433 亿，跌了 25%。**

**核心的批发鞋类生意，五年里从 10.22 亿变成 10.38 亿——纹丝不动。** 中间 2022 年冲到过 11.95 亿，然后掉回来。**这门"看趋势、6 周上架"的看家本领，五年零增长。**

那 46.9% 的营收增长是买来的：Almost Famous（2023，贴牌服装）、Kurt Geiger（2025，3.72 亿美元）。**他们花了将近 4.5 亿美元现金买了 8.75 亿美元的营收，结果利润比五年前还少 25%。**

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：3,069 万美元，占净利润的 21.4%。** 比例不低。这笔钱 GAAP 里已经扣了，不加回来。

**回购与稀释——这一项是全篇最刺眼的信号。**

TTM 回购 **1,368 万美元** ÷ SBC 3,069 万 = **0.45 倍**。

按标准判法：接近 1 说明回购只是在抵消员工发股，大于 3 才是真回馈股东。**0.45 倍意味着连抵消都做不到**——公司买回来的股票还不到发给员工的一半。股本一年实际**增加** 0.66%。

**更要命的是对比历史：**

| 年份 | 回购金额（百万美元） |
|---|---|
| FY2021 | 123.16 |
| FY2022 | 148.88 |
| FY2023 | 142.35 |
| FY2024 | 98.43 |
| FY2025 | **13.52** |
| TTM | **13.68** |

**回购从一年 1.4 亿断崖式掉到 1,370 万，砍掉了 90%。** Steve Madden 曾经是一家非常慷慨的回购公司——2021 到 2024 四年买回了 5.12 亿美元的股票。现在停了。

为什么停：钱去买 Kurt Geiger 了（3.72 亿现金），同时借了 4.675 亿的债，现在要还债。**这不是一个中性的变化，这是一家公司把"把钱还给你"换成了"把钱拿去买增长"，而且买回来的增长不赚钱。**

**分红 6,117 万美元，股息率 1.77%。** 分红倒是稳的，五年一直在 5,000–6,600 万之间。**分红 6,117 万 + 回购 1,368 万 − SBC 3,069 万 = 净还给股东 4,416 万，占市值 1.28%。** 这个数字很难看。

**一次性项目：资产减值与重组 630 万美元。** 注意 FY2025 全年也是 630 万，说明这笔发生在 2025 年下半年、落在重叠区。金额很小，不影响判断。收购现金 TTM 只有 133 万，Kurt Geiger 那笔 3.7155 亿已经在 FY2025 花完了。

**一笔说不清的 3,750 万美元非经营损失——而且它去年更大。**

从经营利润走到税前利润，蒸发了 5,175 万：

| 项目 | 金额（百万美元） |
|---|---|
| 经营利润 | 243.10 |
| − 利息支出（利息保障 17.07 倍推算；现金实付利息 17.46） | ≈ −14.2 |
| − **其余非经营损失（说不清）** | ≈ **−37.5** |
| ＝ 税前利润 | 191.35 |
| − 所得税（有效税率 23.68%） | −45.31 |
| − 少数股东权益等 | ≈ −2.8 |
| ＝ 归属净利润 | **143.26** |

那 3,750 万是什么，**从这四张财报页上看不出来**。合理的候选是三个：Kurt Geiger 的**对赌/或有对价重估**（收购常见）、**英镑汇兑损失**（Kurt Geiger 的收入是英镑，账要折回美元）、以及合营公司的权益法亏损。我不去翻 10-K 猜，只说清楚它有多大。

**但有一件事必须点出来：这个"非经营损失"去年比今年大得多。** FY2025 经营利润 1.759 亿，最后净利润只有 4,466 万——就算按同样 23.68% 的税率倒推，中间也蒸发了约 1.17 亿。**连续两年、经营利润线以下持续大额漏血，这就不能叫"一次性"了。** 单期口径拆不开构成，但"它年年发生"这个判断是站得住的。

**资本化与摊销：折旧摊销一年翻倍，从 1,684 万（FY2024）跳到 3,439 万（TTM）。** 这是 Kurt Geiger 收购产生的**无形资产摊销**——收购时把付出去的价钱分摊到"品牌名""客户关系"这些科目上，然后每年摊销。

公司做 Non-GAAP 时一定会把这笔加回来，理由是"非现金"。**我不加回。** 理由：Kurt Geiger 这个牌子的价值不是永久的，你得年年花钱做营销、开店、维护，才能让它值那个钱；把摊销加回去等于假装这个品牌是白来的。另外一个佐证：**市净率 3.64、但有形账面价市净率高达 8.38**——两者之间的巨大差距全是收购堆出来的商誉和无形资产。你付的价钱里有一大块买的是"空气"，那就得让它按年摊掉。

**利润和现金流的差：净利润 1.433 亿 → 经营现金流 2.638 亿 → 自由现金流 2.243 亿。逐项对账（百万美元）：**

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 143.26 | |
| ＋ 折旧摊销 | 34.39 | 一半以上是 Kurt Geiger 的无形资产摊销 |
| ＋ 其他摊销 | 5.14 | |
| − 资产处置收益 | −0.02 | |
| ＋ 资产减值/重组 | 6.30 | 非现金 |
| ＋ 股权激励 | 30.69 | 非现金 |
| ＋ 其他经营活动 | 28.12 | 主要是递延税和上面那笔非经营损失的非现金部分 |
| − 应收账款增加 | −9.38 | |
| ＋ 存货减少 | +7.86 | 库存管得不错，没有积压 |
| ＋ 应付账款增加 | +4.24 | |
| ＋ 其他净经营资产 | +13.23 | |
| **＝ 经营现金流** | **263.83** | |
| − 资本开支 | −39.55 | 开店装修，是真花掉的钱 |
| **＝ 自由现金流** | **224.27** | |

**这张表是干净的。** 净利润和经营现金流的 1.2 亿差额，基本全是非现金项（折旧摊销 3,953 万 + SBC 3,069 万 + 减值 630 万 + 其他 2,812 万），营运资金变动几乎为零——存货甚至还降了 786 万，说明货没积压。**这一点值得肯定：这家公司的营运资金管理是扎实的，卖的是真货，收的是真钱。**

**资产负债表的方向不好。** 净现金/净负债五年的走向：

> FY2021: +1.527 亿 → FY2022: +1.812 亿 → FY2023: +0.809 亿 → FY2024: +0.504 亿 → FY2025: **−3.737 亿** → 现在: **−2.824 亿**

**从一家手握 1.8 亿净现金的公司，变成一家背 2.82 亿净负债的公司。** 好消息是 TTM 里净还了 1.70 亿的债，正在往回走；坏消息是账上现金只剩 9,474 万，是十年最低。

## 第三部分：市盈率，多口径

市值 34.5 亿美元，企业价值 37.3 亿（含净负债 2.82 亿）。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 3,450 ÷ 143.26 | **24.1×** | **4.15 元** |
| 公司自己吹的 Non-GAAP | 加回收购无形摊销约 1,800 万 + 减值 630 万（税后约 1,854 万），估算 | 21.3× | 4.69 元 |
| **剔除障眼法后的真实市盈率** | 3,450 ÷ (143.26 + 4.81)；只加回减值，无形摊销不加回，SBC 已扣 | **23.3×** | **4.29 元** |
| 自由现金流口径 | 3,450 ÷ 224.27 | **15.4×** | **6.50 元** |
| 企业价值口径 EV/EBIT | 3,730 ÷ 243.10 | 15.3× | 6.52 元 |
| 三年平均利润口径 | 3,450 ÷ [(143.26+44.66+169.39)÷3 = 119.10] | **29.0×** | **3.45 元** |
| 三年平均自由现金流口径 | 3,450 ÷ [(224.27+119.54+172.19)÷3 = 172.00] | 20.1× | 4.99 元 |
| 市净率 / 有形账面价市净率 | — | 3.64× / **8.38×** | — |

### 三年平均那一行：当期利润是被垫高的，不是被压低的

三年平均市盈率 **29.0 倍高于当期的 24.1 倍**，表面上看是"当期利润偏高"。但这是因为 FY2025 只赚了 4,466 万——那一年是关税加 Kurt Geiger 整合费用的双重灾难年，不能代表常态。

**把五年的净利润和经营利润率放一起看，才是真相（百万美元）：**

| 年份 | 营收 | 经营利润率 | 净利润 |
|---|---|---|---|
| FY2021 | 1,866 | 12.84% | 190.68 |
| FY2022 | 2,122 | **13.55%** | **216.06** |
| FY2023 | 1,982 | 11.09% | 171.55 |
| FY2024 | 2,283 | 11.01% | 169.39 |
| FY2025 | 2,534 | 6.94% | 44.66 |
| **TTM** | **2,741** | **8.87%** | **143.26** |

**营收从 18.66 亿涨到 27.41 亿（+47%），经营利润率从 13.55% 掉到 8.87%（−468 个基点），净利润从 2.16 亿掉到 1.43 亿（−34%）。**

为什么利润率塌了？两个原因叠在一起：

1. **业务结构变差。** 直营零售从占 26% 变成占 36.5%。零售的毛利率虽然高（62% vs 批发的 38%），但要背伦敦和纽约的店租、店员工资、装修折旧。**所以你看到毛利率反而从 41% 升到 46.9%，经营利润率却掉了 468 个基点**——这个"毛利率上升、经营利润率下降"的组合就是零售化的典型指纹。
2. **关税。** 供应链从中国往柬埔寨越南转，转移本身有成本，而且新产地一样在被加税。

**所以 TTM 的 1.433 亿不是低点，是"关税灾难年之后回到的新常态"，而这个新常态比五年前低了三分之一。**

### 你现在投 100 块，公司一年替你赚多少

**最保守的合理口径是剔除障眼法后的 23.3 倍，也就是投 100 块一年赚 4.29 元。**

自由现金流口径给出 6.50 元，但那个分母有明确的水分：**3,439 万的折旧摊销里，一半以上是 Kurt Geiger 收购留下的无形资产摊销**。把它当"非现金所以不算钱"是错的——为了维持这个品牌值那个钱，你每年得真金白银地开店、投广告，这笔钱藏在 SG&A 里已经花掉了。所以我取 **4.3 到 5 元**这个区间。

**这 4.3 元里，有多少真回到你口袋？** TTM 分红 6,117 万 + 回购 1,368 万 = **7,485 万，占净利润的 52%**。剩下的一半去了两个地方：资本开支 3,955 万（开店装修）、净还债 1.70 亿。

**但要扣掉 SBC 那 3,069 万——公司回购的钱还不到发给员工股票的一半，你的持股比例每年被稀释 0.66%。真正落到你手里的，是 4,416 万，占市值的 1.28%。**

**这个 4.3 元未来会变大还是变小？我认为变小的概率更大：**

往下的力量：
- **核心的批发鞋类五年零增长**（10.22 亿 → 10.38 亿）。这是主品牌的基本盘，它不长，说明"6 周抄款上架"这个本事已经到顶了——美国百货渠道本身在萎缩，这个池子越来越小。
- **关税还没完。** 供应链在柬埔寨、越南、巴西，这几个地方都在关税名单上，成本是往上的，而鞋子这个品类涨价空间极小（消费者对 99 美元和 109 美元的靴子非常敏感）。
- **要继续增长就得继续收购，但弹药没了。** 五年前手握 1.8 亿净现金，现在背 2.82 亿净负债，账上现金只剩 9,474 万。再买一个 Kurt Geiger 级别的标的，只能靠加杠杆。
- **回购停了。** 过去支撑每股收益的一大块动力消失了。

往上的力量（要说也有）：
- Kurt Geiger 才并进来一年多，欧洲扩店和进美国市场还有空间，如果它能跑通，DTC 这块的经营利润率能从 5%–7% 往上抬；
- 品牌授权那块虽小，但是纯利润，还在慢慢涨；
- 存货管理扎实，没有积压，一旦需求回来利润弹性不小；
- 前瞻市盈率 19.62 暗示市场预期明年利润还能涨两成。

---

## 第四部分：一句话结论

**这不值 24 倍。股价一年涨了 73%，买的是一个五年里"营收 +47%、利润 −25%"的故事。**

把这家公司的五年浓缩成一句话：**它花了将近 4.5 亿美元现金去买 8.75 亿美元的营收，把毛利率买高了、把经营利润率买低了 468 个基点、把 1.8 亿的净现金买成了 2.82 亿的净负债、并且为了付账停掉了每年 1.4 亿的回购。核心的批发鞋类生意，五年一动没动。**

看家本领是真的——"看到趋势 6 周上架"，让百货采购员在猜错之后还有一次纠错机会，这个本事别人学不来。品牌授权那 1,392 万也是干干净净的白拿钱。存货管理扎实，现金流表是干净的，不存在造假嫌疑。

但这个本事已经**触到天花板**了：它服务的美国百货渠道本身在缩，所以主品牌五年零增长；管理层的应对是去买别人的营收，买回来的（Almost Famous 的贴牌服装、Kurt Geiger 的实体店）**都是比原来那门生意更差的生意**——一个没有品牌，一个要背店租。

再加上一个不能忽略的细节：**经营利润线以下连续两年大额漏血**（今年约 3,750 万，去年约 1.17 亿），四张财报页上拆不开，但它不是一次性的。

结论：**主品牌五年零增长、全靠收购堆营收、利润率塌了 468 个基点、回购砍掉九成，还要 24 倍——好公司，坏价格，涨了 73% 之后没有理由现在追。**
