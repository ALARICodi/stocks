# POR · 波特兰通用电力

市值 59.5 亿美元 / 股价约 50.6 美元 / 行业：公用事业（受监管电力） / TTM 截止 2026 年 6 月 30 日

> **这是一家受监管的公用事业，市盈率能用但不够用。** 下面除了常规的多口径市盈率，还要补上受监管企业的核心指标——费率基数（rate base）、准许回报率、市净率与净资产收益率的关系。原因是：这类公司的利润不是市场竞争出来的，是监管机构批出来的，看不懂"批"的逻辑就看不懂这家公司。

---

## 第一部分：它到底做几件事

财报只有**一个报告分部**，所谓的"Revenue by Segment"是按客户类型拆的收入，不是不同的生意。所以这一部分我不拆分部，而是把这门生意本身讲透——因为受监管公用事业的赚钱方式跟正常公司完全不一样，不讲清楚后面所有数字都看不懂。

### 这门生意到底是什么

波特兰通用电力（PGE）是俄勒冈州最大的电力公司，服务范围覆盖波特兰及周边 51 个城市、约 4,000 平方英里，大约 95 万个用电账户，覆盖俄勒冈州将近一半的人口。它是**垂直一体化**的——自己发电、自己输电、自己送到你家电表。

发电这头：克拉卡马斯河和德舒特河上的水电站（有些是 1900 年代建的，现在还在转）、哥伦比亚河谷的风电场（Biglow Canyon、Tucannon River）、几座天然气电厂（Port Westward、Carty）。煤电已经全部退出——2020 年关掉了最后一座 Boardman 燃煤电厂。自己发不够的时候去西部电力市场买。

送电这头：几万公里的输配电线路、变电站、电线杆、变压器，一直到你家墙上那块表。

### 关键：它是怎么赚钱的

**这才是理解这家公司的全部。**

普通公司赚钱靠"卖得贵、成本低"。受监管的电力公司不行——电价不是它定的，是俄勒冈州公用事业委员会（Oregon PUC）批的。那它靠什么赚钱？

靠**花钱**。

流程是这样的：PGE 去建一座变电站，花了 1 亿美元。它把发票拿去给监管机构，说这 1 亿是为了给用户可靠供电必须花的。监管机构审完认可，这 1 亿就进入它的"**费率基数**"——也就是被官方认可的、可以从用户身上赚回报的资产总额。然后监管机构算一笔账：你的费率基数一共多少、其中多少是借的钱（要付利息）、多少是股东的钱（要给回报）、股东那部分批准你赚 **9.3%–9.5% 的回报率**（这叫"准许 ROE"），再加上你的运营成本、燃料成本、折旧。全部加起来除以预计售电量，就是电价。

**所以这门生意的公式是：花的钱越多 → 费率基数越大 → 准许赚的钱越多。** 利润增长几乎等于费率基数增长。

这就解释了两个乍看不合理的现象：

1. **TTM 资本开支 12.28 亿美元，而公司总市值才 59.5 亿。** 它一年往地里埋的钱是自己市值的 21%。正常公司这么烧钱早死了，但对它来说，埋进去的每一块钱都是未来收入的种子。
2. **自由现金流常年为负**（TTM −1.89 亿，FY2023 甚至 −9.38 亿）。它永远赚不出足够的现金覆盖资本开支，差额靠**发债 + 增发股票**补。这不是财务困难，这是这个行业的商业模式。

反过来，风险也在这里：**如果监管机构不批呢？** 如果 PGE 花了钱，监管机构说"这笔支出不合理，不准进费率基数"，或者批准的回报率低于预期，或者审批拖了两年（这段时间叫"监管滞后"），那这笔钱就白花了。**这就是这家公司唯一真正的风险来源，也正是它眼下的问题所在**（见第三部分）。

### 谁在用电，钱从哪来（TTM，截止 2026-06-30，单位百万美元）

| 客户类型 | TTM 收入 | 占比 | FY2025 同比 | 这是谁 |
|---|---|---|---|---|
| 居民 | 1,474 | 41.7% | +2.0% | 95 万个家庭，量最大、单价最高、最稳定 |
| 商业 | 976 | 27.6% | +6.0% | 写字楼、商场、餐厅、医院 |
| **工业** | **576** | **16.3%** | **+23.2%** | **半导体厂 + 数据中心，全部增量在这里** |
| 批发 | 332 | 9.4% | −25.1% | 把富余电力卖给别的电力公司，价格随行就市 |
| 直购电（Direct Access） | 43 | 1.2% | +24.2% | 大客户自己去市场买电，PGE 只收过网费 |
| 替代收入项目摊销净额 | 35 | 1.0% | — | 会计调节项，非现金 |
| 其他 | 98 | 2.8% | — | |
| **合计** | **3,534** | 100% | **+3.9%（TTM 同比仅 +1.3%）** |

**工业那一格是这家公司的全部增长故事。** 五年前只有 2.50 亿，现在 5.76 亿，**翻了 1.3 倍**。原因是波特兰西边的 Hillsboro 一带，也就是俄勒冈人说的"硅森林"——英特尔最大的一批晶圆厂在那里，近几年又叠加了大量数据中心。

这类客户对电力公司是天赐之物：晶圆厂和数据中心**一年 8,760 小时不停机**（术语叫"负荷率高"），不像居民用电白天低晚上高、夏冬两头尖。同样一条线路、同样一座变电站，服务一个数据中心的收入是服务一片住宅区的好几倍，摊薄固定成本的效率高得多。而且它们还逼着 PGE 建新线路新变电站——**又是新的费率基数**。

反过来，批发那一格 TTM 3.32 亿、同比 −25%，是因为水电出力和电力市场价格波动，这部分本来就靠天吃饭，不必当作趋势。

**财报不按客户类型披露利润。** 整体经营利润率 14.35%，我不做分客户估算——受监管企业的成本分摊完全是监管口径的产物，硬估没有意义。

## 第二部分：把会计障眼法剥掉

### 建设期利息资本化（AFUDC）：+2,500 万美元的纸面利润

这是公用事业独有的一个东西，也是本篇最需要点破的会计安排。

PGE 在建一座电厂，建三年。这三年里它借的钱要付利息、投入的股本要占用成本，但电厂还没发电、一分钱收入没有。会计准则允许它把这段建设期的资金成本**当成收入记进利润表**，叫 AFUDC（Allowance for Funds Used During Construction）。

TTM 里这一项是：股权部分 +1,600 万，债务部分 +900 万，**合计 +2,500 万美元**。

问题在哪？**这 2,500 万没有一分钱现金进账。** 它是一张欠条——等电厂建成投产进入费率基数，这笔钱会通过未来的电价一点一点收回来。所以它是"真的"（未来能收到），但它**不是当期赚到的钱**。占 TTM 净利润 2.57 亿的 9.7%，不算小。在本文的真实利润口径里我把它扣掉。

### 一次性项目：−1,300 万美元，规模不大

TTM 有一笔 1,300 万美元的"其他非经常项目"（损失）。FY2025 同样是 −1,300 万，再往前几年是零。金额相对净利润只有 5%，影响有限。按规矩在真实利润里加回去。

### 股权激励（SBC）：1,600 万美元，占净利润 6.2%

**这一批公司里最干净的一家。** 占营收只有 0.45%。公用事业不需要用股票抢硅谷的人才，这是行业特性带来的实在好处。全额当现金成本扣掉。

### 回购与稀释：这一项是全篇最刺眼的地方

- TTM 回购：**0**
- TTM 增发股票：**+2.50 亿美元**
- TTM 派息：**2.36 亿美元**
- **流通股一年增加 5.72%**（FY2025 +6.32%、FY2024 +6.34%、FY2023 +9.27%）

连续四年，每年稀释 6% 上下。

把这三个数放在一起看，一件事就很清楚了：**公司一边发新股募了 2.50 亿，一边把 2.36 亿派给了股东当股息。** 而同期自由现金流是 **−1.89 亿**。

也就是说，**这笔股息不是从赚来的现金里发的，是从新股东和债主口袋里掏出来发给老股东的。**

我要公平地说一句：**几乎所有处于扩张期的受监管公用事业都这么干**，这是行业结构决定的（费率基数要增长就得持续投资，投资额永远超过经营现金流，缺口靠发债和发股补，而股息又必须维持——因为买公用事业的人就是冲股息来的）。这不是 PGE 独有的骗局。

但对你这个投资者，后果是实打实的：**你名义上拿到 4.2% 的股息率，同时每年被稀释掉 5.7% 的持股比例。** 每股收益因此从 FY2024 的 3.01 美元掉到 TTM 的 2.26 美元——**跌了 25%**，其中一部分就是被增发的股数摊薄的。而同期每股股息还从 1.975 涨到 2.126，**连续六年每年涨 5%**。

TTM 派息 2.36 亿 ÷ 净利润 2.57 亿 = **派息率 92%**。这个数字对一家利润在下滑、还要每年花 12 亿资本开支的公司来说，是紧的。

### 利润和现金流的差：完整对账

TTM 净利润 2.57 亿，经营现金流 10.39 亿，差了 7.82 亿——差得非常大，必须逐项拆开（百万美元）：

| 项目 | 金额 | 这是什么 |
|---|---|---|
| 净利润 | 257 | 起点 |
| **+ 折旧摊销** | **+586** | **电厂、电线杆、变电站的账面折旧，不掏现金** |
| + 股权激励 | +16 | 发股票不掏现金 |
| − 应收账款增加 | −21 | 电费还没收上来 |
| + 应付账款增加 | +26 | 多欠供应商一点 |
| − 其他净经营资产 | −22 | |
| **+ 其他经营项目** | **+190** | **⚠️ 见下** |
| + 未单列项 | +7 | 倒挤差额 |
| **= 经营现金流** | **1,039** | |

**这 7.82 亿的差额里，5.86 亿就是折旧。** 这一点对公用事业特别重要：账面上折旧是"费用"，但那笔现金留在公司里，**而且必须原封不动地投回去修电网**。所以公用事业的经营现金流看着很漂亮（市值/经营现金流只有 5.7 倍），实际上其中一大半是电网自己吃掉的。这就是为什么**看公用事业的经营现金流会严重高估它的赚钱能力**。

另外那笔 **+1.90 亿的"其他经营项目"**（FY2025 是 +1.75 亿）值得留意。公用事业这一行通常是递延所得税、养老金、以及**监管资产/负债的摊销**——比如某年燃料成本超支了，监管机构允许你先记成一笔"监管资产"，以后几年通过电价慢慢收回来。这是真现金流入，但本质上是**监管机构给你打的白条在兑现**，不是经营效率变好了。

## 第三部分：估值——市盈率 + 受监管企业专用口径

市值 59.5 亿，企业价值 115.2 亿（多出来的 55.8 亿是净负债）。TTM 有效税率仅 13.47%（风电的生产税抵免 + 超额递延税摊销）。

### 多口径市盈率

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 5,950 ÷ 257 | **23.2 倍** | **4.32 元** |
| 公司自己的调整口径 | 5,950 ÷ 268（仅剔一次性） | 22.2 倍 | 4.51 元 |
| **剔除障眼法后的真实市盈率** | 5,950 ÷ 246.6 | **24.1 倍** | **4.14 元** |
| 自由现金流口径 | FCF = **−1.89 亿** | **无意义** | — |
| 企业价值口径 EV/EBIT | 11,520 ÷ 507 | 22.7 倍 | 4.40 元 |
| 三年平均利润口径 | 5,950 ÷ 292 | **20.4 倍** | **4.90 元** |

**真实市盈率 24.1 倍是这样算的**：税前利润 2.97 亿，加回一次性损失 +0.13 亿，扣掉 AFUDC 的纸面利润 −0.25 亿 = 2.85 亿，按 13.47% 纳税后 2.466 亿。

**自由现金流口径这一格必须留空，不能硬填。** 公用事业的 FCF 结构性为负（过去五年年年为负），因为它的"产品"不是现金，是费率基数。用 P/FCF 评价公用事业等于用体重评价长跑运动员。

**三年平均那一格反而是全表最重要的。** 三年平均净利润 2.92 亿（TTM 2.57 + FY2025 3.06 + FY2024 3.13），比当期的 2.57 亿**高出 14%**。这说明**当前利润是三年里的低点，不是高点**——和第三部分通常揭示的"当前是周期顶"正好相反。

### 受监管企业专用口径：这才是关键

| 指标 | 数值 | 含义 |
|---|---|---|
| 市净率 PB | 1.42 倍 | 你花 1.42 块买它 1 块钱的净资产 |
| 有形账面市净率 | 1.44 倍 | 几乎没商誉，账面很实 |
| **实际净资产收益率 ROE** | **6.45%** | **它实际赚到的股东回报** |
| **监管准许 ROE（俄勒冈）** | **约 9.3%–9.5%** | **监管机构批准它可以赚的** |
| 投入资本回报率 ROIC | 3.34% | |
| 加权平均资金成本 WACC | 5.55% | |
| 利息覆盖率 | **2.04 倍** | 经营利润只够付两倍利息 |
| 负债/权益 | 1.36 倍 | |
| 股息率 | **4.2%** | 每股 2.126 美元 ÷ 50.6 美元 |

**这张表里藏着整个投资逻辑：**

监管机构批准 PGE 可以在股东资本上赚 **9.3%–9.5%**，但它实际只赚到了 **6.45%**。**差了整整 3 个百分点。**

用这套口径换算年回报：ROE ÷ PB = 6.45% ÷ 1.42 = 4.54%，也就是**你投 100 块，一年赚 4.54 元**（和 24.1 倍市盈率对应的 4.14 元是一致的，口径差异来自账面价值与当期利润的时点差）。

**如果它能赚到准许水平**：9.4% ÷ 1.42 = 6.62%，投 100 块年赚 6.62 元，对应市盈率 15 倍。

**所以这只股票的全部问题就一句话：PGE 什么时候能赚回监管批给它的那 3 个百分点？**

为什么现在赚不到？典型原因是"监管滞后"——成本先涨（野火防治投入、保险费暴涨、风暴抢修、外购电价、利率上升带来的利息支出从 FY2021 的 1.37 亿涨到 TTM 的 2.49 亿），而电价调整要等下一次费率听证会才生效，中间这段时间的差额由股东承担。

市场对此的预期是**极其乐观的**：前瞻市盈率只有 **13.68 倍**，倒推每股收益要从 2.26 涨到约 3.70，**一年涨 64%**。对一家受监管的公用事业来说，这个幅度大到不合常理——**我不建议直接采信这个数字**。它要么对应某个具体的费率裁决预期，要么是把远期年份的一致预期错配到了近期。**别把 13.68 倍当成你的买入理由。**

### 说人话：你投 100 块，一年赚多少

按最保守的真实口径，**你投 100 块进去，公司一年替你赚 4.14 元**。

这 4.14 元里回到你口袋的：**股息 4.20 元**（是的，派息比真实利润还多一点点，派息率 92%）。回购是 0。

但这里有个必须说破的东西：**你拿到的这 4.2 元股息，公司并没有赚出来。** 同期自由现金流 −1.89 亿，公司靠增发 2.50 亿新股 + 净增 2.02 亿债务来同时支撑资本开支和股息。所以你名义上拿了 4.2% 的现金回报，实际上**你的持股比例被稀释了 5.7%**。两者相抵，真实回报接近零——**除非公司的费率基数增长（也就是每股背后的资产）跑得比稀释更快**。过去两年它没跑赢：每股收益从 3.01 掉到 2.26。

这个数字未来会变大还是变小？**大概率变大，理由是结构性的**：工业用电（半导体 + 数据中心）五年翻了 1.3 倍还在加速，这类高负荷率客户强制公司扩建电网，费率基数会持续膨胀；三年平均利润高于当期，说明现在是被成本挤压的低点而不是景气顶；监管机构长期不会容忍一家公用事业持续赚不到准许回报，因为那会让它失去融资能力，最终受损的是用户。

变小或者兑现不了的理由：**利息覆盖率只有 2.04 倍**，在一家负债 56 亿、还要每年借新钱的公司身上，这个缓冲很薄；**俄勒冈州的野火责任是一条真实的尾部风险**——西部电力公司因野火索赔而伤筋动骨的先例不止一个，这类事件一旦发生规模是几十亿级别，直接吃掉市值；以及最根本的，**监管是政治过程**，电价上涨会遇到用户和政客的阻力，赚回那 3 个百分点不由公司说了算。

## 第四部分：一句话结论

**不便宜，你买的是"监管机构会补偿它"这个假设，而不是一份现成的现金流。**

24 倍真实市盈率买一家实际净资产收益率只有 6.45%、而准许水平是 9.4% 的公用事业。这个缺口就是全部的多空分歧：它要么是暂时的（成本先涨、电价后调，迟早补回来，那时候这只股票值 15 倍，今天就是便宜的），要么是长期的（俄勒冈的监管环境对股东不友好、野火成本进不了费率基数，那 6.45% 就是它的天花板，24 倍就是贵的）。**这不是一道靠读财报能解决的题，是一道监管题。**

财报本身给出的信号偏谨慎：每股收益两年跌了 25%、派息率 92% 而且股息还在每年涨 5%、自由现金流连续五年为负、每年稀释你 5.7%、利息覆盖率只剩 2.04 倍。**"靠发新股和借债来发股息"这件事，即便是行业惯例，也不能因为惯例就不算数**——它意味着这 4.2% 的股息里没有一分是公司真正赚出来还有余的钱。

好的一面同样真实：垄断特许经营权，95 万用户不可能跑掉；煤电清零，没有搁浅资产的包袱；股权激励只占利润 6%，账面干净、没有商誉泡沫（有形市净率 1.44）；工业用电被"硅森林"的晶圆厂和数据中心推着五年翻 1.3 倍，这是实打实的量增，不是靠涨价撑的。

如果你要的是稳定股息，市面上有股息覆盖得更扎实的公用事业。如果你要赌费率裁决兑现，那就等裁决落地再买——**前瞻 13.68 倍对应利润一年涨 64%，这个预期已经把好消息提前付掉了大半，而它还没发生。**
