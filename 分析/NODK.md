# NODK · NI Holdings（北达科他农场局保险控股）

**市值** 3.10 亿美元 · **股价** 约 15.21 美元 · **行业** 财产与意外险（P&C Insurance）· **交易所** NASDAQ
**TTM 口径截止日：2026 年 6 月 30 日**（最近四个季度滚动，财报发布于 2026 年 8 月 7 日）

> **这是一家保险公司，下面第三部分不用市盈率，改用市净率（PB）、净资产回报率（ROE）、综合成本率这套口径。**
> 原因很简单：保险公司的「利润」是先收钱、后赔钱，中间隔着好几年。今年报出来的利润里，掺着「我猜未来要赔多少」这个主观数字。一家保险公司只要把赔款准备金少提一点，当期利润立刻变好看。所以看保险公司要看两件事：**一是它卖保单本身赚不赚钱（综合成本率），二是它拿着客户的钱去投资赚了多少（投资收益）**。市盈率在这里会骗人——NODK 现在的 40.6 倍市盈率既不说明它贵，也不说明它便宜，只说明它去年利润低得离谱。

---

## 第一部分：它到底做几件事

NI Holdings 是北达科他州法戈市（Fargo）一家老保险公司的上市壳。核心子公司 Nodak Insurance 成立于 1946 年，最早是北达科他农场局（Farm Bureau）给自己会员办的互助保险，2017 年才拆出来上市。到今天，**北达科他州农场局的会员身份仍然是买它某些保单的前提条件**——你得先是农场局会员，才能买 Nodak 的农场险。这个绑定关系是它在北达科他站得住的根本原因，也是它出了北达科他就什么都不是的根本原因。

上市之后它做过一次扩张：花钱买了几家在其他州卖「高风险车险」的公司。这次扩张现在正在被拆掉——这是理解这家公司当下处境最关键的一件事。

按财报披露的分部，它实质上在做五门生意：

### 生意一：房屋和农场险（Home and Farm）—— 最大、最赚钱、最不可替代的一块

这是它的命根子。具体是什么样子：北达科他一个种小麦和大豆的农场主，家里有个住房、几个粮仓、一台约翰迪尔联合收割机、几辆皮卡、还有一片牲畜棚。他跑到镇上的 Nodak 代理人那里，代理人给他开一张「农场主综合保单」（Farmowners Policy）——一张纸把住房、附属建筑、农机具、牲畜、还有「万一雇工在你农场摔断腿告你」的责任险全包进去，一年保费大概三四千美元。冰雹把粮仓砸穿了，Nodak 赔；龙卷风把农机棚掀了，Nodak 赔；家里失火，Nodak 赔。

为什么这门生意不容易被抢走：北达科他人口只有 80 万，全州农场主可能就几万户。State Farm、Allstate 这种大公司为了这么点保费，不值得在法戈养一支懂「粮仓结构怎么定损」「牲畜死亡怎么核价」的理赔队伍。而 Nodak 在这个州有几十年的代理人网络，代理人本身就是当地人，跟农场主是一个教堂的。**这不是技术护城河，是「小市场 + 熟人网络」护城河**——真实存在，但天花板也就是北达科他这 80 万人。

这块 TTM 收了 1.007 亿保费，是全公司最大的一块，而且还在长（+7.2%）。

### 生意二：私家车险（Private Passenger Auto）—— 稳定的第二块

同一个农场主，他家的皮卡和他老婆的 SUV 也在 Nodak 上车险。一年保费一千多美元，撞了车 Nodak 赔修理费。这块跟房屋险是捆着卖的——代理人卖房屋险的时候顺手就把车险也签了，因为捆绑有折扣。所以这块的客户基本就是生意一的同一批人。

TTM 8984 万，基本走平（-1.3%）。这是一门没什么想象力但也不容易掉的生意。

### 生意三：农作物保险（Crop）—— 看着像保险，其实是替美国政府干活

这门生意跟其他几门完全不是一回事，很多人会看错，值得讲清楚。

美国有个联邦项目叫「多重风险农作物保险」（MPCI）。农场主春天播种，最怕的是秋天颗粒无收——可能是旱、可能是涝、可能是冰雹。联邦政府为了保证粮食供应稳定，设了这个项目：**农场主买保险，政府替他掏走一大半保费，赔的钱最后也主要是政府出**。但政府自己不设理赔队伍，它把这活儿外包给 Nodak 这样的私营保险公司来卖单、来定损、来赔付，然后按合同把绝大部分风险再保回联邦风险管理局。

所以 Nodak 在这门生意里，**实质上是拿佣金的承包商，不是承担风险的保险人**。它赚的是「卖单和理赔的服务费」，条款、费率、赔付标准全是联邦定的，它一点定价权都没有。好处是风险有政府兜底；坏处是这门生意的收入完全看天气和粮价，而且永远不可能做成一门有定价权的好生意。

TTM 2117 万，基本走平。

### 生意四：高风险车险（Non-Standard Auto）—— 正在被关掉的那次失败扩张

「非标准车险」（Non-Standard Auto）是行业黑话，说的是：**保险公司都不愿意保的那批司机**。喝酒开车被吊销过驾照的、连续三次追尾的、二十岁开改装车的、信用记录一塌糊涂的。这些人法律上必须有车险才能上路，正规公司拒保，就得去买非标车险——保费贵得多（正常人一年 1200 美元的保额，他要付 3000），但出险率也高得多。

NI Holdings 上市后买了几家专做这个的公司，试图从「北达科他农场主」这个小池子里游出去，到伊利诺伊、内华达这些大州卖高风险车险。结论：**这次扩张失败了，现在正在被拆掉。**

证据就在营收数字里，断崖式的：

| 期间 | 非标车险营收 |
|---|---|
| FY2024（2024年） | 9523 万 |
| FY2025（2025年） | 5000 万 |
| TTM（截至 2026-06） | **2079 万** |

两年掉了 78%。一门生意的营收这么掉，只有一种解释：**公司在主动停售、不再续保、把这块清算掉**（这是从营收轨迹和现金流数据推断的判断，财报分部披露里没有明说「退出」二字）。

这件事对当下的财报影响极大，下面第二部分会看到。

### 生意五：投资组合（Unallocated Net Investment Income）—— 现在唯一真正赚钱的一块

保险公司有个天然优势：保费今天收进来，赔款可能三年后才付出去，这中间的钱可以拿去投资。这笔钱行话叫「浮存金」（float），巴菲特那套玩法的核心就是它。

Nodak 手上的浮存金大概三四亿美元规模（按总资产约 6.5 亿、股东权益 2.49 亿倒推），主要买的是投资级债券这类低风险资产。TTM 收了 **1118 万净投资收益**，外加 **500 万已实现投资收益**（卖债券赚的差价）。

**记住这两个数字，它们是理解这家公司全部利润的钥匙。**

## 第二部分：把会计障眼法剥掉

### 承保到底赚不赚钱？——全篇最重要的一次拆解

这家公司 TTM 税前利润 1119 万。看起来是赚钱的。但钱是从哪来的？

| 项目 | 金额（百万美元） |
|---|---|
| 税前利润（合计） | **11.19** |
| 其中：净投资收益 | 11.18 |
| 其中：已实现投资收益 | 5.00 |
| 其中：手续费及其他 | 0.93 |
| **倒推：承保业务税前损益** | **约 −5.92** |

（估算方法：税前利润减去投资和手续费这几项非承保收入。这是倒推，不是财报直接披露的数字。）

翻译成人话：**它卖了 2.5 亿美元的保单，赔款加上开销比收进来的保费多了大约 590 万。卖保单这件事本身在亏钱。全公司之所以还有 1119 万利润，是因为投资组合赚了 1618 万，把承保的窟窿填上了还有剩。**

换成行业指标就是**综合成本率约 102.4%**（估算）。这个数字的含义是：每收 100 块保费，赔款加费用花掉 102.4 块。行业里 100% 是分水岭，低于 100 才叫承保赚钱。一家优秀的 P&C 保险公司（比如 Progressive 的好年份）能做到 90% 左右。102.4% 属于「不算灾难，但确实在亏」。

### 经营现金流是 −3252 万，这个必须解释清楚

正常公司利润是正的、经营现金流也是正的。NODK 的 TTM 是：**净利润 +783 万，经营现金流 −3252 万**。差了 4000 万，而这家公司市值才 3.1 亿。这是全篇最刺眼的一个数字。

逐项对账（百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | +7.83 | 起点 |
| 加：折旧摊销 | +0.74 | 非现金 |
| 加：其他摊销 | +51.21 | 主要是保单获取成本（给代理人的佣金）的摊销 |
| 加：股权激励 | +1.10 | 非现金 |
| 减：出售投资收益 | −4.56 | 这笔钱算在投资活动里，从经营现金流里剔除 |
| 加：应收账款减少 | +7.82 | 少收了保费——因为保单少了 |
| 加：再保险应收款减少 | +33.98 | 从再保险公司那里收回了钱 |
| 减：未到期保费减少 | −10.47 | **新保单在缩水** |
| 加：所得税项变化 | +1.27 | |
| 减：**保险准备金减少** | **−68.77** | **核心：在付以前年度的赔款，而新保费没跟上** |
| 减：其他经营资产变化 | −6.45 | |
| 减：其他经营活动 | −46.15 | 主要是本期新发生的保单获取成本 |
| **= 经营现金流** | **−32.52** | |

关键在那笔 **−6877 万的保险准备金减少**。保险准备金就是「我估计以后要赔出去的钱」。它减少 6877 万，说明**公司正在大量支付以前卖出去的保单的赔款，而同时新收的保费不足以补上**。

这正是「退出高风险车险」的必然代价：**你停止卖新保单的那一刻，保费流入立刻归零，但旧保单的赔款还要付两三年。** 车祸理赔尤其慢——伤者的医疗费、律师、诉讼，拖上两年是常事。所以退出一门车险生意，会经历一段「只出钱不进钱」的清算期，账面上就表现为经营现金流大幅为负。

**这笔钱不是丢了，是在还债。** 但它意味着接下来一两年，这家公司的现金还会继续往外流，而且这段时间里它的营收和利润基数都会缩水。

公司拿什么填这个洞？看投资活动现金流：**+3245 万**，其中「投资证券」净流入 3195 万——**它在卖债券套现，来支付赔款**。这是清算期的正常操作，但也意味着未来的投资收益会随着投资组合缩水而下降，而投资收益恰恰是它现在唯一的利润来源。

### 股权激励（SBC）

TTM 110 万，占净利润 783 万的 14%。金额不大，不构成扭曲。**按规矩已经当成真实成本从 GAAP 利润里扣掉了，不加回。**

### 回购与稀释

TTM 回购 482 万美元，同期 SBC 110 万。**回购/SBC = 4.4 倍**——这个比值大于 3，说明是真回购，不只是在抵消员工发股。股本从 2059 万股降到 2040 万股，实际减少 0.93%。

按 PB 1.25 倍回购是**略微损害账面价值**的（花 1.25 块买回 1 块净资产），但幅度不大。管理层至少表现出了「把闲钱还给股东」的意愿，这在一堆小盘保险股里不算差。**没有分红**——Ex-Dividend Date 显示 n/a。

### 一次性项目

TTM 里最大的非常规项目是 **500 万已实现投资收益**（卖债券的差价，同比暴增 194%）。这笔钱掺在利润里，让 783 万的净利润看着比实际经营质量好。剔掉这 500 万税前（税后约 350 万），**真实净利润只剩约 433 万**。

需要说明：**只看 TTM 单期，无法判断「卖债券赚差价」是不是年年都有的常规操作。** 从五年数据看，这一项在 FY2021 是 +1548 万、FY2022 是 −1198 万、FY2023 是 +193 万、FY2024 是 +221 万、FY2025 是 +170 万——**波动巨大，不能当成可持续的利润来源**。今年这 500 万显然偏高，很可能是清算期卖债券套现的副产品。

### 资本化的支出

保险公司特有的一项：**递延保单获取成本**（DAC）——付给代理人的佣金不是当期全扣，而是随保单期间摊销。TTM 摊销了 5121 万。这是行业标准做法，没有异常。

## 第三部分：保险口径的估值

### 三个核心比率

| 指标 | 数值 | 怎么读 |
|---|---|---|
| **市净率 PB** | **1.25 倍** | 每股账面净资产 12.21 美元，股价 15.21 美元 |
| 有形账面价值市净率 P/TBV | 1.24 倍 | 跟 PB 几乎一样，说明账上没什么商誉水分——这点是干净的 |
| **净资产回报率 ROE** | **3.18%** | 关键中的关键 |
| 综合成本率（估算） | 约 102.4% | 承保在亏钱 |
| 净投资收益 | 1118 万 | 唯一稳定的利润来源 |
| 净现金 | 5045 万（每股 2.47 美元） | 无负债，这是真实的安全垫 |
| 贝塔（5年） | 0.35 | 股价波动确实小 |

### 换算成「投 100 块，一年赚多少」

保险公司的算法是：**年回报 = ROE × (1 / PB)**。

意思是：公司用自己的净资产一年赚 3.18%，但你不是按净资产价格买的，你付了 1.25 倍。所以你的回报要打个 1/1.25 = 0.8 的折扣。

> **3.18% ÷ 1.25 = 2.54%**
>
> **你现在投 100 块进 NODK，按 TTM 口径，公司一年替你赚 2.54 块。**

这个数字和网站直接算的「盈利收益率 2.52%」完全吻合，互相印证。

### 更保守的口径：把不可持续的投资收益剔掉

上面说了，TTM 里有 500 万已实现投资收益是波动项，不该当常规利润。剔掉之后：

| 口径 | 真实净利润 | 换算 ROE | 投 100 块年回报 |
|---|---|---|---|
| TTM 报表净利润 | 783 万 | 3.18% | **2.54 元** |
| 剔除已实现投资收益后 | 约 433 万 | 1.76% | **1.41 元** |
| 三年平均（FY24 −606万、FY25 −1041万、TTM +783万） | **−288 万** | 负 | **亏钱** |

**最后一行是全表最重要的一行。** 过去三年这家公司平均是亏钱的。2026 年这个 783 万的利润，不是一个正常年份的写照，而是从连续两年亏损里刚爬出来的第一年。五年数据摆在这里：

| 年份 | 净利润（百万美元） | ROE |
|---|---|---|
| FY2021 | +8.42 | 2.39% |
| FY2022 | **−53.10** | −12.88% |
| FY2023 | −5.48 | 7.88%（注：ROE 与净利润符号不一致，为数据源口径差异） |
| FY2024 | −6.06 | 2.67% |
| FY2025 | −10.41 | −4.29% |
| TTM 2026-06 | +7.83 | 3.18% |

**六个期间里四个亏损，最好的一年 ROE 也只有 3.18%。** FY2022 那次亏掉 5310 万——占当时市值的 19%，一年蒸发掉五分之一的公司——是冰雹风暴大年叠加投资组合浮亏。这就是这门生意的真实风险轮廓：**平年赚一点点，灾年一次亏掉五年的利润。**

### 这 2.54 块钱，有多少真回到你口袋

**不分红。** TTM 回购了 482 万，占净利润 783 万的 62%。所以名义上有一半多是通过回购回到股东手上的。

但这里有个陷阱：**公司这一年经营现金流是 −3252 万**。回购这 482 万的钱不是赚来的，是**卖投资组合套现来的**。用变卖资产的钱回购股票，在账面上是「回馈股东」，实质上是在缩小这家公司未来赚钱的本钱。

剩下的钱没有「留在公司里再投资」这一说——投资活动现金流是净流入 3245 万，公司在**净卖出**投资，不是在扩张。

### 这个 2.54% 未来是变大还是变小

大概率**先变小、再看不清**。

**变小的理由是确定的**：
1. 高风险车险清算还没结束，营收还要继续掉，规模效应反向作用，固定费用摊到更少的保费上；
2. 投资组合在被变卖来付赔款，投资收益（唯一的利润来源）会跟着缩；
3. TTM 里那 500 万已实现投资收益属于一次性偏高，明年大概率没有。

**变大的理由是不确定的**：如果它成功退回到「只做北达科他农场主」这个老本行，房屋农场险 +7.2% 的增长是真实的，综合成本率有可能修回到 100% 以下。但这要等清算尾巴付完，至少一两年，而且中间要不出灾年。

## 第四部分：一句话结论

**这家公司不值这个价，而且贵得不含糊。**

摊开说：你花 1.25 倍账面价格，买一家 ROE 只有 3.18% 的保险公司，一年拿回 2.54 块——**这还不如买美国国债**，而且国债不会遇到冰雹。把那笔不可持续的已实现投资收益剔掉，回报掉到 1.41 块；按过去三年平均算，它是亏钱的。

更要命的不是估值贵，是**它现在赚的这点钱全部来自投资组合，卖保险这件事本身在亏**（综合成本率约 102.4%）。一家承保亏钱的保险公司，本质上是一只加了杠杆、还要额外承担飓风冰雹风险的债券基金——你完全可以直接买债券，回报差不多，风险小得多。

唯一真实的正面因素是那 5045 万净现金和干净的资产负债表（几乎零负债、无商誉），以及每股 12.21 美元的账面价值给股价 15.21 美元提供的地板。这个地板意味着它不太可能归零，但也仅此而已。

另外提醒两点：这只股票流通盘只有 605 万股（总股本 2040 万股，大部分被互助控股公司拿着），日均成交 1.9 万股——**买得进去，未必卖得出来**。而且股价过去一年涨了 14.36%，涨的不是利润，是「亏损年终于结束了」这个情绪。

**它正在做的事（退出失败的扩张、缩回老本行）是对的，但市场已经提前把这件事「做成了」的价格给出来了。等它把清算尾巴付完、承保真的转正、PB 跌回 1 倍以下再看，现在没有便宜可占。**
