# QTWO · Q2控股（Q2 Holdings）

市值 $39.2亿 / 股价 $62.84 / 行业：银行数字化软件（SaaS） / TTM 截止 2026-06-30 / 全榜第 699 名（分析日）

---

## 一、它到底做几件事

Q2 实质上做一门生意：**替美国中小银行当"手机银行部门"**，按三种方式收钱。

### 1. 订阅（Subscription）—— 白标数字银行平台，82.6%

美国有几千家地区银行和信用社，资产规模从几亿到几百亿美元不等。它们的储户和大银行的储户一样，要用手机查余额、拍照存支票、转账、还房贷——但一家资产 50 亿美元的社区银行，根本养不起大通银行那种几千人的 APP 开发团队。Q2 干的就是这件事：银行把整个网上银行外包给它。储户打开银行的手机 APP，界面上挂着银行自己的牌子和 logo，底层跑的全是 Q2 的软件。

收钱方式是标准 SaaS：按注册用户数收月费，签 3–5 年长约。一家 30 万数字用户的银行，一年大概付 Q2 两三百万美元。这生意最值钱的地方是**换掉它等于给银行换心脏**——储户要重新学一套 APP、银行要把全部账户数据迁移到新平台、期间任何差错都是挤兑级别的事故，所以银行宁可忍受涨价也不换供应商，客户留存率常年在 95% 以上。

订阅里还包着两个增值件：**PrecisionLender**（商业银行的贷款定价工具——客户经理给企业报贷款利率之前，先问它"按这个客户的存款关系和风险，这单利率报多少才不亏"）和 **Helix**（银行即服务：金融科技公司想给用户开带 FDIC 保险的存款账户，不用自己申请银行牌照，接 Helix 的 API 就行，Q2 背后对接持牌银行）。

### 2. 交易（Transactional）—— 8.4%

储户在平台上交水电费、做账单支付，Q2 从每笔里抽一点手续费。TTM $7,102万，对比 FY2025 全年 $7,064万，基本不增长——这块是随用户量躺着收的过路费，不是增长故事。

### 3. 服务及其他（Services and Other）—— 9.1%

新银行客户上线时的一次性实施费：系统对接、数据迁移、员工培训。TTM $7,663万，同样原地踏步。它的意义是先导指标——实施费进来，说明后面有新的订阅合同。

**分部利润**：财报只按分部披露到营收，利润不拆。整体经营利润率 10.1%（TTM），基本全部由订阅业务贡献——服务和交易业务按行业惯例接近盈亏平衡，此处为估算。

**整体钱况（TTM）**：营收 $8.46亿（+13.9%），毛利率 57.0%，经营利润 $8,533万（利润率 10.1%），净利润 $9,199万。注意这组数字的历史：FY2023 经营利润率还是 **−13.8%**，FY2024 −6.1%，FY2025 +5.3%，TTM +10.1%——这是一家**去年才第一次全年盈利**的公司，经营杠杆正在快速显现。

## 二、把会计障眼法剥掉

**股权激励（SBC）**：TTM $8,426万，**占净利润 $9,199万 的 92%**。这是全篇最大的一个数。公司 Non-GAAP 口径把它加回去，等于说"给员工发的股票不算钱"——不行，它实实在在稀释你的股份，必须当真实成本。GAAP 已经扣了，我们不加回。

**一次性项目**：真正的障眼法藏在税率里——TTM 所得税只交了 $547万，**实际税率 5.6%**。这大概率是历年亏损攒下的递延税资产在转回（亏损年代攒的"抵税券"现在用上了）。抵税券用完后要按 21% 左右的正常税率交税，届时同样的税前利润只剩约 $7,700万净利润。单期口径无法判断这个低税率还能维持几年，但它**一定不可持续**。

**资本化的支出**：TTM 有 $2,421万软件开发费被资本化（现金流表"购买无形资产"一栏），没进当期费用。同期各类摊销 $5,331万（含并购来的无形资产），摊销大于新增资本化，算不上激进,但算 FCF 时这 $2,421万得扣。

**回购与稀释**：TTM 回购 $1.25亿 ÷ SBC $8,426万 = **1.48**——绝大部分回购只是在对冲员工发股，不是回馈股东。股本一年还是**涨了 5.2%**（最近一个季度因集中回购降 3.3%）。另外 TTM 偿还了 $4.95亿可转债，把资产负债表洗干净了：现在净现金 $6,549万，几乎无债。

**利润和现金流的差**：净利润 $9,199万 vs 经营现金流 $2.26亿 vs 自由现金流 $2.13亿，差了一倍多，逐项对账（TTM，百万美元）：

| 项目 | 金额 |
|---|---|
| 净利润 | 92.0 |
| ＋折旧摊销 | 29.0 |
| ＋无形资产摊销 | 53.3 |
| ＋股权激励（非现金） | 84.3 |
| －应收账款增加 | −16.3 |
| ＋应付账款增加 | 11.5 |
| ＋递延收入增加（客户预付） | 6.3 |
| －其他营运资金及杂项 | −34.1 |
| ＝经营现金流 | 226.3 |

现金流远高于利润是 SaaS 的常态（客户预付年费＋SBC 不花现金），本身不是造假。但要算**真实的**自由现金流：$2.13亿 − 资本化软件 $2,421万 − SBC $8,426万 ≈ **$1.05亿**。这才是"如果把发给员工的股票折成现金工资"后，公司真正剩下的钱。

## 三、市盈率，多口径

市值 $39.2亿。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 39.2亿 ÷ 0.92亿 | 42.6 | 2.3元 |
| 公司自己吹的 Non-GAAP | 加回 SBC 后约 1.76亿 | 22.2 | 4.5元 |
| **剔除障眼法后的真实市盈率** | 按 21% 正常税率净利约 0.77亿 | **50.9** | **2.0元** |
| 自由现金流口径 | 39.2亿 ÷ 2.13亿 | 18.4 | 5.4元 |
| 企业价值口径 EV/EBIT | 38.5亿 ÷ 0.85亿 | 45.2 | 2.2元 |
| 三年平均利润口径 | FY23−0.65亿、FY24−0.39亿、FY25+0.52亿，平均为**负** | 无意义 | 0元 |

自由现金流口径的 18.4 倍看着诱人，但它没扣 SBC——扣掉后是 37.4 倍（2.7元）。三年平均那一行是全表最扎眼的：**平均下来这公司三年里还是亏钱的**，眼下的利润是刚出生的新东西。

**大白话**：你现在投 100 块进去，按剔除税收优惠的真实口径，公司一年替你赚约 2 块。这 2 块一分不分红，回购的钱主要在填员工发股的坑，全部留在公司里再投资。好消息是这个"2 块"大概率会变大——营收还在以 14% 增长，经营利润率从三年前的 −14% 一路爬到 +10%，SaaS 的经营杠杆是真的；坏消息是你已经为"它会变大"付了 50 倍的全价。

## 四、一句话结论

生意本身是门好生意——银行换数字银行平台如同换心脏，客户跑不掉，利润刚转正、正在加速释放。但 42.6 倍的账面市盈率靠 5.6% 的临时税率撑着，真实口径约 51 倍，股权激励吃掉九成账面利润，现在买入等于赌"利润连续多年高速增长"一点都不能出错。不便宜，没有安全边际，等它跌。
