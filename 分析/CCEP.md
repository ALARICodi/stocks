# CCEP · 可口可乐欧洲太平洋伙伴（装瓶商）

市值 $477.4 亿（约 €417.4 亿）/ 股价约 $107.7 / 行业：非耐用消费品（软饮料装瓶） / TTM 截止日期：2026 年 7 月 3 日

> **口径说明**：这家公司在纳斯达克上市但用**欧元**记账。下文财务数字一律用欧元（€），涉及市值的地方按 TTM 期间隐含汇率 1 欧元 ≈ 1.144 美元换算。

---

## 第一部分：它到底做几件事

### 先搞清楚一件事：CCEP 不是可口可乐

这是理解这家公司的第一道门槛，绝大多数人搞错。

**可口可乐公司（KO，市值七千多亿美元）卖的是一种叫"浓缩液"（concentrate）的黑色糖浆。** 它在亚特兰大有几个工厂，把配方做成浓缩液，然后卖给全世界的装瓶商。KO 的生意本质是**品牌授权 + 卖糖浆**，毛利率 60%+，几乎不需要资产。

**CCEP 就是买这个糖浆的人。** 它花钱把浓缩液买回来，加水、加糖（或代糖）、打二氧化碳，灌进瓶子和易拉罐，贴上标签，装上卡车，送到英国每一家 Tesco、德国每一家 Aldi、西班牙每一家小酒馆、澳大利亚每一台自动贩卖机里。

打个比方：**KO 是写歌的，CCEP 是全欧洲和亚太的巡演公司**。歌不是你的，但没有你这首歌到不了观众耳朵里。KO 收版税，CCEP 卖门票并且承担场地、卡车、人工的全部成本。

所以两家公司的财务长相完全不同：

| | KO（品牌方） | CCEP（装瓶商） |
|---|---|---|
| 毛利率 | 约 61% | **35.6%** |
| 经营利润率 | 约 30% | **13.6%** |
| 资产 | 轻 | 重（工厂、卡车、冰柜） |
| 生意本质 | 品牌与配方 | 制造与物流 |

CCEP 是全球最大的**上市**可口可乐装瓶商，一年卖 213.5 亿欧元的饮料，39,000 名员工，人均创收 62.6 万美元。

### 它的钱具体怎么赚：三个渠道

**渠道一：超市货架（行话叫 Take-Home / 离店消费）。**

一家英国 Tesco 每周要补三次可乐。CCEP 的卡车拉着托盘进后仓，1.5 升装的可乐一箱（6 瓶）批发给 Tesco 大约 £4，Tesco 零售 £6。这块量最大、单价最低、利润率最薄——超市是有议价权的巨兽，每年都要跟 CCEP 谈降价。这块大约占 CCEP 销量的六成。

**渠道二：小店、餐厅、酒吧（行话叫 On-Trade / 即饮）。**

这是 CCEP 真正赚钱的地方。西班牙马德里街角一家 tapas 小酒馆，CCEP 免费给它装一台**后吧糖浆机**（postmix）——一个不锈钢箱子接自来水和二氧化碳，插一袋 10 升的可乐糖浆。酒馆老板每卖一杯 33cl 的可乐收顾客 €2.5，而那一杯的糖浆成本大概 €0.15。CCEP 卖给他一袋糖浆 €50 左右，能出 300 多杯。

**这台机器是 CCEP 免费送的，条件是店里五年只能卖可口可乐系列。** 冰柜也是免费送的、印着红色 logo 的。这就是为什么 CCEP 的资本开支里有一大块是"冷饮设备"——它在用资产换渠道排他性。这块业务的毛利率远高于超市渠道（估算 45–50% 对超市的 30% 出头）。

**渠道三：自动贩卖机和便利店（即时消费）。**

德国火车站的自动贩卖机，一罐 330ml 可乐 €2.5。这是全渠道毛利率最高的（估算 55%+），因为消费者此刻只想马上喝到，价格弹性接近于零。跟 AutoZone 卖电瓶是同一个道理：**你卖的不是饮料，是"现在就有"**。

### 卖的是什么：不只是可乐

CCEP 手里的品牌组合包括：Coca-Cola / Zero / Diet（约六成销量）、Fanta、Sprite、Schweppes（部分市场）、Monster 能量饮料（CCEP 在欧洲是 Monster 的独家分销商，这块增长最快）、Costa Coffee 即饮咖啡、Powerade 运动饮料、Aquarius、以及各地的瓶装水品牌。近几年增量主要来自**无糖和能量饮料**——欧洲多国开征糖税之后，含糖可乐销量结构性下滑，但零度可乐和 Monster 顶了上来，而且单价更高。

### 钱在哪里赚：按地理分部

CCEP 不按业务线披露分部，按**国家**披露。这是最新 TTM 数字：

| 地区 | TTM 营收（百万欧元） | 占比 | FY2025 同比增速 |
|---|---|---|---|
| 英国 | 3,565 | 16.7% | +4.3% |
| 伊比利亚（西班牙+葡萄牙） | 3,513 | 16.5% | +0.9% |
| 德国 | 3,275 | 15.3% | +0.8% |
| 法国 | 2,492 | 11.7% | +5.0% |
| **澳大利亚** | 2,406 | 11.3% | **−4.6%** |
| **菲律宾** | 1,874 | 8.8% | **+14.4%** |
| 比利时+卢森堡 | 1,104 | 5.2% | +1.1% |
| 荷兰 | 878 | 4.1% | +6.1% |
| 新西兰及太平洋岛国 | 658 | 3.1% | −4.6% |
| 印尼+巴布亚新几内亚 | 569 | 2.7% | −9.4% |
| 瑞典 | 465 | 2.2% | +5.6% |
| 挪威 | 460 | 2.2% | +7.3% |
| 冰岛 | 92 | 0.4% | +7.4% |
| **合计** | **21,351** | 100% | **+2.15%（TTM）** |

**这张表的三个要点：**

1. **西欧五国（英、西、德、法、比荷）合计占七成收入，全部是成熟市场**，增速在 0.8%–5% 之间挣扎。可乐在这些国家已经卖了七十年，人均消费到顶了，增长只能靠涨价和产品结构升级（把普通可乐换成 Monster）。

2. **菲律宾是唯一的亮点**：+14.4%，这是 CCEP 2024 年花 15.24 亿欧元收购菲律宾装瓶业务的成果（现金流量表里 FY2024 那笔 "Cash Acquisitions −1,524" 就是它）。1.1 亿人口、人均可乐消费量只有西欧的三分之一、中位年龄 25 岁——这是 CCEP 未来十年唯一像样的增长故事。

3. **澳大利亚和印尼在退**（−4.6% 和 −9.4%）。印尼的问题是当地经济和消费降级；澳大利亚是竞争和健康趋势。这两块合计占 14%，正在拖后腿。

**利润率说明**：财报按国家披露到营收，**不披露各国的经营利润**。整体经营利润率 13.6%。按行业常识，西欧成熟市场（规模效应大、物流密度高）利润率高于亚太新兴市场（估算西欧 15% 左右、亚太 10% 左右），但这是**估算**，不是财报数字。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 仅 **4,400 万欧元**，占净利润 19.96 亿的 **2.2%**。这是我见过最低的比例之一——欧洲公司普遍不像美国科技股那样用股票发工资，装瓶厂的卡车司机和产线工人拿的是现金工资。这一项对股东几乎没有伤害。

**一次性项目**：TTM 有两笔**方向朝上的**（也就是把利润做好看的）非经常项目：

- **资产处置收益 +9,700 万欧元**：卖厂房、卖地、卖设备赚的钱。
- **重组/减值项目转回 +2,100 万欧元**：过去计提的重组准备金用不完，转回来了。

两笔合计税前 1.18 亿欧元，按 23.23% 的实际税率算，税后约 **9,100 万欧元**，占净利润的 **4.6%**。这两笔在第三部分要扣掉。

需要提醒的是：**只看 TTM 单期无法判断"卖资产赚钱"是不是年年发生。** 事实上 CCEP 近几年在持续关闭和整合欧洲的老旧装瓶厂（FY2024 有 2.18 亿欧元的重组减值，FY2023 是 1,100 万，FY2022 是 4,400 万），所以"重组"这件事对它是**常态**而不是例外——只是今年恰好是转回的一年而不是计提的一年。这种"某几年计提、某几年转回"的模式，让单一年份的利润数字可信度打折。

**资本化的支出**：CCEP 除了 7.17 亿欧元的常规资本开支，还有 **2.32 亿欧元的"无形资产购买"**。装瓶商的无形资产主要是分销权、客户合同和 IT 系统。这笔钱在标准的自由现金流算法里**不被扣除**，导致公布的自由现金流被高估——这是本篇最需要留意的一处口径问题，第三部分我会把两种算法都列出来。

**回购与稀释**：TTM 回购 **11.61 亿欧元**，SBC 仅 4,400 万，**比值 26.4 倍**。这是本次分析里最干净的回购——几乎每一分回购的钱都在真实减少股东人数，而不是填员工发股的坑。股本一年减少 **2.39%**，季度环比 −1.55%（在加速）。同时派息 **9.25 亿欧元**。回购是 2025 年才开始的新政策（FY2024 及之前为零）。

**利润和现金流的差 —— 逐项对账**

TTM 净利润 19.96 亿，经营现金流 30.02 亿，**现金流比利润高出 50%**。这是跟 AutoZone 完全相反的情况。逐项拆开（单位：百万欧元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 1,996 | 起点 |
| + 折旧摊销 | +805 | 装瓶厂、卡车、冰柜的折旧，不用真掏钱 |
| + 其他摊销 | +109 | 收购来的无形资产摊销（菲律宾、澳洲交易的产物） |
| − 资产处置收益 | −97 | 卖资产的账面收益不是经营现金，扣掉 |
| − 重组准备金转回 | −21 | 同上，非现金 |
| + 股权激励 SBC | +44 | 发股票不是现金 |
| **+ 其他经营活动** | **+400** | **口径不透明，见下文** |
| **小计** | **3,236** | |
| − 应收账款增加 | −182 | 超市和分销商欠的钱变多 |
| − 存货增加 | −103 | |
| + 应付账款增加 | +190 | 供应商晚点收钱 |
| − 其他净经营资产 | −139 | |
| **= 经营现金流** | **3,002** | |
| − 资本开支 | −717 | 厂房、产线、冰柜、卡车 |
| **= 标准口径自由现金流** | **2,285** | |
| − 无形资产购买 | −232 | 分销权、IT——实质上是必须花的钱 |
| **= 严格口径自由现金流** | **2,053** | |

**关键在于那笔"其他经营活动 +4.00 亿欧元"。** 这个科目占了净利润的 20%，但财报只给一个汇总数字，不拆分。往年是 +3.17 亿（FY2025）、+1.44 亿（FY2024）、+1.45 亿（FY2023）——说明它是**每年都有的常态项**，不是意外，通常包含养老金精算调整、递延税项变动、衍生品公允价值变动等一堆非现金项目的净额。它年年为正且今年跳增 26%，这一点无法从公开数据里解释清楚，**你需要知道自己的现金流数字里有 20% 是看不透的**。

除掉这个疑点，CCEP 的现金流质量本身是好的：**折旧摊销（9.14 亿）和资本开支（7.17 亿 + 2.32 亿无形 = 9.49 亿）基本打平**，说明公司在维持性投入上不欠账，也没有靠少投资来虚增现金流。存货周转 7.39 次（AutoZone 只有 1.34 次），说明饮料这门生意的周转效率远高于汽配零售。

**债务**：总债务 121.89 亿欧元，现金 19.94 亿，**净负债 101.95 亿**。债务/EBITDA 3.29 倍，利息保障 9.26 倍。这个杠杆比 AutoZone 高（3.29 对 2.73），但**账面净资产是正的（100.3 亿美元，ROE 23.54%）**，不像 AutoZone 那样被回购掏空。债务主要是 2021 年收购澳洲装瓶商（欧元 54 亿）和 2024 年收购菲律宾（15.24 亿）留下的。TTM 借新还旧基本持平（借 19.88 亿、还 19.49 亿），没有恶化。

## 第三部分：市盈率，多口径

先明确基数：市值 **€417.4 亿**（$477.4 亿），企业价值 **€525.5 亿**（$601.1 亿），TTM 净利润 **€19.96 亿**，经营利润 **€28.97 亿**。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 417.4 ÷ 19.96 | **20.9 倍** | **4.78 元** |
| 公司口径 "comparable"（按披露科目还原） | 加回收购无形摊销 1.09 亿、剔重组，税后约 20.5 亿 | 约 20.4 倍 | 4.90 元 |
| **剔除障眼法后的真实市盈率** | 417.4 ÷ 19.05（扣掉税后 0.91 亿一次性收益） | **21.9 倍** | **4.56 元** |
| 自由现金流口径（标准） | 417.4 ÷ 22.85 | **18.3 倍** | 5.47 元 |
| **自由现金流口径（含无形投入，更严格）** | 417.4 ÷ 20.53 | **20.3 倍** | **4.92 元** |
| 企业价值口径 EV/EBIT | 525.5 ÷ 28.97 | **18.1 倍** | 5.51 元（税前、含债权人份额） |
| **三年平均利润口径** | 417.4 ÷ 17.85（TTM+FY25+FY24 平均） | **23.4 倍** | **4.27 元** |

（注：财经网站显示 PE 21.19，用的是"股价 ÷ 每股收益"，每股收益按全年平均股本；这里用"市值 ÷ 净利润"，因为公司在回购、当前股本比全年平均少，所以数字略低。两个都对。）

**说人话：你现在投 100 块进 CCEP，按最保守的真实口径算，公司一年替你赚 4.56 块。**

**三年平均口径给出的 4.27 块，比当期的 4.56 块更低（倍数从 21.9 涨到 23.4）**——这说明 CCEP 现在的利润处在近三年的**相对高点**。原因看得很清楚：FY2024 净利润只有 14.18 亿（当年计提了 2.18 亿重组减值 + 菲律宾收购的一次性费用），FY2025 恢复到 19.42 亿，TTM 19.96 亿。也就是说，**现在的利润水平里有一部分是"没有减值的好年份"带来的**，而 CCEP 关厂整合是持续进行的事，下一次计提大概率还会来。这一点跟 AutoZone（三年平均和当期几乎相同）形成对比。

**这 4.56 块里，你实际能拿到多少？**

CCEP 是本次三家里**唯一真正把钱还给股东的**：

| 用途 | TTM 金额（百万欧元） | 占市值 |
|---|---|---|
| 现金分红 | 925 | **2.22%** |
| 股票回购 | 1,161 | **2.78%** |
| **合计还给股东** | **2,086** | **5.00%** |
| 资本开支（厂房设备） | 717 | 留在公司 |
| 无形资产购买 | 232 | 留在公司 |

**你的 4.56 块里，有整整 5.00 块以分红加回购的形式回到你口袋。** 注意这个数字**超过了**真实盈利口径的 4.56 块——CCEP 派出去的钱比它赚的还多，差额是靠折旧摊销带来的现金（账面折旧 9.14 亿远高于实际的更新支出）和小幅增加的借款补的。这种"派息+回购 > 净利润"的状态可以维持几年，但不是永久性的；一旦下一轮资本开支周期来临（比如再收购一个市场，或欧洲塑料瓶回收法规逼着改产线），回购首先会被砍掉。

**这个 4.56 块未来会变大还是变小？**

**往上的**：菲律宾（+14.4%）是真正的增长引擎，1.1 亿人口的人均可乐消费量还有 2–3 倍空间；Monster 能量饮料在欧洲的分销权是高增长高毛利的业务；欧洲多国开征糖税反而帮了忙——消费者转向零度可乐，而零度可乐的糖成本更低、售价一样；回购在以每年 2.4% 的速度减少股本，这本身就让每股收益复利增长；2026 年糖和铝的大宗价格回落也在改善毛利。

**往下的**：西欧七成的基本盘只有 1–5% 的增长，且完全依赖涨价（销量基本零增长甚至负增长），一旦通胀退潮涨价空间就没了；澳大利亚和印尼在萎缩；101.95 亿欧元的净债务在利率高位是持续的现金流出；欧盟押金回收制度（DRS）和塑料税正在逐国铺开，每铺一国就要重投一遍包装和物流；最根本的结构性风险是——**CCEP 永远在给别人打工**，浓缩液的价格由亚特兰大的 KO 定，KO 每年涨浓缩液价格 CCEP 只能接受，这是装瓶商模式的原罪：**你赚的是运输和灌装的辛苦钱，品牌溢价永远归 KO**。

股价过去 52 周涨了 17.05%，beta 0.48，做空比例 5.89%（不算低）。

## 第四部分：一句话结论

**CCEP 是一门乏味但结实的生意：给别人的品牌开卡车，13.6% 的经营利润率、23.5% 的 ROE、5% 的实打实股东回报（分红 2.2% + 回购 2.8%），在西欧七成成熟市场里赚着稳定的辛苦钱，靠菲律宾提供唯一的增长故事。**

**但 21.9 倍的真实市盈率对一门"营收年增 2%、品牌不归自己、净负债 102 亿"的装瓶生意来说不便宜。** 你买它得到的是一张年化 5% 的类债券票息，外加菲律宾这个彩票。如果你要的就是这个——一个 beta 0.48、跌不动也涨不快、每年现金到账 5% 的仓位——那这个价格勉强说得过去。如果你指望资本增值，别在这里等。

**买它，不如直接买 KO**：同样喝可乐的钱，KO 拿走 30% 的经营利润率而 CCEP 只有 13.6%，KO 不需要买卡车、不需要建厂、不用扛塑料税，还有定价权。CCEP 唯一的优势是便宜——但便宜得也不够多。
