## 第一部分：它到底做几件事

财报按分部披露，两个厂，两门生意，都在德州：

| 分部 | TTM 营收（万美元） | 占比 | FY2025 | 变化 |
|---|---|---|---|---|
| Optex Systems Richardson（理查森厂） | 2344 | 57.1% | 2376 | −1.3% |
| Applied Optics Center Dallas（达拉斯镀膜厂） | 1761 | 42.9% | 1873 | −6.0% |
| 内部交易抵消 | −125 | — | −116 | — |
| **合计** | **3980** | **100%** | **4134** | **+0.81%（同比 TTM 口径）** |

全公司 **140 个员工**，一年做 3980 万美元的生意。客户只有三类：**美国联邦政府、主承包商、外国政府（对外军售）**。没有一个普通消费者。

### 生意一：装甲车辆的"眼睛"——潜望镜和瞄准系统（占 57%）

先说这门生意在物理上是怎么回事。

一辆 M1 艾布拉姆斯主战坦克，车里坐四个人，全部关在一个密封的钢壳里。驾驶员看不见路，车长看不见战场——**他们全靠潜望镜看外面**。一辆坦克上装着十几个这样的光学窗口：驾驶员前方三个视觉块（vision block），车长指挥塔周围一圈，炮长的主瞄准镜旁边还有备份瞄具。布莱德利步兵战车、斯特赖克轮式装甲车、各种轻型装甲车和安保车辆，全是一样的结构。

**这些东西为什么不是普通玻璃？** 四个原因：

1. **抗冲击**——车辆开炮时的爆震、路边爆炸物的破片，玻璃碎了驾驶员就瞎了，所以要用特种夹层玻璃或高强度光学塑料；
2. **抗环境**——从阿拉斯加零下四十度到中东的六十度沙尘，几千小时不能起雾、不能变形、不能划花；
3. **防激光**——这是最值钱的一条。现代战场上对方的测距仪、指示器都是激光，普通玻璃会把激光原样送进人眼，直接致盲。所以镜片上要镀一层**干涉滤光膜**，把特定波长（比如 1064 纳米的钕玻璃激光）反射掉，同时不影响可见光透过。这层膜是整个生意的技术门槛所在；
4. **要通过军方认证**——每一个零件号都对应一份军规图纸，供应商必须通过首件鉴定、进入合格供应商名录，这个过程要一两年。**认证通过之后，替换供应商的成本极高，所以在位供应商的位置很稳。**

Optex 卖的具体是什么（公司自己列的清单）：激光防护和非激光防护的塑料/玻璃潜望镜、电子 M17 日间/热成像潜望镜、视觉块；备用瞄具、数字昼夜瞄准系统、M36 热成像潜望镜、整体反射镜（unity mirror）、车长武器站瞄具、瞄准组件翻修、驾驶员潜望镜组件。还有牵引火炮那一套：**M137 望远镜、M187 座架、M119 瞄准装置、XM10 瞄准圆盘**——这些是 M119、M777 榴弹炮上的机械光学瞄准部件。

**钱是怎么收的，举个具体的账：** 美国陆军的坦克大修线（比如阿拉巴马州 Anniston 基地的艾布拉姆斯翻修项目）一年要翻修几百辆车，每辆车要换一整套视觉块和潜望镜。Optex 通过公开招标拿下这类合同，一份典型订单是**几百万美元、分两到三年交付**。单价上，一个普通塑料视觉块几百美元，一个带激光防护的电子 M17 热成像潜望镜可以到几千美元。所以一份 500 万美元的合同，大概是几千件东西。

**过去三年这门生意为什么爆发：** 俄乌战争之后，北约国家的弹药和装备库存被大量消耗，美国自己的装甲车队也进入了集中翻修周期，同时对外军售订单激增。Optex 的营收从 FY2023 的 2566 万做到 FY2025 的 4134 万，两年 +61%，这一波补库存是主要推力。

### 生意二：Applied Optics Center——镀膜厂（占 43%）

达拉斯这个厂是 Optex 2014 年买下来的，做的是上面提到的那层膜本身，以及围绕它的精密光学件。

产品清单：**激光干涉滤光片、光学组件、激光滤光单元、分划板（reticle，就是瞄准镜里那个十字线）、日间窗口、特种薄膜镀层**，还有枪口基准系统、双筒望远镜、准直仪、测速仪、光学镜片和窗口。

工艺上是这么回事：在真空腔里，把二氧化硅、二氧化钛这类材料一层一层蒸镀到玻璃基片上，每一层的厚度控制在几十纳米（头发丝的千分之一），叠几十层。层数、厚度、材料的组合决定了哪些波长被反射、哪些通过。**这是一门经验大于理论的手艺活**——同样的设备、同样的图纸，不同工厂做出来的良率能差一倍，这也是它的护城河所在。

AOC 的产能一部分供给理查森那边自用（所以有 125 万美元的内部抵消），一部分对外接单——给其他国防承包商和商用光学厂做镀膜代工。**对外这块是这家公司唯一不完全依赖军方订单的收入。**

## 第二部分：把会计障眼法剥掉

### 股权激励（SBC）：一年翻了一倍多

**TTM 股权激励 87 万美元**，而 FY2025 全年只有 38 万、FY2024 43 万、FY2023 25 万。**一年之内跳了 129%。**

- 占 TTM 净利润 389 万的 **22.4%**；
- 占营收的 2.2%。

对一家 6988 万市值、140 人的公司来说，一年发 87 万美元的股票不是小数目。GAAP 已经把它扣在上面那 389 万里了，我不加回来。但要指出：**这笔膨胀发生在营收增长停滞（+0.81%）的同一年**，管理层在生意不增长的时候给自己和员工多发了一倍的股票。

### 一次性项目：一笔 80 万美元的资产减值，位置在营业利润线下面

现金流量表里有一行 **"资产减值与重组费用 80 万美元"**，TTM 和 FY2025 都是 80 万——说明这是同一笔，发生在 FY2025 财年内，还留在 TTM 窗口里。

它的位置可以从利润表倒推出来：经营利润 527 万 − 80 万减值 + 约 14 万利息收入 = **461 万税前利润**，跟财报页给的税前 461 万完全对上。**所以这 80 万记在营业利润线以下，上面那个 527 万的经营利润是干净的。**

这笔减值具体减的是什么，这四个财报页不提供明细。合理的猜测是跟 FY2024 花 105 万买的那笔无形资产有关，但**我没有证据，不下结论**。

**按本文规则，把这笔真一次性损失加回来**（税率 15.73%，税后 67 万）：调整后净利润 **456 万美元**。

**同时必须说清楚一个单期口径的局限：只看 TTM 这一期，分不清"真一次性"和"每年都有的一次性"。** Optex 在 FY2021–FY2024 都没有过这一项，这是五年里第一次，所以我倾向于当作真一次性处理——但如果明年再出现一笔，这个判断就得推翻。

### 资本化的支出：没有

不资本化研发，不资本化软件。FY2024 有一笔 105 万的无形资产购买（外购，不是自己开发资本化），此外五年空白。**这一项干净。**

### 回购与稀释：回购是象征性的

- **TTM 回购 15 万美元**（FY2025 是 5 万，FY2024 是 25 万）。
- **回购 ÷ SBC = 15 ÷ 87 = 0.17。** 参考线：接近 1 才只是抵消员工发股，大于 3 才算真回购。**0.17 意味着公司回购的量只够抵消发出去的股票的六分之一。**
- 结果：**股本一年增加 0.52%**。稀释幅度不大，但方向是错的。
- 唯一一次像样的回购是 FY2022 的 475 万美元，那次把股本实实在在收了一截，之后就再没有过。
- 不分红。

### 利润和现金流的差：这是全篇最需要注意的地方

TTM 净利润 389 万，经营现金流只有 **255 万**，自由现金流只有 **145 万**。差额很大，逐项对账：

| 项目 | 金额（万美元） | 说明 |
|---|---|---|
| 净利润 | 389 | 起点 |
| + 折旧摊销 | 42 | 轻资产 |
| + 资产减值 | 80 | 非现金 |
| + 股权激励 SBC | 87 | 非现金，但是真成本 |
| + 其他经营项 | −20 | |
| − 应收账款增加 | −11 | 收款正常 |
| **− 存货增加** | **−194** | **最大的一笔现金流出** |
| − 应付账款减少 | −8 | |
| − 预收账款减少 | −13 | |
| − 其他经营性资产 | −100 | |
| **= 经营现金流** | **255** | |
| − 资本开支 | **−110** | 比 FY2025 的 49 万翻了一倍多 |
| **= 自由现金流** | **145** | |

**看两件事：**

1. **存货一年增加了 194 万美元。** 财报页给的存货周转率是 **1.78 次/年**——也就是说存货要压七个月才能变成收入。这是国防供应链的常态（长周期订单、特种玻璃和镀膜材料要提前备料、军规件不能临时采购），**但它意味着这家公司每增长一块钱营收，就要先垫进去一笔现金**。营收停滞的这一年存货还在涨，说明要么在为在手订单备货（好事），要么是订单交付被推迟（坏事）。单看一期分不出来。

2. **拉长看，现金转化没有 TTM 这么难看。** 三年累计：净利润 1281 万，经营现金流 1126 万，减去累计资本开支 227 万，自由现金流 899 万 —— **三年现金转化率 70%**。不算优秀，但也不是造假。**TTM 这一期的 37% 是被存货和资本开支的双重高峰压出来的，不是常态。**

## 第三部分：市盈率，多口径

Optex 有 618 万美元现金、148 万美元债务，**净现金 469 万**，占市值的 6.7%——比例不大，但企业价值（EV）因此降到 **6519 万**。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率（市值口径） | 6988 万 ÷ 389 万 | **18.0 倍** | **5.57 元** |
| 公司自己吹的 Non-GAAP | 财报页未提供调整后净利 | — | — |
| **剔除障眼法后的真实市盈率** | 6988 万 ÷（389 + 80×0.843 = 456 万） | **15.3 倍** | **6.52 元** |
| **自由现金流口径** | 6988 万 ÷ 145 万 | **48.2 倍** | **2.07 元** |
| 企业价值口径 EV/EBIT | 6519 万 ÷ 527 万 | **12.4 倍** | — |
| 主业口径（先把净现金拿回来） | 6519 万 ÷ 税后经营利润 444 万 | **14.7 倍** | **6.81 元** |
| **三年平均利润口径** | 6988 万 ÷（377+515+389）/3 = 427 万 | **16.4 倍** | **6.11 元** |
| 市场预期的明年（远期 PE） | 财报页给的 forward PE | 11.2 倍 | 8.94 元 |

（税后经营利润按实际有效税率 15.73% 折算。）

**用大白话说清楚：**

**你现在投 100 块进 Optex，按最保守的口径（剔掉那笔 80 万减值之后的真实利润）算，公司一年替你赚 6.5 块；用三年平均口径算 6.1 块；用最苛刻的自由现金流口径算只有 2.1 块。**

**这三个数字差这么远，全部来自同一个原因：存货和资本开支正在吃掉利润变成的现金。** 我的判断是**取 6 块左右这个中间值最接近真相**——因为三年累计现金转化率是 70%，TTM 的 37% 是一次性的备货和设备投入高峰，不是常态。但要提醒：**如果明年存货继续涨、现金流继续跟不上，那就不是高峰而是这门生意的本来面目**，那时候正确的数字就是 2 块。

**这 6.5 块里，有多少回到你口袋？** 答案是 **0.2 块**——一年 15 万美元的回购，摊到 6988 万市值上是 0.21%。不分红。**剩下的 6.3 块全部留在公司里**，去向很清楚：**194 万变成了存货，110 万变成了设备**。也就是说，这家公司现在赚的钱，正在被它自己的增长（或者说它自己的库存周期）吃掉。

**这个 6.5 块未来大概率变大还是变小？**

**支持变大：** 市场给的远期市盈率是 **11.2 倍**，意味着分析师预期明年每股收益跳到 0.90 美元左右（比 TTM 的 0.55 高 64%）。这个预期的依据只能是在手订单——国防合同是先中标、后交付，backlog 是可见的。如果这个预期兑现，现在 18 倍的市盈率一年后就变成 11 倍。同时 **ROIC 19%、ROE 15.3%** 说明这门生意本身的资本回报是健康的，钱投进去能生出钱来。北约整体扩军、装甲车队翻修周期、对外军售，这几个大环境在未来几年都不会转向。

**支持变小：** TTM 营收只增长 0.81%，两个分部都在环比下滑（Richardson −1.3%，AOC −6.0%）。**过去两年 +61% 的爆发已经结束了。** 而且它的终端客户只有一个——美国政府。美国国防预算里"装甲车辆现代化"这条线的钱是逐年谈判出来的，一次预算调整、一个项目延期，Optex 的营收就断档。**30.7% 的毛利率也说明它在供应链里的位置不算强势**——它是合格供应商，不是不可替代的技术垄断者；真正卡脖子的东西毛利率不会只有三成。

## 第四部分：一句话结论

**这是一门真生意，价格在公道和偏贵的边界上，倾向公道。**

它有实实在在的护城河（军规件认证一旦拿到就极难被替换、镀膜是手艺活）、健康的资本回报（ROIC 19%）、干净的账（不资本化研发、唯一一笔 80 万减值老老实实进了报表）、还有净现金。剔掉那笔一次性减值后 **15.3 倍市盈率、投 100 块一年赚 6.5 块**，对一家在结构性上升的国防供应链里、终端需求确定的公司来说，这个价钱说得过去。股价过去 52 周跌了 6%，现在比 200 日均线低 21%，市场已经把"增长停滞"这件事计入了一部分。

**但要盯住两件事：** 第一，**自由现金流只有 145 万，是账面利润的 37%**——利润正在变成存货而不是现金，这个状态如果持续两年，上面所有的估值都要打三折重算。第二，**营收增速从 +32%、+22% 掉到 +0.81%**，市场却按远期 11 倍在定价（隐含明年利润涨 64%），**这个预期和眼下的实际增速之间是有落差的**，落差要靠在手订单来填。

**这是一家值得放进观察名单的小公司——但下一份季报里的存货和营收，比利润表更值得看。**
