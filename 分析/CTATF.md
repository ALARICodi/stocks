## 第一部分：它到底做几件事

财报的分部只分成「电气机械制造」和「采矿冶炼」两栏，等于没分。按宁德时代年报里的产品线口径，它实质上做四门生意，前两门占九成。

> 分部营收比例按 2024–2025 年报的产品线占比外推到 TTM，标为估算。

### 生意 A：动力电池——给电动车装「心脏」，全球每三辆电动车有一辆用它的电池

**这是什么：** 电动车最贵的一个零件就是电池包，占整车成本三到四成。宁德时代把锂、镍、钴、石墨这些材料做成电芯，再把几百个电芯组装成电池包，卖给车厂。一辆 60 度电（60 kWh）的家用电动车，磷酸铁锂电池包 2025 年的价格大约 0.45–0.5 元/Wh，一包 2.7–3 万元；高端三元锂（麒麟电池）贵一半。特斯拉上海厂的 Model 3/Y、宝马、奔驰、大众、理想、蔚来、小米、吉利、上汽……全球最大的十几家车厂几乎都是它的客户。全球市场份额 38% 左右，第二名比亚迪只给自己用，所以在「对外卖电池」这个市场里它没有对手。

**客户为什么非买不可：** 三个原因。第一，规模——它一年出货 500 多 GWh，材料采购价比小厂低一截，同样的电池它能卖得比别人便宜还赚得比别人多；第二，技术——神行电池充电 10 分钟跑 400 公里、麒麟电池能量密度最高、2025 年推出的钠离子电池不用锂，这些都是行业第一个量产；第三，安全记录——车厂出一次电池起火召回就是几十亿损失，宁德时代十几年没有大规模召回，车厂不敢为省 5% 的价格换供应商。

**怎么收钱：** 跟车厂签年度框架协议，按季度谈价（跟碳酸锂价格联动），车厂下订单、宁德时代交货、账期三到六个月。这门生意的毛利率 22%–25%。

| 动力电池 | 数字（估算） |
|---|---|
| TTM 营收 | 约 3500 亿元 |
| 比上一整年 | 约 +20%（出货量涨、单价基本止跌） |
| 占集团营收 | 约 67% |
| 毛利率 | 约 23% |
| 贡献经营利润（估算） | 约 600 亿元 |

### 生意 B：储能电池——给电网装「充电宝」，增速最快的一门

**这是什么：** 风电和光伏白天发电多、晚上没有，电网需要巨大的电池把电存起来晚上放。宁德时代把电芯装进 20 英尺集装箱（天恒 TENER 系列，一箱 6.25 MWh），一个集装箱大约 300–350 万元，一个大型储能电站要几十到几百个箱子。客户是电力公司、新能源开发商和储能集成商：美国的 NextEra、Fluence，中东的沙特、阿联酋巨型光伏储能项目，澳大利亚、欧洲的电网公司。全球储能电池份额 37%，也是第一。

2025 年开始这门生意爆发：碳酸锂价格跌到底之后，储能的度电成本降到跟建燃气电站差不多，各国电网大规模采购。TTM 营收比上一整年增长估计 40% 以上。储能的毛利率比动力电池高（约 25%–28%），因为客户对价格没车厂那么敏感、对安全和寿命更看重。

| 储能电池 | 数字（估算） |
|---|---|
| TTM 营收 | 约 1100 亿元 |
| 比上一整年 | 约 +40% |
| 占集团营收 | 约 21% |
| 毛利率 | 约 26% |
| 贡献经营利润（估算） | 约 220 亿元 |

### 生意 C：电池材料与回收（邦普循环）

**这是什么：** 子公司邦普把报废电池和生产废料拆开，把里面的锂、镍、钴提出来，做成三元前驱体和碳酸锂再卖回给自己或别人。一吨报废三元电池能回收几万块钱的金属，回收率 99% 以上。这门生意一是保证原材料供应、二是对付欧盟「电池必须含一定比例回收材料」的法规。营收占 5%–6%，利润薄。

| 材料与回收 | 数字（估算） |
|---|---|
| TTM 营收 | 约 300 亿元 |
| 占集团营收 | 约 6% |
| 贡献经营利润 | 小，约 20 亿元 |

### 生意 D：矿产资源 + 其他（技术授权、换电）

财报里的「采矿冶炼」60 亿元就是这个：江西宜春的锂云母矿、玻利维亚锂盐湖、印尼镍矿。矿是拿来压原材料成本的，不是拿来赚钱的，碳酸锂价格低的时候宜春矿还停过产。「其他」里最值得一提的是**技术授权（LRS 模式）**：福特在美国密歇根建电池厂，宁德时代不出资、不持股，只授权技术和派工程师，按产量收授权费，绕开美国对中国公司的限制；换电业务（巧克力换电块）在国内几十个城市铺电站，还在早期。

### 四门生意合起来

| 合计（TTM 截止 2026-06-30） | 数字 |
|---|---|
| 营收 | 5217 亿元（比去年同期 TTM +39.5%） |
| 毛利率 | 24.5% |
| 经营利润 | 935 亿元，利润率 17.9% |
| 净利润 | 850 亿元，利润率 16.3% |
| 每股收益 | 18.70 元（+40.7%） |

**要点：** 2024 年营收曾经跌 9.7%，那是碳酸锂从 60 万元/吨崩到 8 万元/吨、电池降价传导到营收的结果，但利润反而涨了 15%——降价没有伤到它的利润率。现在碳酸锂价格触底，出货量涨 30% 以上直接变成营收涨 39%，利润率还在往上走。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：** 现金流量表没有单列。宁德时代 2020 年以来几轮限制性股票计划，每年摊销的费用大约 10–20 亿元，占净利润 2% 以内，可以忽略。

**一次性项目——这里有一个真正需要扣的大项：** TTM 现金流量表里有 **137 亿元「投资收益」**（Gain from sale of investments），2025 全年 94 亿、2024 年 50 亿、2023 年 39 亿，一年比一年大。这不是一次性的，它是账上 4400 亿现金买理财、结构性存款和股权投资赚的钱——**本质是利息收入，不是卖电池赚的**。占净利润 16%。算真实市盈率时我把它扣掉，因为你买宁德时代是买电池生意，不是买一个 4400 亿的货币基金；而且这个收益随利率和股市波动。另外 TTM 有 32 亿资产减值（主要是宜春锂矿和设备），2024 年高峰时 65 亿，跟碳酸锂价格周期挂钩，单期口径判断不了是否年年有，我按一半加回。

**资本化的支出：** 研发投入一年 200 多亿，绝大部分费用化，资本化比例很低。没有问题。

**回购与稀释：** TTM 回购 51 亿元，分红 387 亿元。但**股本一年增加 3.68%**——2025 年 5 月在香港上市发行 H 股融资约 410 亿港币，用于匈牙利、西班牙工厂建设。这是真稀释，回购远远没抵消。你每股的权益被摊薄了 3.7%，虽然公司拿到了钱。

**利润和现金流的差：** 净利润 850 亿，经营现金流 1348 亿，自由现金流 875 亿。经营现金流比净利润多 500 亿，必须对账，**这张表是理解宁德时代的关键**：

| 从净利润到经营现金流（TTM，亿元） | 金额 | 说明 |
|---|---|---|
| 净利润 | 850 | |
| + 折旧与摊销 | 280 | 工厂设备折旧，固定资产 2000 多亿 |
| + 其他摊销 | 24 | |
| + 资产减值 | 32 | |
| − 投资收益（非经营） | −137 | 理财和股权投资的钱，归在投资活动 |
| + 其他经营调整 | 190 | 主要是售后服务费（质保金）计提，以及递延税 |
| − 应收账款增加 | −621 | 卖得多了，车厂欠的钱也多了 |
| − 存货增加 | −641 | 为了交货备的料和成品 |
| **+ 应付账款增加** | **+1425** | **这一行是关键** |
| **= 经营现金流** | **1348** | |
| − 资本开支 | −472 | 国内外新工厂 |
| **= 自由现金流** | **875** | |

**大白话：** 宁德时代一年多收了车厂 621 亿的欠款、多压了 641 亿的存货，这两项本该吃掉 1262 亿现金，但它同时多欠了供应商 1425 亿——**它用供应商的钱垫了自己的营运资金，还多出 160 亿**。这是行业霸主才有的待遇：车厂要等它交货、供应商要等它付款，钱在它账上多躺半年。2025 年应付款涨了 900 亿，2022 年涨了 1154 亿，年年如此。这不是造假，但要明白：**经营现金流里有一大块是「欠供应商的钱越来越多」撑出来的**，哪天它增速放缓、不再扩张，这条河就会倒流。自由现金流 875 亿跟净利润 850 亿刚好对得上，是巧合，不是「利润全是现金」的证明。

另外投资活动里有 617 亿「买入证券」——就是拿现金买理财，跟上面 137 亿投资收益对应。

## 第三部分：市盈率，多口径

A 股市值 16448 亿元。净现金 2912 亿元（现金及投资 4402 亿、有息负债 1490 亿），占市值 18%。企业价值 13882 亿元。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率（A 股） | 16448 ÷ 850 | 18.8 倍 | 5.3 元 |
| 同上，按港股/场外价 | 乘 1.08 | 20.3 倍 | 4.9 元 |
| 公司自己吹的口径 | 中国公司用「扣非净利润」，TTM 约 760 亿（扣掉政府补助和投资收益的一部分） | 21.6 倍 | 4.6 元 |
| **剔除障眼法后的真实市盈率** | 16448 ÷（850 − 投资收益税后 118 + 减值加回一半 14 = 746） | **22.0 倍** | **4.5 元** |
| 自由现金流口径 | 16448 ÷ 875 | 18.8 倍 | 5.3 元（含供应商垫资，虚高） |
| 企业价值口径 EV/EBIT | 13882 ÷ 935 | **14.8 倍** | 6.7 元（税前） |
| 三年平均利润口径 | 16448 ÷ 三年平均净利润 557（2023 年 441、2024 年 507、2025 年 722） | 29.5 倍 | 3.4 元 |

三年平均口径 29.5 倍，比当期 18.8 倍高一半——**当期利润是三年里的最高点**。但这跟 NVDA 那种「周期顶」不一样：宁德时代的利润是一路涨上来的（441 → 507 → 722 → TTM 850），营收 TTM 还在涨 39%，是成长把利润推高，不是一次性景气。这一行提醒你的是：如果电动车和储能增速掉到个位数，市盈率会从 19 倍立刻变成 25 倍以上。

**大白话：你现在投 100 块进去（按 A 股价），按最保守的真实口径算，公司一年替你赚 4.5 块；按场外/港股价买，是 4.2 块。**

这 4.5 块里：分红拿走 2.4 块（每股 8.37 元，股息率 2.38%，派息率 45%，比大多数中国成长股大方得多），回购只有 0.3 块，而且被 H 股增发抵掉了还倒亏 3.7%——**去年回到你口袋的实际是 2.4 块分红减去 3.7% 的稀释**，等于没拿到。剩下的钱全部投进了新工厂（资本开支 472 亿：德国图林根、匈牙利德布勒森、西班牙萨拉戈萨跟 Stellantis 的合资厂、印尼一体化项目），以及买了 617 亿理财。

**这个 4.5 块未来变大还是变小？** 大概率变大，速度取决于两件事。储能是确定的：全球电网储能装机每年增长 40% 以上，宁德时代吃 37%，这门生意三年内会从两成营收涨到三成。动力电池看欧洲：中国电动车渗透率已经过半、增速放缓到 20% 以下，欧洲还在 25% 渗透率往上爬，匈牙利和西班牙工厂 2026–2027 年投产就是冲着这个。分析师给的三年 EPS 增速预测 26%，只要做到一半，19 倍就是便宜的。

**风险只有一个，但是硬的：地缘政治。** 美国的 IRA 法案把它列为「受关注外国实体」，美国市场基本进不去（只能靠给福特授权技术的曲线方式）；欧盟随时可能加关税或者用「本地化含量」卡它；2025 年美国国防部把它列进「中国军工企业」名单。这些不影响它今天赚钱，但决定了它的天花板在中国 + 欧洲 + 新兴市场，全球最大的单一市场美国基本是零。

## 第四部分：一句话结论

**便宜，是全场少见的「好生意 + 高增速 + 低倍数」组合，前提是你能接受地缘政治这个硬风险。** 企业价值口径 14.8 倍买一家全球份额 38%、营收增长 39%、净现金占市值 18%、股息率 2.4% 的行业霸主，放在美股主板上这个数字要翻倍。真实口径 22 倍是因为我扣掉了 137 亿理财收益，但那 4400 亿现金是实实在在的。要盯的三件事：应付账款那条河别倒流、H 股增发别再来一轮、欧洲别关门。按港股/场外价买要贵 8%，还是便宜。
