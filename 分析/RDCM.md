# RDCM · 瑞康通信（RADCOM Ltd.）

**市值** 1.711 亿美元 ｜ **股价** 10.22 美元 ｜ **行业** Technology Services（电信网络监测软件，以色列公司，纳斯达克上市）｜ **TTM 截止** 2026 年 6 月 30 日 ｜ **全榜名次** 第 1172 名

---

## 第一部分：它到底做几件事

RADCOM 的财报**不按业务分部披露，只按地区披露**——因为它实质上只做一件事。所以这一节我先把这件事讲透，再拆它的收钱方式和地域结构。

### 这件事是什么：给电信运营商的网络装一套"行车记录仪 + 会诊系统"

先说清楚它的客户面对的是什么问题。

一家大型电信运营商有几千万到上亿用户。它的 5G 网络不再是过去那种一台一台的专用设备，而是被拆成了几百个**软件化的网元**（3GPP 标准里的 AMF、SMF、UPF、PCF 这一串缩写），全部以容器的形式跑在 Kubernetes 集群上，分布在几十个数据中心里。这个架构的好处是弹性，坏处是——**出问题的时候没人知道是哪里出的问题**。

具体场景：某个城市的用户开始在社交媒体上抱怨"晚上八点视频通话总是掉线"。运营商的网络运维中心收到告警，但告警只告诉它"某个数据中心的丢包率上升了"。要定位到根因，工程师过去得同时打开十几个系统——核心网的日志、无线基站的性能计数器、传输网的流量图、计费系统的话单——人工比对，一次排障要几个小时到几天。而在这几天里，这个城市的用户在一个一个地转网走人。

**RADCOM 卖的就是解决这件事的软件。** 它的做法是：在网络的关键节点上镜像一份流量出来（不影响正常业务），实时解码里面的信令，把每一个用户的每一次通话、每一次上网、每一次视频会话，**完整还原成一条可以回放的记录**。然后它能直接回答那个问题：

> "晚上八点掉线的是这 4.2 万个用户，他们都挂在 A 数据中心；他们的会话在 SMF 这个网元申请服务质量（QoS）资源时失败了；失败的原因是 UPF 所在的那批服务器在八点被另一个业务的流量打满了 CPU。"

**这就是它的全部价值：把"网络出了点事"翻译成"这一台机器上的这一个函数返回了这一个错误"。** 在电信业这叫 **service assurance（服务保障）**，RADCOM 是这个细分市场里少数几家做到云原生（能跟着 5G 核心网一起跑在容器里、跟着一起自动扩缩容）的供应商。

公司自己列出来的产品线是同一件事的几个层次：

- **RADCOM ACE** —— 核心平台，做网络可见性、服务保障和网络洞察，云原生、容器化；
- **RADCOM AIM** —— AI 分析层，可以套在自家 ACE 上，**也可以套在运营商已经买了的别家老系统上**（这一点很重要，是它抢别人客户的入口）；
- **RADCOM RAN** —— 把同一套能力延伸到无线接入网这一段；
- **RADCOM NWDAF** —— 3GPP 标准里正式定义的"网络数据分析功能"，做闭环自动化，也就是让网络自己发现问题自己调整，不用等人；
- **RADCOM NetTalk** —— 生成式 AI 界面，运维人员可以直接用大白话问："上周三凌晨北区的语音接通率为什么掉了？"

### 钱是怎么收的：大单 + 尾巴

一个大型运营商的合同通常是**多年期、几百万到上千万美元**的规模，按覆盖的用户数或网络容量定价。结构上分两块：

1. **项目交付**——软件许可、部署、跟运营商现有系统的集成。这一块金额大、确认收入的时点集中，**是营收季度间大幅波动的根源**；
2. **年度维护与订阅**——通常是许可金额的 15–20% 每年，只要客户不换供应商就一直收。这是它的经常性收入。

财报页不拆这两块，但可以从毛利率反推它的性质：**TTM 毛利率 76.6%**（营收 6759 万，毛利 5180 万）。这是典型的软件公司毛利率，说明它卖的主要是许可和订阅，不是硬件探针。

### 客户结构：这是全篇最重要的一句话

财报只按地区披露，TTM 口径下（用 FY2025 全年数据看结构）：

| 地区 | FY2025 营收（百万美元） | 占比 | 同比 |
|---|---|---|---|
| 北美 | 38.85 | 54.3% | +7.6% |
| EMEA（含以色列） | 22.52 | 31.5% | +89.7% |
| 亚洲（含日本） | 9.90 | 13.8% | −22.2% |
| 拉美 | 0.22 | 0.3% | −33.3% |
| **合计** | **71.49** | **100%** | **+17.2%** |

北美那 3885 万，**基本上是一个客户**。RADCOM 多年在年报里披露单一最大客户占其营收过半——就是北美的一家超大型运营商（这条信息来自公司年报的客户集中度披露，不在上面那四个财报页里，我单独标注出处）。

**这意味着：这家公司不是有几百个客户的软件公司，它是一个大客户的长期供应商，加上几十个中小客户。** 那个客户如果决定换供应商、或者压价、或者把这块能力自研，RADCOM 一半的生意当天蒸发。EMEA 从 1187 万涨到 2252 万（+90%）是过去一年最好的消息——它说明公司在努力摆脱这个结构，但还远没摆脱。

## 第二部分：把会计障眼法剥掉

### 股权激励（SBC）：这是全篇最刺眼的数字

**FY2025 的股权激励是 612 万美元**（FY2024 610 万，FY2023 612 万——三年纹丝不动地稳定在这个水平）。对比一下：

- 占营收 **8.6%**；
- 占 TTM 经营利润 352 万的 **174%**；
- 换句话说，**这家公司一年发给员工的股票，比它整个主业一年赚的经营利润还多七成**。

按 GAAP 规则，SBC 已经在上面那个 352 万里扣过了，我不给它加回来——这是对的，因为它确确实实稀释了你的股份。但把这个比例摆出来，是为了说明一件事：**如果这家公司不发股票、改成发等额现金奖金，它的主业在 TTM 这个口径下会亏钱。**（营收 6759 万，经营利润 352 万，SBC 612 万——现金口径的经营利润是正的 964 万，但股份数每年多 2%。）

### 一次性项目：没有

TTM 和最近三个财年的利润表里没有大额重组、诉讼和解、商誉减值或并购费用。FY2023 有一笔 248 万的现金收购，规模很小。**这一项干净。**

### 资本化支出：几乎没有

资本开支 FY2025 只有 38 万美元，占营收 0.5%。**RADCOM 不把研发费用资本化**——这是好事，很多软件公司靠把开发人员工资挂到资产负债表上来虚增利润，它没有。研发全部当期费用化，所以那个 5.2% 的经营利润率是老老实实的。

### 回购与稀释：这一项是零分

- **TTM 和过去五年，回购金额都是 0。** 现金流量表的融资活动栏里，五年只有 FY2025 的一笔 **+34 万美元发行股票**（员工行权），此外空白。
- **回购 ÷ SBC = 0 ÷ 612 万 = 0。** 这个比值的正常参考线是：接近 1 说明回购只在抵消员工发股，大于 3 才是真回馈股东。RADCOM 是 **0**。
- 结果：**股本一年增加 2.02%**。你持有的比例每年被稀释掉 2%，而公司账上趴着 1.07 亿美元现金，一分钱不动。
- 也从不分红。

**这是以色列小市值科技股最典型的一种形态：公司很稳、账上很有钱、管理层很舒服，但那笔钱永远不属于小股东。** 从 2021 年到现在，净现金从 6863 万涨到 10685 万，五年多攒了 3822 万，同时股份数一直在增加。**攒下来的钱没有一分钱以任何形式回到过股东手里。**

### 利润和现金流的差：现金流比利润好，但好的部分是纸

FY2025 口径（TTM 的现金流量表这四页没提供，我用 FY2025）：

| 项目 | 金额（万美元） | 说明 |
|---|---|---|
| 净利润 | 1199 | 起点 |
| + 折旧摊销 | 69 | 轻资产，几乎可以忽略 |
| **+ 股权激励 SBC** | **612** | **非现金，但它是真成本** |
| + 存货变动 | 127 | |
| − 应收账款增加 | −120 | |
| + 应付账款 | 18 | |
| **− 预收账款减少** | **−575** | **客户预付的钱在消耗，是个负面信号** |
| + 其他经营性资产 | 131 | |
| **= 经营现金流** | **1461** | |
| − 资本开支 | −38 | |
| **= 自由现金流** | **1422** | |

这张表要看两件事：

1. **自由现金流 1422 万比净利润 1199 万高，靠的主要是把 612 万 SBC 加回来。** 按本文的原则，SBC 是真实成本，所以**"扣掉股权激励后的真实自由现金流"只有 1422 − 612 = 810 万美元**。网站上那个漂亮的 12 倍市现率（P/FCF）、4.5 倍 EV/FCF，都是没扣 SBC 的口径。
2. **预收账款（unearned revenue）一年减少了 575 万。** 预收账款是客户已经付钱但公司还没确认成收入的部分，它是软件公司未来收入的蓄水池。**蓄水池在放水，说明新签的合同没跟上已交付的合同。** 这跟 2026 上半年营收下滑 10% 是同一件事的两面。

## 第三部分：市盈率，多口径

**先说一个必须先做的调整。** RADCOM 市值 1.711 亿美元，账上净现金 **1.0685 亿美元，每股 6.38 美元，占股价 10.22 美元的 62%**。也就是说，你买一股 RADCOM，其中 6.38 美元买的是现金，只有 **3.84 美元**买的是那门生意。企业价值（EV）只有 **6422 万美元**。

同时，TTM 税前利润 791 万里，**有 439 万（55%）是这笔现金存在银行赚的利息，不是主业赚的**。所以直接看 24 倍市盈率会严重误判——它一半是在给一个存款账户估值。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 1.711 亿 ÷ 708 万 | **24.2 倍** | **4.13 元** |
| 公司自己吹的 Non-GAAP | 财报页未提供调整后净利 | — | — |
| **剔除障眼法后的真实市盈率** | 无一次性项目可剔，SBC 按 GAAP 已扣 | **24.2 倍** | **4.13 元** |
| 自由现金流口径（网站口径，未扣 SBC） | 1.711 亿 ÷ 1422 万 | 12.0 倍 | 8.30 元 |
| **自由现金流口径（扣掉 SBC 后）** | 1.711 亿 ÷ 810 万 | **21.1 倍** | **4.74 元** |
| 企业价值口径 EV/EBIT（TTM） | 6422 万 ÷ 352 万 | **18.2 倍** | — |
| **主业口径（先把现金拿回来）** | 6422 万 ÷ 税后经营利润 315 万 | **20.4 倍** | **4.90 元** |
| 主业口径（按 FY2025 正常年景） | 6422 万 ÷ 税后经营利润 743 万 | **8.6 倍** | **11.6 元** |
| **三年平均利润口径** | 1.711 亿 ÷（697+1199+708）/3 = 868 万 | **19.7 倍** | **5.07 元** |

（税后经营利润按实际有效税率 10.55% 折算——RADCOM 享受以色列"优先企业"税收优惠，税率长期在 10% 出头。）

**用大白话说：**

**你现在投 100 块进 RADCOM，按最保守的口径（GAAP TTM 或扣掉股权激励的现金流口径）算，公司一年替你赚 4.1 到 4.7 块。** 这个数字对一家没有债务、毛利率 76%、账上现金堆成山的软件公司来说，**不算便宜**。

**这 4.1 块里，回到你口袋的是 0 块。** 没有股息，没有回购，五年一分钱没还过。全部留在公司里——但也不是拿去再投资了：资本开支一年只有 38 万，研发已经费用化在利润里，收购五年只做过一笔 248 万。**这笔钱既不还给你，也没被用来扩大生意，它就是躺在那里。** 从 2021 到现在，它躺出了 3822 万的增量，仅此而已。

**关键的分歧在最后三行。** 同一家公司，用 TTM 主业口径算是 **20.4 倍**，用 FY2025 主业口径算是 **8.6 倍**——差了 2.4 倍。这个巨大的差距只取决于一个问题：

**2026 上半年营收掉 10%、经营利润腰斩，是一次交付节奏的波动，还是趋势的开始？**

我倾向于"不只是节奏"，理由是预收账款一年放水 575 万——**如果只是这半年的交付晚了，未来的合同还在，预收账款应该是涨的，而不是跌的。** 另外亚洲市场营收 FY2025 已经跌了 22%。

**这个 4.1 块的回报未来会变大还是变小？** 分两种情形，而且分歧极大：

- **变大的路径**：EMEA 那条线继续按 +90% 的势头往上跑，把北美单一客户的占比稀释掉；AI 那几个产品（AIM、NWDAF、NetTalk）在运营商的自动化预算里卡到位置，把营收拉回增长。这条路走通，主业回到 FY2025 的 830 万经营利润甚至更高，现在的 6422 万企业价值就是明显低估。
- **变小的路径**：北美那个大客户的项目周期过去，收入台阶式下滑；成本刚性（325 个员工、612 万的年度股权激励）不跟着降；主业经营利润被压到接近零，公司变成一个"账上有 1 亿现金、生意刚好打平"的壳——而那 1 亿现金你永远拿不到。

## 第四部分：一句话结论

**它值这个价，但它值的那部分主要是账上那 1.07 亿美元现金，不是它的生意。**

你花 10.22 美元买一股，其中 6.38 美元是现金——这给了你一个很硬的底，所以它跌不到哪去。剩下 3.84 美元买的那门生意，用最近这一年的表现算是 20 倍，用去年的表现算是 8.6 倍，**你到底在买哪一个，取决于 2026 上半年营收掉的那 10% 是不是会继续掉**，而预收账款放水 575 万这个细节让我更倾向于会继续掉。

真正让这只票配不上"便宜"两个字的，不是估值，是**分配**：一年发 612 万美元的股票给员工（超过主业整年的经营利润），一年回购 0 元，股本每年多 2%，1.07 亿现金五年不动。**公司的钱确实很多，但那笔钱在管理层手里，不在你手里。**

一半营收压在一个客户身上这件事，最后再说一遍——它不是风险提示，它是这门生意的结构。

**便宜的是壳，贵的是芯。可以放进观察名单，但要等两样东西之一：营收重新增长，或者管理层开始把现金还给股东。**
