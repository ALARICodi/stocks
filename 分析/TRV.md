# TRV · 旅行者保险（The Travelers Companies）

市值 $771.5亿 / 股价约 $370 / 行业：财产与意外险（P&C） / TTM 截止 2026-06-30 / 分析日期 2026-08-29（任务2榜第20名，PE 0–15段）

**这是保险企业，下面用市净率+ROE+综合成本率口径而不是市盈率当主尺子。** 原因：保险公司的「利润」由当年灾害多寡和准备金调整决定，单年市盈率会在周期顶显得极便宜、周期底显得极贵，全反着看；净资产和长期 ROE 才是稳的锚。

---

## 第一部分：它到底做几件事

一门生意：**收保费、赌赔付、拿浮存金吃利息**。具体分三条线（财报按此分部，占比按公司披露结构估算）：

1. **企业保险（约占保费55%）**——给美国中小企业和大公司卖财产险、工伤险、商用车险、责任险。一家有 200 名工人的建筑公司每年付 TRV 几十万美元保费，换工地失火、工人摔伤、工程车撞人时 TRV 来赔。这是 TRV 的看家本领，靠 3 万多名核保员和百年赔付数据给每个客户单独定价——定价错 5%，一单生意就从赚变亏，这门手艺就是护城河。
2. **债券与专业险（约占保费13%，利润率最高）**——给工程项目开履约保证（承包商跑路烂尾，TRV 赔业主）、给上市公司高管卖董责险（股东告高管，TRV 出律师费和和解金）。件均保费高、赔付率低，是三条线里最肥的。
3. **个人保险（约占保费32%）**——通过独立代理人网络卖家庭房屋险和车险，跟 GEICO/State Farm 抢生意。这条线最近几年被通胀（修车修房变贵）和飓风冰雹折磨，刚靠连续大幅提价缓过来。

保险的赚钱公式要拆成两截看：**承保利润**（保费 − 赔付 − 费用，考验定价手艺）+ **投资收益**（保费先收后赔，中间躺在账上的「浮存金」拿去买债券吃息）。TRV 的浮存金对应约 950 亿美元投资组合（按投资收益反推估算），几乎全是债券。

## 第二部分：把会计障眼法剥掉（保险版）

- **股权激励（SBC）**：现金流量表未单列，历年约 2.5–3.5 亿（估算），占净利润约 4%，不构成问题。
- **最大的「障眼法」是周期本身**：TTM 净利 82.4 亿，而 2023–2025 三年分别只有 29.7 / 49.6 / 62.4 亿。**当期利润是三年前的 2.8 倍**，来源是三件好事同时发生：连续多年大幅提价到位、巨灾赔付偏少、往年准备金有释放（单期口径无法精确拆出释放金额，但 ROE 从常年 12% 跳到 26.5% 本身就是证据）。这三件事没有一件能永远持续——财产险是明牌周期行业，提价潮已经见顶（保费增长归零就是信号），下一个飓风大年利润就会被打回去。
- **准备金**：赔付准备金是保险公司最大的可调节科目。TRV 过去十几年准备金持续正向释放（当年提的比实际赔的多），是行业里出了名的保守派，这是加分项。
- **回购与稀释**：TTM 回购 55.1 亿 ÷ SBC 约 3 亿 ≈ **18 倍，真回购**；股本一年缩 4.0%。分红另有 9.9 亿（派息率仅 13%，大头全走回购）。回购+分红合计 65 亿，占市值 8.4%——公司自己也知道利润在周期顶，把超额资本赶紧还掉而不是拿去扩张，这是懂行的做法。
- **利润 vs 现金流**：经营现金流 110.3 亿 > 净利 82.4 亿，差额主要是「先收保费、后赔钱」的时间差（保险负债增加 22.9 亿+摊销 72.4 亿等非现金项，减投资和应收变动）。保险公司现金流常年好于利润，正常。

## 第三部分：估值，保险口径

| 指标 | 数值 | 怎么读 |
|---|---|---|
| 市净率 PB | **2.33** | **它自己十年来最高**（2021年1.33，2022–25年在1.75–2.04） |
| 有形市净率 P/TBV | 2.68 | 同上，历史高位 |
| TTM ROE | 26.5% | 周期顶数字；2021–2023 常态是 11–13% |
| 三年平均 ROE | ≈17.5% | 更接近真实盈利能力 |
| 综合成本率 | ≈88.5%（估算） | 每收100块保费赚11.5块承保利润，好得反常（常态95左右） |
| 浮存金投资组合 | ≈950亿（估算） | 收益率约4.4%，利率下行则缩水 |
| 杠杆 | 债务/权益仅0.27，利息覆盖23.7倍 | 资本结构很干净 |
| GAAP TTM 市盈率 | 9.4 | 假便宜，见下 |
| **三年平均利润市盈率** | **16.3** | **全篇最重要的数字** |

换算成投 100 块的年回报：
- **按 TTM 利润算：一年赚 10.7 块**——这是把周期顶当常态，会高估；
- **按三年平均利润算：一年赚 6.1 块**——这才是靠谱的锚（ROE 17.5% ÷ PB 2.33 ≈ 7.5 块，口径略宽是因为三年里含了 2023 这个灾害大年，真实中枢在 6–7.5 块之间）。

而且要记住：这个回报建立在保险杠杆上（4.8 倍资产/权益），飓风大年或通胀重燃时会剧烈缩水——2023 年它就只赚了 30 亿。好消息是回报里的兑现比例极高：65 亿回购+分红，等于把赚的钱几乎全数还给股东，你的持股每年被动增厚 4%。

## 第四部分：一句话结论

一流的承保手艺、行业里最保守的准备金、真回购、干净的资本结构——生意本身是财产险里的优等生；但 9.9 倍市盈率是周期顶利润造出来的假便宜，按三年平均利润算是 16.3 倍，PB 2.33 更是它自己十年最贵，股价一年涨了 36% 而保费增长已经归零。**好公司，坏时点：现在买等于在提价周期的顶点为「利润会永远这么好」付钱，等下一个灾害大年把 PB 打回 1.8 以下再看。**
