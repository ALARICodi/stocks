# RLLCF / RYCEY · 罗尔斯·罗伊斯（Rolls-Royce Holdings plc）

市值 1,671 亿美元 ≈ **1,257 亿英镑**（按 1 英镑 = 1.33 美元）｜ADR 价 20.12 美元（1 ADR = 1 股普通股）｜行业：航空发动机 / 国防 / 动力系统｜TTM 截止 2026-06-30（财年 = 自然年）｜财报货币：英镑，**全文数字统一用英镑**

> 说明：筛选榜上的代号 RLLCF 是普通股场外线，数据源没有这条线的财报页；同一家公司的 ADR 代号 RYCEY 数据齐全，本文数字全部取自 RYCEY 页面。两条线对应同一份财报、同一个市值。
>
> 这家公司跟汽车「劳斯莱斯」没关系——汽车品牌 1998 年就卖给宝马了。这是造飞机发动机的那个罗尔斯·罗伊斯。2020 年疫情它差点破产，以 32 便士一股贱卖新股融资 20 亿英镑，2022 年还在亏；2023 年新 CEO 上台，三年把经营利润率从 5.6% 拉到 20.7%，股价涨了 18 倍。

## 第一部分：它到底做几件事

数据源的分部只按「卖新机 / 售后服务」拆，公司自己按业务线分四块。两种拆法都要看，因为**罗尔斯·罗伊斯的商业模式核心就在「卖新机」和「售后」的关系上**。

### 先看收钱方式：新机 44%、售后 56%

| 收入来源 | TTM（2026-06） | 上财年（2025） | 变化 | 占比 |
|---|---|---|---|---|
| 卖新设备（发动机、柴油机、反应堆） | 101.21 亿英镑 | 91.03 亿 | +11% | 44% |
| 售后服务（维修、大修、按小时收费） | 130.44 亿英镑 | 121.04 亿 | +8% | 56% |
| 合计 | 231.65 亿 | 212.07 亿 | +9% | |

这张表说的是：**它一半以上的收入来自已经卖出去的机器**，而这些机器在天上要飞 25 年。

### 生意一：民用航空发动机——约占一半，核心中的核心

**这件事是什么**：给宽体客机（就是双通道的大飞机，飞洲际航线那种）造发动机。全球能造大型宽体机发动机的只有两家：美国 GE 和罗尔斯·罗伊斯。具体到机型：空客 A350 只能装 Rolls 的 Trent XWB（独家，没得选），A330neo 只能装 Trent 7000（独家），波音 787 可以选 Rolls 的 Trent 1000 或 GE 的 GEnx。一台 Trent XWB 目录价约 3,000 万美元，一架 A350 装两台。

**怎么收钱——这是理解这家公司的关键**：新发动机基本是亏本或平价卖的。真正赚钱的是「TotalCare」服务合同：航空公司按发动机每飞一小时付一笔钱（几百美元一小时），罗尔斯负责这台发动机 25 年内所有的维护、大修、换件。一台发动机一生要进厂大修三到四次，每次几百万美元，全部包在那个小时费里。

为什么航空公司非签不可：发动机热端的涡轮叶片是单晶合金加特殊冷却孔，只有原厂能造能修，没有第三方。而且发动机不飞就不收钱，航空公司也乐意把风险转给制造商。

这个模式的后果是：**装机量 × 飞行小时 = 收入**。疫情期间宽体机停飞，小时费收不到，公司差点死掉；现在国际航线飞行小时已超过 2019 年，装机量还在涨（A350 订单排到 2030 年后），收入就跟着涨。新 CEO 做的最重要一件事，是把老合同重新谈价——过去为了抢装机，小时费定得太低，现在到期一份涨一份。

### 生意二：国防——约占 22%，最稳的一块

**这件事是什么**：三样东西。第一，英国所有核潜艇的核反应堆——Rolls-Royce Submarines 是唯一供应商，从 1960 年代到现在没换过，正在造的 Dreadnought 级和英美澳 AUKUS 计划的下一代攻击核潜艇都用它的反应堆，一艘潜艇的反应堆是十亿英镑级的合同，排产排到 2040 年代。第二，军用飞机发动机：F-35B 垂直起降那套升力风扇是它造的，美军 B-52 轰炸机换发动机选了它的 F130（76 架、每架 8 台），欧洲台风战斗机的发动机它占一份。第三，军用运输机和舰船的发动机。

**怎么收钱**：政府长期合同，价格锁定、按进度付款，利润率不高但几乎不会丢。现在欧洲各国国防开支从 GDP 的 2% 往 3.5% 加，这块只会涨。

### 生意三：动力系统（MTU）——约占 23%，意外的 AI 受益者

**这件事是什么**：德国 MTU 品牌的大型柴油机和燃气机，装在游艇、货船、火车、矿山卡车上，还有一块是**数据中心备用发电机组**。数据中心不能断电，每个机房都配柴油发电机组，一个大型 AI 数据中心要配几十台、一台上百万美元。2024 年起这块订单翻倍增长，成了 MTU 最大的增长来源。

### 生意四：小型模块化核反应堆（SMR）——现在不赚钱，是未来的故事

把潜艇反应堆的技术放大，做成工厂预制、现场组装的 4.7 亿瓦小型核电站。2025 年被英国政府选为首批三座 SMR 的供应商，捷克也签了意向。2030 年前不会有收入，现在每年往里投几亿。

**分部利润说明**：数据源只披露「新机 / 售后」两分的营收，不披露按业务线的营收和利润。上面四块的营收占比和利润率按公司过往披露的分部数据比例估算，四块贡献利润加总后再扣集团费用，凑到 TTM 经营利润 47.99 亿英镑。**全部标注为估算。**

**整体**：TTM 营收 231.65 亿英镑（+9%），毛利率 28.8%，经营利润率 20.7%（2022 年是 5.6%），净利润 30.38 亿（净利率 13.1%）。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 0.87 亿英镑，占净利润 2.9%。英国公司发股少，**不是问题**。GAAP 里已扣，不加回。

**一次性项目——这家公司的问题不在经营利润，在经营利润以下那一截**：TTM 经营利润率 20.7%，税前利润率却只有 17.4%，中间差了约 7.7 亿英镑的非经营损失。罗尔斯·罗伊斯有一本巨大的外汇对冲账（它用英镑发工资、收美元货款，锁了几百亿美元的远期合约），汇率一动，这本账的公允价值就在利润表里大幅波动，**跟真实生意毫无关系**。TTM 是亏的方向（英镑走弱），FY2025 是赚的方向——**FY2025 净利润 58.41 亿英镑里，有约 27 亿是这种账面浮盈**，那一年税前利润率 32.7% 而经营利润率只有 19.8%。所以看这家公司**不能看净利润，要看经营利润**。单期口径判断不了这种波动每年往哪个方向，但它每年都有、方向随机，这一点是确定的。

**资本化的支出**：TTM 资本化了 3.45 亿英镑的开发费（现金流量表「购买无形资产」那一行，主要是新发动机研发）。同期无形资产摊销 3.04 亿，两边大致相抵，利润表没被明显美化。

**回购与稀释**：TTM 回购 17.26 亿英镑 ÷ SBC 0.87 亿 = **20 倍，是真回购**，股本一年减少 0.70%。另派息 7.95 亿（2020 年停发、2024 年恢复）。回购是 2025 年才开始的，公司 2020 年那次 20 亿英镑的贱价增发让股本膨胀了 39.5%，现在每年买回 0.7%，要买 50 年才能买回来——记着这个。

**利润和现金流的差**：净利润 30.38 亿，经营现金流 51.17 亿，自由现金流 44.61 亿。差距大，拆开：

| TTM 项目 | 亿英镑 | 说明 |
|---|---|---|
| 净利润 | 30.38 | |
| + 折旧摊销 | 5.91 | |
| + 无形资产摊销 | 3.04 | 对应资本化的研发 |
| + SBC | 0.87 | |
| + 其他非现金调整 | 11.12 | **主要就是上面说的对冲账浮亏，账面亏了、没花现金** |
| − 减值 / 出售 / 权益投资收益 净额 | −0.33 | |
| + 应收款减少 | 8.36 | 航空公司按小时预付，收得比记账快 |
| − 存货增加 | −5.68 | 备货交新机 |
| − 其他营运资本 | −2.50 | |
| = 经营现金流 | 51.17 | |
| − 资本开支 | −6.56 | |
| = 自由现金流（数据源口径） | 44.61 | |
| − 资本化的研发 | −3.45 | 数据源没扣，我扣 |
| − 租赁付款 | −2.80 | IFRS 把租金算成还债，我算回成本 |
| = **真实自由现金流** | **约 38.4 亿** | |

结论：现金流比净利润高，**主要因为净利润被 11 亿账面对冲浮亏压低了**，现金流才是真面目。把资本化研发和租赁扣掉后，真实自由现金流约 38 亿，跟「经营利润税后 + 折旧」的量级对得上。**这家公司的账是干净的，只是净利润那一行被汇率噪音搅得看不清。**

## 第三部分：市盈率，多口径

市值按 1,257 亿英镑算。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP（IFRS）TTM 市盈率 | 1,257 亿 ÷ 30.38 亿 | **41.4 倍** | 2.4 元 |
| 公司自己吹的「基础利润」（underlying） | 剔掉对冲浮盈亏后的经营利润 47.99 亿，按 24.4% 税率、扣约 1.5 亿净利息 ≈ 34.8 亿（估算） | 36 倍 | 2.8 元 |
| **剔除障眼法后的真实市盈率** | 净利润 30.38 亿加回约 6 亿税前对冲浮亏的税后影响 4.5 亿 ≈ 34.9 亿；SBC 不加回 | **36 倍** | **2.8 元** |
| 自由现金流口径（数据源） | 1,257 亿 ÷ 44.61 亿 | 28.2 倍 | 3.5 元 |
| 自由现金流口径（扣资本化研发和租赁） | 1,257 亿 ÷ 38.4 亿 | 32.7 倍 | 3.1 元 |
| 企业价值口径 EV/EBIT | (1,257 − 21 净现金) ÷ 47.99 亿 | 25.8 倍 | 3.9 元 |
| 三年平均利润口径 | FY2023–2025 三年经营利润各按税后、扣利息清洗（12.4 / 16.9 / 30.3 亿），平均 **约 20 亿** | **63 倍** | 1.6 元 |

三年平均那一行说明：当期 36 倍，三年平均 63 倍——**现在的利润是三年翻了近三倍之后的数字**。这不是周期顶点（宽体机装机量和飞行小时都还在涨），而是利润率从 11% 到 21% 的一次性修复：老合同涨价、成本削减、疫情后复飞。修复完了，后面只剩装机量增长的 8–10%，没有第二次翻倍。市场给的远期市盈率 33 倍，说明它已经把这个算进去了。

**大白话说：你现在投 100 块进去，按剔除障眼法的真实口径算，公司一年替你赚 2.8 块。** 这 2.8 块里，以分红回到你口袋的 0.6 块、以回购回来的 1.4 块，合计 2 块（真实自由现金流 38 亿几乎全部还给了股东，因为账上已经净现金 21 亿、不缺钱）。留在公司里再投资的：资本开支 6.6 亿加资本化研发 3.5 亿，投向新发动机（UltraFan）、SMR 和产能。

**这 2.8 块未来大概率会变大，但变大的速度是每年 10% 上下，不是过去三年那种**：A350 产量爬坡、数据中心发电机组、国防开支上涨，三个方向都是确定的顺风；老服务合同还有一批没重谈完。**风险**：宽体机是航空业里最周期性的一段，下一次全球衰退或油价飙升，飞行小时一跌，小时费收入立刻缩；Trent 1000 那批发动机的可靠性问题（2018 年曾让几十架 787 停飞）每隔几年出一次；英镑对美元每动 10%，对冲账就在利润表里制造几十亿的噪音。

## 第四部分：一句话结论

**这是一门真正的好生意，价格却是为完美剧本定的。** 宽体机发动机是全球两家分的生意，A350 和 A330neo 独家，卖出去的每台机器绑定 25 年小时费，售后占收入 56%——这是最接近「印钞机」的工业模式。账干净、净现金、真回购、新管理层三年把利润率翻了四倍，这些都是真的。但 41 倍 GAAP、36 倍真实、63 倍三年平均，投 100 块一年赚 2.8 块，买的是「利润率修复已经完成、以后每年再涨 10%」这个剧本，而修复完成恰恰意味着最快的那段增长已经过去。它的报表比西门子能源干净得多（西门子能源的现金流是客户预付款堆的，它的是真的），护城河也深得多——但价格一样贵。**好公司，等一次航空业的坏消息再买。**

**归篮：很贵 / 好生意。**
