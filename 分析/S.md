# S · SentinelOne（AI 终端安全平台）

市值 81.4 亿美元 / 股价 23.98 美元 / 软件-网络安全 / TTM 截止 2026-07-31（财年 1 月底，本文 TTM = 2025-08 到 2026-07 四个季度）

**先说这是哪种亏。** TTM 经营亏损 2.86 亿，但经营现金流是正的 5,730 万，自由现金流 5,650 万。亏的钱几乎全是股权激励（3.22 亿）和摊销。按本文的规矩，发给员工的股票是真成本，所以这是**真亏**：把员工工资全算上，这门生意本身还不赚钱。但它不烧现金，账上 6.55 亿现金零负债，不会死。问题只有一个：值不值 81 亿。

---

## 第一部分：它到底做几件事

财报只按地区分（美国 60%、海外 40%），不按产品分。按它的产品线，实际是两门生意。

### 生意 A：终端安全（Singularity Endpoint）—— 主力，估算占 60%–70%

**大白话**：一家公司有 5,000 名员工、6,000 台电脑和服务器，每台装一个 SentinelOne 的小程序（代理）。这个代理不靠「病毒库」认坏人，而是盯着每个程序的行为：一个程序突然开始批量加密硬盘上的文件，它判断这是勒索软件，当场杀掉进程，并且**把已经被加密的文件自动回滚到加密前**。这个「回滚」是它的招牌功能，对手 CrowdStrike 没有。

**怎么收钱**：按设备数按年订阅，一台设备一年几十美元，套餐越高越贵（基础版只做防护，高配版带调查、威胁狩猎、24 小时托管服务）。上面那家 6,000 台设备的公司，一年付它 30 到 50 万美元。合同一般签一到三年，先收钱后服务，所以资产负债表上有一大笔「递延收入」。

**卖给谁**：中型企业为主。它大量走渠道，尤其是「托管安全服务商」（MSSP，替几百家小公司代管安全的外包商）。2024 年跟联想签了协议，联想卖商用电脑可以预装它。客户里年付费超 10 万美元的有一千多家。

**为什么买它而不是 CrowdStrike**：便宜，同等功能大约打七折到八折；自动化程度高，安全团队人少的公司用得起；有回滚。**为什么很多人还是不买它**：CrowdStrike 是老大，品牌和生态更强；微软把 Defender 打包进 Office E5 套餐，很多公司觉得「反正都付了」。SentinelOne 是这个市场稳定的老三。

### 生意 B：云安全、数据湖、AI 安全 —— 新增长点，估算占 30%–40%

- **云工作负载保护**：保护公司跑在 AWS、Azure 上的服务器和容器。2024 年 1 月花约 1 亿美元买了 PingSafe 补齐这块。
- **Singularity 数据湖 / AI SIEM**：把全公司的安全日志集中存起来、用 AI 查。对标 Splunk 和 CrowdStrike 的日志产品。按存储量收费。
- **Purple AI**：用自然语言问「昨晚哪台机器有异常登录」，AI 给你查出来。是加价卖的附加模块。
- **Prompt Security**（2025 年 8 月，约 2.5 亿美元买的）：企业员工用 ChatGPT 这类工具时，防止把公司机密贴进去、防止 AI 应用被「提示词注入」攻击。这是它押的下一个方向。

公司说新签的订单里有四成以上来自终端以外的产品，所以这块占比在往上走。

| | TTM | 上年同期 | 增速 | 占比 |
|---|---|---|---|---|
| 美国 | 6.64 亿 | 约 5.5 亿 | 约 +21% | 60% |
| 海外 | 4.35 亿 | 约 3.6 亿 | 约 +21% | 40% |
| **合计** | **10.99 亿** | **9.08 亿** | **+21%** | 100% |

毛利率 72.5%，经营利润率 −26%。增速从三年前的 +106% → +47% → +32% → +22% → +21%，减速已经放缓，但也回不去了。分产品利润没有披露，按行业规律：终端这块成熟、应该是赚钱的；数据湖和云安全在投入期、亏。

## 第二部分：把会计障眼法剥掉

**股权激励**：TTM **3.22 亿，占营收 29.3%**。3.4 亿净亏损里 95% 就是它。这不是「非现金」，这是用你的股份给员工发工资：每年发出去相当于市值 4% 的股票。

**一次性项目**：
- **所得税 4,640 万**。一家亏 3 亿的公司交了 4,600 万的税，2026 财年全年更是 1.7 亿（税前亏 2.8 亿、净亏 4.5 亿）。这种规模只可能是递延税资产计提或知识产权跨境转移的税务处理，**单期口径无法判断会不会再来**。
- 其他没有。

**资本化的支出**：两笔。销售佣金签单时不一次计费用，分几年摊，TTM 摊销 1.01 亿；自研软件资本化 2,570 万（在投资活动里）。这两笔加起来 1.27 亿，意味着 GAAP 利润表已经比「现金视角」好看了一些。

**回购与稀释**：回购 1.47 亿 ÷ SBC 3.22 亿 = **0.46 倍**。股本仍然 +3.3%。翻译：花 1.47 亿现金回购，只是把发给员工的股票买回不到一半。这 1.47 亿不是回馈股东，是工资的另一种支付方式。

**利润和现金流的差**（逐项对账，单位百万美元）：

| 项目 | 金额 |
|---|---|
| 净利润 | −340.1 |
| 加：折旧摊销 | +48.4 |
| 加：资本化佣金摊销 | +101.0 |
| 加：股权激励 | +322.1 |
| 减：投资收益 | −8.5 |
| 加：其他 | +9.5 |
| **非现金调整后** | **+132.3** |
| 应收账款增加 | −39.7 |
| 递延收入增加（客户预付一年） | +29.4 |
| 其他营运项目 | −63.1 |
| **经营现金流** | **+57.3** |
| 减：资本开支 | −0.8 |
| **自由现金流** | **+56.5** |

看懂这张表：5,650 万自由现金流是「客户先付一年的钱」和「工资用股票发」堆出来的。**把 SBC 当现金，自由现金流是 −2.65 亿。** 另外 TTM 还花了 2.5 亿现金买 Prompt Security，这笔不在自由现金流里扣。

## 第三部分：亏损口径

| 项目 | 数字 | 说明 |
|---|---|---|
| TTM 营收、同比增速 | 10.99 亿，+21% | 前三年 +47%、+32%、+22%，减速趋缓 |
| TTM 经营亏损（GAAP） | −2.86 亿（−26%） | 四年前是 −130%，改善很快但正在放慢：−60% → −40% → −30% → −26% |
| TTM 经营现金流 / 自由现金流 | +5,730 万 / +5,650 万 | 利润为负、现金为正，差的全是 SBC |
| 一年净烧多少现金 | 不烧钱 | 但把 SBC 当现金，每年少 2.65 亿 |
| 账上现金 − 有息负债 | 6.55 亿 − 0 = 6.55 亿 | 占市值 8% |
| 还能烧几年 | 不适用 | 现金够它按一年 2.5 亿的节奏再收购两三家 |
| SBC 占营收、股本一年膨胀 | 29.3%、+3.3%（回购后） | 股东真正在付的钱 |
| **做到成熟利润率能赚多少** | 拿 Fortinet（GAAP 经营利润率约 30%）和 Palo Alto（约 10%）之间取 **25%**：10.99 亿 × 25% = 2.75 亿，税后（20%）**2.2 亿**。市值 81.4 亿 ÷ 2.2 亿 = **假想市盈率 37 倍，投 100 块年回报 2.7 元** | 这是它明天就变成 Fortinet 的假设 |

**大白话：假设它明天就做到成熟利润率，你投 100 块一年也只能赚 2 块 7。** 而它离那一天还差 51 个百分点的利润率（从 −26% 到 +25%）。过去两年每年改善 10 个点、最近半年只改善 4 个点，按这个速度还要五年以上，期间每年稀释 3%。如果你说「五年后营收翻到 20 亿再乘 25%」，那是 5 亿利润、16 倍市盈率——但那要它五年保持 15% 增速并且 SBC 从 29% 压到 10%，两件事同时成立。

## 第四部分：一句话结论

**会不会死：不会。** 6.55 亿现金、零负债、现金流为正，它想活多久活多久。

**值不值：不值。** 81 亿是在给一个行业老三、增速从 47% 掉到 21%、每年拿营收 29% 发股票的公司，按「它能变成 Fortinet」定价，而变成 Fortinet 之后也只有 37 倍。产品是真的好（回滚功能、AI 安全的布局都不是吹的），但好产品和好价格是两回事。比 CrowdStrike 便宜不是理由，CrowdStrike 也贵。
