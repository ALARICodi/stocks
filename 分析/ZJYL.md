# ZJYL · Jin Medical International（吉美国际／常州中进医疗器材）

市值 1.835 亿美元 · 股价 $2.34 · 行业：医疗器械（轮椅制造，中国江苏常州）· TTM 截止 2026 年 3 月 31 日

---

## ⚠️ 开篇必须先说的一件事：15.62 倍市盈率是假的

这家公司是靠"市盈率 15.62 倍"被筛进任务1名单的。**这个数字是一个数据口径事故，真实市盈率是 157 倍。**

拆开看就明白了：

| 数字 | 数值 | 出处 |
|---|---|---|
| 股价 | $2.34 | 2026-08-28 收盘 |
| 每股收益 EPS | $0.15 | TTM（截至 2026-03-31） |
| **股价 ÷ EPS = 显示的市盈率** | **15.62 倍** | ← 筛选器抓到的就是这个 |
| TTM 净利润 | **117 万美元** | 同一份财报 |
| 当前流通股数 | **7843 万股** | 2026-08-29 |
| **市值 ÷ 净利润 = 真实市盈率** | **157 倍** | |

两个数字差了十倍，原因是：**那个 $0.15 的每股收益，是用截至 2026 年 3 月的加权平均股数约 780 万股算出来的（117 万 ÷ 780 万 = 0.15）；而 $2.34 的股价对应的是今天的 7843 万股。** 分子用今天的价，分母用五个月前的股数，中间这家公司的股份增加了十倍——市盈率就凭空缩小了十倍。

同一个错误在市净率上重复了一遍：网站显示 **PB 0.60 倍**（股价 2.34 ÷ 每股净资产 3.87，而 3.87 = 净资产 3015 万 ÷ 旧股数 780 万），看起来"低于净资产、白菜价"。但用市值直接除：**1.835 亿 ÷ 3015 万 = 6.09 倍市净率**。同一个网站自己给出的 P/TBV（市值/有形净资产）是 **6.29 倍**，EV/Earnings 是 **148.68 倍**，EV/EBITDA 是 **265 倍**，EV/EBIT 是 **417 倍**——这三个用市值口径算的指标才是对的，它们互相印证，也印证了 157 倍这个结论。

**所以这家公司不是"15 倍的便宜医疗器械股"，它是一家 157 倍市盈率、9.3 倍市销率、6.1 倍市净率的公司，而且营收在下降、经营利润率从 15.5% 塌到 2.1%、自由现金流是负的 696 万。**

下面还是按完整规格分析一遍，因为"为什么股数会在五个月里增加十倍"这件事本身，比市盈率更值得看。

## 第一部分：它到底做几件事

Jin Medical International 是一家在开曼注册、2023 年在纳斯达克上市的公司，实际经营主体是**常州中进医疗器材有限公司**，2006 年成立，江苏常州。273 名员工，TTM 营收 1973 万美元（约 1.4 亿人民币）——**这是一家人民币一亿多营收的中国小制造厂**。

需要先说清楚股权结构：常州中进是一家 **VIE（可变利益实体）**，也就是说你买的这只美股，法律上持有的是一家开曼公司，这家开曼公司通过一堆合同（而不是股权）来控制常州中进的经营和利润。这是中国公司赴美上市的老结构，风险是众所周知的：**你手里那张纸和常州那家工厂之间，隔着一叠合同，不是股权。**

财报没有按产品线拆分部，只按地区拆。但从公司披露的产品结构看，实质上是**一门半生意**。

### 生意一：轮椅制造（占营收 97% 左右）

这就是全部。公司自己披露过：2022 财年，轮椅和轮椅零部件占营收 **96.9%**，其余 3.1% 是氧气机、洗澡机之类的生活辅助器具。

生意具体长什么样：**这是一家 ODM 代工厂，不是品牌商。**

一个日本的医疗器械经销商（比如给日本各地的介护保险机构、老人院、康复中心供货的批发商）拿着一份规格书找到常州中进：要一款手动轮椅，铝合金车架、可拆卸脚踏、24 寸后轮、承重 100 公斤、总重必须低于 12 公斤（日本老人院对护工搬运重量有硬要求）、坐垫用特定的抗菌面料、必须通过日本 JIS T9201 认证。常州中进负责设计、开模、采购铝管和轴承、焊接、喷涂、装配、包装，贴上经销商自己的品牌标签（或者不贴品牌，由经销商在日本再贴），装柜发到大阪港。**一台这样的中高端手动轮椅，出厂价大约在 150–250 美元之间。**

按 TTM 营收 1973 万美元、假设平均单价 200 美元倒推，**一年大约卖出十万台上下的轮椅**。手动轮椅这个品类，公司有三十多个型号，覆盖从最便宜到中高端的价位带。

**两个市场，两套打法：**

- **日本（FY2025 占 58.6%，1213 万美元）**——卖中高端。日本是全世界老龄化最深的国家，介护保险制度会给符合条件的老人报销轮椅租赁费用，需求刚性且长期稳定。日本客户的特点是验厂严、认证多、改单少、价格谈定就长期不变、账期规矩。**这是公司最好的一块业务，也是它唯一称得上"护城河"的东西——通过了日本客户的验厂和认证体系，换一家供应商的转换成本对日方来说不低。**
- **中国大陆（FY2025 占 21.3%，441 万美元）**——卖中低端，走国内经销商和医疗器械集采渠道，价格战激烈，毛利远低于日本。

其余散在美国（FY2025 166 万，8.0%）、韩国（134 万，6.5%）、香港（44 万）、新加坡（20 万）、澳大利亚（20 万）、其他（30 万）。

**这门生意的经济本质**：铝材加工 + 人工装配，技术门槛不高（轮椅不是植入器械，不需要临床试验），壁垒在于**认证 + 客户关系 + 成本控制**三样。毛利率 31.28%，对一家代工厂来说算不错，说明日本那部分中高端产品确实有溢价。但它的天花板也很清楚：**你永远赚的是代工的钱，客户随时可以把订单挪到越南或者国内另一家厂。**

### 生意零点五：新工厂和一份还没落地的收购意向

TTM 里最反常的一个数字是**资本开支 637 万美元**。对比历史：FY2021 是 4 万、FY2022 是 4 万、FY2023 是 11 万、FY2024 是 14 万——**然后 FY2025 突然变成 663 万，TTM 是 637 万。**

钱花在哪：公司在**安徽滁州**设了一家全资子公司"中进医疗器械（安徽）有限公司"，建了新厂（对外称"三号工厂"），已经投产。从常州搬一部分产能到滁州，逻辑是常州的人工和地价太贵，滁州便宜——这是长三角制造业最常见的产能外迁路径。

另外公司还签了一份**收购"医疗器械共享平台"的意向书**（MOU）——共享平台的意思大致是把轮椅、护理床这类设备做成扫码租赁，按天收费。这跟制造完全是两门生意。**意向书不是协议，还没花钱，但它说明管理层的注意力已经不在轮椅代工上了。**

### 这门生意的钱

|---|---|---|---|
| 营收 | **1973 万** | 2069 万 | **−4.65%** |
| 毛利 | 617 万 | 624 万 | −1.1% |

**分部利润财报不披露，无法拆分日本业务和中国业务各自赚多少。** 合理推断是日本业务贡献了绝大部分（甚至全部）利润，中国业务在盈亏线附近——但这是估算，不是财报数字。

**真正要看的是营收和利润率的五年轨迹：**

| 财年 | 营收 | 经营利润率 | 净利润 |
|---|---|---|---|
| FY2021 | 2076 万 | 12.67% | 263 万 |

**FY2024 是顶点，之后两年营收掉了 16%，经营利润率从 15.48% 塌到 2.12%——掉了 86%。** 毛利率只从 40.89% 降到 31.28%（降了 9.6 个百分点），但经营利润率降了 13.4 个百分点，说明**费用还在按老规模开支，而收入撑不住了**：新建的滁州工厂产生折旧和固定人工，销量却在下滑，典型的产能爬坡期挨打。

## 第二部分：把会计障眼法剥掉

### 1. 股权激励
财报现金流量表里**没有股权激励这一行**，公司规模太小、也没有这个惯例。**没有。**

### 2. 一次性项目
TTM 里没有大额一次性损益：坏账计提 10 万、资产处置损失 4 万、其他经营活动 −43 万，都是零头。**净利润 117 万里没有一次性水分。**

需要点出的反而是相反的方向：**税前利润 126 万比经营利润 41.8 万高出 84 万**，也就是说这家公司经营层面几乎不赚钱，净利润主要靠非经营项目撑着（很可能是利息收入、政府补贴和汇兑损益——中国制造业上市公司拿地方政府补贴是常态，但财报页不拆分，无法确认）。**一家净利润 117 万的公司，其中约 70% 不来自主营业务。**

另外有效税率只有 **7.84%**（交了 9.9 万美元税）。中国的高新技术企业所得税优惠税率是 15%，小微企业更低，7.84% 说明它享受了地方性税收减免。**这部分优惠不是经营能力，而且随政策变动。**

### 3. 资本化的支出
财报没有单列研发资本化或软件资本化。但 **637 万美元的资本开支**本身就是一种"把当期支出变成未来折旧"的操作——滁州新厂的投入现在计入固定资产，不进当期损益，未来会以折旧的形式一点点吃掉利润。TTM 折旧摊销只有 **31 万美元**，说明新厂的折旧还没大规模开始计提。**未来两年，仅滁州工厂一项就会给这家净利润只有 117 万的公司增加每年数十万美元的折旧。**

### 4. 回购与稀释 —— 这是本篇最严重的一项
公司**从未回购过一股**。反方向的事情倒是做了很多：

| 时间点 | 股数 |
|---|---|
| FY2021–FY2023 加权平均 | 约 700 万股 |
| FY2024–FY2025 加权平均 | 约 800 万股 |
| TTM（截至 2026-03-31）加权平均 | 约 **780 万股** |
| **今天的流通股数** | **7843 万股** |

**在最近一份财报之后的这五个月里，股份增加了大约十倍。**

同期还发生了一件事：**2026 年 3 月 16 日做了 1 比 20 的反向拆股**（20 股并成 1 股）。反向拆股的唯一用途是把股价拉高——纳斯达克要求上市公司股价长期不低于 1 美元，跌破就退市警告。做 1:20 的反向拆股，意味着拆股前股价大约是 **0.10–0.15 美元**。

把这两件事放在一起，故事就完整了：

1. 股价跌到一毛钱，面临退市；
2. 1:20 反向拆股，股价拉回到 2–3 美元；
3. 拆股后立刻大规模增发新股，股份从 780 万变成 7843 万。

**这是小盘股最经典的一套动作：反向拆股腾出发行空间 → 增发 → 股价被稀释再跌 → 再反向拆股。** 数据完全吻合：52 周股价跌幅 **−85.71%**（而且这还是在反向拆股把股价乘以 20 之后的口径）；日均成交量 **216 万股**，对一家 6484 万股流通盘的公司来说换手极高，是典型的高度投机交易；**机构持股比例 0.03%**——基本上没有任何一家机构投资者持有这只股票；Piotroski 财务健康评分 **2 分（满分 9 分）**；Beta 值 **7.34**，意思是大盘涨跌 1%，它平均动 7.34%。

### 5. 利润和现金流的差 —— 差额巨大，逐项对账
净利润 117 万，经营现金流 **−59 万**，自由现金流 **−696 万**。**赚了账面利润，却在流出现金。**

| 步骤 | 金额 | 说明 |
|---|---|---|
| 净利润 | +117 万 | |
| + 折旧摊销 | +31 万 | |
| + 坏账计提 | +10 万 | |
| + 资产处置损失 | +4 万 | |
| − 其他经营活动 | −43 万 | |
| + 应收账款减少 | +30 万 | 收回了一点货款 |
| **− 存货增加** | **−167 万** | ← 主要漏点：货压在仓库里 |
| − 应付账款减少 | −60 万 | 给供应商付款更快了 |
| + 预收款增加 | +14 万 | |
| − 所得税相关变动 | −30 万 | |
| + 其他经营性资产变动 | +35 万 | |
| **= 经营现金流** | **−59 万** | |
| − 资本开支（滁州工厂） | −637 万 | |
| **= 自由现金流** | **−696 万** | |

**两个漏点：存货增加 167 万，资本开支 637 万。**

存货这一笔要特别看：存货周转率 **2.16 次/年**，意味着一批货平均要在仓库里躺 **169 天**。在营收下滑 4.65% 的同时存货还在增加 167 万，这是"生产出来卖不掉"的典型信号。轮椅不像电子产品会技术过时，但铝制品会积压占用资金，而且一旦客户改款，老库存就要打折清。

现金怎么补上的：**借钱。** 债务从 FY2022 的 0 → FY2023 的 411 万 → FY2024 的 1160 万 → FY2025 的 1891 万 → 现在 **2090 万美元**。TTM 借新还旧的流水是借入 2662 万、偿还 2197 万，净借入 465 万。**账面现金 3010 万看起来很厚，但其中 2090 万是借来的，净现金只有 920 万，而且一年就少了 14%。**

对一家净资产只有 3015 万美元的公司来说，2090 万的债务对应 **0.69 倍的债务/净资产比**，Debt/EBITDA 高达 **23.9 倍**（EBITDA 只有 66 万美元）——**这个杠杆水平，靠现在的盈利能力还债需要二十四年。**

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| ~~网站显示的市盈率~~（**错误口径**） | 股价 2.34 ÷ 旧股数算出的 EPS 0.15 | ~~15.6 倍~~ | ~~6.41 元~~ |
| **GAAP TTM 市盈率（正确口径）** | 市值 1.835 亿 ÷ 净利润 117 万 | **157 倍** | **0.64 元** |
| 公司自己吹的 Non-GAAP | 不提供 | — | — |
| **剔除障眼法后的真实市盈率**（只算主营） | 1.835 亿 ÷ 经营利润税后约 39 万 | **471 倍** | **0.21 元** |
| 自由现金流口径 | 自由现金流为 **−696 万** | **无意义（负数）** | **−3.79 元** |

**三年平均利润口径的算法**：FY2023 净利润 288 万、FY2024 净利润 368 万、FY2025 净利润 119 万，三年平均 **258 万美元**。市值 ÷ 258 万 = **71.1 倍**。

这一行说明的东西和别的公司相反：**这家公司当前的 117 万利润不是高点，而是低点**——三年平均是 258 万，是现在的两倍多。但这不构成"利润会回来"的理由，因为下滑的原因是结构性的（营收下滑 + 新厂折旧上来 + 中国市场价格战），不是周期性的。而且**就算利润完全恢复到三年平均的 258 万，市盈率仍然是 71 倍。**

### 说人话：你投 100 块进去会怎样

**你现在投 100 块买这只股票，按最保守的真实口径算，公司一年替你赚 0.21 元——两毛一分钱。** 按最宽松的 GAAP 净利润口径也只有 0.64 元。就算利润恢复到过去三年的平均水平，也只有 1.41 元。

**作为对比：现在把 100 块存在美国的货币市场基金里，一年拿 4 块多。**

这 0.64 元里有多少回到你口袋？**零。公司不分红，也不回购。** 钱都去了哪：TTM 投资活动净流出 638 万（几乎全是滁州工厂的 637 万资本开支），靠净借入 465 万补上，现金净减少 205 万。**公司把所有钱、以及借来的钱，都投进了一座新工厂，而它的营收在下降。**

### 这个 0.64 元未来会变大还是变小？

**大概率变小，而且有三条独立的下行通道：**

**第一，分母（股数）还在扩张。** 五个月增加十倍不是终点——一家现金流为负、每年要还利息、又在建厂的公司，只有两个融资渠道：继续借（债务已经是 EBITDA 的 24 倍，借不动了）和继续增发。**每一次增发，你手里这 100 块能分到的利润就再少一块。**

**第二，分子（利润）还在下滑。** 营收 −4.65%、经营利润率 2.12%、存货在涨、滁州工厂的折旧还没完全计提上来。经营利润只有 41.8 万美元，这个数字距离归零只有一步，而且非经营收入（补贴、利息）撑着的那部分随时会消失。

**第三，最大的市场在缩。** 日本占 58.6% 的营收，是这家公司的命根子。日元汇率、日本介护保险的报销标准调整、日方经销商换一家越南或印尼供应商——任何一件发生，这家公司立刻会从"利润微薄"变成"亏损"。而中国大陆业务（21.3%）的营收 TTM 只有 374 万，比 FY2025 的 441 万还少。

**还有一层信息风险要说清楚：这家公司是外国私人发行人，只按半年披露财报，最近一次财务数据更新是 2026 年 3 月 31 日——已经过去五个月。** 也就是说，从 3 月到 8 月这五个月里股份增加了十倍，而这段时间的经营状况、增发的具体条款、募资去向，公开财务数据里**一个字都没有**。你是在完全看不见的情况下买。

## 第四部分：一句话结论

**这家公司之所以出现在"市盈率 15–50 倍"的筛选名单上，纯粹是一个数据事故：它的每股收益用的是五个月前 780 万股的口径，股价用的是今天 7843 万股的口径，两个口径一除，157 倍的市盈率被压成了 15.6 倍。真实情况是——你在用 157 倍市盈率、9.3 倍市销率、6.1 倍市净率，买一家营收在下滑、经营利润率从 15.5% 塌到 2.1%、自由现金流负 696 万、债务是 EBITDA 二十四倍、五个月内股份增加十倍、机构持股率 0.03%、刚做完 1 比 20 反向拆股保住上市地位的中国轮椅代工厂。**

轮椅这门生意本身没有问题——日本的老龄化是真的、介护需求是刚性的、31% 的毛利率对代工厂也算体面。**问题不在工厂，在这张股票**：股份在以肉眼可见的速度增发，公司在用借来的钱建新厂，而营收在往下走。你买的不是那家常州的工厂（法律上你买的是一叠 VIE 合同），你买的是一个正在被稀释的分母。

**不要碰。**

**归档：价格「很贵」（真实 157 倍市盈率，三年平均口径也要 71 倍，自由现金流为负，投 100 块一年回报两毛一）／质量「有硬伤」（营收下滑 + 经营利润率塌了 86% + 债务/EBITDA 24 倍 + 五个月股份增加十倍 + 反向拆股保壳 + VIE 结构 + 半年才披露一次财报）。**
