## 第一部分：它到底做几件事

英飞凌是从西门子半导体部门 1999 年分出来的，现在是**全球最大的汽车芯片公司和全球最大的功率半导体公司**。它不做 CPU、不做手机芯片，做的是「管电」的芯片：把电压变高变低、把直流变交流、控制电机转多快。财报分四个分部，实质上是两门生意——**汽车（一半）和功率器件（三成）**，另外两个是小生意。

### 生意 A：汽车（Automotive）——全球第一的汽车芯片供应商

**这是什么：** 一辆现代汽车里有几百到上千颗芯片，英飞凌做其中三类。第一类是**微控制器**（AURIX 系列），管发动机点火、刹车防抱死、安全气囊、自动驾驶辅助——一颗几欧元到几十欧元，一辆车用几十颗，全球份额第一。第二类是**功率半导体**，电动车最值钱的芯片就在这里：电池 400 或 800 伏的直流电要变成驱动电机的交流电，靠的是逆变器里的 IGBT 或碳化硅（SiC）功率模块，一辆电动车的功率模块价值 300–500 欧元，是燃油车芯片含量的两三倍。第三类是**传感器**（雷达、压力、磁传感器）和 2025 年花 25 亿美元从 Marvell 买来的**车载以太网**芯片（车内各控制器之间的高速通信）。

**客户是谁、怎么卖：** 卖给博世、大陆、电装这些一级供应商，再装进大众、宝马、丰田、比亚迪、蔚来的车里；也直接跟特斯拉、比亚迪谈。汽车芯片一旦定型（design-win），这款车型生命周期 5–7 年内都用它，所以英飞凌的汽车业务前 3 年都能大致看清。全球汽车芯片份额约 13%–14%，连续多年第一。

**最近三年的故事：** 2023 财年是顶峰——芯片荒让车厂囤货、价格抬高，营收 82 亿欧元；之后车厂消化库存、欧洲电动车增速放缓、中国本土芯片（比亚迪半导体、士兰微）开始替代低端产品，2025 财年跌到 74 亿。TTM 74.4 亿，止跌、没有回升。

### 生意 B：功率与传感系统（Power & Sensor Systems）——AI 数据中心的电源芯片，现在的增长引擎

**这是什么：** 功率 MOSFET、氮化镓（GaN）、碳化硅器件，用在所有需要「管电」的地方：手机快充头里的 GaN 芯片（一颗 1–2 欧元）、电脑电源、电动工具的电机控制、以及**AI 服务器的供电**。这最后一项是 2025–2026 年的热点：一个英伟达 GB200 机架耗电 120 千瓦以上，从电网 48 伏到芯片 0.8 伏要经过好几级降压，每一级都要用功率器件，一个机架要用上千颗英飞凌的芯片、价值几千欧元。英飞凌 2025 年跟英伟达签了 800 伏高压直流供电架构的合作，是这个赛道的头号供应商。另外还有 MEMS 麦克风（手机、耳机里的，全球第一）。

分部利润估算合计约 28 亿欧元，减去总部费用和收购无形资产摊销（Cypress、Marvell 车载以太网），到集团经营利润 25.5 亿。**经营利润 25.5 亿到税前利润 16.6 亿之间又少了 9 亿欧元**——利息只占 2 亿，剩下 7 亿是财务和非经营项目（汇兑、收购相关、投资减值），单期口径看不清全部构成，但它把净利润压到了 12 亿。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：** TTM 2.57 亿欧元，占净利润 21%，比 2021 财年的 0.27 亿涨了近十倍。GAAP 里已经扣了，我不加回。但要注意这个趋势：利润在跌，发给员工的股票在涨。

**一次性项目：** TTM 减值和重组 0.45 亿，很小。2025 财年有 2.72 亿重组费用（裁员 1400 人）。上面说的经营利润到税前利润之间 9 亿欧元的缺口才是大项，我在真实市盈率里不做调整（因为看不清哪些会重复发生），只提醒它存在。

**资本化的支出：** 无形资产投入 3.7 亿欧元，主要是研发资本化，占研发总投入约 15%，偏高但在半导体行业正常范围。

**回购与稀释：** TTM 回购 2.26 亿，SBC 2.57 亿，**回购 ÷ SBC = 0.9**——回购刚好抵消员工发股，股本一年还是涨了 0.52%。这不是回馈股东。分红 4.56 亿（每股 0.35 欧元，股息率 0.62%）。

**利润和现金流的差：** 净利润 12.0 亿，经营现金流 33.6 亿，自由现金流 16.5 亿。对账：

| 从净利润到经营现金流（TTM，亿欧元） | 金额 | 说明 |
|---|---|---|
| 净利润 | 12.1 | |
| + 折旧与摊销 | 17.3 | 晶圆厂重资产 |
| + 其他摊销 | 1.5 | 收购无形资产 |
| + SBC | 2.6 | |
| + 减值和其他 | 1.6 | |
| − 应收账款增加 | −3.0 | |
| − 存货增加 | −1.9 | |
| + 应付账款和其他 | 3.4 | |
| **= 经营现金流** | **33.6** | |
| − 资本开支 | −17.2 | 德累斯顿新厂、马来西亚居林碳化硅厂 |
| **= 自由现金流** | **16.5** | |

自由现金流 16.5 亿比净利润多 4.5 亿，差额是收购摊销和 SBC 这些不花现金的成本，干净。但注意资本开支：2023–2024 财年花了 27 亿和 24 亿建厂，现在降到 17 亿，自由现金流才从 2024 财年的 3.5 亿回升到 16.5 亿。**半导体厂的自由现金流看的是资本开支周期，不是利润周期。**

净负债 55.9 亿欧元，比 2023 年的 15 亿涨了 40 亿——2025 年买 Marvell 车载以太网花了 22 亿，加上建厂。TTM 新借了 17 亿。

## 第三部分：市盈率，多口径

市值 737.2 亿欧元。净负债 55.9 亿。企业价值 793.1 亿。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 737.2 ÷ 12.0 | 61.6 倍 | 1.6 元 |
| 公司自己吹的口径 | 英飞凌用「调整后每股收益」（剔除收购摊销、重组、SBC 等），TTM 约 1.55 欧元 | 36.7 倍 | 2.7 元 |
| **剔除障眼法后的真实市盈率** | 737.2 ÷（12.0 + 减值 0.45 加回） | **59.3 倍** | **1.7 元** |
| 自由现金流口径 | 737.2 ÷ 16.5 | 44.7 倍 | 2.2 元 |
| 企业价值口径 EV/EBIT | 793.1 ÷ 25.5 | 31.1 倍 | 3.2 元（税前） |
| 三年平均利润口径 | 737.2 ÷ 三年平均净利润 17.9（2023 财年 31.1、2024 财年 12.7、2025 财年 10.0） | **41.1 倍** | **2.4 元** |

这次三年平均口径比当期便宜（41 倍 vs 62 倍），说明当期利润在谷底。这是对英飞凌最有利的一行。但即使利润回到 2023 财年顶峰的 31 亿，市盈率也还有 24 倍——**你现在付的价格，已经把利润回到历史最高点这件事完全算进去了。**

**大白话：你现在投 100 块进去，按最保守的真实口径算，公司一年替你赚 1.7 块。**

这 1.7 块里：分红给你 0.6 块，回购被 SBC 抵消、等于零。剩下 1.1 块加上折旧的钱，全部投进德累斯顿和马来西亚的新厂。

**这个 1.7 块未来变大还是变小？** 会变大，市场赌的是大很多：远期市盈率 22.6 倍意味着分析师预期明后年利润接近翻三倍（三年 EPS 增速预测 39.7%）。逻辑有三条：汽车库存周期结束、AI 数据中心电源芯片放量、碳化硅和氮化镓替代硅基器件。前两条我认，第三条有变数（中国碳化硅厂商正在把价格打下来）。**但把利润翻三倍的预期兑现之后，市盈率也只是回到 22 倍**，对应回报 4.5 块，这是一家 ROIC 8%、周期性强、上一轮顶峰过后两年利润跌六成的公司的「正常价」。

## 第四部分：一句话结论

**贵得没道理，是典型的「好公司坏价格」。** 62 倍市盈率、真实口径 59 倍、三年平均 41 倍，买的是一家处在周期底部的功率半导体厂——底部没错，但价格已经按周期顶部定了。利润从 31 亿跌到 12 亿的两年里股价涨了 80%，回购刚好被员工发股抵消，股息率 0.6%。汽车芯片全球第一、AI 电源芯片头号供应商，这些都是真的，2023 年 13 倍的时候它是好机会，现在不是。等它跌回 20 倍以下、或者利润真的回到 25 亿以上再看，两个条件满足一个就行。
