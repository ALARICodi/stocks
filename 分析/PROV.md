# PROV · Provident Financial Holdings（普罗维登特金融）

市值 1.148 亿美元 / 股价约 18.36 美元 / 行业：储蓄银行（加州内陆帝国） / TTM 截止 2026-06-30（恰好是它的 2026 财年整年）

> 这是金融企业（储蓄银行），下面用市净率 PB + ROE 口径为主、市盈率为辅，原因是：银行的利润是利息差和拨备摆出来的，资产负债表才是本体。不过这家的市盈率（17.8 倍）难得地能看，因为它的利润里没什么水分。

---

## 第一部分：它到底做几件事

**一件事：加州"内陆帝国"的一家 70 年老储蓄银行，主业是给本地人买房放贷。**

主体是 Provident Savings Bank，1956 年创立，总部在加州 Riverside——洛杉矶以东的 Riverside/San Bernardino 都会区，美国人叫它"内陆帝国"（Inland Empire），是洛杉矶房价买不起的人往东搬的目的地，人口四百多万、以物流仓储业和通勤族为主。

生意模式：吸收本地存款，主要放三类贷款——**单户住宅按揭**（本地仓库主管家庭买 55 万美元的房子，做浮动利率按揭）、**多户公寓贷款**（房东买一栋 20 户出租公寓借 400 万）、**商业地产贷款**。全行总资产约 12.3 亿美元（按 ROA 0.54% 与净利润倒推），185 名员工，十来个网点。它 2020 年把原来的按揭代销业务（做了再卖给房利美那种）关掉了，现在就是纯粹的存贷生意：**放出去的贷款自己拿着收利息，不玩花活。**

**和前面分析过的一串小储蓄银行有个本质区别：它是完全转股的正常上市公司，没有 MHC 太上皇。** 1996 年就完成了全额上市，总股本 625 万股里流通 424 万股，管理层和董事持股 10.16%，机构持股 48.36%。股东投票是真的算数的——这也解释了它的行为模式为什么完全不同：**分红 + 回购一年还给股东约 830 万美元，比它一年赚的还多**（下面细说）。

**钱的情况（TTM = FY2026，截止 2026-06-30）：**

| 项目 | TTM | 上年同期趋势 |
|---|---|---|
| 营收（净利息收入+手续费） | 4061 万美元 | 同比 +2.4%（五年来一直横在 3900–4100 万） |
| 净利润 | 666 万美元 | FY2025 626 万，同比 +6.4%；EPS +10.75%（股本在缩） |
| ROE / ROA | 5.22% / 0.54% | 正常银行 10% / 1%，它常年只有一半 |

利润五年序列：909 → 859 → 735 → 626 → 666 万——加息周期一路阴跌（存款成本涨得比贷款收益快），FY2026 首次回升。注意一个细节：**净利润只 +6.4%，EPS 却 +10.75%**，差的那几个点就是回购缩股本缩出来的。这家的看点从来不是增长（营收五年没动），而是每股价值被回购慢慢顶上去。

## 第二部分：把会计障眼法剥掉

- **股权激励（SBC）**：老派社区银行，SBC 极小，对 666 万净利润无实质影响。
- **一次性项目**：TTM 无大额一次性项目。有效税率 30.94%，是正常足额缴税（加州州税重），不存在税务美化。这 666 万是干净的。
- **资本化的支出**：无（银行不适用）。
- **回购与稀释**：**这是全篇的亮点。** 股本一年缩 4.11%，FY2022–25 每年回购 260–507 万美元，SBC 约为零——回购/SBC 比值趋近无穷大，教科书级的真回购。而且是在 0.9 倍账面价值以下买的，每买一股都在给留下的股东增厚每股净资产。
- **分红**：每股年派 0.56 美元，股息率 3.05%，每年稳定付 380–420 万美元。**分红 + 回购合计约 830 万/年，超过净利润（666 万）**——它在有意识地缩表还钱：FHLB 借款从峰值 2.4 亿降到 1.57 亿，存款规模基本横着，多余资本全数吐给股东。对一家 ROE 只有 5% 的银行，这是管理层能做的最正确的资本配置：**赚不到高回报，就把钱还给能赚的人。**
- **利润和现金流的差**：净利润 666 万 vs 经营现金流 809 万，差额是折旧和拨备等非现金项，方向正常金额小，不需要对账表。

账面干净：无商誉（P/TBV = PB），无 MHC 结构，无隐藏杠杆。

## 第三部分：银行口径的估值

| 指标 | 数值 | 说明 |
|---|---|---|
| 市净率 PB | 0.91 倍 | 账面 1.262 亿，市值 1.148 亿，九一折 |
| 有形账面市净率 P/TBV | 0.91 倍 | 无商誉 |
| ROE（TTM） | 5.22% | 五年序列 7%+ 一路降到 5%，FY2026 企稳回升 |
| ROA（TTM） | 0.54% | 平庸，但稳定 |
| GAAP 市盈率 | 17.82 倍 | 利润干净，这个倍数是真的 |
| 预期市盈率 | 15.04 倍 | 市场预期息差继续修复 |
| 市值/三年平均净利润 | 约 17.0 倍 | FY2024–26 平均 676 万，和当期几乎一样——当前利润不在高点也不在低点，就是常态 |
| 股东综合回报率 | **约 7.2%/年** | 股息 3.05% + 股本收缩 4.11% |

**投 100 块的年回报，两种算法：** 按盈利能力算，ROE × (1/PB) = 5.22% × 1.10 ≈ **5.7 块**；按实际到手算，**分红给你 3 块 + 回购间接给你 4.1 块 ≈ 7.2 块**——之所以能还得比赚得多，是因为它在动用多余资本缩表。这个 7.2 块是过去四年每年兑现的事实，不是承诺。对比国债 4 块出头：**它是这批小银行里唯一一个实实在在跑赢无风险利率的。**

代价是别指望这个数变大多少：营收五年横盘，内陆帝国的按揭生意没有增长故事，ROE 天花板大概 6%–7%（预期 PE 15 倍对应的就是这个修复空间）。还钱超过利润的模式也不是永动机——多余资本吐完（equity/assets 从 10% 降到 8% 左右）之后，回报率就回落到 ROE 本身。**这是一只"债券加强版"：买它是收 7% 的现金回报外加 0.91 倍账面的下行保护，不是买成长。** 另外它 52 周已涨 19%，RSI 74 偏热，急着买没必要，这种股票永远给你慢慢买的机会（日均成交才 1.4 万股，也快不起来）。

## 第四部分：一句话结论

**值这个价，是这批微型储蓄银行里唯一及格的一家。生意平庸（ROE 5%、营收五年不动）但账干净、没有 MHC 挟持，管理层用 0.9 倍账面的回购加 3% 股息，一年真金白银还你 7% 出头——赚得不多但全给你。当"收息+缩股本"的类债券持有可以，当成长股买必失望；涨了 19% 之后不用追，它跑不掉。**
