# AVB · 艾芙隆海湾社区（AvalonBay Communities）

**TTM 口径截止日** 2026 年 6 月 30 日（全篇所有数字均为最近四个季度滚动）
**全榜名次** 第 258 名 · **分析日期** 2026-08-16

## 第一部分：它到底做几件事

AvalonBay 就是个包租公——在美国沿海最贵的那几个城市里，拥有约 **9.5 万套高档出租公寓**，收房租。它旗下的楼盘挂着 Avalon、AVA、Eaves by Avalon 三个牌子，分布在波士顿、纽约/新泽西、华盛顿特区、西雅图、旧金山湾区、南加州，近年也在往丹佛、奥斯汀、达拉斯、夏洛特、罗利、佛州扩张。

财报把营收拆成"同店 / 其他已稳定 / 开发中"，但那不是三门生意，**那只是同一批楼房处在三个不同的成熟阶段**。按那个口径拆解毫无意义。真正有意义的拆法是按**赚钱方式**拆——AvalonBay 实际上在做三件性质完全不同的事。

### 生意一：收房租（占营收 90%，TTM 同店营收 27.88 亿）

最朴素的一门。一套位于波士顿郊区 Avalon 楼盘的两居室，月租约 **$3,200**，一年 $38,400。租客签 12 个月合约，到期时 AvalonBay 会根据市场行情提价续约——通常涨 2–4%。

这 $38,400 收进来之后要花出去一部分：物业税约 $5,500、水电公共区域能耗约 $2,200、维修保养约 $2,800、保险约 $900、现场管理人员工资约 $2,600。**剩下约 $24,400 是这套房的净运营收入（NOI），利润率约 64%。** 这个 60%+ 的 NOI 利润率是优质公寓资产的标准水平。

TTM 同店营收 27.88 亿，比 FY2025 的 27.12 亿增长 **+2.8%**。这 2.8% 里包含两个东西：租金涨价，和出租率变化。

> **数据页不披露出租率。** AvalonBay 长期把出租率维持在 95.5–96.5% 区间，+2.8% 的同店增长意味着**租金实际涨了 2–3%、出租率基本持平**——不是靠塞满空房冲出来的增长。但具体的出租率数字财报数据页没有提供，这里不编造。

这门生意的护城河不在楼本身，在**土地**。波士顿、旧金山、纽约近郊这些地方的规划审批极其难拿——一块地从买下到开工可能要跟市议会耗三到五年。这意味着新供给天然稀缺，**老房东有定价权**。这也是 AvalonBay 只在"高门槛市场"买地的原因，它买的不是钢筋水泥，是"别人盖不了房"这件事。

### 生意二：自己盖楼赚价差（这才是它区别于普通包租公的地方）

AvalonBay 不只买现成的楼，它**自己买地、自己设计、自己当总承包商盖**。3,041 名员工里有相当一部分是建筑师、工程师和项目经理——这在 REIT 行业里很少见，同行大多是买现成资产。

这门生意的钱是这么赚的：假设 AvalonBay 在丹佛买一块地、盖一栋 300 套的公寓楼，全部造价（地价+建安+资本化利息）3.0 亿美元。楼盖好租满后，每年产生的 NOI 是 1,860 万，**相对于造价的收益率（yield on cost）是 6.2%**。

而在市场上，同样一栋租满的新公寓楼，买家愿意接受的资本化率（cap rate）只有 **约 5.0%**——也就是说，这栋产生 1,860 万 NOI 的楼，市场估值是 1,860 万 ÷ 5.0% = **3.72 亿美元**。

**盖好的那一天，这栋楼就比造价多值 7,200 万美元。** 这 7,200 万不是卖掉才算数——它是实打实创造出来的价值，也是 AvalonBay 每年最重要的价值创造来源。TTM 里"开发/重建"分部营收从 4,620 万跳到 **7,376 万（+59.7%）**，就是新楼盖好开始收租的信号。

TTM 花在买地建楼上的现金是 **16.03 亿美元**，这是公司最大的一笔资金去向。

### 生意三：买进卖出，换仓（TTM 卖楼收益 3.60 亿）

第三门生意是资产组合管理：**卖掉老的、增长慢的、维修费高的（多在加州和东北部老市场），换成新的、人口在流入的（德州、东南部、丹佛）**。

TTM 卖楼收回现金 **9.02 亿**，其中确认的账面收益是 **3.60 亿美元**。这个数字非常重要——下面第二部分会看到，**它占了整个公司账面净利润的 35%**。

| 按赚钱方式拆 | TTM 规模 | 说明 |
|---|---|---|
| 收租（同店） | 营收 27.88 亿，+2.8% | NOI 利润率约 64%（**估算**，财报未按物业披露） |
| 开发新楼 | 投入 16.03 亿现金 | 造价收益率约 6.2% vs 市场 cap rate 约 5.0%，价差即利润 |
| 买卖换仓 | 卖出 9.02 亿，收益 3.60 亿 | 收益直接计入净利润，一次性 |
| 其他已稳定 + 未分配 | 营收 1.69 亿 | 新交付尚未纳入同店口径的楼盘 |
| **合计营收** | **30.84 亿，+3.4%** | |

**总结：一门极其枯燥、极其稳定的收租生意（90% 的营收），外挂一个真正能创造价值的开发能力（价差 1.2 个百分点），再加一个每年贡献几亿账面利润的资产腾挪动作。**

## 第二部分：把会计障眼法剥掉

REIT 的财报有两层特殊的滤镜，不摘掉的话，看到的净利润和市盈率**全是错的**。

**障眼法之一（最大的一个）：净利润里有 35% 是卖楼的一次性收益。**

TTM 账面净利润 **10.25 亿美元**，EPS $7.29，看着很漂亮。但现金流量表第一屏就写着一行"资产处置收益 **−3.60 亿**"（现金流里是负号，因为要从利润里减掉这笔非经营性收益）。

**也就是说：10.25 亿利润里，有 3.60 亿是卖楼卖出来的，不是收租收出来的。** 剥掉之后，**靠正经收租赚到的经常性净利润只有 6.65 亿**。

而且这不是偶发的——FY2025 卖楼收益 3.40 亿、FY2024 是 3.64 亿、FY2023 是 2.88 亿。**它年年都在卖楼，年年靠卖楼撑起三分之一的账面利润。** 这就带来一个判断上的困难：**单看一期，无法断定这该算"经常性"还是"一次性"**——从行为上它是年年发生的，但从性质上每一笔都是不可重复的资产处置，而且能卖的好楼总有卖完的一天。

**障眼法之二：折旧是假的。**

TTM 折旧与摊销 **9.30 亿美元**，会计上假设这些公寓楼在几十年里会磨损到一文不值。**现实完全相反**——一栋 2005 年在波士顿建成的 Avalon 楼盘，二十年后的市场价值远高于当年造价。会计规则强行每年从利润里挖掉 9.3 亿，而那 9.3 亿从来没有真的流出去过。

这正是全世界都用 **FFO（营运资金流）** 而不是净利润来衡量 REIT 的原因：

> **FFO = 净利润 ＋ 房地产折旧 − 卖楼收益**
> = 10.25 亿 + 9.30 亿 − 3.60 亿 = **15.95 亿美元**
> 每股 FFO = **$11.11**

（交叉验证：stockanalysis 直接给出的 Price/FFO 是 16.33 倍，对应每股 FFO $11.27，与上面自算的 $11.11 相差 1.4%，口径差异在"其他摊销"要不要计入，结论不受影响。）

**障眼法之三：股权激励很小，不是问题。** TTM SBC **2,607 万美元**，只占净利润的 2.5%。这笔钱按 GAAP 已经扣掉了，**本篇不加回**。这是一家由物业经理、租赁顾问、工程师组成的公司，报酬以现金为主。这一项干净。

**障眼法之四：资本化的支出。** REIT 行业惯例是把开发期的**贷款利息和内部开发团队的人工成本**资本化进楼盘造价，而不是当期费用化——这会让当期利润显得更好看，代价是未来几十年多提折旧。AvalonBay 有自己的开发团队，这块金额不小，但**数据页未单列，无法量化**。这是本篇看不透的一个角落，如实标出。

**回购与稀释：这一项的数字极具误导性，必须看穿。**

| 项目 | TTM |
|---|---|
| 股票回购金额 | 6.9998 亿 |
| **同期增发股票募资** | **6.9307 亿** |
| 股权激励（SBC） | 0.2607 亿 |
| 回购 ÷ SBC | **26.8 倍**（看着极好） |
| **股本实际变动（同比）** | **仅 −0.50%** |

表面上回购是 SBC 的 26.8 倍，按常规标准这是"教科书级的真回购"。**但这个结论是错的。** 因为它一手回购 7.00 亿，另一手又增发了 **6.93 亿**——两个数字几乎完全对冲，股本一年只净减 0.50%。

这不是回馈股东，这是 REIT 特有的**资本循环**：当股价低于管理层认为的资产净值时买回自家股票，同时通过 ATM（随行就市增发）机制在股价合适的时候卖出新股给开发项目筹钱。本质是"融资渠道"而不是"股东回报"。**判断这家公司时，回购这一项应该按接近零来计。**

**利润和现金流的差：这家公司的现金流质量非常高。**

| 逐项对账（百万美元） | TTM |
|---|---|
| 净利润 | **1,025** |
| ＋ 折旧与摊销（非现金） | +929.84 |
| ＋ 其他摊销 | +14.64 |
| － **资产处置收益（非经营性）** | **−360.05** |
| ＋ 资产减值 | +14.63 |
| ＋ 股权激励（非现金） | +26.07 |
| － 权益法投资收益 | −23.03 |
| ＋ 其他经营性资产净变化 | +22.01 |
| ＋ 其他经营活动 | +8.86 |
| **＝ 经营现金流** | **1,660** |

对账严丝合缝。**净利润 10.25 亿 → 经营现金流 16.60 亿，现金流是账面利润的 1.62 倍**——和 CenterPoint、NRG 那种"利润在账上、现金在别处"完全相反。这是收租生意的本色：**租金每月 1 号打进账户，没有应收账款黑洞，没有存货，没有衍生品保证金。**

**再往下看这 16.6 亿花去哪了（这才是真正的资本配置）：**

| 现金去向 | TTM |
|---|---|
| 经营现金流入 | +16.60 亿 |
| － 派发股息 | **−9.98 亿** |
| － 买地建楼 | −16.03 亿 |
| － 收购现成物业 | −2.98 亿 |
| ＋ 卖楼回收 | +9.02 亿 |
| ＋ 净新增借款 | +3.61 亿 |

清清楚楚：**租金收入的六成拿去发股息，剩下的四成加上卖楼回收的钱和一点新债，全部投进了新楼盘。** 这是一台运转得非常规矩的机器。

**债务：REIT 里最保守的那一档。**

总债务 **91.87 亿**，股东权益 122.3 亿，**债务/股本仅 0.75 倍**，债务/EBITDA **4.91 倍**，利息保障 **3.36 倍**。作为对比，前面两家公用事业的债务/股本是 2.10 倍和 4.83 倍。住宅 REIT 同行普遍在 5.5–6.5 倍 EBITDA，**AvalonBay 是行业里杠杆最轻的几家之一**。

> 数据页不提供债务到期年份的明细结构，无法逐年核对再融资压力。但从总量指标看，这张资产负债表有充足的缓冲。

**最后提一个容易被误读的数字**：ROIC 只有 **4.35%**，低于公司自己的加权资本成本 **6.92%**——账面上看"投出去的钱赚不回成本"。**但这个指标对 REIT 严重失真**：分母是按历史成本减去累计折旧的账面净值，一栋 2005 年花 2 亿建、如今账上只剩 1.1 亿、市场价却值 4 亿的楼，会把 ROIC 算得离谱地低。同理，GAAP 派息率 **97.68%** 看着像"利润全发光了"，那也是折旧压低净利润造成的幻觉——按 FFO 算，真实派息率只有 63%。

## 第三部分：估值 —— 用 FFO/AFFO 口径，不用市盈率

> **这是一家房地产投资信托（REIT），下面不用市盈率作为主口径，改用 FFO / AFFO。** 原因上面已经讲透：REIT 的净利润被两件事同时扭曲——一头被根本没发生的折旧压低（TTM 9.3 亿），另一头被卖楼的一次性收益抬高（TTM 3.6 亿）。**净利润这个数字在 REIT 上几乎不携带信息。** 市盈率仍然列出，但只作为对照，不作为判断依据。

市值 264.3 亿，企业价值 355.3 亿（含净债务 91.0 亿）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率（**误导性口径**） | 264.3 亿 ÷ 10.25 亿 | 25.8 倍 | $3.88 |
| 剔除卖楼收益后的市盈率 | 264.3 亿 ÷ 6.65 亿 | 39.7 倍 | $2.52 |
| **P/FFO（REIT 主口径）** | 264.3 亿 ÷ **15.95 亿** | **16.6 倍** | **$6.03** |
| **P/AFFO（扣掉真实维修支出，最保守）** | 264.3 亿 ÷ **约 14.50 亿**（**估算**） | **约 18.2 倍** | **约 $5.49** |
| 企业价值口径 EV/EBITDA | 355.3 亿 ÷ 18.6 亿 | 19.1 倍 | — |
| **三年平均 FFO 口径** | 264.3 亿 ÷ (16.22+15.63+14.56)/3 = **15.47 亿** | **17.1 倍** | **$5.86** |
| **股息收益率（真正到手的现金）** | 每股 $7.12 ÷ $184.06 | — | **$3.87** |

**AFFO 的算法说明**：AFFO = FFO 减去维持现有楼盘正常运转必须花的经常性资本开支（换屋顶、换空调、翻新厨房卫浴、更换地毯——这些是真金白银的支出，但会计上被资本化，不进利润表）。AvalonBay 约 9.5 万套公寓，按行业惯例每套每年约 $1,500 计，**约 1.45 亿美元**，故 AFFO ≈ 15.95 − 1.45 = **14.50 亿**，每股约 $10.10。**这是估算，财报数据页未直接提供 AFFO**；交叉验证：数据页给出的"杠杆后自由现金流"为 14.09 亿，与此高度吻合。

**这张表里最值得注意的是最后一个口径。**

三年平均 FFO 口径 **17.1 倍 vs 当期 16.6 倍——只差 3%**。

这个数字说明了一件很重要的事：**AvalonBay 当前的盈利完全没有虚高，它就站在自己的长期中枢上。** 三年 FFO 轨迹是 14.56 → 15.63 → 16.22 亿，一条平滑上升的直线。

对比一下前面两家就知道这有多难得：NRG 的三年平均口径是当期的 1.5 倍（因为三年前巨亏）。而更极端的例子——之前分析过的英伟达，当期 34 倍、三年平均 73.5 倍，差了一倍多，说明它的当期利润踩在历史高点上。**AvalonBay 这里几乎没有周期风险可言。**

**你现在投 100 块进去，一年公司替你赚多少？**

按最保守的 **AFFO 口径，一年 5.49 块**（按 FFO 口径是 6.03 块，按三年平均口径 5.86 块——三个口径高度一致，本身就说明数字可靠）。

**这 5.49 块里，有多少真的回到你口袋？**

- **股息：3.87 块**，实打实的现金，每季度打到账上。这是三家公司里唯一一个股息**完全由真实现金流覆盖**的：TTM 分红 9.98 亿 ÷ AFFO 14.50 亿 = **派息率 68.9%**，安全边际充足。（对照 CenterPoint：股息 100% 靠借债发放。）
- **回购：约 0 块**。名义上回购了 7.00 亿，但同期增发 6.93 亿对冲掉了，股本只减 0.50%，实际贡献约 0.5 块，且这个动作的性质是融资而非回报。
- **剩下约 1.6 块**：留在公司里，和卖楼回收的钱、新借的债一起，投进新楼盘开发——按 6.2% 的造价收益率对 5.0% 的市场资本化率，这笔再投资**每投 1 块钱大约立刻创造 1.24 块的资产价值**。这是留存收益里少见的高质量再投资。

**这个 5.49 块未来会变大还是变小？**

**大概率缓慢变大，但增速会很平淡，别指望惊喜。** 三条逻辑：

1. **租金**：同店营收 +2.8%，基本等于通胀。美国沿海高门槛市场的新增供给受审批限制，租金长期能跟住通胀甚至略高，但**不会加速**——这是一门天花板很低也很结实的生意。
2. **开发价差**：6.2% 造价收益率 vs 5.0% 市场资本化率的 1.2 个百分点价差，是超额回报的真正来源。但这个价差正在被建筑成本和高利率挤压，**是最需要盯的变量**。如果利率长期居高，cap rate 上行到 6%，这门开发生意的价值创造会直接归零。
3. **换仓**：从加州、东北部往德州、东南部搬，能提升长期增长率，但也是在从"高门槛低增长"换向"低门槛高增长"——阳光地带的公寓正在大量新建，那边**新供给过剩才是未来几年的真风险**。

## 第四部分：一句话结论

**这是三家里唯一一家不需要靠故事、不需要靠杠杆、不需要靠借钱发股息的公司——你投 100 块，一年实实在在拿回 3.87 块现金，公司再替你赚 1.6 块投进新楼，价格 16.6 倍 FFO 也没有任何虚高。买它不会发财，但你知道自己买的是什么。**

它的账干净到几乎无处可挑：现金流是账面利润的 1.6 倍、杠杆是同行里最低的一档、股息由真实现金覆盖（派息率 69%）、三年平均口径和当期几乎一致（17.1 vs 16.6 倍）说明利润没有踩在周期高点上。它甚至还有一项同行大多没有的真本事——自己盖楼，靠 1.2 个百分点的造价/估值价差凭空创造资产价值。

唯一需要点破的两个软肋：**一是它三分之一的账面利润来自卖楼**，看净利润和市盈率会被严重误导（真实市盈率是 39.7 倍不是 25.8 倍，所以必须看 FFO）；**二是那笔看起来很漂亮的 7 亿回购是假动作**，被同期 6.93 亿的增发对冲光了，别把它算进股东回报里。

**16.6 倍 FFO、3.87% 股息、行业最低杠杆——这个价格谈不上便宜，但配得上它的质量。** 它是那种买了之后可以十年不看的东西，代价是它十年也不会给你惊喜。
