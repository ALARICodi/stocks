# BHE · Benchmark Electronics（基准电子）

市值 26.1 亿美元 / 股价约 72.7 美元 / 行业：电子科技 — 电子制造服务（EMS 代工） / TTM 截止 2026-06-30

---

## 第一部分：它到底做几件事

先说结论：**Benchmark 只做一门生意——替别人造电子设备**。它在财报里按三个地区（美洲、亚洲、欧洲）拆营收，但那是拆工厂位置，不是拆生意。生意只有一门，只是分成三道工序卖。

### 这门生意具体是怎么回事

世界上有一大批公司，设计能力很强，但不想自己开工厂。比如一家做半导体刻蚀机的设备商、一家做核磁共振仪的医疗器械商、一家做军用雷达的国防承包商。它们的产品单价高（几十万到几百万美元一台）、批量小（一年几百台）、变化快，自己建一条产线既不划算也养不起熟练工。

Benchmark 就是接这些活的。客户把物料清单（BOM，就是"这台机器需要哪些零件、各要几个"）和设计图纸交过来，Benchmark 负责：**去买料 → 把芯片焊到电路板上 → 测试 → 把板子和金属结构件装成整机 → 贴上客户的牌子发货**。客户收到的是可以直接卖给终端用户的成品，上面印的是客户的商标，没人知道是 Benchmark 造的。

**怎么收钱：成本加成。** 这是理解这家公司全部财务特征的钥匙。假设一台刻蚀机的子系统里有 40 块控制板、一套真空气路、一个铝合金腔体，元器件成本 25 万美元。Benchmark 先自己掏钱把这 25 万的料买回来（这笔钱压在它的存货和应收账款里），加工完按 28 万美元卖给客户——**它赚的是那 3 万，不是那 28 万**。但营收记的是 28 万。

这就解释了为什么这家公司 TTM 营收 28.18 亿美元，毛利只有 2.90 亿——**毛利率 10.3%**。因为营收里九成是转手的元器件钱，那不是它的生意，是它替客户垫的钱。

### 它实际卖三样东西

**一、工程设计服务（Engineering Solutions）**
客户有个想法但没有工程队，Benchmark 帮它画电路图、选元器件、做样机、跑 EMC 电磁兼容认证和 FDA 医疗认证。这块单价最高、毛利率也最高（通常 20–30%），但规模小。它真正的价值是**抢入场券**：帮客户设计了产品，后面的量产订单几乎必然落到自己手里——因为设计图是自己画的，换代工厂要重新做一遍认证，客户不愿意折腾。

**二、印制电路板组装（PCBA）**
主体业务。就是把电阻、电容、芯片、连接器用贴片机焊到裸板上，再做 X 光检查和功能测试。这道工序全世界有几百家厂能干，纯粹拼产能利用率和良率，毛利率在 8–12% 之间。

**三、精密机加工与整机集成（Precision Technologies / Systems Integration）**
用五轴机床加工铝合金真空腔体、焊接高纯度气体管路、把电路板 + 结构件 + 线束装成一整台可以出厂的设备。这块比纯贴片值钱一些，因为半导体设备的真空腔体对表面粗糙度和洁净度要求极高，能干的厂不多。

### 终端市场

Benchmark 自己对外讲的是六个终端市场：半导体设备（Semi-Cap）、医疗、航空国防、先进计算（跟 AI 服务器沾边）、下一代通信、工业。**过去一年股价涨 90%，主要就是买"先进计算 + 半导体设备"这两个 AI 沾边的标签。** 但请注意下面的数字：营收只涨了 8.87%，净利润 5314 万美元。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：TTM 1908 万美元，占净利润的 35.9%。**
一家净利润只有 5314 万的公司，一年发出去 1908 万的股票给员工。这笔钱 GAAP 已经扣了，我不加回。但要记住它的分量：**每 3 块钱净利润里，就有 1 块钱是靠发新股省下来的现金。**

**一次性项目：资产减值与重组 1110 万美元。**
TTM 里有 1110 万的资产减值和重组费用，全部发生在 FY2025，FY2024 是零，FY2023 是 108 万。这看起来像真一次性。但代工厂关停并转是家常便饭（FY2021 也有 436 万），**只看当期一年无法判断这是不是隔几年就来一次的"常规一次性"**。另有 319 万的资产处置收益（卖厂房设备赚的），这是真一次性收益，往下算真实利润时要扣掉。

**资本化的支出：几乎没有。** TTM 购买无形资产 327 万，相对 28 亿营收可以忽略。代工厂没有软件开发费资本化那套把戏。

**回购与稀释：TTM 回购 2548 万，SBC 1908 万，比值 1.34。**
这个比值是判断"回购到底是回馈股东还是抵消员工发股"的核心指标——接近 1 说明公司买回来的股票基本刚够填上发给员工的窟窿，大于 3 才算真回购。**Benchmark 是 1.34，属于勉强填平、略有剩余。** 股本实际减少 1.42%，配上 2433 万股息，一年真正回到股东口袋的现金是 2548 + 2433 = 4981 万，对应 26.1 亿市值的股东回报率 1.9%。

**利润和现金流的差：这是本篇最重要的一段。**

净利润 5314 万，经营现金流 17699 万，自由现金流 12698 万。现金流是利润的 3.3 倍，看起来极健康。**但拆开看，一大半是欠供应商的钱。**

| 项目 | 金额（百万美元） |
|---|---|
| 净利润 | 53.14 |
| + 折旧摊销 | 42.56 |
| + 其他摊销 | 5.17 |
| + 股权激励 SBC | 19.08 |
| + 资产减值与重组 | 11.10 |
| + 坏账计提 | 0.41 |
| − 资产处置收益 | -3.19 |
| − 其他经营调整 | -4.66 |
| **小计：不含营运资金的经营现金** | **123.61** |
| ± 应收账款变化 | **-104.34** |
| ± 存货变化 | -13.61 |
| ± 应付账款变化 | **+186.60** |
| ± 预收款变化 | -2.14 |
| ± 所得税变化 | +3.49 |
| ± 其他营运资产 | -16.61 |
| **营运资金净贡献** | **+53.39** |
| **= 经营现金流** | **176.99** |

看清楚这两行：**应收账款多占了 1.04 亿（客户欠它更多钱了），应付账款多欠了 1.87 亿（它欠供应商更多钱了）。** 一进一出，净流入 5339 万。

这 5339 万占了经营现金流的 30%。它不是赚来的，是**账期腾挪出来的**——今年多拖供应商三十天货款，现金流就好看一截，明年拖不动了就还回去。对一家营收 28 亿的公司，1.87 亿的应付款增加相当于账期拉长了约 24 天。这种事不能年年干。

**把营运资金腾挪剔掉，结构性的经营现金流是 1.236 亿，减去 5001 万资本开支，真实自由现金流约 7360 万**——不是账面的 1.27 亿。这个差别在下一节直接决定估值贵不贵。

## 第三部分：市盈率，多口径

市值 26.09 亿，企业价值 25.90 亿（账上现金 3.15 亿，总负债 2.92 亿，**净现金 2300 万**，负债结构干净，这是它为数不多的优点）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 2609 ÷ 53.14 | **49.1 倍** | **2.04 元** |
| 公司自己吹的 Non-GAAP（估算） | 2609 ÷ 65.4（加回减值重组与无形摊销的税后额） | 39.9 倍 | 2.51 元 |
| **剔除障眼法后的真实市盈率** | 2609 ÷ 59.0（GAAP + 减值重组税后 8.3 − 处置收益税后 2.4） | **44.2 倍** | **2.26 元** |
| 自由现金流口径（账面） | 2609 ÷ 126.98 | 20.6 倍 | 4.85 元 |
| **自由现金流口径（剔掉账期腾挪）** | 2609 ÷ 73.6 | **35.5 倍** | **2.82 元** |
| 企业价值口径 EV/EBIT | 2590 ÷ 105.35 | 24.6 倍 | 4.07 元（税前） |
| **三年平均利润口径** | 2609 ÷ 46.37（TTM 53.14、FY2025 24.85、FY2024 61.13 的均值） | **56.3 倍** | **1.78 元** |

Non-GAAP 那一行是估算值：公司自己发布的调整后净利润我没有直接数据，是按"加回资产减值重组 1110 万和其他摊销 517 万的税后影响"倒推的，仅供参考。

### 说人话

**你现在投 100 块进 Benchmark，按最保守的真实口径（44.2 倍）算，公司一年替你赚 2.26 元。**

这 2.26 元里，真正回到你口袋的是 1.9 元（回购 2548 万 + 股息 2433 万，摊到 26.1 亿市值）；剩下的留在公司里，主要花在 5001 万的资本开支上（买贴片机、扩泰国的产能）。

**关键是最后那一行：三年平均口径 56.3 倍，比当期的 49.1 倍还贵。** 这说明现在这个 5314 万的净利润**不是高点，是刚从坑里爬出来**——FY2025 只赚了 2485 万，FY2024 赚 6113 万，FY2023 赚 6894 万。三年下来利润是往下走的，营收也是（FY2022 28.86 亿 → FY2025 26.59 亿）。

这个 2.26 元未来会变大还是变小？**大概率变大一点，但涨不到能撑住 49 倍的地步。** 理由是：

一、公司的远期市盈率（Forward PE）是 22.76，市场预期未来一年 EPS 从 1.46 涨到约 3.2，翻一倍多。这个预期建立在半导体设备和 AI 服务器订单回暖上。就算全实现，22.76 倍买一家净利率 2% 的代工厂也不算便宜。

二、**这门生意的天花板是结构性的。** 成本加成模式意味着毛利率永远锁死在 10% 左右，客户随时可以把订单挪给伟创力、捷普、新美亚——转换成本存在但不高。营收要涨，得先垫更多的钱买料，所以营收增长必然伴随现金流恶化，上一节那张对账表已经演示了这一点。

三、**最扎眼的一个数字：投入资本回报率（ROIC）6.12%，加权平均资本成本（WACC）10.55%。** 翻译成人话：**这家公司每投一块钱进去，赚回来的比它借这一块钱的代价还低。** 它每扩张一分产能，就在毁灭一分股东价值。这不是我的判断，是它自己财务比率算出来的。

四、有效税率 36.49%，明显高于美国 21% 的法定税率——多国经营、部分海外利润无法抵扣，这部分税负是长期的，不会消失。

## 第四部分：一句话结论

**Benchmark 是一家净利率 1.9% 的电子代工厂，过去一年股价涨了 90%，利润却比三年前低，现在要你出 49 倍市盈率（真实口径 44 倍，三年平均口径 56 倍）买它——这个价格不值。**

账面上那个 20.6 倍的自由现金流估值是个陷阱，其中三成来自多欠供应商 1.87 亿货款，剔掉之后是 35.5 倍。真正致命的是 ROIC 6.12% 低于 WACC 10.55%：这门生意越做越大，股东越亏。

它的优点是真的——净现金 2300 万、负债率低、账目干净、没有资本化把戏、回购略多于股权激励。但**账干净不等于值钱**。你花 49 倍买的是一家帮别人垫钱买元器件、赚 3% 加工费、且这个 3% 还跟着半导体设备周期上下摆动的公司。

如果你想赌 AI 服务器和半导体设备的下一轮上行周期，直接买设备商或芯片厂，不要买给它们代工的。代工厂在景气周期里分到的利润最薄，在下行周期里第一个被砍单。
