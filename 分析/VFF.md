# VFF · Village Farms International（乡村农场国际）

市值 3.559 亿美元 | 当前股价约 $2.91 | 行业：加工工业（温室农业 / 大麻） | TTM 截止 2026-06-30

---

## 第一部分：它到底做几件事

这家公司名字叫「乡村农场」，听起来是种菜的，实际上今天它 76% 的钱来自卖大麻。这个转变是理解它的钥匙。

财报把营收拆成五块。按 FY2025 全年（TTM 那一列公司没有拆分部，只给了总数）：

### 生意一：加拿大大麻（Cannabis - Canada）—— 真正的主业

**这件事具体是什么：** 公司在加拿大不列颠哥伦比亚省有一片玻璃温室，原本是种番茄的，2019 年前后整片改造成了大麻种植场，挂在一个叫 **Pure Sunfarms** 的牌子下面。加拿大 2018 年大麻全面合法化之后，形成了一套很特别的销售链路：**种植商不能直接卖给消费者**，必须先卖给各省政府开的批发局——安大略省的 OCS、艾伯塔省的 AGLC、魁北克的 SQDC 等等——由这些政府机构统一采购，再分销给持牌零售店。

所以他们的生意流程是这样的：Pure Sunfarms 收割、烘干、分级，把大麻干花装成 3.5 克、7 克、28 克的罐子，贴上品牌标签，报价给安大略省 OCS。OCS 下采购单，比如「这个月要 40 万克 Pink Kush 品系」。公司发货、收货款。一克干花的批发价大概在 1.5–2.5 加元之间浮动，一年 1.6 亿美元的营收，意味着一年要卖出去大约 **一亿克**（一百吨）级别的干花和相关制品。

**为什么客户非买不可：** 这个行业没有品牌忠诚度神话，OCS 采购看三样东西——**每克成本、THC 含量（消费者盯着看的数字）、以及能不能稳定供货**。Pure Sunfarms 的竞争力全部来自第一条：**它是从种菜温室改的**。种番茄的温室本来就是为了「用最低的每平米成本、全年不停地长出植物」设计的——自动化灌溉、玻璃采光、规模化。而 2018 年前后一堆大麻创业公司是从零建的高精度室内种植厂，用 LED 灯代替太阳，每克成本高一大截。合法化后加拿大产能严重过剩、干花价格连年下跌，这是一场纯粹的成本战，Pure Sunfarms 是少数几家能在低价里赚钱的。行业里它的干花市占率长期排在前列（约 10% 上下）。

**营收（FY2025）：** 1.637 亿美元，占公司总营收 **75.8%**，同比 FY2024 的 1.489 亿增长 **+10.0%**。

### 生意二：温室蔬菜（Produce）—— 正在被砍掉的老本行

**这件事具体是什么：** 在德州和加拿大的玻璃温室里种番茄、彩椒、黄瓜，摘下来装箱，卖给 Costco、Kroger、Walmart 这些大型连锁超市的生鲜采购部门。超市签的是季度或年度供货合同，按箱计价，一箱番茄十几美元。这是典型的农产品生意——**没有定价权，卖的是一种任何人都能种出来的东西**，赚的是运输半径和规模摊薄下来的几个点毛利。墨西哥的露天农场用更便宜的人工种同样的番茄，运到美国还便宜。

**这门生意正在消失，而且是公司主动砍的。** 看数字最直观：

| 年份 | Produce 营收 |
|---|---|
| FY2021 | 1.598 亿 |
| FY2022 | 1.604 亿 |
| FY2023 | 0.288 亿 |
| FY2024 | 0.289 亿 |
| FY2025 | 0.263 亿 |

一年之内从 1.6 亿掉到 0.29 亿，跌掉 82%。这就是公司总营收 FY2023 同比 **-44.4%** 的全部原因——**不是生意崩了，是把温室从种番茄改成种大麻了**（同样一平米，种大麻的产值是种番茄的十几倍）。剩下这 2600 万主要是分销业务：帮别的农场把菜卖给超市，赚个中间差价，不再自己种。

**营收（FY2025）：** 2630 万美元，占 **12.2%**，同比 -9.0%，还在缩。

### 生意三：美国大麻 / CBD（Cannabis - U.S.）—— 电商卖油

**这件事具体是什么：** 美国联邦层面大麻还是违法的，但 2018 年农业法案放开了 **CBD**（大麻二酚，一种不致幻的提取物）。公司买下了一家叫 **Balanced Health Botanicals** 的电商公司，旗下品牌 **CBDistillery**，在自己的网站上直接卖给消费者：CBD 滴油、软糖、外用膏、给狗吃的宠物版。一瓶 30 毫升的油卖 40–60 美元，走 DTC（直接面向消费者）电商，靠 Google 广告和复购。

**这门生意在缩：** FY2022 的 2330 万 → FY2023 的 2033 万 → FY2024 的 1739 万 → FY2025 的 1444 万，三年跌了 38%。CBD 那波热潮已经过去，货架上全是同类产品，没有壁垒——**任何人都能进口大麻提取物、灌进瓶子、开个 Shopify 店**。

**营收（FY2025）：** 1444 万美元，占 **6.7%**，同比 **-17.0%**。

### 生意四：荷兰大麻（Cannabis - Netherlands）—— 新赌注

**这件事具体是什么：** 荷兰长期是一个奇怪的状态——咖啡店卖大麻是被容忍的，但供货给咖啡店的种植是非法的（所谓「后门问题」）。荷兰政府启动了一个封闭供应链试点，发放少数几张合法种植许可证，让持证种植商合法向指定城市的咖啡店供货。公司在这里拿到了一张牌照并建了种植设施。这是 FY2025 才开始产生营收的新业务。

**营收（FY2025）：** 986 万美元，占 **4.6%**，从零开始。这是公司下一步增长故事的主要素材。

### 生意五：清洁能源（Clean Energy）

一个历史遗留的发电资产，FY2025 营收 164 万，占 **0.8%**。可以忽略。

### 分部利润

**财报只按分部披露营收，不披露分部利润。** 从整体看，TTM 毛利率 44.3%——这个数字对一家「种菜的」来说高得离谱，对大麻公司则正常。可以反推：大麻业务的毛利率显著高于 40%，而 Produce 分销业务毛利率大概率是个位数。**以下为估算**：加拿大大麻贡献了公司几乎全部的经营利润，Produce 和美国 CBD 大致在盈亏平衡线上下，荷兰仍在投入期。

### 总账（TTM，截止 2026-06-30）

| 项目 | TTM | 同比（对照 FY2025） |
|---|---|---|
| 营收 | 2.306 亿 | +15.3% |
| 毛利 | 1.021 亿（毛利率 44.3%） | +16.5% |

## 第二部分：把会计障眼法剥掉

### 股权激励（SBC）

TTM **214 万美元**，占净利润 **9.4%**。这个比例在小盘股里算克制的——很多同市值的公司 SBC 比净利润还大。**本文所有利润数字里 SBC 都已经作为成本扣除了**，不加回。

### 一次性项目

TTM 期内没有大额资产减值或重组费用（FY2024 有 1194 万、FY2023 有 1402 万、FY2022 有 4330 万的减值，都是温室转产大麻时把旧资产核销掉的）。TTM 这一期干净。

但净利润跌 30% 这件事需要解释：**FY2025 的 3244 万净利润里有一块不可重复的东西**。看现金流量表的两行——FY2025 的「其他经营活动」是 **-1242 万**（利润里有 1242 万是非现金的账面收益），同时「其他投资活动」有 **+3871 万** 的现金流入。合起来指向同一件事：FY2025 公司处置或重估了某项资产，一次性拉高了当年利润。**TTM 的 2271 万才是接近常态的数字，FY2025 的 3244 万不是。**

**税**：TTM 交税 1182 万，有效税率 **33.86%**。这是个真实的、没有优惠的税率——大麻行业在美国还受制于税法 280E 条款（不允许扣除常规经营费用），公司的美国部分承担了偏高的税负。**这意味着未来利润没有「税率下降」这个甜头可等。**

### 资本化的支出

无软件或内容资本化。有 40 万的无形资产购买，可忽略。

### 回购与稀释 —— 这一节是全篇最刺眼的地方

| 项目 | TTM 金额 |
|---|---|
| 回购股票 | **-976 万** |
| 发行股票 | **+2021 万** |
| **净额** | **+1045 万（净增发）** |
| 股本变化（同比） | **+11.38%** |

**回购除以 SBC = 976 万 ÷ 214 万 = 4.6 倍。** 单看这个比值会得出「真回购」的结论——**这是错的，因为它漏掉了另一边**。公司一手花 976 万买回股票，另一手发了 2021 万的新股票出去，**净结果是股本一年增加了 11.38%**。

翻译成人话：**你去年持有这家公司 1% 的股份，今年你只剩 0.898%。** 公司赚的 2271 万，摊到你名下的那部分被稀释掉了十分之一。这 976 万的回购不是在回馈股东，它是在给一场更大规模的增发做遮掩。

### 利润和现金流的差 —— 逐项对账

净利润 2271 万，经营现金流 2639 万，自由现金流 **-200 万**。差在哪：

| 项目 | 金额（万美元） | 说明 |
|---|---|---|
| 净利润 | +2271 | 起点 |
| 加：折旧与摊销 | +1655 | 温室、设备的账面折旧，不花现金 |
| 加：其他摊销 | +21 | |
| 加：资产处置损失 | +9 | |
| 加：股权激励 SBC | +214 | 发股票代替现金，不花现金（但稀释你） |
| 加：其他经营活动 | +105 | |
| 减：应收账款增加 | **-375** | 卖出去的货还没收到钱 |
| 加：存货减少 | +114 | |
| 加：应付账款增加 | +670 | 欠供应商的钱多了，等于占用别人资金 |
| 加：应交税金增加 | **+1199** | **计提了税但还没缴出去** |
| 减：其他经营性资产变化 | **-3087** | 本期最大的现金流出项 |
| **= 经营现金流** | **+2639** | 上述合计约 2796，与报告值差约 157 万（递延税等未单列项） |
| 减：资本开支 | **-2839** | 建温室、买设备 |
| **= 自由现金流** | **-200** | **负数** |

三个必须看懂的地方：

**1. 那笔 +1199 万的「应交税金增加」。** 公司这一年计提了 1182 万的所得税，但**大部分还挂在账上没有实际缴出去**。所以经营现金流里有一千多万是「暂时还没付出去的税」。这笔钱明年是要还的——它让今年的现金流看起来比真实经营能力好。

**2. 那笔 -3087 万的「其他经营性资产变化」。** 这是本期现金的最大黑洞，规模超过全年净利润。财报把它归在一个笼统的科目里，从公开财报页看不出具体是什么（可能是预付款、生物资产的公允价值调整、或递延项目）。**一个占净利润 136% 的现金流出躲在「其他」科目里，这本身就是要打折扣的理由。**

**3. 自由现金流是负的。** 经营赚回 2639 万，建温室花掉 2839 万，**净额 -200 万**。stockanalysis 的市销率页面上，P/FCF 和 EV/FCF 都显示 n/a，就是因为分母是负数。公司账上有 7293 万现金、4619 万债务，净现金 2674 万——**这个净现金头寸不是经营攒出来的，是靠今年发行 2021 万新股换来的。**

## 第三部分：市盈率，多口径

市值 3.559 亿，净现金 2674 万，企业价值 3.291 亿。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 3.559 亿 ÷ 2271 万 | **15.7 倍** | **6.38 元** |
| 公司自己吹的口径（调整后 EBITDA） | 3.559 亿 ÷ 5365 万 | 6.6 倍 | 15.15 元 |
| **剔除障眼法后的真实市盈率** | TTM 无大额一次性，SBC 已按 GAAP 扣除 | **15.7 倍** | **6.38 元** |
| 自由现金流口径 | 3.559 亿 ÷（-200 万） | **无意义（负数）** | **负** |
| 经营现金流口径 | 3.559 亿 ÷ 2639 万 | 13.5 倍 | 7.41 元 |
| 企业价值口径 EV/EBIT | 3.291 亿 ÷ 3710 万 | 8.9 倍 | 11.27 元 |
| **三年平均利润口径** | 3.559 亿 ÷ 643 万 | **55.3 倍** | **1.81 元** |

**关于「调整后 EBITDA」这一行**：公司在业绩发布里主推这个数字（TTM 5365 万，听起来很漂亮，6.6 倍）。**这是全表最没用的一行。** EBITDA 的意思是「不算利息、不算税、不算折旧摊销之前的利润」——可这家公司的折旧是 1655 万实打实的温室损耗（玻璃、钢架、灌溉系统真的会坏），税是 1182 万实打实要交的钱。把这两样加回来假装赚了 5365 万，是在讲故事。

**关于三年平均那一行 —— 这是全表最重要的数字。**

三年的真实净利润是：TTM **+2271 万**、FY2025 **+3244 万**、FY2024 **-3585 万**。平均下来一年只有 **643 万**。

也就是说，**这家公司在两年前还在巨额亏损，盈利是最近两年才刚刚出现的事**。当期 15.7 倍看着便宜，是因为分母用了历史最好的一年；换成三年平均，市盈率立刻变成 **55.3 倍**。这个 3.5 倍的差距，就是「这个利润到底能不能持续」这个问题的价格标签。

### 你现在投 100 块进去，一年赚多少

**按最保守的真实口径（三年平均利润），公司一年替你赚 1.81 元。**

按最乐观的当期 GAAP 口径，是 6.38 元。**但这 6.38 元里，有多少真正回到你口袋？答案是：零，而且还倒贴。**

- **分红：没有。** 公司不派息（Ex-Dividend Date 显示 n/a）。
- **回购：名义上花了 976 万，但同期发行了 2021 万新股，净增发 1045 万。** 你的持股比例一年被稀释 **11.38%**，也就是说你名下那份「6.38 元」，明年只剩 5.65 元的份额。
- **留在公司再投资的部分：** 看投资活动现金流，2839 万全部花在建温室和设备上（主要是荷兰的新产能和加拿大的扩产）。这笔钱比全年经营现金流还多——**公司不但没给你钱，还在靠增发股票来填补投资缺口。**

**这个「X 块」未来会变大还是变小？**

有两个方向拉扯：

**往上拉的力量**——荷兰业务从零起步，FY2025 已经贡献 986 万营收，如果荷兰的封闭供应链试点转成永久制度，这块能长成几千万级别的生意，而且是一个受保护的、牌照稀缺的市场。加拿大那边营收还在 +10% 增长，公司也确实是低成本供应商。远期市盈率 13.4 倍说明分析师预期利润还会涨。

**往下压的力量更重**——第一，**ROIC 8.38%，而加权平均资本成本 10.55%**。这两个数字放在一起的意思是：**公司每投入 100 块新资本，产生 8.38 块回报，而这 100 块钱本身的成本是 10.55 块。它每扩张一次，就毁灭一次价值。** 而它现在正在大举扩张（资本开支 2839 万，超过经营现金流）。第二，加拿大大麻是一个**产能严重过剩、干花批发价连年下跌**的行业，公司的全部竞争力建立在「比别人成本低」上，这是最脆弱的一种护城河——它没有品牌溢价，只有相对成本优势，而竞争对手一旦倒闭出清，剩下的都是同样低成本的玩家。第三，美国 CBD 业务年跌 17%，还在缩。

## 第四部分：一句话结论

**15.7 倍是个幻觉，别买。**

这家公司三年里两年在亏钱，最近两年刚转正，你看到的 15.7 倍用的是历史最好的一年当分母；把三年拉平，它是 **55 倍**。它的自由现金流是 **负的**——赚回来 2639 万，转手花 2839 万去建温室。它一年增发了 **11.38%** 的股票来填这个洞，同时花 976 万回购来让报表好看一点。它的投入资本回报率 **8.38%** 低于自己的资本成本 **10.55%**，意味着它现在做的每一分钱扩张都在减损股东价值。而它赖以生存的加拿大干花市场，是一场没有品牌、只拼成本的价格战。

股价刚从 50 日均线的 2.17 涨到 2.91（RSI 78.4，严重超买），52 周整体还是下跌 3.96% 的。**这是一家统计上便宜、商业上可疑的公司**——真正的便宜应该是「现金流充沛、股本在减少、只是暂时没人喜欢」，而 VFF 是「现金流为负、股本在膨胀、利润刚出现两年」。

真要看它，值得等的是两件事：**荷兰业务证明自己能规模化赚钱**，以及**自由现金流转正、股本停止稀释**。这两件事发生之前，15.7 倍不是折扣，是对不确定性的正确定价。
