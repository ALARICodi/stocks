# ROIV · Roivant Sciences（罗伊万特）

市值 252.3 亿美元 / 股价约 34.9 美元 / 生物医药（研发型控股公司） / TTM 截止 2026-06-30（财年 3 月底结束） / 任务5 · 主板亏损公司 第 29 名

---

## 第一部分：它到底做几件事

先说一个数字让你有概念：**这家公司 TTM 营收 753 万美元，市值 252 亿美元，市销率 3,350 倍。**它不是一家卖药的公司，它是一家「造药企的公司」。

### 它的模式：Vant 工厂

Roivant 的创始人 Vivek Ramaswamy（后来去搞政治了，现在管事的是 CEO Matt Gline）2014 年想出一套玩法：大药企手里有很多「看着不错但排不上优先级」的在研药，Roivant 把它们便宜地买过来，**每一个药单独成立一家子公司**，名字统一以 -vant 结尾，请一小队人专心把这一个药推过临床，成了就整家子公司卖给大药企或者独立上市。母公司 Roivant 只做三件事：找药、配人、出钱。

这套模式已经兑现过两次大的：
- **Telavant（肠炎药 RVT-3101）**：2023 年 12 月整家卖给罗氏，首付 71 亿美元。这就是财报里 2024 财年那笔 43.5 亿净利润的来源——不是卖药赚的，是卖公司赚的。
- **Dermavant（银屑病外用药 Vtama）**：2024 年 10 月卖给欧加隆，首付 1.75 亿加最高 12 亿里程碑，2025 财年确认了约 4.9 亿收益。

卖完 Telavant 后公司账上一度有 65 亿现金，它拿其中 13 亿回购了股票，剩下的继续养下一批 Vant。

### 现在手里押的三个赌注

**赌注一：Immunovant（IMVT，纳斯达克上市，Roivant 持股约 57%）——FcRn 抗体**
FcRn 是一类很热的自身免疫病靶点：人体里有一种蛋白负责回收「坏抗体」，把它挡住，坏抗体就被清掉，重症肌无力、甲状腺眼病、格雷夫斯病这些「自己的抗体攻击自己」的病就能缓解。这个赛道已经有成品了——argenx 的 Vyvgart 一年卖 20 多亿美元，证明了市场存在。Immunovant 的第二代分子 IMVT-1402 主打「效果一样但不伤血脂、可以长期用」，正在跑格雷夫斯病、重症肌无力等多个二期三期试验。它是独立上市公司，自己账上有几亿现金，Roivant 合并报表时把它的亏损和现金都并进来了——财报里那 6.9 亿「少数股东权益」就是 Immunovant 外部股东的份额。

**赌注二：Priovant（Roivant 持股约 75%）——brepocitinib，皮肌炎**
这是一个口服的 TYK2/JAK1 双靶点抑制剂，从辉瑞手里买来的。皮肌炎是一种肌肉和皮肤发炎的罕见病，目前没有专门获批的口服药，病人只能用激素和静脉注射免疫球蛋白。2025 年三期试验达标，已经报了上市申请。如果获批，它是 Roivant 手里最先能变成产品收入的东西。峰值销售市场普遍估 10–20 亿美元。

**赌注三：Genevant（跟 Arbutus 合资）——LNP 专利官司**
LNP（脂质纳米颗粒）是 mRNA 疫苗的「包装盒」，没它 mRNA 进不了细胞。Genevant 和 Arbutus 手握一批早期 LNP 专利，主张 Moderna 和辉瑞/BioNTech 的新冠疫苗侵权，官司打了好几年。新冠疫苗累计卖了上千亿美元，哪怕判几个百分点的许可费都是几十亿的数字，这是市场给 Roivant 估值里一块「不确定但可能很大」的期权。**TTM 财报里经营性资产增加了约 7.2 亿美元、其他流动资产从 1.1 亿跳到 8.7 亿，从财报页看不出具体性质，很可能跟诉讼或税务相关的款项有关，我不猜。**

另外还有 mosliciguat（吸入式肺动脉高压药）、几个早期项目，以及一个叫 Roivant Health 的小规模健康科技业务——TTM 那 753 万营收基本就是这类零星服务费。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：TTM 3.47 亿美元。**营收 753 万，SBC 是营收的 46 倍；是经营亏损的四分之一。这是一家 721 人的公司，人均 48 万美元的股票薪酬。这钱当然要当真实成本扣，它就是股东在给管理层和科学家的工资。

**一次性项目**：TTM 有 1.93 亿卖投资的收益、1,100 万卖资产收益、1,560 万重组费用。**Roivant 的「一次性」是它的商业模式本身**——它就是靠隔几年卖一家 Vant 赚大钱，中间年份全是亏损。所以单看 TTM 的净亏损 2.66 亿完全没有意义，看经营亏损 13.6 亿才对。

**资本化的支出**：没有。研发全费用化。

**回购与稀释**：TTM 回购 4.07 亿，SBC 3.47 亿，**回购 ÷ SBC = 1.17**——回购基本上只是在抵消发给员工的股票，不是回馈股东。同期还有 3.16 亿「发行普通股」（主要是期权行权和 Immunovant 层面的融资），净下来股本一年减少 1.06%，聊胜于无。

**利润和现金流的差**：净亏 2.66 亿，经营现金流却是 −8.16 亿，现金流比利润**难看**5.5 亿。这个方向跟大多数公司相反，值得拆开：

| 项目 | 百万美元 | 说明 |
|---|---|---|
| 净利润（含少数股东） | −266 | |
| 加：股权激励 | +347 | 非现金 |
| 加：折旧摊销、重组 | +18 | |
| 减：卖投资和资产的收益 | −204 | 这些收益在投资活动里体现，不是经营现金 |
| 减：其他经营项目 | −95 | 主要是少数股东分摊的亏损 |
| 加：应付和应交税增加 | +100 | |
| **减：其他经营性资产增加** | **−717** | **见上文，性质不明的大额现金流出** |
| = 经营现金流 | −816 | |
| 减：资本开支 | −5 | |
| = 自由现金流 | −821 | |

把那笔性质不明的 7.17 亿拿掉，**底层的经营烧钱大约是每年 1 亿出头（−816 + 717 = −99）？不对——**这个数字太好看了，是因为经营现金流里含了 40 亿现金产生的约 1.8 亿利息收入。正确的看法是：**研发 + 行政 − SBC = 每年真金白银烧约 10 亿美元，利息收入回填 1.8 亿，净烧 8 亿多。**

## 第三部分：亏损公司口径——它会不会死、活成了值多少

Roivant 是**真亏**里最纯粹的一种：没有产品、没有营收、全部靠账上现金和资本市场活着。

| 项目 | 数字（百万美元） | 说明 |
|---|---|---|
| TTM 营收、同比 | 7.5 · −68% | 可以视为零 |
| TTM 经营亏损（GAAP） | −1,363 | |
| TTM 经营现金流 / 自由现金流 | −816 / −821 | |
| 一年净烧多少现金 | 约 820 | 含 1.8 亿利息回填 |
| 账上现金 − 有息负债 | 3,735（另有长期投资 445） | 但其中一部分属于 Immunovant 外部股东 |
| 还能烧几年 | **约 5 年** | 4,180 ÷ 820 |
| SBC 占营收、股本年膨胀 | 4,600% · −1.1% | SBC 被回购抵消，代价是每年 4 亿现金 |
| **做到成熟利润率能赚多少** | 见下 | |

**假想利润怎么算：**它没有营收，只能假设「三个赌注都成了」。给一个乐观但不离谱的场景——brepocitinib 峰值 15 亿、IMVT-1402 峰值 20 亿（Vyvgart 的水平）、其他项目 5 亿，**2031 年前后合计营收 40 亿美元**。拿成熟专科药企 30% 的经营利润率（吉利德、再生元这一档）算，假想利润 12 亿。

**252 亿 ÷ 12 亿 = 假想市盈率 21 倍，投 100 块年回报 4.8 元。**

**大白话：**假设它明天就做到 40 亿营收、30% 利润率——注意这需要三个三期药全部获批并且全部卖到峰值——你投 100 块一年也只能赚 4.8 块。而它离那一天还差：营收要从 0 变 40 亿（不是翻几倍，是从无到有）、至少要 4–5 年、中间每年烧 8 亿多。这期间股本不怎么膨胀（回购顶住了 SBC），但代价是每年拿 4 亿现金去买回发给员工的股票。

**LNP 官司是唯一能改变这道算术的东西**：如果最终拿到几十亿美元的和解或判赔，那是一笔纯利润、可以直接加到现金上。市场显然已经在为这个定价——过去 52 周股价涨了 177%，营收和亏损都没变，涨的全是对这几件事的预期。

三年平均口径：2024 财年 +43.5 亿（卖 Telavant）、2025 财年 −1.7 亿、2026 财年 −3.0 亿，三年平均 +12.9 亿，**按这个算市盈率 19.6 倍——但这是把一次性卖公司的钱摊平了，除非它每三年都能卖出一个 Telavant，否则这个数字不成立。**不过公平地说，「每隔几年卖一个 Vant」确实就是它的商业模式，2023 年卖了一个、2024 年又卖了一个。

## 第四部分：一句话结论

**营收 753 万美元的公司卖 252 亿，你买的是三个三期临床赌注加一场专利官司，价格已经把大部分好结果都算进去了——很贵。**

它会不会死？五年内不会，40 亿现金够烧到三个赌注全部出结果。活成了值不值？三个全成也只是 21 倍假想市盈率，一个失败估值就得砍三分之一。**这家公司的模式（低价买药、精干推进、高价卖出）是真的跑通过两次，管理层的资本运作能力不假；但 252 亿这个价是股价一年涨了 177% 之后的价，你不是在买 Roivant 的模式，你是在给已经涨上去的预期接盘。**等它某个赌注出问题、股价回到 15–20 美元的时候再看，那时候才是「用 Roivant 的方式买 Roivant」。
