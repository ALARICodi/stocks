# CFRUY · 历峰集团（Compagnie Financière Richemont SA）

市值 1,348 亿美元 ≈ **1,172 亿欧元**（按 1 欧元 = 1.15 美元）｜ADR 价 22.86 美元（10 ADR = 1 股 A 类股）｜行业：奢侈品（珠宝、腕表）｜TTM 截止 2026-03-31（财年 4 月–3 月，半年报公司，TTM = FY2026 全年）｜财报货币：欧元（瑞士公司、欧元记账），**全文数字统一用欧元**

> 一句话认识它：**卡地亚（Cartier）和梵克雅宝（Van Cleef & Arpels）的东家。** 这两个牌子占了它四分之三的收入、几乎全部的利润。剩下的是一堆顶级腕表（江诗丹顿、积家、万国、沛纳海、朗格）和几个时装皮具牌子（Chloé、Alaïa、Montblanc 万宝龙）。

---

## 第一部分：它到底做几件事

财报按三个分部披露营收：珠宝、专业制表、其他。三门生意质量差得很远。

### 生意一：珠宝（Jewellery Maisons）——占 74%，全球最好的珠宝生意

**这件事是什么**：卡地亚和梵克雅宝两个牌子，加上 2019 年买的意大利 Buccellati。卖的东西很具体：卡地亚的 Love 手镯（一只黄金款约 7,000 欧元，每年卖几十万只）、Juste un Clou 钉子手镯、Trinity 三环戒指、Tank 和 Santos 腕表；梵克雅宝的 Alhambra 四叶草项链（一条最基础的约 3,000 欧元，配钻的几万）。这些款式几十年不变，价格每年涨 5–10%，二手市场保值率仅次于爱马仕。

**怎么收钱**：全球 2,000 多家自营精品店（不走经销商，自己开店自己卖，毛利全留），加上官网。一件东西的材料成本（黄金、钻石）大约占售价的 25–30%，剩下是品牌溢价。客户为什么非买不可：结婚戒指、纪念日礼物、送人的场合，「卡地亚」三个字本身就是礼物的一部分，换个牌子省的钱不值得冒「显得小气」的风险。

**这门生意有多好**：过去五年营收从 111 亿涨到 165 亿（年化 10%），经营利润率稳定在 32% 上下——同期 LVMH 的时装皮具部门利润率往下掉、Gucci 崩了、腕表行业萎缩，只有硬奢珠宝在涨。原因是珠宝比时装「保值」，中国消费者收紧钱包时先砍包和衣服、最后砍珠宝。

### 生意二：专业制表（Specialist Watchmakers）——占 14%，在缩

**这件事是什么**：江诗丹顿（Vacheron Constantin）、积家（Jaeger-LeCoultre）、万国（IWC）、沛纳海（Panerai）、朗格（A. Lange & Söhne）、伯爵（Piaget）、名士（Baume & Mercier）、罗杰杜彼（Roger Dubuis）——八个瑞士机械表牌子。一只万国飞行员表 5,000–10,000 欧元，一只江诗丹顿 3 万起、朗格 4 万起。

**怎么收钱**：一半自营店，一半走经销商（这块比珠宝差，经销商压库存、打折）。问题是**整个瑞士表行业在萎缩**：除了劳力士、百达翡丽、爱彼这三个「无法买到」的牌子还在涨，其他所有人的销量都在跌，尤其中国内地跌了两位数。历峰的表牌子里没有一个是劳力士那种级别的，所以跟着行业一起缩。

### 生意三：其他（Other）——占 12%，基本不赚钱

万宝龙（笔、皮具、腕表）、Chloé、Alaïa、Peter Millar、Dunhill、Delvaux、Gianvito Rossi 等时装皮具牌子。规模都小、利润率薄，历峰做时装从来没做好过。**这块最重要的事已经解决了**：2024 年把电商平台 YNAP（Yoox Net-a-Porter）甩给了 Mytheresa——那是 2018 年花 27 亿欧元全资收购的网店，六年亏了几十亿，FY2023 一次计提 34 亿减值把当年净利润打到只剩 3 亿。FY2026 为了脱手还倒贴了 6.4 亿现金（现金流量表「Divestitures −640」就是它）。这个包袱卸掉后，利润表干净了。

**分部利润说明**：数据源只披露分部营收。上表利润率按公司过往年报披露的分部经营利润率（珠宝 31–33%、制表 10–19% 且下行、其他亏损）估算，三块加总扣约 8 亿集团费用，凑到 FY2026 经营利润 46.51 亿欧元。**标注为估算。**

**整体**：FY2026 营收 224.20 亿欧元（+4.8%），毛利率 64.4%（三年前 68.7%，**金价翻倍是主因**，卡地亚的黄金成本涨了，涨价没完全跟上），经营利润率 20.8%，净利润 34.84 亿（净利率 15.5%）。**珠宝一门生意赚的利润比整个集团还多，其他两块合起来是拖累。**

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：数据源现金流量表没有单列（IFRS 公司常见）。历峰的股份支付按年报口径每年不到 1 亿欧元，占净利润 2–3%，**不是问题**。IFRS 利润里已扣，不加回。

**一次性项目**：FY2026 资产出售损失 0.65 亿加减值重组 0.99 亿，合计 1.6 亿，占净利润 4.7%，小。但往前三年这一行是灾难：FY2025 出售损失 9.7 亿、FY2024 12.7 亿、FY2023 34.4 亿，全部是 YNAP——**过去三年的净利润（27.5 / 23.6 / 3.1 亿）都被 YNAP 严重压低了**，真实的持续经营利润三年都在 36–38 亿。这件事对第三部分「三年平均」的影响是反向的：剔掉一次性损失后，三年平均利润**比当期还略高**，说明现在的利润不是高点，是常态。YNAP 已经卖掉，这类损失不会再有（FY2026 那 0.65 亿是尾巴）。

**资本化的支出**：每年资本化约 0.8–1.2 亿的软件和无形资产（「购买无形资产」−0.77 亿），相对 224 亿营收可忽略。没有。

**回购与稀释**：FY2026 回购 1.86 亿欧元，SBC 约 1 亿，**比值不到 2，回购只是在抵消员工发股**，股本 YoY 还微增 0.12%。历峰不是回购型公司，它是**分红型**：FY2026 派息 18.88 亿欧元，派息率 54%，每年涨 10% 以上（从 FY2022 的 10.4 亿涨到 18.9 亿）。

**利润和现金流的差**：净利润 34.84 亿，经营现金流 48.80 亿，自由现金流 39.18 亿。差距正常，对账：

| FY2026 项目 | 亿欧元 | 说明 |
|---|---|---|
| 净利润 | 34.84 | |
| + 折旧摊销 | 15.50 | 2,000 多家店的装修和租赁资产折旧，真成本 |
| + 其他摊销 | 0.59 | |
| + 出售损失 + 减值重组 | 1.64 | YNAP 尾巴 |
| + 其他非现金调整 | 1.42 | |
| − 应收款增加 | −0.77 | |
| − **存货增加** | **−8.76** | 见下 |
| + 其他营运资本 | 4.39 | |
| = 经营现金流 | 48.80 | |
| − 资本开支 | −9.62 | 开店、翻新、工厂 |
| = 自由现金流（数据源口径） | 39.18 | |
| − 租赁付款 | −7.80 | **店租**，IFRS 16 把它算成还债，我算回经营成本 |
| = **真实自由现金流** | **约 31.4 亿** | |

两个要点。第一，**存货每年增加 8–9 亿**，五年累计 40 亿，存货周转率只有 0.85（一年周转不到一次）——这是奢侈品珠宝的天性：金库里的黄金和钻石、店里的陈列、订制的库存，卖得慢但不贬值（金价涨了存货还升值）。它不是坏信号，但确实吃掉了四分之一的经营现金流。第二，**7.8 亿店租**被 IFRS 藏进了融资活动，数据源的 FCF 没扣，我扣回来——历峰自营店模式的代价就是这笔租金，它跟工资一样是硬成本。扣完之后真实自由现金流 31.4 亿，**比净利润低 10%**，也就是说净利润是实的、略有水分，水分在存货。

## 第三部分：市盈率，多口径

市值按 1,172 亿欧元算。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP（IFRS）TTM 市盈率 | 1,172 亿 ÷ 34.84 亿 | **33.6 倍** | 3.0 元 |
| 公司自己吹的「持续经营利润」 | 净利润加回 YNAP 尾巴 1.6 亿 ≈ 36.4 亿 | 32 倍 | 3.1 元 |
| **剔除障眼法后的真实市盈率** | 同上，一次性损失是真一次性；SBC 不加回 | **32 倍** | **3.1 元** |
| 自由现金流口径（数据源） | 1,172 亿 ÷ 39.18 亿 | 29.9 倍 | 3.3 元 |
| 自由现金流口径（扣店租） | 1,172 亿 ÷ 31.4 亿 | 37 倍 | 2.7 元 |
| 企业价值口径 EV/EBIT | (1,172 − 37 净现金) ÷ 46.51 亿 | 24.4 倍 | 4.1 元 |
| 三年平均利润口径 | FY2024–2026 各剔除 YNAP 损失（36.3 / 37.2 / 36.4 亿），平均 **36.6 亿** | **32 倍** | 3.1 元 |

三年平均那一行是这三家里最健康的：**当期 32 倍、三年平均也是 32 倍**——利润三年没涨也没跌，稳在 36–37 亿。这跟西门子能源（三年平均 140 倍）和罗尔斯·罗伊斯（63 倍）完全不同：那两家是利润刚从谷底冲上来、市场在赌能持续，历峰是利润本来就在这儿、市场在为「稳」付钱。但反过来说，**三年利润没涨，市值却从 900 亿涨到 1,170 亿**，涨的 30% 全是估值抬升，不是生意变好。

**大白话说：你现在投 100 块进去，按剔除障眼法的真实口径算，公司一年替你赚 3.1 块。** 这 3.1 块里，以分红回到你口袋的 1.6 块（派息 18.9 亿，54% 派息率，每年涨 10%），回购可以忽略，剩下 1.5 块留在公司：一部分变成存货（黄金和钻石，不贬值），一部分开新店和建工厂。账上净现金 37 亿，172 亿现金对 135 亿债务（其中一半以上是店租的租赁负债，不是真借款），非常安全。

**这 3.1 块未来会不会变大**：珠宝每年涨 8%、制表每年跌 4%、其他不动，合起来营收涨 5%；珠宝利润率 31% 已经接近天花板，涨价空间被金价吃掉一半。所以**利润大概率每年涨 5–8%，不会更快**。风险：中国消费者（含港澳、海外购物）占三分之一，2024–25 年那轮中国奢侈品下滑让制表部门跌了两位数，珠宝靠涨价和欧美日本客户顶住；金价再涨一倍毛利率还会往下走；瑞士法郎升值让成本上升（工厂在瑞士、收入在全球）。

## 第四部分：一句话结论

**全世界最好的珠宝生意，卖一个合理偏贵的价。** 卡地亚和梵克雅宝是硬奢里最能涨价、最抗周期的两个牌子，31% 的利润率五年没掉、净现金、账干净、派息年年涨 10%，YNAP 那个大坑也已经填完卖掉——生意本身挑不出硬伤。问题只在价格：32 倍市盈率、投 100 块一年赚 3.1 块，买的是一门每年增长 5–8% 的生意，而且三年利润没涨、市值涨了 30%，估值已经从「合理」抬到了「偏贵」。它不像那两家工业公司那样在赌一个翻倍剧本，所以不算离谱；但爱马仕以外的奢侈品在 2024 年都跌过 30%，这种机会隔两三年来一次。**值得留着观察，等它回到 25 倍以下再动手。**

**归篮：偏贵 / 好生意。**
