# SPSC · SPS Commerce（零售供应链数据网）

市值 29.09 亿美元 / 股价 77.38 美元 / 行业：科技服务（供应链 SaaS）/ TTM 截止 2026-06-30（数据更新至 2026-07-30 财报）

---

## 第一部分：它到底做几件事

SPS Commerce 干的事一句话说不清，但只要举个例子就秒懂。

假设你在浙江做拖鞋，好不容易谈下沃尔玛的订单。沃尔玛不会给你发邮件说"我要 3000 双 41 码蓝色"。沃尔玛的采购系统会吐出一份叫 **EDI 850（采购订单）** 的电子文件，格式是 1980 年代定下来的一串结构化代码；你必须在 24 小时内回一份 **EDI 855（订单确认）**，发货时回 **EDI 856（发货通知，里面要写清楚每个箱子里装了什么、每个托盘上码了几个箱子、条码是什么）**，开票时回 **EDI 810（发票）**。任何一份格式错了、晚了、字段少了，沃尔玛的系统会自动罚你钱——一次几百到几千美元不等，这叫 chargeback。

问题是：你同时还在给塔吉特、Costco、亚马逊、家得宝供货，**每一家的 EDI 方言都不一样**。沃尔玛要的箱码规则和塔吉特不同，Costco 的托盘标签又是另一套。你要么雇 3 个人天天手工填，要么自己养一个 IT 团队维护 20 套接口。

SPS 就是站在中间的那根管子。你把货品和订单信息按 SPS 的一套格式扔给它，SPS 负责翻译成每个零售商各自的方言，负责传输、重传、格式校验、版本升级。零售商那头改了规则，SPS 改，不用你管。

**收钱方式**：按月订阅，一家中小供应商大概每月 300–1,500 美元，取决于接了几个零售商、跑多少单据量。合同一般一年起,自动续约。SPS 有约 **12–13 万家**这样的付费客户,平均单客户年费大约 5,000–6,000 美元——所以它是一门**极度分散**的生意,没有任何一个客户占比超过 1%。

**它为什么难被换掉**:这不是你一个人的决定。你换掉 SPS,意味着要跟沃尔玛、塔吉特、Costco 逐一重新做接口测试认证,每家两到六周,期间任何一单出错就是真金白银的罚款。而 SPS 一个月只收你几百块。**"省下的钱不够赔一次错"**——这就是护城河的全部内容。更狠的是,零售商自己会推:很多零售商在《供应商手册》里直接写明推荐用 SPS 对接,新供应商开户时就被引导过来了。这是**双边网络效应**——零售商越多,供应商越必须来;供应商越多,零售商越懒得自己搭。

四条营收线(TTM 截止 2026-06-30,单位:百万美元):

| 生意 | TTM 营收 | 占比 | 同比(估算) | 这是什么 |
|---|---|---|---|---|
| Fulfillment 履约 | 660.31 | 85.5% | 约 +12% | 上面说的核心管道，订阅制 |
| Analytics 分析 | 56.64 | 7.3% | 约 +1% | 把管道里流过的数据卖回去 |
| Other Recurring 其他订阅 | 24.51 | 3.2% | 约 +9% | Carbon6 / SupplyPike 等新收购的工具 |
| One-Time 一次性 | 31.03 | 4.0% | 约 −13% | 新客户上线的实施费 |
| **合计** | **772.49** | 100% | **+9.8%** | |

> 同比是估算：SPS 只披露分部的年度数字，上年同期 TTM 由 FY2024 和 FY2025 插值倒推，用来看方向，不要当精确数。

**Analytics 是什么**：管道里每天流过几百万条订单和发货单，SPS 顺手把这些数据洗干净卖回去。一个卖狗粮的品牌可以买到"我在塔吉特全美 1,900 家店里，哪 300 家上周断货了"——因为塔吉特的库存回传单据（EDI 852）就从 SPS 的管子里过。这门生意毛利极高，但**几乎不涨了：TTM 5,664 万，比 FY2024 的 5,572 万只多了不到 2%**。这是全篇第一个警报。

**Other Recurring 是买来的**：2024 年底花 1.48 亿收 Carbon6（帮亚马逊第三方卖家自动申诉、追回被亚马逊扣掉的费用），2025 年花 1.43 亿收 SupplyPike（帮供应商自动申诉沃尔玛的 chargeback 罚款）。逻辑是通的——SPS 已经握着单据流，知道你哪一单被罚了，顺手替你申诉，按追回金额抽成。但目前只有 2,451 万，占 3.2%，撑不起大局。

**财报只披露到营收，不披露分部利润**。整体经营利润率 15.83%，Fulfillment 作为主业大概率高于这个数，Analytics 和收购来的业务因为无形资产摊销拖累会低不少——但这是**估算**，没有精确数字。

## 第二部分：把会计障眼法剥掉

**股权激励 SBC：6,163 万美元，是 GAAP 净利润 7,800 万的 79%。**

这个比例非常吓人。SPS 一年发给员工的股票，价值相当于它给股东赚的钱的八成。GAAP 报表里已经扣掉了（所以 7,800 万是扣完的数），但公司自己吹的"调整后 EPS"和券商用的"前瞻市盈率 15.36 倍"**全都把这 6,163 万加回去了**。加回去等于假装员工白干活。本文一律不加回。

**一次性项目：这里有个说不清的窟窿，必须点名。**

经营利润 1.223 亿，税前利润只有 1.048 亿，**中间少了 1,750 万**。但 SPS 手里有 1.73 亿净现金、几乎没有债务（总负债才 631 万），利息应该是**净收入**（按 4% 算约 +600 万）。也就是说，有大约 **2,300 万美元**的"其他支出"塞在经营利润和税前利润之间，财报摘要页看不到明细。

最可能的来源是并购的**或有对价（earn-out）公允价值变动**或投资减值——SPS 两年花了近 3 亿收购，earn-out 重估走非经营科目是常规做法。但**只看 TTM 单期无法判断这是真一次性还是年年都有**，我不下结论，只标出来：**这 2,300 万如果是一次性的，税后约 1,700 万，GAAP 净利润应该是 9,500 万而不是 7,800 万；如果年年都有，那 37 倍市盈率就是真的。**

**资本化支出：SPS 不资本化软件开发费**（研发全部费用化），这一项是干净的。

**回购与稀释：TTM 回购 1.531 亿 ÷ SBC 6,163 万 = 2.48 倍。** 高于 1（不只是抵消发股），但没到 3。实际结果：股本从 36.62M 降到 36.00M，**一年只减了 1.68%**——因为公司同时还通过员工持股计划发出去 1,080 万美元的新股。花 1.53 亿真金白银，净减 1.68% 股本，效率一般。

**利润和现金流的差：差得非常大，必须对账。**

净利润 7,800 万，经营现金流 2.281 亿，**差了 1.5 亿，接近 3 倍**。逐项拆开（单位：百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| GAAP 净利润 | 78.00 | 起点 |
| ＋折旧摊销 | +60.90 | 大头是收购来的无形资产摊销，不花钱 |
| ＋股权激励 SBC | +61.63 | **不花现金但真实稀释你，别当白捡** |
| ＋坏账计提 | +10.43 | 中小供应商倒闭收不回的钱 |
| ＋其他经营项 | +17.61 | 含上面那笔说不清的非经营支出回加 |
| −应收账款增加 | −8.72 | 生意涨了，客户欠得多 |
| −预收/应付等变动 | +0.69 | 基本持平 |
| −其他净经营资产 | −15.84 | |
| **＝ 经营现金流** | **228.14** | |
| −资本开支 | −29.45 | |
| **＝ 自由现金流** | **198.70** | FCF 利润率 25.7% |

**这张表的结论**：1.5 亿的差额里，**1.22 亿是折旧摊销＋股权激励这两笔"不花钱"的**。折旧摊销 6,090 万确实基本是纸面数字（收购无形资产摊销，不需要真花钱去补）；但股权激励 6,163 万**不是**——它是你的股份被稀释掉的部分。所以 SPS 真正属于股东的自由现金流是 **198.70 − 61.63 = 1.371 亿**，不是 1.987 亿。

## 第三部分：市盈率，多口径

市值 29.09 亿，企业价值 27.42 亿（因为有 1.67 亿净现金，EV 比市值小）。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 2,909 ÷ 78.00 | **37.3 倍** | **2.68 元** |
| 公司/券商口径（加回 SBC 和摊销，估算） | 2,909 ÷ 约 170 | 约 17 倍 | 约 5.9 元 |
| **剔除障眼法后的真实市盈率** | 2,909 ÷ 92.6（把那 2,300 万当一次性加回，SBC 不加回） | **31.4 倍** | **3.18 元** |
| 自由现金流口径 | 2,909 ÷ 198.70 | 14.6 倍 | 6.84 元 |
| **自由现金流扣掉股权激励** | 2,909 ÷ 137.07 | **21.2 倍** | **4.71 元** |
| 企业价值口径 EV/EBIT | 2,742 ÷ 122.30 | 22.4 倍 | 4.46 元 |
| 三年平均利润口径 | 2,909 ÷ 82.80（TTM+FY25+FY24 平均） | **35.1 倍** | **2.85 元** |

**先说三年平均这一行，因为它这次说的是好消息。** 三年平均 35.1 倍，比当期 37.3 倍还**低**——意思是**现在的利润不是高点，反而是三年里最差的一年**（净利润 7,800 万 vs 去年 9,334 万，倒退了 16%）。倒退的原因是无形资产摊销（收购）和那笔 2,300 万非经营支出，不是生意崩了：营收还在涨 9.8%，自由现金流反而涨了 40%。所以这里不存在"用高点利润算出低市盈率"的陷阱，反而是反过来。

**那 15.36 倍的"前瞻市盈率"是怎么来的？** 它把 6,163 万 SBC 和约 4,000 万无形资产摊销全加回去，凑出一个约 1.8 亿的"调整后利润"。摊销加回去我认可（那确实不花钱），**SBC 加回去我不认可**。所以别信 15 倍。

**说人话：你现在投 100 块进 SPS Commerce。**

按最保守的口径（自由现金流扣掉股权激励，也就是真正属于你的那部分现金），公司一年替你赚 **4.71 元**。

这 4.71 元里：
- **约 5.3 元**（按市值算的回购收益率 1.53 亿 ÷ 29.09 亿 = 5.3%）名义上以回购形式回到你口袋，但其中约 2.1 元被员工新发的股票吃掉了，**净到你手上大概 1.7 元**（对应股本实际减少 1.68%）。
- 不分红，一分钱都不分。
- 剩下的钱留在公司：TTM 没有新收购（现金收购 = 0），投资活动只花了 2,068 万，说明**并购刹车了**，现金在账上堆着（净现金从 1.44 亿涨到 1.67 亿）。

**这 4.71 元未来会变大还是变小？大概率变大，但变大的速度在肉眼可见地慢下来。** 营收增速从 23% → 17% → 19% → 19% → 18% → **9.8%**，而且这 9.8% 里有相当一部分是 Carbon6 和 SupplyPike 两笔收购贡献的（合计花了 2.9 亿），**有机增速可能只有 6–7%**。FCF 利润率 25.7% 已经是历史最高，靠利润率继续扩张来提速的空间不大。

## 第四部分：一句话结论

**一门真正有护城河的好生意，跌了三分之一之后第一次算得上公道价——但你买的是"增速能稳在 10%"这个假设，而不是便宜。**

好的地方是真好：12 万客户没有一个占比超过 1%，零售商替它拉新客，换掉它的代价远高于它收的钱，70% 毛利、26% 自由现金流利润率、1.67 亿净现金零负债、ROIC 11.5% 高出资本成本 6.9% 一大截。21 倍的"真实自由现金流"配 10% 的增长，不算贵。

不好的地方也不含糊：增速从 18% 腰斩到 10%，Analytics 这门本该最性感的数据生意**一年只涨 1%**，一次性实施费收入在下滑（意味着新客户上线在减速），股权激励等于净利润的 79%，花 1.53 亿回购只买回 1.68% 的股本，GAAP 口径 37 倍并且利润在倒退。8% 的做空比例说明市场里有一群人认为 EDI 这门 1980 年代的生意会被 API 和 AI 直接绕过去。

我的判断：**公道价，不是便宜价。** 值得放进观察名单，但它需要的不是"再跌 20%"，而是"下个季度证明有机增速没有继续往 6% 掉"。如果 Fulfillment 增速跌破 8%，21 倍就立刻变成偏贵。
