# WOR · 沃辛顿企业（Worthington Enterprises）

市值 28.04 亿美元 | 股价约 57.3 美元（市值 ÷ 4893 万股倒推） | 行业：制造业 / 消费品与建材 | 交易所：NYSE
TTM 截止日期：2026 年 5 月 31 日（该公司财年 5 月底结束，TTM 即 FY2026 完整财年）

---

## 第一部分：它到底做几件事

Worthington Enterprises 表面上是一家做金属容器的俄亥俄州制造商，但它的利润结构里藏着一个必须先讲清楚的事实：**它自己经营的工厂，只贡献了 38% 的税前利润；剩下 62% 来自两家它只占一半股权、财报上根本不合并营收的合资企业。**

换句话说，你买的这 13.81 亿营收的公司，实际上是"一家中等规模的制造商 + 两张常年派现金的分红票"。先说前面那家制造商。

### 生意一：消费品（Consumer Products）—— TTM 5.198 亿美元，占营收 37.6%

这一块做的是**你能在家得宝、沃尔玛货架上拿起来的金属罐子和工具**：

- **Coleman 丙烷气瓶**——就是露营时接在炉头上那个绿色的小钢瓶，一次性、用完扔。Worthington 拿的是 Coleman 品牌授权，自己造罐、自己灌气。一个零售价 5–8 美元，靠的是巨大的走量和铺货：全美几乎每一家户外用品店、加油站便利店、超市都摆着。
- **Bernzomatic 焊枪与气罐**——水管工用来焊铜管的那把喷枪，配丁烷/丙烷罐。厨师用来烤焦糖布丁的也是它。枪卖一次，罐子买一辈子——**这是标准的"剃须刀 + 刀片"模式，真正赚钱的是那个每次十几美元的补充罐。**
- **Balloon Time 氦气球套装**——超市里卖的那个一次性氦气罐，家长买回去在生日会上吹三十个气球。
- **Level5 Tools** ——专业干墙（石膏板）施工工具，抹泥刀、自动上料机之类。
- **HALO 户外炉具**——披萨炉、烤架。

这一块 TTM 5.198 亿，比上年的 4.996 亿只涨了 **4.0%**。它的特点是**稳但不长**：北美露营和 DIY 的需求是成熟市场，钢价波动会直接吃掉利润率，好处是品牌认知强、货架位置难被替代，家得宝不会为了省几毛钱去换一个消费者没听过的丙烷罐牌子。

### 生意二：建筑产品（Building Products）—— TTM 8.615 亿美元，占营收 62.4%

- **水处理压力罐（Amtrol / WELL-X-TROL）**——美国有几千万户人家用自家水井取水，井泵不能一开水龙头就启动一次（会烧掉），所以要装一个压力罐当缓冲：泵一次性把水打进罐里压住空气，之后用水靠气压推出去。这个罐子寿命十来年，坏了必须换，装修工人和水管工只认那几个牌子。一个零售 300–600 美元。
- **家用和商用丙烷储罐**——农村家庭取暖用的那种几百加仑的大罐、叉车用的可换气瓶、烧烤用的 20 磅罐。
- **冷媒钢瓶**——空调制冷剂的运输和储存钢瓶，法规要求极严（承压容器），准入门槛来自认证而不是技术。
- **Elgen Manufacturing（FY2026 花 3.04 亿现金收购）**——做 HVAC（暖通空调）的**风管配件**：商业楼宇里天花板上方那些镀锌铁皮方管的接头、弯头、法兰、调风阀。这笔收购是本财年营收暴涨 19.72% 的主要来源，也是它把业务从"卖罐子"往"卖建筑系统零件"推的一步。

建筑产品 TTM 8.615 亿，比上年 6.541 亿涨了 **31.7%**——但这个增速里绝大部分是买来的（Elgen 并表），不是自己长出来的。

### 生意三和生意四：两家合资企业——利润的真正来源

财报的营收里**完全看不到**这两块，因为 Worthington 只占 50%，按权益法核算：营收不并表，只把"分到的利润"一行记进利润表。

- **WAVE（Worthington Armstrong Venture）**——与 Armstrong World Industries 各占 50%。做的是**吊顶龙骨系统**：办公楼、学校、医院天花板上那些托着矿棉板的金属网格。这是个近乎双寡头的市场，Armstrong 卖板、WAVE 卖架，两个一起装。
- **ClarkDietrich**——与丸红伊藤忠钢铁的合资，各占一半。做**轻钢龙骨**：商业建筑内墙里那些代替木龙骨的镀锌钢立柱和横撑。美国商业建筑内墙的标准做法就是钢龙骨加石膏板，它是这个品类的最大玩家之一。

**这两家 TTM 一共给 Worthington 分回了 1.3463 亿美元的利润**——而 Worthington 自己所有工厂加起来的经营利润只有 **8331 万**。

而且这块必须看趋势：FY2022 是 1.8386 亿、FY2023 1.5326 亿、FY2024 1.6772 亿、FY2025 1.4484 亿、TTM 1.3463 亿。**四年下来掉了 27%**，跟美国商业地产（写字楼开工）的低迷完全对得上。

## 第二部分：把会计障眼法剥掉

### 股权激励（SBC）
TTM **1373 万美元**，占 1.5609 亿净利润的 **8.8%**，占营收不到 1%。对一家制造业公司来说这是很克制的水平，没什么可挑剔的。GAAP 已经扣了，不加回。

### 一次性项目
TTM 明细清楚，金额都不大：
- 并购与重组费用 **−687 万**（Elgen 收购的交易费用）
- 投资出售损失 **−393 万**
- 其他非经常项 **−23 万**
- 汇兑收益 **+712 万**（这一笔是**收益**，而且波动性强，判断持续盈利能力时应该剔掉）

合计非经常项净额约 **−392 万**（税前）。TTM 期内**没有商誉减值、没有资产减值**——这一点很关键，因为上一年 FY2025 有 **5081 万的资产减值**、FY2024 有 **1421 万商誉减值 + 3050 万资产出售损失 + 1877 万减值**。**只看 TTM 一期，无法判断这种减值是不是每隔一两年就来一次**，但从 FY2024、FY2025 连着两年都有来看，它更像常客而不是意外。

### 一个必须单独拿出来说的口径问题：已终止经营
FY2024 的净利润 1.1062 亿里，有 **8284 万是"已终止经营"**——那是 2023 年 12 月分拆出去的 Worthington Steel（钢材加工业务，现已独立上市）。分拆前那半年的利润还挂在报表里。**它跟今天这家公司毫无关系。**

这意味着：任何拿"三年平均净利润"来算的人，如果不剔掉这 8284 万，就会把一个已经不存在的业务算进现在的估值里。下面第三部分我会给出两个版本。

### 资本化的支出
无软件或研发资本化。

### 回购与稀释
TTM 回购 **4966 万美元**，SBC 1373 万。

**回购 ÷ SBC = 3.62 倍。** 这是本批三家里唯一真正合格的数字——大于 3 意味着回购不只是在抵消员工发股，而是在真实地替股东减少股份。实际股本一年减少 **0.83%**，符合这个金额（4966 万 ÷ 28 亿市值 ≈ 1.8%，扣掉发股稀释后净减 0.83%，对得上）。

TTM 分红 **3689 万**（股息率约 1.3%）。回购加分红合计 **8655 万，占市值 3.09%**——这就是股东实打实拿到手的部分。

### 利润和现金流的差
TTM 净利润 1.5609 亿，经营现金流 **2.2612 亿**，自由现金流 **1.7021 亿**。现金流比利润还高，这在制造业里是好信号。逐项对账（单位：百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 156.09 | 起点 |
| + 折旧摊销 | 57.27 | 非现金，工厂设备 |
| + 资产出售损失 | 3.29 | 非现金 |
| + 投资出售损失 | 0.98 | 非现金 |
| **+ 权益投资相关净调整** | **+5.36** | **关键项，见下方解释** |
| + 股权激励 | 13.73 | 非现金 |
| + 坏账计提 | 0.36 | |
| + 其他经营活动 | 7.39 | |
| + 应收账款减少 | 7.71 | 收回了一点现金 |
| − 存货增加 | -11.56 | Elgen 并进来带来的备货 |
| + 应付账款增加 | 3.82 | |
| − 其他净经营资产 | -18.31 | |
| **= 经营现金流** | **226.12** | |
| − 资本开支 | -55.91 | |
| **= 自由现金流** | **170.21** | |

**这张对账表里藏着本篇最重要的一个发现。**

注意：利润表里那 **1.3463 亿的合资企业权益收益**，在现金流量表里**几乎没有被扣掉**——权益投资相关的调整净额只有 **+536 万**。

按会计规则，权益法确认的收益是纸面利润，做现金流量表时必须先减掉，再把实际收到的现金分红加回来。这里净调整只有 +536 万，唯一合理的解释是：**WAVE 和 ClarkDietrich 把赚到的钱基本全额以现金分红的形式派回给了 Worthington，收到的现金甚至比确认的利润还多出约 536 万。**

这条推断很重要，因为它把一个通常的怀疑点直接消掉了：**那 1.35 亿不是画在纸上的利润，是每年真的打进公司账户的现金。** 这也解释了为什么它的经营现金流 2.26 亿能远超净利润 1.56 亿。

（说明：这是从现金流量表倒推的判断，财报页没有单列"收到的合资企业分红"这一行。）

### 一个必须提醒的资产负债表变化
账上现金从上年的 **2.5 亿掉到 2773 万**，净负债从 7960 万涨到 **3.245 亿**。原因不神秘：花了 **3.0415 亿现金收购 Elgen**。债务／EBITDA 2.28 倍，利息覆盖 13.3 倍，不算危险；但**现金垫子已经基本用光了**，接下来一两年它没有再做一笔大收购的弹药，除非借钱。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 28.04 亿 ÷ 1.5609 亿 | **18.0 倍** | 5.57 元 |
| 公司自己吹的 Non-GAAP | 财报页未提供该口径 | 未披露 | — |
| **剔除障眼法后的真实市盈率** | 28.04 亿 ÷ 1.591 亿（净利 1.5609 + 一次性损失税后 0.085 − 汇兑收益税后 0.055） | **17.6 倍** | **5.68 元** |
| 自由现金流口径 | 28.04 亿 ÷ 1.7021 亿 | **16.5 倍** | 6.07 元 |
| 企业价值口径 EV/EBIT（官方口径） | 31.3 亿 ÷ 0.8331 亿 | **37.6 倍** | 2.66 元 |
| **企业价值口径（把合资企业收益并进来）** | 31.3 亿 ÷（0.8331 + 1.3463）亿 | **14.4 倍** | 6.96 元 |
| 三年平均利润口径（含已终止经营） | 28.04 亿 ÷ 1.2092 亿 | **23.2 倍** | 4.31 元 |
| **三年平均利润口径（只算持续经营，更诚实）** | 28.04 亿 ÷ 0.950 亿（1.5504 / 0.9497 / 0.3498 的平均） | **29.5 倍** | **3.39 元** |

**关于 EV/EBIT 那两行，必须解释一下**：官方的 37.6 倍看起来吓人，但那个口径对这家公司是系统性失真的——EBIT 只包含它自己工厂的经营利润，完全不含合资企业分回的 1.35 亿，而市值和企业价值里显然包含了那两家合资企业的价值。分子含、分母不含，倍数当然虚高。把合资企业收益加回分母之后是 **14.4 倍**，这才是可比的数字。同样的道理也解释了为什么它的 **ROIC 只有 4.73%、远低于 9.81% 的 WACC**——合资企业的收益不在分子里，这个 ROIC 被系统性低估了，不能直接拿来判它毁灭价值。

### 说人话

**你现在投 100 块进 Worthington，按最保守的真实口径算，公司一年替你赚 5.68 块。** 自由现金流口径更好一点，6.07 块。

这 5.68 块里有多少真的回到你口袋？**回购加分红一共 8655 万，占市值 3.09%——所以约 3.1 块是实打实回到你手上的**（其中 1.3 块是现金分红，1.8 块是通过回购让你手里的股份变值钱）。剩下的 2.5 块左右留在了公司里，去向很明确：**TTM 花了 3.04 亿收购 Elgen、5591 万做资本开支**，也就是说留存利润全部、并且额外动用了账上的两亿多现金去买增长。

这个 5.68 块未来变大还是变小？**这是全篇最需要独立判断的地方，因为它的两条腿方向相反：**

- **自营这条腿在往上。** 经营利润从 FY2025 的 5062 万涨到 TTM 的 8331 万（+65%），毛利率 27.39% 稳住了，Elgen 带来了一整块新业务，消费品那边靠品牌和货架位置吃老本但不掉。
- **合资这条腿在往下。** 1.8386 亿 → 1.3463 亿，四年掉 27%，跟着美国商业建筑的开工量走。**而这条腿贡献了 62% 的税前利润。** 如果写字楼和商业地产继续低迷，它每年还要再掉几个百分点，那自营那条腿涨的钱刚好被抵消掉。

所以那个 5.68 块能不能变大，**几乎完全取决于美国商业建筑什么时候回暖**——这不是管理层能控制的，也不是你能从财报里看出来的。

## 第四部分：一句话结论

**大致值这个价，是本批三家里唯一一家买着不亏的——但你要清楚自己买的一半是别人家的公司。**

真实市盈率 17.6 倍、自由现金流 16.5 倍、把合资企业算进去的企业价值口径 14.4 倍，对一家消费品加建材、毛利 27%、回购真做到 SBC 的 3.6 倍、股东回馈率 3.1% 的公司来说，这个价格是公道的，不便宜也没有明显泡沫。报表也干净：SBC 只占净利 8.8%，没有资本化研发的把戏，经营现金流 2.26 亿实实在在高于 1.56 亿的净利润，合资企业的利润确认为现金收得回来。

要扣分的地方有三处，都不致命但都真实：**第一，62% 的税前利润来自两家不并表、且连续四年下滑 27% 的合资企业，这块的好坏你既看不见细节也影响不了；第二，本体的营业利润率只有 6.03%，这是一门靠走量、被钢价来回捶的制造生意；第三，三年平均持续经营口径是 29.5 倍**——意思是当前这个 18 倍，建立在 FY2026 利润同比暴涨 62.5% 的基础上，而那个暴涨里有一大半是买来的（Elgen）和上一年基数太低（FY2025 有 5081 万减值）。

最后一句实在话：现金从 2.5 亿花到只剩 2773 万，净负债翻了四倍。它把子弹打出去买了 Elgen，接下来两年就得靠这笔收购和商业建筑回暖来证明这一枪没打偏。**在这个价格上留着观察是合理的，追高不必——等它公布下一两个季度、看 Elgen 的整合利润率和合资企业收益有没有止跌，再决定要不要动手。**
