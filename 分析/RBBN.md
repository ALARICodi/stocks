# RBBN · Ribbon Communications（瑞邦通信）

市值 3.63 亿美元 / 股价 $2.03（2026-08-28 收盘） / 行业：通信设备与软件（Technology Services） / TTM 截止 2026-06-30

企业价值（EV）7.17 亿美元 · 全榜第 1079 名 · 网站显示市盈率 24.66 倍

---

## 第一部分：它到底做几件事

Ribbon 是做"电话网络的管子和路由器"的。它有两门生意，财报按两个分部披露。

### 生意一：Cloud and Edge（云与边缘）—— 把老式电话网搬到互联网上

**这件事到底是什么。**

你打一通电话，声音要经过一堆设备才能到对方耳朵里。上世纪九十年代到本世纪初，这些设备是电信局机房里的"程控交换机"——一屋子专用硬件，一台几百万美元，只会做一件事：接电话。现在全世界的电信运营商都在拆这些老机器，改成用普通服务器跑软件来接电话（叫 VoIP，网络电话）。Ribbon 卖的就是替换用的软件和设备。

具体举个例子。美国有几百家区域性小电话公司（比如某个州的乡村电话合作社），机房里还摆着 1998 年买的诺基亚/朗讯交换机，厂家早就不生产配件了，坏一块板子要去 eBay 上淘二手的。Ribbon 上门说：我给你装一套 Ribbon Application Server，跑在四台普通服务器上，把你两万个固定电话用户全迁过来，老机器可以断电了。这笔单子大概两三百万美元，其中硬件（服务器）只占一小部分，大头是软件许可证和迁移服务，之后每年还要收 15–20% 的维护费。这是它最典型的一单生意。

**第二件典型产品叫 SBC（会话边界控制器）。** 名字唬人，作用很好懂：它是一个门卫，摆在企业内网和外部电话网的交界处。比如一家有 5000 员工的银行，内部用微软 Teams 开会打电话，但员工也要往外拨真实号码打给客户。Teams 说的是一种协议，运营商的电话网说的是另一种，中间必须有个东西做翻译；同时这个门口天天被人扫描攻击（有人专门爆破企业电话系统然后拨国际长途，一夜能刷掉几十万话费）。SBC 就同时干翻译和挡攻击这两件事。一台 Ribbon SBC 5400 硬件盒子卖几万到几十万美元不等，看能同时扛多少路通话；银行这种要买两台做主备。这个市场 Ribbon 全球排前二，主要对手是 Oracle（收购 Acme Packet 来的）和 AudioCodes。

**第三块叫 STIR/SHAKEN 防骚扰电话。** 美国 FCC 强制规定：运营商发出的每一通电话都必须用数字签名"盖章"，证明主叫号码不是伪造的，接收方要验章。这是法律要求，不做就罚款。Ribbon 卖的就是这套盖章验章的系统。好处是客户没得选（合规刚需），坏处是一次性建设完就没有增量了。

**客户是谁**：主要是电信运营商（Verizon、AT&T、英国电信、德国电信这类），加上政府部门、大型金融机构。**为什么非买不可**：老设备停产、监管强制、以及"电话打不通"是运营商绝对不能出的事故——所以他们宁愿多花钱买有名气的品牌，也不敢用便宜货。这是 Ribbon 唯一真实的护城河：客户换供应商的迁移风险太大。

**这门生意的问题**：它本质上是一次替换性需求。全世界的老交换机总有拆完的一天，拆完之后 Ribbon 只剩每年那点维护费。TTM 这个分部收入 4.77 亿美元，比 2025 全年的 5.11 亿低了一截，2021 年还是 5.57 亿——**五年时间少了 14%，这是一门在慢慢缩水的生意**。

### 生意二：IP Optical Networks（IP 光网络）—— 卖光纤传输和路由设备

这块是 2020 年花 3.2 亿美元收购以色列 ECI Telecom 来的。做的是更底层的东西：光纤上跑数据的设备。

**具体是什么。** 一根光纤要同时传很多路数据，靠的是把不同颜色的激光叠在一起（叫波分复用）。两端各要一台机器负责把数据变成光、把光还原成数据，中间每隔几十公里还要放大器。Ribbon 的 Apollo 系列做的就是这个；配套的 Neptune 系列是数据包路由器，决定每一包数据往哪条路走；再配一套叫 Muse 的管理软件，让运营商在一个屏幕上看到整张网。

举个真实的单子形态：印度的国有电信在做农村宽带工程，要在几千个乡镇之间铺光纤骨干网，招标采购几千台传输设备。Ribbon 中标一段，合同额可能两三千万美元，分两三年交货。这种单子的特点是**金额大、毛利薄、时间不确定**——政府预算一拖，收入就从今年挪到明年。Ribbon 在印度、欧洲、中东有相当比重的收入来自这类项目。

**竞争格局对它很不利。** 这个市场上站着华为、诺基亚、爱立信、Ciena、中兴。Ribbon 的体量（这块一年 3.2 亿美元）大概是 Ciena 的十分之一、诺基亚的几十分之一。规模小意味着研发摊不薄、芯片采购议价能力弱。它能活着靠的是"不能用华为"的那部分市场（美国、印度、部分欧洲的政府和运营商因为安全审查排除中国厂商），这是政治红利不是技术优势。

## 第二部分：把会计障眼法剥掉

这家公司的"利润"是全篇最需要讲清楚的东西。先把三个数并排放：

| 项目 | TTM 金额（百万美元） |
|---|---|
| 经营利润（EBIT） | **−11.96** |
| **税前利润** | **−75.32** |
| 所得税 | **−90.91（是退税，不是交税）** |
| **净利润** | **+15.60** |

**看懂了吗：这家公司税前实实在在亏了 7532 万美元，最后报出 1560 万利润，靠的是账上记了一笔 9091 万美元的所得税收益。**

这笔税不是真的有人给它退了 9000 万现金。它叫"递延所得税资产估值备抵转回"——公司过去连亏很多年（2021 年亏 1.77 亿、2022 年亏 9808 万、2023 年亏 6621 万、2024 年亏 5424 万），累积了一大堆税务亏损额度，将来赚钱时可以抵税。会计上原本认为"这公司大概率赚不回来，这些额度不值钱"，就不入账；某一期管理层改口说"我们觉得将来能用上了"，就把它记成一笔利润。**一分钱现金没进来，纯粹是会计判断变了。**

现金流量表印证了这一点：TTM 经营活动里有一项"其他经营活动 −8445 万"，几乎正好把这笔税务收益扣回去了。

所以**网站上那个 24.66 倍的市盈率是假的**，分母是一笔账面数字。

其余各项逐条：

**股权激励（SBC）**：TTM 2142 万美元，占营收 2.7%。相对净利润 1560 万来说，SBC 比净利润还大——也就是说发给员工的股票比赚的钱还多。这笔钱 GAAP 已经扣了，我这里不加回，本来也不该加回：它实实在在稀释了你的股份。

**一次性项目**：TTM 没有列示重大资产减值或重组费用（2021 年有过 1.16 亿的减值和重组）。但税前亏损 7532 万里有一块要说明：经营亏损只有 1196 万，剩下 6336 万是经营利润线以下的支出。按网站给的利息保障倍数 −0.27 倒推，利息支出约 **4400 万美元/年**（对应 3.97 亿债务，约 11% 的实际成本，含摊销费用），另外约 1900 万是汇兑、债务相关或养老金一类的杂项。**单看一期分不清这 1900 万是不是年年都有**，但 4400 万利息是铁定年年都有的。

**资本化支出**：软件开发费资本化不显著，购买无形资产 TTM 只有 55 万美元。没有靠资本化美化利润。

**回购与稀释**：TTM 回购 1347 万美元，同期 SBC 是 2142 万——**比值 0.63，回购连抵消员工发股都不够。** 结果是股本一年增加了 2.46%（1.7 亿股 → 1.788 亿股）。也就是说，你持有的股份被稀释了 2.5%，公司还花了 1347 万现金去回购，两件事加起来你什么都没得到。这不是回馈股东，这是发工资。

**利润和现金流的差**：这张对账表是全篇最实的东西（单位：百万美元）。

| 步骤 | 金额 | 说明 |
|---|---|---|
| 净利润 | +15.60 | 起点，含那笔假的税务收益 |
| + 折旧摊销 | +59.57 | 非现金，主要是 ECI 收购形成的无形资产摊销 |
| + 其他摊销 | +2.88 | |
| + 股权激励 | +21.42 | 非现金，但真实稀释你 |
| − 其他经营活动 | **−84.45** | **主要就是把那笔递延税收益扣回去** |
| + 应收账款减少 | +25.85 | 收回了老欠款——但也是收入下滑的副产品 |
| − 存货增加 | −8.27 | |
| + 应付账款增加 | +0.79 | |
| + 预收款增加 | +6.00 | |
| − 其他经营性资产变动 | −17.15 | |

**一年到头，这家 8 亿美元营收的公司只产生了 735 万美元的真实自由现金。** 而它一年要付 4400 万的利息——利息是从借新债和账上现金里出的，不是从经营里出的。TTM 现金从 9641 万降到 4351 万，净现金流 −1679 万。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 363.01 ÷ 15.60 | **23.3 倍**（网站显示 24.66） | 4.30 元 |
| 公司自己吹的 Non-GAAP | 公司口径调整后利润（加回 SBC、摊销、重组） | 约 11–13 倍（远期市盈率 13.72） | 约 7.5 元 |
| **剔除障眼法后的真实市盈率** | 363.01 ÷ 税前利润 −75.32 | **不存在（亏损）** | **−20.75 元** |
| 自由现金流口径 | 363.01 ÷ 7.35 | **49.4 倍** | 2.02 元 |
| 企业价值口径 EV/EBIT | 716.51 ÷ 经营利润 −11.96 | **不存在（经营亏损）** | 负 |
| 企业价值/自由现金流 | 716.51 ÷ 7.35 | **97.5 倍** | 1.03 元 |
| EV/EBITDA | 716.51 ÷ 47.60 | 15.05 倍 | — |
| **三年平均利润口径** | 363.01 ÷ [(15.60 + 39.64 − 54.24) ÷ 3] = 363.01 ÷ 0.33 | **约 1100 倍** | **0.09 元** |

**最后一行是全表最重要的。** 把 TTM、2025、2024 三年的净利润平均一下，是 33 万美元——三年下来，这家公司平均每年赚的钱四舍五入是零。如果换成 2023–2025 三年，平均是 **每年亏 2694 万**。

### 说人话

**你现在投 100 块钱进 Ribbon，按最保守的真实口径算，公司一年替你赚 −20.75 元。** 也就是说它不赚钱，它亏钱。

如果你愿意退一步，只看它真实产生的自由现金流（这是最宽容的正数口径），**100 块钱一年产生 2.02 元现金**——年化 2%，比美国国债还低一半。

而且这 2.02 元里，**没有一分钱回到你口袋**：公司不分红（无股息），回购的 1347 万还不够抵消员工股票稀释。这点现金全部拿去还了 875 万的债，剩下的补了运营缺口。

**如果算上债务，情况更难看。** 你买的是 3.63 亿的股权，但你同时接手了 3.53 亿的净债务——公司总的企业价值 7.17 亿，而它一年只产生 735 万自由现金，**企业价值是自由现金流的 97.5 倍**。债务/EBITDA 4.83 倍，属于高杠杆区间；利息保障倍数 −0.27，意味着**经营利润连利息的零头都覆盖不了**。

**这个数字未来大概率变大还是变小？** 两边看：

往好处说的唯一理由是 —— 公司自己给的远期市盈率 13.72，说明管理层和分析师预期明年利润会翻倍。ROIC 是 −1.60%，只要经营利润转正，账面数字就会好看很多；而且股价一年跌了 49%，市净率只有 0.92，理论上有清算价值托底。

往坏处说的理由更多，而且更硬：**营收在缩水**（TTM −7.62%，两个分部同时缩），缩水的生意再怎么降本也只是延缓；**利息是刚性的**，4400 万一年不会因为收入少了就少收；**账上现金只剩 4351 万**，一年经营现金流 2223 万，缓冲很薄；**PB 0.92 的托底是假托底**，3.93 亿净资产里大头是 ECI 收购留下的商誉和无形资产（有形账面价值市净率 P/TBV 显示为 n/a，说明有形净资产接近零或为负），真清算的话股东拿不到什么。

所以答案是：**这个 X 大概率继续变小**，除非光网络那块能在印度/欧洲拿到足够大的单子把规模做起来——而那需要它去正面赢诺基亚和 Ciena。

## 第四部分：一句话结论

**不值这个价，而且贵得不明显、所以更危险。**

$2.03 的股价、24 倍的市盈率、0.92 的市净率，三个数字摆在一起会让人觉得"跌了 49%，是不是可以捡漏了"。但把账拆开看：**它的利润是一笔递延税的会计动作变出来的，税前实亏 7532 万；它的经营利润是负的，连利息都赚不回来；它的营收两个分部一起缩；它的自由现金流 735 万，对应 7.17 亿的企业价值是 97.5 倍。**

用最宽容的口径，你投 100 块一年拿回 2 块钱现金，还一分不给你；用诚实的口径，你投 100 块一年亏掉 20 块。市净率 0.92 看着有安全垫，但那点净资产是收购以色列公司留下的商誉和无形资产，不是能变现的东西。

它不会马上死——手上有几百个运营商客户，维护费收得动，债务也不是明天到期。但这是一家**在缩水的市场里、背着 3.5 亿净债务、靠会计调整才能报出利润的公司**，$2 的股价不是便宜，是市场在给一个持续失血的资产负债表定价。要等的话，等的应该是"经营利润真的转正、并且能覆盖 4400 万利息"这一天，而不是等股价再跌一点。
