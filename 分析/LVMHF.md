# LVMHF · LVMH 酩悦轩尼诗–路威酩轩

市值 2459 亿美元（约 2152 亿欧元，按 1 欧元 = 1.1425 美元）/ 场外价 500.64 美元（≈438 欧元/股，巴黎主板同一股票）/ 奢侈品 / TTM 截止 2026-06-30（法国公司，半年报，全文用欧元）

> 任务4 海外巨头第 6 名。财报按 IFRS 以欧元编制，市值按 stockanalysis 当天美元市值折成欧元后再算倍数。

## 第一部分：它到底做几件事

LVMH 是全世界最大的奢侈品集团，手里攥着 75 个牌子。财报把它们分成五门生意，但你先记住一句话：**这家公司本质上是「一个 LV + 一个 Dior」，其余 73 个牌子加起来赚的钱，还不如这两个的零头。**

### 生意 A：时装与皮具（LV、Dior、Fendi、Celine、Loewe、Loro Piana……）——集团的印钞机

**这是什么：** 卖包、卖衣服、卖鞋，但卖法跟普通服装公司完全不同。一只 Louis Vuitton 的 Neverfull 手袋卖 2000 欧元出头，皮料、五金、人工加起来成本大概三四百欧元，毛利率 70% 往上。关键在于**它只在自己的店里卖**：LV 全球 460 多家直营店，不批发给百货公司、不打折、不进奥特莱斯、卖不掉的宁可销毁也不降价。这样做的结果是：价格由它一个人说了算，每年涨价 5%–8% 顾客照买，而且顾客越是买不到、越是要排队，就越想要。

Dior 是第二台印钞机（2017 年花 65 亿欧元把 Christian Dior 时装从 Arnault 家族手里买进上市公司），一件 Dior 女装外套 4000–6000 欧元，一只 Lady Dior 手袋 5000 欧元上下。Fendi、Celine、Loewe、Loro Piana（一件羊绒大衣 5000–10000 欧元）是第二梯队，各自几十亿欧元营收。

**怎么赚钱：** 顾客走进店里，全款付清，没有账期、没有应收账款。一家 LV 旗舰店一年做几亿欧元生意，租金、店员、装修全算完，店面本身的利润率仍然高达 40% 左右。这门生意 2023 年顶峰时做到 422 亿欧元、经营利润率接近 40%；现在 TTM 是 368 亿欧元，从顶峰缩水 13%，主要是中国人买奢侈品的热情退潮了，中产顾客先撤，剩下的是最有钱的那批人。

| 时装与皮具 | 数字 |
|---|---|
| TTM 营收 | 368.0 亿欧元 |
| 比上一整年（2025 年 377.7 亿） | −2.6% |
| 占集团营收 | 46% |
| 经营利润率（估算） | 约 36% |
| 贡献经营利润（估算） | 约 132 亿欧元，占集团经营利润约 76% |

> 财报只披露到分部营收，分部利润是按 LVMH 年报历年公布的分部「经常性经营利润」比例外推到 TTM 的估算值，下同。

### 生意 B：精选零售（Sephora 丝芙兰 + DFS 免税店）——营收第二大，利润却薄得像纸

**这是什么：** Sephora 是全球最大的美妆连锁店，3000 多家店，卖的主要是**别人家的**化妆品（雅诗兰黛、欧莱雅、各种网红品牌），自己的自有品牌只是一小部分。它就是一家零售商：从品牌进货、加价卖给消费者，赚的是批零差价，毛利率 40% 上下，扣掉房租店员广告，能剩 8%–10% 就算好年景。一个女孩子进店买 60 欧元的粉底，Sephora 大概赚 5 欧元。

DFS 是开在机场和香港、澳门的免税店，2019 年之前靠中国游客过得很滋润，疫情之后一直没缓过来，现在是亏损的，LVMH 正在关店。

| 精选零售 | 数字 |
|---|---|
| TTM 营收 | 181.3 亿欧元 |
| 比上一整年（2025 年 183.5 亿） | −1.2% |
| 占集团营收 | 23% |
| 经营利润率（估算） | 约 7%–8% |
| 贡献经营利润（估算） | 约 13–14 亿欧元 |

营收占集团近四分之一，利润只占 8%。它存在的理由不是赚钱，是让 LVMH 的香水（Dior、Guerlain）在自家渠道里有最好的货架。

### 生意 C：钟表与珠宝（Tiffany、Bulgari、TAG Heuer、Hublot、Chaumet）

**这是什么：** 2021 年花 158 亿美元买下 Tiffany（LVMH 史上最大收购），加上原有的 Bulgari，凑成珠宝板块。一枚 Tiffany 订婚钻戒 5000–20000 美元，一条 Bulgari Serpenti 项链 1–3 万欧元。珠宝的毛利没有皮具高（钻石和黄金是硬成本），而且 Tiffany 买来之后 LVMH 花了几年翻新纽约旗舰店、砍掉低端银饰、往高端推，这个过程很烧钱。钟表（TAG Heuer、Hublot、Zenith）是板块里的弱项，被劳力士和百达翡丽压着打。

### 生意 D：香水与化妆品（Dior 香水、Guerlain、Givenchy、Fenty Beauty）

**这是什么：** Dior 的 Sauvage 男香是全球卖得最好的香水之一，一瓶 100 毫升卖 130 欧元，液体本身成本几欧元。听起来暴利，但这行的钱大部分砸在广告和明星代言上（Johnny Depp、Rihanna），再加上要给 Sephora 之类的零售商留一大块利润，最后落到手里的经营利润率只有个位数。这个板块的战略意义是「入门级奢侈品」：买不起 5000 欧元的包，先买 130 欧元的香水，跟品牌建立关系。

### 生意 E：葡萄酒与烈酒（Moët & Chandon、Dom Pérignon、Veuve Clicquot、Hennessy 轩尼诗）

**这是什么：** 集团起家的两个 M 和 H 就在这里。轩尼诗干邑一瓶 VSOP 卖 50 欧元、XO 卖 200 欧元，酒液在木桶里躺了几年到几十年，所以毛利率极高，历史上经营利润率能到 30% 以上。但最近三年是集团表现最差的板块：营收从 2022 年的 71 亿欧元跌到 TTM 的 54 亿欧元，缩水 24%。原因两个：美国人喝干邑的热潮退了，加上中国 2024 年对欧盟白兰地征反倾销税，直接砍掉轩尼诗最大的两个市场。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）：** LVMH 是 Arnault 家族控制的欧洲公司（家族持股约 48%、投票权约 64%），不像美国科技公司那样大把发股票。现金流量表没有单列 SBC 一行，年报历年披露的股权激励费用大约在 1 亿多欧元量级，占净利润约 1%，可以忽略。股本一年减少 0.61%，说明没有稀释。

**一次性项目：** TTM 有 6.1 亿欧元「资产减值与重组」（2025 全年 6.2 亿），主要是 DFS 免税店关店和一些小品牌减值。单期口径判断不了是不是年年都有，但从 2023 年（0.4 亿）到 2025 年（6.2 亿）是逐年放大的，更像「下行周期里持续清理」而不是真一次性。我在真实市盈率里只把它加回一半。另外每年有 7.9 亿欧元「其他摊销」，是收购 Tiffany、Dior 等带来的无形资产摊销，这个是真实成本的会计影子，不加回。

**资本化的支出：** 没有值得说的。奢侈品公司的开支是门店装修和广告，广告直接费用化了。

**回购与稀释：** TTM 回购 20.8 亿欧元，分红 64.4 亿欧元。SBC 几乎为零，所以回购 ÷ SBC 这个比值没意义，直接看结果：股本一年少了 0.61%，回购是真的回馈股东，不是抵消发股。

**利润和现金流的差：** 净利润 108.8 亿，经营现金流 186.4 亿，自由现金流 143.7 亿。差得很大，值得对账：

| 从净利润到经营现金流（TTM，亿欧元） | 金额 | 说明 |
|---|---|---|
| 净利润 | 108.8 | |
| + 折旧与摊销 | 58.1 | 里面约 29 亿是租赁资产折旧（IFRS 16 把店铺租金变成了折旧） |
| + 其他摊销 | 7.9 | 收购来的品牌无形资产摊销 |
| + 减值与重组（非现金） | 6.1 | |
| + 其他经营调整 | 15.8 | 主要是递延税和少数股东损益 |
| − 存货增加 | −17.0 | 卖得慢了，货压在仓库里 |
| + 应收应付等其他营运资金 | 6.7 | |
| **= 经营现金流** | **186.4** | |
| − 资本开支 | −42.7 | 开店、翻新旗舰店 |
| **= 自由现金流** | **143.7** | |
| − 租赁付款 | −29.7 | **这一行必须扣**：店铺房租在 IFRS 下算「融资活动」，不扣的话自由现金流虚高 |
| **= 扣掉房租后的真自由现金流** | **114.0** | |

结论：**真自由现金流约 114 亿欧元，跟净利润 109 亿基本对得上。** 表面上 144 亿的自由现金流是 IFRS 租赁规则造成的假象——LVMH 一年付 30 亿房租，这钱不能不付。stockanalysis 显示的 15 倍 P/FCF 是用虚高的 144 亿算的，别信。

另外注意存货：TTM 又压了 17 亿欧元存货，2023 年压了 42 亿、2024 年 11 亿。存货周转从 1.38 次降到 1.13 次，货卖得越来越慢，这是行业下行的直接证据。LVMH 不打折的政策意味着这些货只能慢慢消化或销毁。

## 第三部分：市盈率，多口径

市值 2152 亿欧元。净负债 249 亿欧元（有息负债 372 亿，其中约 170 亿是租赁负债；现金 122 亿）。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 2152 ÷ 108.8 | 19.8 倍 | 5.1 元 |
| 公司自己吹的口径 | LVMH 用「经常性经营利润」，TTM 173.8 亿，税后约 118 亿 | 18.2 倍 | 5.5 元 |
| **剔除障眼法后的真实市盈率** | 2152 ÷（108.8 + 减值加回一半 2.3） | **19.4 倍** | **5.2 元** |
| 自由现金流口径（扣房租） | 2152 ÷ 114.0 | 18.9 倍 | 5.3 元 |
| 企业价值口径 EV/EBIT | （2152 + 249）÷ 173.8 | 13.8 倍 | 7.2 元（税前） |
| 三年平均利润口径 | 2152 ÷ 三年平均净利润 128.7（2023 年 151.7、2024 年 125.5、2025 年 108.8） | **16.7 倍** | **6.0 元** |

**大白话：你现在投 100 块进去，按最保守的真实口径算，公司一年替你赚 5.2 块。**

这 5.2 块里：分红拿走 3.0 块（股息率 3.03%，每股 15.19 美元），回购再还你 0.9 块，加起来 3.9 块真正回到你口袋。剩下 1.3 块留在公司开新店、翻修旗舰店（TTM 资本开支 43 亿欧元，比 2023 年顶峰的 75 亿已经收紧很多）。

**这个 5.2 块未来变大还是变小？** 这是全篇最关键的判断，我认为**大概率变大**，理由是三年平均口径那一行：现在的 109 亿净利润是三年里最低的一年，比 2023 年顶峰低 28%。跟 NVDA 那种「当期利润是顶峰、三年平均才 73 倍」正好相反，LVMH 是**当期利润在谷底、三年平均比当期便宜**。时装皮具板块的利润率从 40% 掉到 36%，酒类从 30% 掉到 20%，这两个数只要回到中间值，净利润就能回到 130 亿以上，市盈率立刻变成 16 倍。

**风险在哪：** 全部押在「中国和美国的有钱人重新开始买包」这件事上。如果奢侈品需求进入日本 1990 年代那种长期萎缩，那 109 亿就不是谷底而是新常态。但 LVMH 的定价权（每年涨价照涨）、只做直营（不被经销商砍价）、Arnault 家族的长期主义，是全行业最能扛周期的一家。

## 第四部分：一句话结论

**值这个价，是公道价，不是便宜价。** 20 倍市盈率买在明确的行业下行周期底部附近，利润率从 26.5% 掉到 21.8%、营收从顶峰缩水 8%，而它的定价权和品牌壁垒一点没坏。真实回报 5.2%、三年平均口径 6%，分红加回购每年实打实还你 3.9%，等周期回暖还有利润率修复的空间。市值从 2021 年的 4165 亿美元跌到 2459 亿美元，跌掉 41%，该跌的已经跌过一轮。不是捡漏，但这是用公道价买全世界最好的消费品生意的窗口。
