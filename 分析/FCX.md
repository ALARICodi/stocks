# FCX · 自由港麦克莫兰（Freeport-McMoRan, Inc.）

市值 964 亿美元 / 股价约 67 美元 / 行业：有色金属（铜矿开采与冶炼）/ TTM 截止日期：2026-06-30

> 三个数字先摆出来，它们互相矛盾，本文就是要把矛盾讲清楚：
> - 股价过去 52 周**涨了 56.5%**；
> - 但营收 TTM 只增长 **0.19%**（几乎零增长）；
> - 而市盈率 **32.7 倍**，是三家里最贵的，同时 EV/EBITDA 只有 **11.3 倍**，看起来又最便宜。
>
> **矛盾的答案藏在两个地方：一是它 36% 的利润不归你，二是它一年 41 亿的资本开支。**

---

## 第一部分：它到底做几件事

本质上只有一件事：**从地里挖出铜矿石，磨碎、提炼成铜，卖给做电线的人。** 顺带因为矿里伴生黄金和钼，一并挖出来卖。财报按地理和加工环节拆成六块，我按"这钱是怎么赚的"重新分成三类。

### 第一类：挖矿（真正赚钱的部分）

**a) 印尼 Grasberg —— 全公司的皇冠，也是全公司最大的风险**

TTM 收入 **61.89 亿美元，占 23.9%**。对比 FY2025 全年的 86.18 亿，**掉了 28.2%——这是全篇最刺眼的一个数字。**

Grasberg 在印尼巴布亚省海拔四千多米的山上，是**全世界最大的金矿，同时是第二大铜矿**。矿石里同时含铜和金，意味着挖同样一吨石头，卖两样东西——所以它的成本结构好得离谱：黄金的销售收入可以直接冲抵采矿成本，算下来**铜的"净现金成本"能压到接近于零甚至为负**。地表那个巨型露天坑已经挖完了，现在整个作业转到地下，靠"崩落法"（block caving）——在矿体下面掏空，让上面的矿石靠自重塌下来，再用地下铁路运出去。

**掉 28% 的原因**：这类地下崩落法作业最怕的事就是塌方和泥石涌入，一旦出事整个矿区要停产整顿、重新做地质评估，而且不是几周能恢复的。2025 年下半年 Grasberg 就发生了这类地下事故并导致停产，收入断崖式下滑正是这个的结果。**这提醒你：这不是一门"稳定挖矿"的生意，一个矿区出事就能砍掉全公司四分之一的收入。**

**更要命的是所有权**：FCX 只持有印尼子公司 PT Freeport Indonesia 的 **48.76%**，剩下 51.2% 归印尼政府旗下的 MIND ID。也就是说，**Grasberg 赚的钱有一半以上根本不是你的**。这一点在第二部分会算出确切金额。

**b) 南美（秘鲁 Cerro Verde + 智利 El Abra）**

TTM 收入 **54.20 亿美元，占 21.0%**，对比 FY2025 的 46.15 亿 **增长 17.4%**——这是印尼掉下去时的主要补位者。

Cerro Verde 在秘鲁南部，是一个巨型露天铜钼矿；El Abra 在智利北部阿塔卡马沙漠。这两个矿的作业方式很直白：**炸药炸开山体 → 巨型卡车（一车拉 300 吨）运到破碎机 → 磨成粉 → 浮选出铜精矿（含铜约 25%）→ 装船运去中国和日本的冶炼厂。** 客户是全球冶炼厂和贸易商，价格完全按伦敦金属交易所（LME）的铜价定，FCX 没有任何定价权——**它是纯粹的价格接受者**。

Cerro Verde 同样不是 100% 持股（FCX 约持 53.6%），秘鲁本地股东和住友分走一部分。

**c) 北美铜矿（亚利桑那、新墨西哥）**

TTM 对外收入只有 **3.42 亿美元，占 1.3%** —— **这个数字会骗人。**

北美矿区（Morenci、Bagdad、Safford、Sierrita、Chino、Miami）产量其实很大，但它们挖出来的铜**绝大部分卖给了公司内部的加工厂**（下面第二类），报表把内部交易抵消掉了，所以"对外销售"只剩零头。**不要以为北美业务微不足道——它是 FCX 唯一 100% 持股、且政治风险最低的一块资产**，而且美国政府近年把铜列为关键矿产，这块的战略溢价在上升。

这里也是钼的产地（Climax、Henderson 两个纯钼矿），钼用来炼特种钢，价格波动比铜还猛。

### 第二类：加工与冶炼（走量不赚钱的部分）

**d) Rod & Refining（美国精炼与铜杆）** —— TTM 收入 **78.14 亿美元，占 30.2%**，+14.1%。**收入最大的一块，也是最不赚钱的一块。**

它做的事：把自家矿产的铜精矿电解成 99.99% 的阴极铜板，再把铜板拉成手指粗的**铜杆**，卖给做电线电缆的厂商。一家电缆厂买一卡车铜杆，价格 = **当日 LME 铜价 + 每磅几美分的加工费**。也就是说：**这门生意的收入随铜价上下几十亿美元地摆动，但真正属于它的利润只有那"每磅几美分"**——估算经营利润率**只有 2%–4%**。

**e) Atlantic Copper（西班牙韦尔瓦冶炼厂）** —— TTM 收入 **35.78 亿美元，占 13.8%**，+13.4%。

同样的逻辑：收精矿，炼成阴极铜，赚"冶炼加工费"（TC/RC）。这块在近年全球冶炼产能过剩、加工费被压到历史低位的环境下，**基本是微利甚至亏损**，估算利润率 0%–2%。它存在的意义是给自家精矿一个出口，不是为了赚钱。

**f) 其他（TTM 25.25 亿，9.8%，+22.3%）** —— 钼销售、贸易、公司层面的其他收入。

### 把六块重新归类

| 类别 | TTM 营收（百万） | 对比 FY2025 | 占比 | 估算经营利润率 |
|---|---|---|---|---|
| **挖矿**（印尼 + 南美 + 北美 + 其他） | 14,476 | −11.9% | 56.0% | 约 **45%–50%** |
| — 其中 印尼 Grasberg | 6,189 | **−28.2%** | 23.9% | 约 55%（最高） |
| — 其中 南美 | 5,420 | +17.4% | 21.0% | 约 40% |
| — 其中 北美（对外）+ 其他 | 2,867 | +7.1% | 11.1% | 约 30% |
| **加工冶炼**（铜杆 + Atlantic Copper） | 11,392 | +13.5% | 44.0% | 约 **2%–3%** |
| **合计** | **25,868** | **+0.19%** | 100% | 实际整体 26.8% |

*财报只按分部披露营收，不披露分部利润，上表利润率为按行业惯例的估算。*

**这张表说明了一件重要的事**：FCX 一半的营收（加工冶炼）几乎不产生利润，只是把铜价从左手倒到右手。**真正决定它赚多少钱的，是那 56% 的挖矿收入，而这 56% 里最赚钱的一块（印尼）刚刚掉了 28%，而且一半以上不归股东。**

## 第二部分：把会计障眼法剥掉

### ⚠️ 最大的一项不是"障眼法"，是**少数股东权益**——它拿走 36% 的利润

这不是会计花招，是实打实的股权结构，但**不看清楚就会把估值算错一倍**：

| 项目 | TTM 金额（百万美元） |
|---|---|
| 税前利润 | 6,660 |
| − 所得税（有效税率 31.06%） | −2,068 |
| **= 税后总利润** | **4,592** |
| **− 少数股东（印尼政府、秘鲁股东等）分走** | **−1,647** |
| **= 真正归你（FCX 股东）的净利润** | **2,945** |

**少数股东拿走了税后利润的 35.9%。**

这带来两个直接后果：

1. **EV/EBITDA 11.3 倍是假便宜。** EBITDA 90.7 亿是**整个集团**的，包含印尼政府那一半；而企业价值 1,027 亿只算了 FCX 股东的市值加净负债，**没有把少数股东权益加进去**。分子只算你的、分母算所有人的——分母被人为放大了。修正后的真实倍数要高得多（见第三部分）。
2. **有效税率 31.06% 已经很高**（对比 Intuit 21.6%、CME 23.4%）——印尼和秘鲁的矿业税负重，还有特许权使用费。**挖矿这行，政府永远是第一个分钱的。**

### 股权激励（SBC）：**1.50 亿美元，占净利润 5.1%**

很低，占营收只有 0.58%。矿业公司靠机器和矿权赚钱，不靠抢工程师，不需要拿股票当工资。**这一项对 FCX 的估值影响可以忽略。**

### 一次性项目：没有可辨识的大额一次性项目

TTM 内没有重组、没有并购（收购支出为 0）、没有披露大额减值。现金流量表里"其他调整 −2.99 亿"是把一部分非现金账面收益减掉——从历史看（FY2025 +4.31 亿、FY2024 +4.40 亿都是正的，今年转负），**这一项年年方向不定**，按单期口径无法判断是否一次性。

**但有一件事必须点名**：印尼那 28% 的收入下滑，本身在会计上不是"一次性项目"（没有计入任何非经常性损益），它就是实实在在的经营结果。所以**你在 TTM 报表上看到的 29.45 亿净利润，已经是在印尼半瘫痪状态下赚出来的**——这既是坏消息（说明利润被压制），也是好消息（说明恢复后有向上空间，这也是市场给出 19.8 倍前瞻市盈率、股价一年涨 56% 的原因）。

### 资本化的支出：**这才是真正吃掉现金的东西**

- **TTM 资本开支：41.38 亿美元**
- **TTM 折旧摊销：21.47 亿美元**
- **资本开支 ÷ 折旧 = 1.93 倍**

对比一下前两家：Intuit 资本开支只有折旧的 0.16 倍，CME 是 0.29 倍。**FCX 花的是折旧的近两倍。**

矿业的残酷之处在于：**矿是消耗品**。每挖走一吨矿石，剩下的矿就少一吨，而且越挖品位越低（浅层富矿先挖完）。要维持同样的产量，必须不停地剥离表土、打新的地下巷道、建新的选矿厂。所以这 41 亿里有相当一部分**不是扩张，是维持**——不花这笔钱，明年产量就会掉。

而会计上，这些钱先记成资产，再按矿的储量慢慢折旧。**结果就是：利润表看着还行，现金一直不够花。**

### 回购与稀释：**基本不回购，股本纹丝不动**

- TTM 回购：**2.48 亿美元**（占市值 0.26%）
- TTM 股权激励：**1.50 亿美元**
- **比值 = 1.65** —— 按本篇标准，**这是"回购只是在抵消员工发股"的典型**，远够不上"大于 3 才算真回购"

实际效果：流通股一年只减少 **0.09%**，等于没变。

分红：TTM **8.66 亿美元**，四年没涨过（FY2022–FY2025 都是 8.65 亿左右），股息率 **0.90%**。FCX 的分红政策名义上有"基础分红 + 与业绩挂钩的浮动分红"，但**浮动那部分近几年基本没发出来**——因为钱全花在资本开支上了。

### 利润和现金流：**净利润 29.45 亿，自由现金流只剩 17.62 亿**

| 项目 | 金额（百万美元） | 说明 |
|---|---|---|
| 税后总利润（含少数股东） | 4,592 | 现金流表从这个口径起算 |
| ＋ 折旧摊销 | 2,147 | 矿的账面损耗 |
| ＋ 股权激励 | 150 | |
| − 其他非现金调整 | −299 | |
| ＋ 应收账款减少 | 67 | |
| **− 存货增加** | **−818** | **囤了 8 亿的铜和在产矿石，压住现金** |
| ＋ 应付账款增加 | 12 | |
| **− 应交税金减少** | **−595** | **补交去年欠的税** |
| − 其他经营项目 | −119 | |
| ＋ 抓取数据未列示的其余项（倒算） | +763 | 数据源未展开的明细 |
| **= 经营现金流** | **5,900** | |
| **− 资本开支** | **−4,138** | **占经营现金流的 70%** |
| **= 自由现金流** | **1,762** | |

**这张表的结论很硬**：账上赚 29.45 亿，但**经营现金流里有 16.47 亿本来就属于印尼政府和秘鲁股东**，剩下的现金还要先拿出 41.38 亿去填矿坑。最后能自由支配的只有 **17.62 亿**——而分红要花掉 8.66 亿、回购 2.48 亿，**只剩 6.5 亿左右**。

再看一个更狠的数字：数据源列出的"**杠杆自由现金流 −4.81 亿**"（扣掉利息和债务本金后的自由现金流是**负的**）。FCX 净负债 **62.79 亿美元**，TTM 借新还旧 36.42 亿 / 还款 35.57 亿，基本靠滚动融资维持。**这不是一家能自我造血扩张的公司，它在借钱挖矿。**

## 第三部分：市盈率，多口径

市值 964.4 亿美元，企业价值 1,027.2 亿美元。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 964.4 ÷ 29.45 | **32.7 倍** | **3.05 元** |
| 公司自己吹的 Non-GAAP（估算） | 964.4 ÷ 约 32（剔除若干非现金调整） | **约 30.1 倍** | **约 3.32 元** |
| **剔除障眼法后的真实市盈率** | SBC 已按 GAAP 扣除不加回；无可辨识的真一次性项目 → **等于 GAAP** | **32.7 倍** | **3.05 元** |
| 自由现金流口径 | 964.4 ÷ 17.62 | **54.7 倍** | **1.83 元** |
| 企业价值口径 EV/EBIT（**表面值，具误导性**） | 1,027.2 ÷ 69.23 | *14.8 倍* | *6.75 元* |
| **EV/EBIT（扣掉少数股东后的归属口径）** | 1,027.2 ÷ 44.38（69.23 × 64.1%） | **23.1 倍** | **4.32 元** |
| **三年平均利润口径** | 964.4 ÷ 23.46（29.45、22.04、18.89 三年均值） | **41.1 倍** | **2.43 元** |

*注：EV/EBIT 两行是税前口径，不能直接和市盈率的税后回报比较；FCX 有效税率 31%，把它按税后折算，那个 4.32 元实际相当于约 3.0 元。*

### 三年平均口径的警报：**41.1 倍 vs 当期 32.7 倍**

**这是全表最重要的一行。** 三年平均比当期高了 **26%**，方向和 CME（差 9%）、Intuit（差 20% 但趋势向上）都不同——它说明 **FCX 现在的利润高于过去三年的常态水平**。三年净利润分别是 18.89 亿 → 22.04 亿 → 29.45 亿，一路往上，靠的是**铜价上涨**，而不是产量增长（营收几乎零增长，印尼还掉了 28%）。

翻译成人话：**你现在看到的这个利润，是铜价给的，不是公司给的。铜价回到三年前的水平，这个利润会掉三分之一以上。**

### 大白话版本

**你现在投 100 块进 FCX，按最保守的真实口径（三年平均 41.1 倍）算，公司一年替你赚 2.43 块；按当期最乐观的 GAAP 口径算，赚 3.05 块。**

这 3 块钱里，回到你口袋的有多少？

- **分红**：8.66 亿，占市值 **0.90%** → 每 100 块给你 **0.90 块**。
- **回购**：2.48 亿，占市值 0.26%，但其中大部分在抵消股权激励，股本只减少 0.09% → **真实增厚约 0.09 块**。
- **留在公司再投资**：**41.38 亿的资本开支，占市值 4.3%**。这是绝对的大头——你赚的钱几乎全部又回到地里去了。

**所以：每 100 块投资，一年只有约 1 块钱以现金形式回到你手上，剩下的全部埋进了新矿坑。** 而且这些矿坑要五年、十年后才知道回报如何。

### 这个数未来变大还是变小？

**变大的理由**（市场正在赌这个，所以前瞻市盈率只有 19.8 倍、PEG 0.62、股价一年涨 56%）：
- **印尼 Grasberg 恢复**。那 28% 掉下去的收入是全公司利润率最高的部分，一旦复产，利润弹性巨大——这是从 32.7 倍当期市盈率到 19.8 倍前瞻市盈率之间那 40% 差距的全部来源。
- **铜的长期需求故事是真的**：电动车用铜量是燃油车的 3–4 倍，电网改造、数据中心供电、光伏风电全都吃铜，而**全球十年没有开出像样的新大矿**（找矿要十年、审批要十年）。供给刚性 + 需求增长，这是过去二十年最扎实的商品多头逻辑。
- 那 41 亿资本开支里，有一部分是北美"浸出法回收"（从已有的废石堆里再提铜）和 Bagdad 扩产，成本低、回报快。

**变小的理由**：
- **它对铜价没有任何控制力。** 铜价跌 20%，FCX 的利润跌 50% 以上（因为成本是固定的）。这就是 Beta 1.38 的来源。
- **印尼风险是结构性的，不是一次性的。** 一半以上的股权已经归了印尼政府，采矿许可要定期续，出口配额、冶炼本地化要求年年谈。而且地下崩落法的地质风险，这次出事下次还可能出事。
- **资本开支下不来。** 矿是消耗品，41 亿里有很大一块是"不花就没产量"的维持性支出。

## 第四部分：一句话结论

**这是一家优质的铜矿公司，但它现在的股价既不便宜、也不是在赌它的经营能力——你买它，本质上是在用 32 倍市盈率买一张铜价看涨期权，而且这张期权还得跟印尼政府五五分账。**

展开说：FCX 拥有真实且稀缺的资产——Grasberg 是地球上最好的铜金矿之一，Cerro Verde 和 Morenci 都是世界级规模，这些东西**买不到、也造不出来**。铜的长期供需故事也是我认为最扎实的商品叙事之一。

但把这些好话放进估值里，账就难看了：

- **36% 的税后利润归少数股东**，那个诱人的 11.3 倍 EV/EBITDA 是分子分母口径不一致造成的错觉，真实归属口径是 23 倍。
- **自由现金流口径 54.7 倍**，因为 70% 的经营现金流被资本开支吃掉，而这些开支很大一部分只是为了不让产量下滑。
- **三年平均市盈率 41.1 倍高于当期 32.7 倍**，明确告诉你当前利润高于常态——这是周期股最危险的时点特征：**便宜的前瞻市盈率 + 昂贵的历史平均市盈率 + 已经涨了 56% 的股价**。
- **每 100 块投资一年只有 0.9 块现金分红回到你手上**，其余全埋进地里。

**值不值这个价：在铜价继续上涨、且 Grasberg 顺利复产的假设下值；这两个假设有任何一个不成立，就不值。** 而这两件事，一件取决于全球宏观，一件取决于四千米高山下的地质条件——**都不在公司管理层的控制范围内，也不在你的判断能力范围内。**

跟本批另外两家对比会更清楚：Intuit 是"用 21 倍买一家自己能决定命运、还在加速的公司"，CME 是"用 22 倍买一台永远不会坏但也永远不会快的收费机"，而 FCX 是"用 33 倍买一个你猜不准的价格变量"。**前两家是买公司，这一家是买商品，别把它们放在同一个尺子上量。**
