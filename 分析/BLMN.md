# BLMN · Bloomin' Brands（澳拜客牛排馆母公司）

市值 $9.1 亿 / 股价 $10.58 / 休闲连锁餐厅 / TTM 截止 2026-06-28

---

## 一、它到底做几件事

四个连锁餐厅品牌的母公司，实质是一门生意：**在美国开一千多家中档坐下来吃的餐厅**。

**主力：Outback Steakhouse（澳拜客牛排馆，约占收入一半）**

澳洲主题牛排连锁，美国约 670 家店。客单价 $25–30，招牌是炸洋葱花和 $20 出头的西冷牛排，开在郊区购物中心旁边，目标客户是想庆祝点什么但不想花 $100 的美国中产家庭。这个定位正是问题所在：**通胀几年下来，它的客户是被挤压最狠的人群**——比它便宜有 Chili's 和快餐，比它好有真正的牛排馆，中间地带的客流量连年往下掉。

**其他三个品牌**：Carrabba's（意大利菜）、Bonefish Grill（海鲜）、Fleming's（高端牛排，唯一活得不错的，但店少）。

另有小额加盟收入（TTM $7,000 万，占 1.8%）。2025 年把巴西业务的控股权**卖掉了**（回收约 $3.2 亿现金还债）——那曾是它增长最快的市场，卖它等于承认要收缩过冬。

| 分部 | TTM 营收 | 占比 |
|---|---|---|
| 自营餐厅销售 | $39.1 亿 | 98% |
| 加盟与其他 | $0.7 亿 | 2% |
| **合计** | **$39.8 亿**（同比 +1.2%，靠涨价撑平，客流在跌） | 100% |

餐厅行业的账本残酷：食材吃掉三成，人工吃掉三成，房租水电再一层——毛利率只有 13.6%（三年前还有 17.9%），经营利润率 3.3%。**6.4 万名员工，人均一年只替公司赚 $432**。

## 二、把会计障眼法剥掉

- **⚠️ 利润是税务局给的，全篇最大的坑**：TTM 经营利润 $1.32 亿，付完约 $1.34 亿利息后，**税前利润是 −$206 万，亏的**。账面净利润 $2,766 万全部来自 **$3,582 万的所得税返还**。也就是说：**这家公司 TTM 靠生意本身一分钱没赚到，筛选器上那个 31.5 倍 PE 的分母是税务红利**。
- **年年都有的"一次性"**：资产减值和重组费 TTM $7,760 万，前三年分别是 $7,300 万、$6,400 万、$3,400 万——**逐年放大、从不缺席**。关店、减值已经是这门生意的常规成本，不是意外。
- **股权激励**：$1,040 万，公司利润太薄反而显得不小，但绝对额可忽略。
- **回购与分红双双熄火**：FY2024 还回购 $2.67 亿、派息 $8,300 万；TTM 回购只剩 $118 万、分红砍到 $1,276 万（削了 85%）。钱全拿去还债了——净负债从 $22.2 亿降到 $18.6 亿。**股东回报已停摆。**
- **利润 vs 现金流**：净利润 $2,766 万 vs 经营现金流 $3.2 亿，差距全是非现金项：

| 项目 | 万美元 |
|---|---|
| 净利润 | 2,766 |
| + 折旧摊销（餐厅装修设备年年磨损，是真成本） | 20,600 |
| + 资产减值重组（关店认亏） | 7,760 |
| + SBC 及其他 | −1,500 |
| + 营运资金变动 | 2,350 |
| **= 经营现金流** | **31,980** |
| − 资本开支 | −16,480 |
| **= 自由现金流** | **15,500** |

FCF $1.55 亿看着是真钱，P/FCF 只有 5.9 倍——但两个脚注：① 资本开支 $1.65 亿已低于折旧 $2.06 亿，是在**少翻新老店省出来的现金**，餐厅不翻新客流只会掉得更快；② 这些现金的第一债权人是 $18.6 亿净负债（市值的两倍），不是你。

## 三、市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率（筛选器看到的） | 9.06 ÷ 0.277 | 32.3 | 3.1 元 |
| 公司自己吹的 Non-GAAP（远期） | 加回减值重组后的调整 EPS | 11.6 | 8.6 元 |
| **剔除障眼法后的真实市盈率** | 税前 −$206 万，真实利润 ≈ 0 | **∞（亏损）** | **0 元** |
| 自由现金流口径 | 9.06 ÷ 1.55 | 5.9 | 17.1 元* |
| 企业价值口径 EV/EBIT | 27.6 ÷ 1.32 | 20.9 | 4.8 元 |
| 三年平均利润口径 | 9.06 ÷ 0.43（含已卖掉的巴西的利润） | 21.3 | 4.7 元 |

*FCF 口径的 17.1 元是幻觉：它建立在压缩翻新开支 + 债主排你前面的基础上。

说人话：**你投 100 块进去，这门生意本身现在一年替你赚 0 块**（税前亏损）。公司自己吹的 11.6 倍远期市盈率，靠的是把年年发生的关店减值当成"一次性"剔掉。它的 EV $27.6 亿里，你的股票只占 $9.1 亿，剩下 $18.6 亿是债——**经营利润连利息都刚勉强覆盖（覆盖倍数 2.8，扣掉减值后不到 1）**。生意稍有恶化，先归零的是股东这一层。股价一年反弹 46% 是空头回补加转型故事，不是利润回来了。

## 四、一句话结论

一门正在萎缩的生意（客流连年下滑、巴西卖了、分红砍了 85%）背着两倍于市值的债，税前已经不赚钱，账面利润靠税务返还、远期故事靠把年年关店的钱叫"一次性"。表面 32 倍、真实无穷倍——**这不是便宜股，是杠杆上的翻盘赌票**，赌输了股东排在 $18.6 亿债务后面。不碰。
