# ADTTF · 爱德万测试（Advantest）

市值 23.96 万亿日元（约 1,560 亿美元）｜东京股价 33,090 日元（场外 ADTTF/ATEYY 按此折算）｜半导体测试设备｜TTM 截止 2026-06-30（财年 4 月–3 月）

> 任务4 海外公司。**全文数字统一用日元**，倍数全部用东京市场的日元市值直接算，不经过汇率；标题美元市值按约 1 美元 = 153 日元。日本公司不报美式 Non-GAAP，账是 IFRS。

## 第一部分：它到底做几件事

一颗芯片造出来之后，出厂前必须一颗一颗通电测一遍：几十亿个晶体管有没有坏的、跑到标称频率会不会发热、内存每个单元能不能正确读写。做这件事的机器叫「自动测试设备（ATE）」，全世界只有两家能做高端的：日本的爱德万和美国的泰瑞达（Teradyne），两家合计超过 90% 的市场。爱德万现在是老大，份额约 55%–60%。

财报只分两块：「测试系统」和「服务及其他」，实质就是「卖测试机」和「测试机的售后」。

### 生意 A：卖测试机（占营收 90%）

**它到底是谁在买、测什么：**

- **SoC 测试机（主力机型 V93000 EXA Scale）**：测逻辑芯片——英伟达的 GPU、苹果和高通的手机处理器、AMD 的 CPU、博通的网络芯片。芯片不是英伟达自己测的，是台积电下游的封测厂（日月光、Amkor）和台积电自己的先进封装厂买机器来测。**一台 V93000 配齐插卡大约 300 万–800 万美元。** 一颗 Blackwell GPU 的测试时间是上一代 H100 的两三倍——晶体管更多、带 HBM、还要测芯粒之间的互联，所以同样的出货量需要多一倍的测试机。这就是它过去两年营收翻倍的全部原因。
- **内存测试机（T5800 系列等）**：测 DRAM、NAND、特别是 HBM（高带宽内存）。HBM 是把 8 层、12 层 DRAM 叠起来焊在一起，任何一层坏了整颗报废，所以每一层都要测、叠完还要再测——**HBM 的测试强度是普通 DRAM 的三到五倍**。三星、SK 海力士、美光的 HBM 产线都在买它的机器。内存测试机它的份额约 50%。
- **配套的分选机、探针卡接口**：把芯片送进测试机的机械手，以及测试机和芯片之间的接触件。

**客户为什么非买不可：** 测试程序是围绕某一台机型写的，一颗芯片从设计验证到量产用的是同一套机器，换供应商等于重写几百万行测试代码、重新认证。而且英伟达、苹果这种大客户会指定封测厂用哪台机器测自己的芯片。一旦设计阶段选了 V93000，量产阶段封测厂就只能买 V93000。

**它的软肋：** 跟 TEL 一样是周期股，只是更极端。2024 财年（截止 2024 年 3 月）营收跌 13%、净利润腰斩到 623 亿；两年后净利润 4,600 亿，**翻了七倍**。它的生意随着 AI 芯片的出货量一起涨，也会一起跌。

|---|---|

| 同比（FY2026 vs FY2025） | 1.019 万亿 vs 6,828 亿，**+49%** |

### 生意 B：服务及其他（占营收 10%）

装出去的机器的保养合同、备件、软件升级、翻新旧机、租赁，还有 2020 年收购的 Essai（测试插座）和一块测试数据云服务。这块跟着装机量走，增速 13%，比新机稳。

| 生意 B：服务及其他 | TTM（截止 2026-06） |
|---|---|
| 营收 | 1,199 亿日元 |
| 同比（FY2026 vs FY2025） | 1,092 亿 vs 969 亿，**+13%** |
| 占总营收 | 10% |
| 经营利润率 | **估算**约 40% |

整体：TTM 营收 1.232 万亿日元（+36%），**毛利率 65.7%**，经营利润 5,627 亿（45.7%），净利润 4,600 亿（37.3%）。这是一家设备公司做出了软件公司的利润率。

## 第二部分：把会计障眼法剥掉

- **股权激励（SBC）**：TTM 44.5 亿日元，占净利润 1%。日本公司的常态，忽略不计。
- **一次性项目**：**有一块要注意。** 税前利润 6,295 亿，经营利润 5,627 亿，**中间差了 668 亿的营业外收入**，税前利润率 51% 比经营利润率高 5 个百分点。它的客户几乎全在海外、以美元结算，手里的美元资产在日元贬值时会记出汇兑收益，另外还有金融收益。单看 TTM 一期无法判断这 668 亿明年是正是负——汇率反过来就变成损失。**真实利润要剔掉它**：按 26.9% 税率，税后约 488 亿。
- **资本化的支出**：无形资产购置 36 亿日元，可忽略。研发全部费用化。
- **回购与稀释**：TTM 回购 1,411 亿 ÷ SBC 44.5 亿 = **32 倍**，回购是真回购；股本一年缩了 1.09%。另派息 428 亿（派息率只有 9%，它宁可回购）。分红 + 回购合计 1,839 亿，占净利润 40%。有一点别扭：TTM 它一边握着 4,131 亿现金，一边新发了 1,000 亿债券、又买了 917 亿的有价证券——不是大问题，但没必要。
- **利润和现金流的差**：净利润 4,600 亿 → 经营现金流 4,255 亿 → 自由现金流 3,883 亿。**现金转化率 84%，对一家营收一年涨 36% 的公司来说非常好**（营收暴涨时应收和存货通常会吞掉大量现金）。逐项对账：

| 项目 | TTM（亿日元） | 说明 |
|---|---|---|
| 净利润 | 4,600 | |
| + 折旧摊销 | +266 | 轻资产，折旧很少 |
| + 股权激励 | +45 | |
| − 其他经营调整 | −293 | 主要是汇兑收益是非现金、税款时点 |
| − 应收账款增加 | −421 | 营收涨 36%，应收只涨这么点，回款很快 |
| − 存货增加 | −612 | 为下一季出货备货 |
| + 应付账款增加 | +402 | |
| + 其他营运资金 | +267 | 客户预付款 |
| **= 经营现金流** | **4,255** | |
| − 资本开支 | −372 | 只占营收 3%，测试机是组装业务，不需要大厂房 |
| **= 自由现金流** | **3,883** | |

账很干净。这家公司的问题不在报表里，在价格里。

## 第三部分：市盈率，多口径

市值 23.96 万亿日元。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 23.96 万亿 ÷ 4,600 亿 | **52.1 倍** | 1.92 元 |
| 公司自己吹的 Non-GAAP | 日本公司不报，无 | — | — |
| **剔除障眼法后的真实市盈率** | 23.96 万亿 ÷（4,600 − 488 亿营业外收入）= ÷ 4,112 亿 | **58.3 倍** | **1.72 元** |
| 自由现金流口径 | 23.96 万亿 ÷ 3,883 亿 | 61.7 倍 | 1.62 元 |
| 企业价值口径 EV/EBIT | （23.96 万亿 − 3,050 亿净现金）÷ 5,627 亿 | 42.0 倍 | 2.38 元 |
| 三年平均利润口径 | 23.96 万亿 ÷ FY2024–2026 平均净利润 1,996 亿 | **120 倍** | **0.83 元** |

**大白话：你现在投 100 块进去，按剔掉汇兑收益的真实口径，公司一年替你赚 1.7 块。** 这 1.7 块里约 0.7 块以回购和分红回到你口袋，剩下 1 块留在公司——但它根本花不掉（资本开支只要 372 亿），所以钱在往账上堆、往有价证券里堆。

**三年平均那一行：120 倍。** 这是全篇最重要的一个数。三个财年的净利润是 623 亿、1,612 亿、3,754 亿——这不是一家利润平稳的公司，这是一家利润随 AI 芯片出货量翻了六倍的公司。市场按 52 倍给今年的利润定价，等于赌两件事同时成立：**AI 芯片的测试需求永远不回落，并且还要继续高增长**。股价 52 周涨了 209%，利润涨了 104%，估值翻了一倍。

这个 1.7 块会变大还是变小？短期看还会变大——Blackwell 之后是 Rubin，HBM4 的测试强度比 HBM3 更高，2027 财年的预期市盈率 36 倍就是这个意思。但测试设备行业的规律是：**芯片厂扩产完了，测试机就够用了，下一年订单直接砍一半**。2024 财年它就是这样掉下来的。

## 第四部分：一句话结论

**生意好到近乎完美，价格贵到没法碰。** 66% 毛利、46% 经营利润率、ROIC 68%、跟泰瑞达双寡头、AI 芯片和 HBM 越复杂它越赚钱——这些全是真的。但 52 倍名义、58 倍真实、**120 倍三年平均**，是把周期顶点的利润当成永远的底线在定价。一年前它 29 倍、两年前 17 倍，那时候它也是全球第一的测试机公司。等 AI 资本开支哪怕只是增速放缓、封测厂说一句「今年测试机够用了」，它会先跌一半再谈估值。现在不值。
