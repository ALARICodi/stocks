# VALU · 价值线公司（Value Line, Inc.）

市值 3.437 亿美元 | 当前股价 $36.63 | 行业：消费服务 / 投资研究出版 | TTM 截止 2026 年 4 月 30 日（该公司财年 4 月底结束，所以这份 TTM 恰好等于刚结束的 FY2026 完整财年）

---

## 第一部分：它到底做几件事

Value Line 财报上分成三块营收（Print、Digital、Copyright Fees），但**这三块加起来一年只赚 403 万美元的经营利润，而公司一年的净利润是 2163 万**。也就是说，看财报上写着「营收」的那三门生意，只贡献了这家公司利润的一小角。真正撑起利润的第四件事，压根没出现在营收里。所以这家公司实质上做四件事，我一件一件讲。

### 生意一：印刷版《价值线投资调查》(Print) — TTM 营收 845 万美元

这是 1931 年就在卖的东西，九十五年了，形式基本没变：一本按周寄到你信箱的纸质活页册子。

具体是这样运作的：Value Line 有一个 106 人的公司（对，整个上市公司只有 106 名员工），其中一批分析师负责盯住大约 1700 家美股。每家公司做成**一整页**，这一页上密密麻麻印着这家公司过去 15 年的每股营收、每股利润、每股账面价值、股息、利润率、ROE，还有未来 3–5 年的预测值，再加上一段几百字的文字点评。最出名的是右上角那两个数字：**Timeliness（及时性）排名 1–5** 和 **Safety（安全性）排名 1–5**。1 代表未来 12 个月最可能跑赢大盘，5 代表最可能跑输。

订户是谁？典型画像是：一位 60 多岁、自己管着几十万到几百万美元退休金的美国散户，不用 Bloomberg 终端、也不信 YouTube 上的荐股，但愿意每年花几百美元买一本「有人替我把 1700 家公司都算过一遍」的册子。还有相当一部分订户是**公共图书馆**——美国很多县立图书馆的参考书架上就摆着 Value Line 的活页夹，这是机构订阅，一订几十年不换。

怎么收钱：个人订户全套年费大约 700–800 美元，图书馆和机构版更贵。按 845 万美元营收倒推，付费的印刷版订户大概在**一万多户**这个量级。

为什么在萎缩：老订户在自然减少（字面意义上的——他们在老去），而新的年轻散户不会为一本按周寄来的纸册子付 700 美元。Print 这条线五年从 1125 万掉到 845 万，跌掉了四分之一。

### 生意二：数字版订阅 (Digital) — TTM 营收 1541 万美元

同样的内容，搬到网站和 App 上，加了筛选器、可下载的 Excel、组合跟踪工具。价格通常比纸质版便宜一些，也允许只买某一个板块（比如只订「小盘股专版」或「ETF 专版」）。

这条线是三块里最大的一块，占营收 46%。它承担了一个很关键的角色：**接住从纸质版流失下来的老订户**。一个订了二十年纸质版的老先生，某天觉得册子太厚了、想在 iPad 上看，就转成数字版——公司没丢掉他，只是每年从他身上少收一两百美元。

问题是，Digital 自己也在萎缩：15.89 → 16.27 → 16.13 → 15.90 → 15.41，五年几乎原地踏步后开始下滑。这说明**数字版接住的流失，还赶不上数字版自己的流失**。原因不难理解：一个 2026 年的散户想要「1700 家公司的标准化财务页」，Yahoo Finance、stockanalysis.com、券商 App 全都免费给，而且更新更快。Value Line 唯一还卖得动的，是那个用了六十年、有学术论文背书的 Timeliness 排名——这是品牌，不是数据。

### 生意三：版权授权费 (Copyright Fees) — TTM 营收 959 万美元

**这是三条线里利润率最高、也最像「印钞机」的一条。** 它是这么回事：

别人要用 Value Line 的名字和指数去做金融产品，得付 Value Line 授权费。最典型的例子是**芝加哥期权交易所（CBOE）**——CBOE 有一个交易了几十年的期货合约叫「Value Line 综合指数期货」，用的是 Value Line 编制的等权重指数。每一手合约成交，CBOE 都要按约定给 Value Line 分钱。

还有一类是 ETF 和结构化产品：某家资产管理公司想发一只「按 Value Line Timeliness 排名选股」的 ETF，就要付授权费——通常是按该产品管理规模的一个固定基点数（比如每年 AUM 的 0.05%）收。

这条线的美妙之处在于**几乎零边际成本**：分析师反正要给 1700 家公司排名（Print 和 Digital 都要用），排完了再授权给第三方，不多花一分钱。959 万营收里绝大部分直接变成利润。

但它也在跌：1338 → 1346 → 1207 → 1040 → 959，五年跌了 28%。原因是 Value Line 综合指数期货的成交量在长期萎缩（这个老合约被标普和罗素的指数产品挤掉了），而挂钩 Value Line 排名的 ETF 规模也不大。

### 生意四（财报上找不到、却贡献了六成半利润）：EAM 信托的利润权益 — TTM 权益法收益 1897 万美元

这一件事要从 2009 年说起。那年 SEC 查出 Value Line 在近二十年里通过一家关联的经纪商，向自家共同基金的持有人收取了 2400 多万美元的虚假交易佣金——本质上是拿基民的钱补贴自己。案子和解后，**SEC 事实上把 Value Line 赶出了资产管理业务**。

于是 2010 年做了一次结构手术：Value Line 把管理那批「Value Line 品牌共同基金」的业务整个装进一个独立的信托——**EULAV Asset Management Trust（简称 EAM）**，交给管理层去经营。Value Line 这家上市公司**不再参与经营、不再有投票权**，但保留了一份合同权利：按 EAM 每期的管理费收入提取一个固定比例，外加 EAM 调整后利润的一份分成，同时持有 EAM 20% 的非投票权益。

翻译成大白话：**Value Line 现在是 EAM 的「收租的房东」。** 它不管基金怎么运作、不管谁当基金经理、不管买什么股票，只在每个季度末伸手，从 EAM 管理费收入里拿走约定的那一份。

这份"租金"有多大？TTM 是 **1897 万美元**，而三条正经业务线加起来的经营利润只有 403 万。也就是说：

> **Value Line 这家公司，五分之四的利润来自一份它自己不经营、不控制、只负责收钱的合同。**

而且这笔租金还在涨：1113 万（FY22）→ 1328 万（FY24）→ 1832 万（FY25）→ 1897 万（TTM）。为什么涨？因为 EAM 管理费收入 = 基金规模 × 费率，而过去几年美股一直在涨，基金规模跟着水涨船高。**这意味着 VALU 的核心利润，本质上是一个杠杆化的美股 beta 敞口**——股市涨，它涨；股市跌 30%，这 1897 万也会跟着缩水 30%，而它占了公司利润的 65%。

### 第五项资产：8647 万美元的现金和证券组合

顺带一提，公司账上还有 **8647 万美元的现金和有价证券**，总债务只有 227 万，净现金 8419 万——**占市值的 24.5%**。这笔钱每年产生大约 640 万美元的利息、股息和已实现收益（税前利润里除去主业 403 万和 EAM 1897 万，剩下的部分）。

## 第二部分：把会计障眼法剥掉

- **股权激励（SBC）：没有。** 这一点值得单独说——现金流量表里**根本没有「股权激励」这一行**，五年都没有。106 个员工，一家 92% 股份被创始人家族控股的公司，不给员工发股票。对小股东来说这是纯粹的好消息：你的股份没有被稀释走。股本一年只变动 -0.19%（也就是说几乎完全没动）。

- **一次性项目：有一项，1500 万级别的"投资出售收益"每年都在。** 现金流量表里 "Loss (Gain) From Sale of Investments" 这一行 TTM 是 **-369 万**（负数=从利润里减掉的收益，说明利润表里有 369 万的证券已实现收益）。往回看五年：-369、-56、-29、+13、+140 万，**方向和金额都在乱跳**。这是公司卖掉自己组合里的股票债券实现的收益，不是经营成果。单看 TTM 一期分不清它是「真一次性」还是「年年都有的一次性」，但可以确定它**不可预测**，做估值时应该剔掉。

- **资本化的支出：几乎没有。** 五年的资本开支合计不到 25 万美元，TTM 是零。这家公司的"资产"是 106 个人的脑子和一个 95 年的品牌，不需要买设备。

- **回购与稀释：回购 93 万，SBC 为零，比值无穷大——但金额太小，不构成回馈。** 93 万美元的回购只占市值的 0.27%。真正回到股东口袋的是分红：TTM 派了 **1223 万美元**（每股约 $1.30，股息率 3.56%），是回购的 13 倍。

- **利润和现金流的差：净利润 2163 万，经营现金流 1858 万，差 305 万。** 差额不大，但成因值得看清楚，因为它揭示了 EAM 那笔钱到底是不是真现金：

| 项目 | 金额（万美元） | 说明 |
|---|---|---|
| 净利润 | 2163 | |
| + 折旧摊销 | 129 | 非现金 |
| **− EAM 权益法收益** | **−1897** | 会计上确认的利润，本身不是现金 |
| **+ 从 EAM 实际收到的现金分配** | **+1941** | （现金流量表 "Other Operating Activities"） |
| − 已实现证券出售收益 | −369 | 现金计在投资活动里，不算经营 |
| ± 营运资金变化（应收、预收、税） | −109 | 主要是预收订阅费减少 125 万 |
| **= 经营现金流** | **1858** | |

**关键在中间那两行**：会计上确认了 1897 万的 EAM 收益，同期实际从 EAM 收到的现金是 1941 万——**比确认的还多**。所以这笔"租金"是**实打实的现金进账，不是纸面数字**。这一点很重要：很多靠权益法收益撑利润的公司，钱是永远拿不出来的，VALU 不是。

顺带看一眼：预收订阅费（Unearned Revenue）一年减少了 125 万。这是订阅生意的领先指标——**预收在减少，说明新签和续订的合同金额在缩水**，验证了三条线都在萎缩。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 3.437 亿 ÷ 2163 万 | **15.9 倍** | **$6.29** |
| 公司自己吹的 Non-GAAP | 公司不发布调整后利润 | 同 GAAP，15.9 倍 | $6.29 |
| **剔除障眼法后的真实市盈率** | 3.437 亿 ÷（2163 万 − 369 万证券出售收益 × 73.5% 税后）= ÷ 1892 万 | **18.2 倍** | **$5.50** |
| 自由现金流口径 | 3.437 亿 ÷ 1858 万 | **18.5 倍** | **$5.41** |
| **企业价值口径（扣掉 8419 万净现金后）** | 2.595 亿 ÷ 1892 万 | **13.7 倍** | **$7.29** |
| 企业价值 ÷ 出版主业经营利润 | 2.595 亿 ÷ 403 万 | **64.4 倍** | $1.55 |
| 三年平均利润口径 | 3.437 亿 ÷（2163+2069+1902）÷3 = ÷ 2045 万 | **16.8 倍** | **$5.95** |

**三年平均那一行说明当前利润不在高点**——16.8 倍对 15.9 倍，差距很小，说明这家公司的利润这几年是稳步爬升的（1902 → 2069 → 2163 万），没有周期性虚高。这和第一部分的发现并不矛盾：**主业在跌，但 EAM 的租金涨得更快，把总利润托住了。**

**那个 64.4 倍是全表最刺眼的数字。** 它的意思是：如果你把公司账上 8419 万净现金和 EAM 那份合同的价值全都当成零，光为那三条出版业务付钱，你付的是 64 倍。反过来说，市场其实**完全没在为出版业务定价**——它给的 3.44 亿市值，基本就等于「8419 万现金 + EAM 租金流的现值」，出版业务算白送的。这是个合理的定价方式，因为出版主业确实在系统性地死掉。

### 你投 100 块，一年能拿回多少？

按最保守的真实口径（剔掉不可预测的证券出售收益），**公司一年替你赚 $5.50**。

这 $5.50 的去向，可以精确算出来：

- **$3.56 以现金分红发到你手上**（TTM 派息 1223 万 ÷ 市值 3.437 亿 = 3.56%）
- **$0.27 通过回购变成你手里股票的价值**（回购 93 万 ÷ 市值）
- **剩下 $1.67 留在公司里** —— 去向很明确：TTM 净买入了 **1533 万美元的证券**。也就是说，留下的钱既没有投进主业（资本开支为零），也没有去收购，而是**买了更多股票和债券放着**。

所以你实际到手的现金回报是 **3.83%**，剩下的部分在公司账上变成了一个越来越大的证券组合（现金和投资五年从 5783 万涨到 8647 万）。

**这个 $5.50 未来会变大还是变小？** 要拆成两半看，而且两半的方向是相反的：

- **出版主业（占利润 14%）：确定性地变小。** 三条线全部下跌，五年营收从 4053 万跌到 3345 万（-17.5%），经营利润从 1147 万跌到 403 万（**-65%**）。注意后者跌得远比前者快——因为出版是重固定成本生意（分析师工资、编辑部），营收跌一块钱，利润跌得更多。按当前斜率，**出版主业的经营利润在三到四年内会归零甚至转负**。
- **EAM 租金（占利润 65%）：完全取决于美股。** 它涨是因为基金规模涨，基金规模涨是因为股市涨。如果美股在未来五年横盘或下跌，这 1897 万会缩水，而且没有任何缓冲。

结论：**这 $5.50 的稳定性，取决于你对美股未来五年的看法，而不是取决于 Value Line 这家公司做了什么。**

## 第四部分：一句话结论

**账面上 15.9 倍看着便宜，扣掉那 24.5% 的净现金后是 13.7 倍，确实不贵——但这不是一家出版公司，而是一个「正在死掉的出版业务 + 一份收美股 beta 租金的合同 + 8400 万证券组合」的三合一包裹，而且这个包裹几乎买不到也卖不掉。**

三件事决定了它值不值：

1. **你买的其实是 EAM 那份合同。** 主业利润三四年内会归零，届时 100% 的利润都来自 EAM 和证券组合。愿意的话，你可以把 VALU 理解成一只「收管理费提成的类 ETF」，13.7 倍 EV 市盈率、3.56% 股息、24.5% 现金垫，这个价格并不离谱。
2. **但你对这份合同没有任何控制权。** 公司不经营 EAM，不能换基金经理，不能提高费率。合同条款怎么修改、EAM 业绩烂了怎么办，小股东说了不算——伯纳德家族持有 **92.04%** 的股份，剩下 7.96% 才是外面的人。
3. **最要命的是流动性。** 自由流通股只有 **746,840 股**，日均成交量 **4,094 股**——按 $36.63 算，这只股票**一天成交额只有 15 万美元**。这意味着：如果你投 10 万美元进去，你就占了全天成交额的三分之二，买的过程会自己把价格推上去；想卖的时候如果市场情绪不好，你可能要花几周才能出清。对绝大多数人来说，**这不是一只可以正常买卖的股票**。

价格上它算公道，生意本身有硬伤：主业在结构性萎缩，利润押在一份自己不控制的合同上，加上事实上无法交易的流动性。数字上的便宜是真的，但便宜有它的理由。
