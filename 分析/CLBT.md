# CLBT · 赛乐布莱特（Cellebrite DI Ltd.，手机取证）

市值 28.19 亿美元 · 现价 $11.24 · 行业：技术服务（数字取证软件）· TTM 截止 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

一句话概括：**警察抓到一个嫌疑人，从他兜里搜出一部锁着的 iPhone。把这部手机里的东西挖出来、整理成能上法庭的证据，用的就是 Cellebrite 的东西。**

这家公司是以色列人办的，客户是全球一百多个国家的**警察局、检察院、缉毒署、海关、军队情报部门**，还有一小部分是做内部调查的大企业。财报按"收入类型"分四块，但产品其实是一条链，我按链条讲。

### 第一环：把数据从手机里挖出来（Inseyets，原名 UFED）

**这件事到底是什么。** 一部现代 iPhone 是加密的。你不知道密码，苹果也不会帮你开——2016 年圣贝纳迪诺枪击案，FBI 要求苹果解锁凶手的 iPhone，苹果公开拒绝，最后 FBI 花钱找了第三方公司搞定。**Cellebrite 就是干这个的。**

具体长什么样：警察局的取证室里有一台看着像加固平板的设备（UFED Touch），或者一台装了 Cellebrite 软件的笔记本。取证员把嫌疑人的手机用线连上去，软件会：

1. **识别机型和系统版本**，从自己的漏洞库里挑一个能用的方法绕过锁屏；
2. **做完整物理提取**——不只是你在手机上能看到的东西，还包括**已删除的照片和短信**（删除只是标记为可覆盖，数据往往还在）、每个 App 的数据库、Wi-Fi 连接记录、GPS 轨迹点、健康 App 里的步数（能证明当天他在跑而不是在睡觉）；
3. **生成一份带哈希校验的取证报告**，证明这份数据从提取那一刻起没被改动过。

**最后这一条是全部生意的命门。** 法庭上，辩护律师第一个攻击的就是"你怎么证明这份聊天记录不是警察自己敲上去的"。Cellebrite 的报告格式在全球法院打过成千上万次官司，是被接受的。一个警察自己写的 Python 脚本，哪怕技术上能提取出同样的数据，**在法庭上一句话就被打掉了**。

**怎么收钱**：按"取证员席位"卖年度订阅。一个席位大致在**每年一万到一万五千美元**（按等级、按支持的机型范围分档）。一个中等规模的美国市级警局有 4–6 个取证员，一年就是 5 万–9 万美元。全球客户约七千家机构。

### 第二环：把挖出来的数据变成线索（分析软件）

一个贩毒案可能扣了 20 部手机，每部提取出 50 万条记录。人是看不完的。

Cellebrite 的分析软件把这 20 部手机的数据倒进一个池子里，自动找：**哪两个号码在案发前一小时通过话、哪三部手机在同一时间出现在同一个基站附近、谁的通讯录里有同一个陌生号码、哪些照片的 EXIF 定位落在同一个仓库**。原来要三个警察查两周的活，现在半天出图。

这是加价卖的模块，按用户或按案件量收订阅费。

### 第三环：把证据发给检察官（Guardian 云平台）

以前的做法是：取证员把 200GB 的提取结果拷到移动硬盘，开车送到检察官办公室。**Guardian 把这一步搬到云上**——检察官、辩护律师、法官各自拿一个权限受控的账号登录查看，谁在什么时间看了哪一条，全都有审计日志。按用户数收 SaaS 费用，单价比取证席位低得多，但**用户数多得多**（一个案子的取证员只有 1 个，但相关的检察官、警探可能有 20 个）。这是公司现在增长最快的一块。

### 第四环：Corellium（2025 年花约 1.7 亿美元买的）

Corellium 做的是**云端的虚拟 iPhone**——在浏览器里跑一台"假 iPhone"，可以随便改、随便崩溃、随便装恶意软件来观察。安全研究员和 App 厂商用它测漏洞。

Cellebrite 买它有两层意思：一是卖给企业安全部门，开一个新市场；二是**自己用**——要找 iOS 的新漏洞，得先有大量可反复折腾的测试机，虚拟化比买几百台真机快得多、便宜得多。TTM 现金流量表里那笔 **1.627 亿美元的收购支出**就是它。

### 第五环：培训和认证

Cellebrite 卖证书（CCO、CCPA 等）。一个取证员要拿到这些证书得上课考试，几千美元一个人。这一块钱不多，但它是**护城河的水泥**：一个警局的 5 个取证员全都考了 Cellebrite 的证，换供应商就意味着 5 个人全部重新培训、重新考试，同时手上几百个在办案件的证据格式全部要迁移。**没有哪个警察局长愿意为了省 20% 的软件费去承担一个案子被翻掉的风险。**

**这张表最重要的三个读数：**

1. **订阅 + 定期授权 = 90.5% 的营收**，都是合同化的重复性收入。这是一门"每年自动续费"的生意，不是一锤子买卖。
2. **订阅这一块 +22.2%，是全公司的引擎**，而且它在加速取代一次性授权模式。
3. **整体毛利率 82.96%，但经营利润率只有 10.86%。** 中间那 72 个百分点全花在研发和销售上——这不是效率问题，是**漏洞军备竞赛的成本**（下一节细说）。

### 这门生意最特别的地方：它必须永远跑

苹果每年出一个新 iOS，每次都堵掉一批漏洞；Google 也一样。**Cellebrite 每一个季度都得找出新的绕过方法，否则产品当场作废。** 这是一场永不停止的追赶。

这件事**同时是它最大的风险和最深的护城河**：
- 风险面：如果哪天苹果的安全做到了真正无解，这家公司的核心产品价值归零。
- 护城河面：要养一支能持续攻破 iOS 的团队，一年要烧掉上亿美元的研发，全世界能拿出这个钱、又能拿到执法机构订单的公司，一只手数得过来（主要就是它和被 Thoma Bravo 收走的 Magnet Forensics/Grayshift，以及瑞典的 MSAB）。**这个赛道的进入门槛不是技术，是"持续烧钱的技术 + 各国政府愿意跟你签合同"。**

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）—— 这是本篇最大的问题**：TTM **5,694 万美元**。

- 占净利润 5,825 万的 **97.8%**。也就是说，**公司一年赚的钱，几乎全额等于它发给员工的股票。**
- 占营收 **11.1%**。
- 按 GAAP 这笔钱已经从利润里扣了（所以 GAAP 净利润 5,825 万是可信的）。公司自己吹的 Non-GAAP 会把它**加回来**，那是骗人的——**员工手里的股票是从你的持股比例里切出来的，跟发现金没有区别。全文一律当成本扣掉。**

**回购与稀释 —— 比 SBC 本身更糟**：

| 指标 | 数值 |
|---|---|
| TTM 回购股票 | **0 美元** |
| TTM SBC | 5,694 万美元 |
| **回购 / SBC** | **0 倍** |
| 股本一年变化 | **+9.33%** |
| FY2025 股本变化 | **+19.30%** |
| FY2024 股本变化 | +10.16% |

**看清楚这几个数字。** 公司一分钱回购都没有，而股数一年多了 9.33%（约 2,140 万股），前一年更是多了 19.30%。三年下来股数增加了四成以上。

这些新股从哪来？现金流量表里"发行普通股"只有 1,473 万美元（员工持股计划和期权行权的收款），远解释不了 2,140 万股。剩下的主要来自 **SBC 兑现的限制性股票、以及很可能有一部分是收购 Corellium 时用股份支付的对价**（现金支出 1.627 亿，交易总价高于这个数）。

**给你的实际影响，这一条是全篇最该记住的**：假设这门生意的利润每年真能涨 18%，**你手上那一股能分到的利润只涨约 8%**——另外 10 个百分点被新发的股票稀释掉了。**你是在跟公司员工和被收购方的股东一起分这块蛋糕，而且他们不用出钱。**

**一次性项目**：TTM 有 176 万的减值/重组、203 万的投资处置收益，都可以忽略不计。

**但历史上的一次性项目大得离谱，必须解释一下**，否则你看历史数据会被吓到：

| | FY2022 | FY2023 | FY2024 | FY2025 | TTM |
|---|---|---|---|---|---|
| 营收 | 270.7 | 325.1 | 401.2 | 475.7 | 514.3 |
| 经营利润 | 1.0 | 33.2 | 56.9 | 66.5 | 55.9 |
| **净利润** | **+116.1** | **−81.1** | **−283.0** | **+77.8** | **+58.3** |
| 现金流表"其他经营项" | −119.9 | +116.7 | **+334.9** | −7.5 | −5.4 |

营收一路平稳上涨，经营利润也一路上涨，净利润却能从 +1.16 亿翻到 −2.83 亿。**原因是认股权证（warrant）的公允价值重估。** Cellebrite 2021 年是通过 SPAC（借壳）上市的，SPAC 交易会留下一堆认股权证，会计规则要求每个季度按市价重新估值，股价涨了就记一笔巨额"亏损"，股价跌了就记一笔"利润"。**跟经营完全无关，也跟现金完全无关。**

对照上表最后一行就一目了然：FY2024 那 2.83 亿的亏损，现金流量表里原封不动加回了 3.349 亿。

**好消息是这个噪音已经基本出清**：TTM 的"其他经营项"只剩 −540 万。**现在的 GAAP 净利润终于可以直接看了。**

**资本化的支出**：TTM 购买无形资产 1,562 万（收购带来的），资本开支只有 1,339 万（占营收 2.6%）。**这是一门几乎不需要资本的生意**——它的资产是人和漏洞库，不是厂房。折旧摊销从 FY2025 的 1,187 万跳到 TTM 的 2,256 万，多出来的一千万主要是 Corellium 的无形资产摊销。

**利润和现金流的差 —— 逐项对账**（单位：百万美元）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 58.3 | 起点 |
| ＋折旧摊销 | +22.6 | 含 Corellium 无形资产摊销约 1,000 万 |
| ＋股权激励 SBC | **+56.9** | ← 最大一项。非现金，但它稀释你 |
| ＋减值重组 | +1.8 | |
| −投资处置收益 | −2.0 | |
| −其他经营项 | −5.4 | 认股权证残余，已很小 |
| ＋**预收账款增加** | **+33.6** | ← 客户提前付了明年的订阅费 |
| ＋应付账款增加 | +7.4 | |
| −应收账款增加 | −12.2 | |
| ＋存货减少 | +1.5 | |
| −其他经营资产 | −5.3 | |
| **＝经营现金流** | **157.6** | |
| −资本开支 | −13.4 | |
| **＝自由现金流** | **144.2** | |

**这张表要读出两件事：**

1. **自由现金流 1.442 亿是净利润 5,825 万的 2.5 倍**——差额的 5,694 万是 SBC，3,359 万是预收账款增长。**账是真的，现金是真收到的。** 这一点比很多同规模的软件公司干净。
2. **但 1.442 亿这个数字有水分，两处：**
   - **SBC 那 5,694 万不是免费的**，它换成了 2,000 多万股新股。把它扣回去，**真实自由现金流 = 1.442 − 0.569 = 8,723 万美元**。
   - **预收账款那 3,359 万是增长带来的**——客户在为明年预付。营收一旦停止增长，这一项立刻归零，自由现金流再少 3,300 万。

**另外一个容易被忽略的事实**：税前利润 7,538 万，经营利润只有 5,586 万，**中间多出来的 1,952 万是利息收入**——公司账上躺着 5.46 亿现金和投资，按 3.75% 左右吃利息。**也就是说公司税前利润里有 26% 不是靠卖软件赚的，是靠存款赚的。** 这不是坏事（净现金 5.22 亿，占市值 18.5%，是实打实的安全垫），但估值时要知道这一层。

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 28.19 亿 ÷ 净利润 0.5825 亿 | **48.4 倍** | **2.07 元** |
| 公司自己吹的 Non-GAAP（估算） | 加回 SBC 0.569 亿 + 收购无形摊销约 0.107 亿 ≈ 1.20 亿调整后利润 | 约 23.5 倍 | 4.26 元 |
| **剔除障眼法后的真实市盈率** | 28.19 亿 ÷（0.5825 + 0.0176 减值 − 0.0203 投资收益）= ÷ 0.5798 亿，**SBC 不加回** | **48.6 倍** | **2.06 元** |
| 自由现金流口径 | 28.19 亿 ÷ 1.442 亿 | 19.6 倍 | 5.11 元 |
| **自由现金流（SBC 当成本扣掉）** | 28.19 亿 ÷ 0.872 亿 | **32.3 倍** | **3.09 元** |
| 企业价值口径 EV/EBIT | 22.96 亿 ÷ 0.5586 亿 | 41.1 倍 | 2.43 元 |
| 企业价值口径 EV/（FCF−SBC） | 22.96 亿 ÷ 0.872 亿 | 26.3 倍 | 3.80 元 |
| **三年平均利润口径** | 剔除认股权证噪音后：FY24 约 0.518 亿 / FY25 约 0.703 亿 / TTM 约 0.529 亿，均值 **0.583 亿** | **48.3 倍** | **2.07 元** |

**三年平均那一行说明什么：** 把 SPAC 认股权证的会计噪音清掉之后，三年平均真实利润 5,830 万，跟当期的 5,825 万**几乎一模一样**。所以——**这个 48 倍不是"利润处在低谷所以倍数虚高"，也不是"利润处在高点所以倍数虚低"。48 倍就是 48 倍，没有折扣可打。**

**还要注意远期市盈率 18.32 倍这个陷阱。** 网上到处看到的"CLBT 才 18 倍"，用的是**卖方按公司 Non-GAAP 口径预测的明年利润**——那个口径把 5,694 万 SBC 加回去了。**你不能把它加回去，因为你的股份每年真的在被稀释 9.33%。** 从 48 倍到 18 倍这个跳跃，一半来自"预计明年利润会涨"，一半来自"假装股票不是钱"。

### 说人话

**你现在投 100 块进去，按最保守的真实口径（GAAP 利润、SBC 全额当成本）算，公司一年替你赚 2.06 元。按现金口径（自由现金流减去 SBC）稍好一点，2.06 到 3.09 元之间。**

这 2 到 3 元里，**你现在能拿到手的是 0 元**。没有分红，没有回购。而且**你的持股比例还在以每年 9.33% 的速度缩水**——粗暴地说，光是稀释这一项，就把这 2 元先吃掉了一大半。

那 2 到 3 元去哪了？看投资活动：**收购花了 1.627 亿**（Corellium），买证券 1,790 万，买无形资产 1,562 万。**公司把赚的钱、加上账上的存款，全拿去买新业务了。**

**这个 2.06 元未来会变大还是变小？**

**大概率变大，而且速度不慢**，理由是实打实的：
- 营收 +17.76%，而且最赚钱的订阅业务是 +22.2%，占比 71.5% 还在升。**收入结构在往更好的方向走。**
- 毛利率 82.96%，投入资本回报率 **ROIC 39.04%**，远高于 10.63% 的资本成本。**这门生意每投一块钱能赚回来将近四毛，属于顶级。**（注意 ROE 只有 12.42%——被账上那 5.46 亿只吃 3.75% 利息的现金拖低了，ROIC 39% 才是生意本身的真实水平。）
- 经营杠杆还没释放：毛利 82.96%，经营利润率才 10.86%。研发和销售费用如果只按 10% 增长而营收按 18% 增长，利润率能在两三年内翻倍。
- 净现金 5.22 亿，占市值 18.5%，零债务压力。**扣掉现金看，真实的企业价值只有 22.96 亿。**

**会把上面全部打折的三件事：**

1. **稀释。** 这是最确定的一条。生意涨 18%，你每股只涨 8%。除非公司开始大规模回购（现在是 0），否则这 10 个百分点的损耗每年都会准时发生。
2. **苹果。** 整个公司的核心价值建立在"能打开锁着的手机"上。每一次 iOS 大版本更新都是一次考试。它至今每次都过了，但**这是一门永远没有毕业的生意**——这也是为什么毛利 83% 却只剩 11% 经营利润率，钱全烧在这里了。
3. **政治。** 客户是各国政府警察，产品是"侵入公民手机"。这家公司被人权组织点过名（曾向缅甸、白俄罗斯等国供货，后来主动切断了部分国家），在美国也因为给移民执法部门供货挨过骂。**一次足够大的丑闻可能让一批西方客户被迫停止采购**——这不是理论风险，2021 年之后它已经主动砍掉过好几个国家的客户。另外研发全在以色列，地缘风险不为零。

顺带：股价过去 52 周跌了 **30.45%**，RSI 32.8（接近超卖），空头只占流通股 3.25%（不高，说明市场不是在赌它崩，只是在重新给增长股定价）。

## 第四部分：一句话结论

**这是一门真正好的生意——83% 毛利、90% 收入是合同化续费、ROIC 39%、净现金占市值 18.5%、客户换不掉它、收入还在以 18% 增长——但 48 倍 GAAP 市盈率、32 倍"扣掉股权激励后的自由现金流"，加上每年 9.33% 的股本稀释和一次回购都没有，这个价格没有便宜可占。**

它不贵得离谱，它只是**把未来三年该赚的钱已经付掉了**。你今天买入，赌的是"这门生意能在苹果的持续加固、政治压力和自我稀释三重损耗下，仍然把利润率从 11% 做到 25%"。这个赌注不荒谬，甚至有相当的胜算，但**你没有安全边际，而且每年要先交 9.33% 的稀释过路费**。

真正会改变判断的是一件事：**公司什么时候开始拿那 5.22 亿现金回购股票**。到那天，稀释这个最大的漏洞被堵上，同样的生意就值得认真出价了。在此之前，它属于"生意值得研究、价格值得等"的那一档。
