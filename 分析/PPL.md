# PPL · PPL 公司（美国宾州—肯塔基—罗德岛电力燃气公用事业）

市值 271.1 亿美元 · 股价约 36.02 美元 · 行业：受监管的电力与燃气公用事业 · TTM 截止 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

先说一句最要紧的话，不然下面全看不懂：**这不是一门普通生意，这是一台"把资本开支翻译成利润"的机器。**

普通公司想多赚钱，得多卖货、卖得更贵、成本更低。受监管的公用事业不行——它卖多少钱、赚多少利润，是各州的公用事业委员会（PSC / PUC / BPU）开听证会定的。定价的逻辑是这样：

1. 公司把埋在地下的管道、竖在路边的电线杆、变电站、发电厂加总起来，算出一个数，叫**费率基数（rate base）**。PPL 的费率基数大约 250 亿美元量级（净固定资产口径）。
2. 监管机构批一个**允许的股东回报率（allowed ROE）**，美国目前普遍在 9.5%–10.5%。
3. 然后倒推电价：让公司能收回全部运营成本 + 折旧 + 债务利息，再加上"费率基数里属于股东那一半 × 允许回报率"。
4. 于是——**公司每多埋一根管子、每多建一座变电站，明年的利润就自动多一块。** 花的钱越多，赚的越多。

这就是为什么 PPL 一年花掉 46.5 亿美元资本开支，而它一年只赚 12.6 亿净利润。它不是在"投资扩张"，它是在**买利润**：今天花 100 块埋在地里，监管机构允许它未来几十年每年从用户身上收回折旧 + 大约 10% 的股东回报。

看懂这个，PPL 的三门生意就只是同一台机器的三个地区版本。

### 生意一：肯塔基（Kentucky Regulated）—— 从挖煤到送到你家插座，全包

**TTM 营收 39.59 亿美元，占 42.1%。**

这门生意的法律实体叫 **LG&E（路易斯维尔燃气电力公司）和 KU（肯塔基公用事业公司）**，服务肯塔基州约 100 万电力用户和 33 万燃气用户。

它和另外两块最大的区别是：**它自己有发电厂**。Mill Creek、Ghent、Trimble County 这些燃煤和燃气电厂是 PPL 自己的资产，总装机 8 千兆瓦左右。所以肯塔基这块是"垂直一体化"的——从燃料采购、发电、高压输电、降压配电，一直到你家门口的电表，全是它一家的。

具体到收钱：路易斯维尔一户普通家庭，一个月用 1000 度电，账单上大概 130 美元。这 130 块里，燃料成本（煤和天然气）大约 35 块是**原样转嫁**的——燃料涨价它就通过"燃料调整条款"直接加到你账单上，公司一分不多赚也一分不少赚；剩下的才是发电厂折旧、输配电网折旧、人工、以及监管机构批准的股东回报。工商业客户单独一套电价表，比如一家铝厂签的是可中断供电合同，电价便宜但电网紧张时公司有权拉闸。

肯塔基这块最近几年的增长引擎有两个：一是**数据中心正在往肯塔基跑**（电价便宜、土地便宜），一个 200 兆瓦的数据中心签下来，相当于凭空多出 15 万户居民的用电量，而且用电曲线平稳、不挑时段，对电网是好客户；二是**燃煤机组退役换成燃气 + 光伏**，退役旧机组、新建新机组，两头都是资本开支，两头都进费率基数。

### 生意二：宾夕法尼亚（Pennsylvania Regulated）—— 只管送，不管发

**TTM 营收 33.16 亿美元，占 35.3%。**

法律实体是 **PPL Electric Utilities**，服务宾州东部和中部约 140 万用户（阿伦敦、斯克兰顿、哈里斯堡一带）。

和肯塔基完全不同：**宾州早在 1990 年代末就把发电和输配电拆开了，PPL 在宾州一台发电机都没有。** 它是纯粹的"收费公路"——电是别人发的，它只负责用自己的电线把电送到你家，按你用了多少度收一笔"输配电费"。

这个模式对用户是这样的：宾州居民可以自己上网挑电力供应商，比如挑一家报价 8 美分/度的零售电商。你的月账单大概 130 美元，其中约 75 美元是"供电费"（付给你挑的那家供应商），约 55 美元是"输配电费"（这才是 PPL 的钱）。如果你懒得挑，PPL 会替你去批发市场买电，叫"默认服务"，这部分的电费也走 PPL 的账，**但它是原价转手、零毛利的** —— 所以宾州这 33 亿营收里有相当一块是这种"过路钱"，看起来是营收，实际不产生一分利润。

对股东来说，纯输配电其实是**三门里最好的一门**：没有发电厂就没有燃料价格风险、没有环保合规风险、没有机组非计划停机风险，也没有煤电资产提前退役被减值的风险。它只有一件事要做——把电线杆维护好、把老旧线路换成新的、把智能电表装上去，然后每花一块钱资本开支，就往费率基数里多加一块。

### 生意三：罗德岛（Rhode Island Regulated）—— 2022 年花 38 亿买回来的，到现在还没赚够

**TTM 营收 21.22 亿美元，占 22.6%。**

法律实体是 **Rhode Island Energy**。这块不是 PPL 自己长出来的，是 **2022 年 5 月从英国国家电网（National Grid）手里花 38 亿美元买下来的**，一次性买断了整个罗德岛州的电力和燃气配送网——约 78 万个用户账户。

业务形态和宾州一样，是纯配送：电和天然气都是别人生产的，Rhode Island Energy 只负责用管道和电线送到最终用户，按输送量收费。

**这门生意目前是三块里最难看的一块。** TTM 营收 21.22 亿，比 2025 财年全年的 21.68 亿还略低——收缩了。原因是收购后实际赚到的股东回报一直低于监管机构批准的水平（业内叫"under-earning"），主要是：新英格兰地区的运维成本比 PPL 原来预想的高，老旧燃气管网的更换开支巨大，而费率调整要走听证程序、有滞后。PPL 收购时讲的故事是"我们比国家电网管得更精细，能把成本压下来"，四年过去，这个故事兑现得比预期慢。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：TTM 5,400 万美元，占净利润 4.3%。这个比例在美股里算极低的（科技公司常见 30%–80%）。原因很简单：公用事业招的是线路工、调度员、工程师，不是硅谷工程师，工资是现金发的。这 5,400 万我按规矩当真实成本扣掉，不加回，但对结论几乎没影响。

**一次性项目**：TTM 这一期非常干净——没有资产减值、没有重组费用、没有诉讼和解、没有资产处置损益。上一次大额一次性是 2021 财年（当年净利润 -14.8 亿，那是卖掉英国配电业务 WPD 的会计后果，一次性砍了一刀）。**要提醒的是：只看 TTM 这一期，我分不清"真一次性"和"年年都会来一次的一次性"。** 公用事业最容易冒出来的是燃煤机组提前退役的资产减值和飓风/暴风雪的灾后修复费用，PPL 过去五年里这两类都出现过。今年没有，不代表明年没有。

**资本化的支出**：没有软件资本化、内容资本化这类问题。但**公用事业本身就是一台巨型资本化机器**——花在电网上的 46.5 亿是正常的、必须资本化的、监管机构也认可的资本开支。这不是障眼法，但它是理解这家公司的关键（见下）。

**回购与稀释 —— 这一项最难看**：

| | TTM 金额（百万美元） |
|---|---|
| 回购股票 | **0** |
| 发行股票 | **+401** |
| 股权激励 SBC | 54 |
| 回购 ÷ SBC | **0 倍** |
| 股本一年变化 | **+1.31%（增加）** |

按我一贯的标准，回购/SBC 接近 1 说明回购只是在对冲员工发股，大于 3 才叫真回馈股东。**PPL 是 0——它一股都没回购，反而净发行了 4.01 亿美元的新股，股本一年增加了 1.31%。**

这意味着：你今天买 100 股 PPL，一年后你手里还是 100 股，但公司总股本多了 1.31%，**你对这家公司的所有权被稀释了 1.31%**。这个稀释是每年都在发生的，不是意外。原因也不神秘：它一年花 46.5 亿资本开支，经营现金流只有 26.5 亿，缺口 20 亿全靠借债和发新股填。

**利润和现金流的差 —— 逐项对账**：

| 项目 | 金额（百万美元） | 说明 |
|---|---|---|
| GAAP 净利润 | 1,264 | 起点 |
| + 折旧与摊销 | +1,491 | 不花现金的账面成本，加回来 |
| + 其他摊销 | +8 | |
| + 股权激励 SBC | +54 | 发的是股票不是现金，现金流表加回，但它稀释你 |
| + 其他经营活动 | +70 | 主要是递延所得税 |
| − 应收账款增加 | −145 | 电费收出去了但用户还没交钱 |
| − 存货增加 | −83 | 燃料和备件囤货 |
| − 应付账款减少 | −37 | 提前还了供应商的钱 |
| − 所得税相关变动 | −25 | |
| + 其他经营性资产净变动 | +55 | |
| **= 经营现金流** | **2,654** | |
| − 资本开支 | **−4,646** | **重点在这里** |
| **= 自由现金流** | **−1,992** | **负的** |

这张表的结论只有一句话：**PPL 一年真金白银赚回来 26.5 亿，转身花了 46.5 亿修电网，自由现金流是 -19.9 亿。它还倒贴了 8.18 亿现金给股东发分红。**

那这 28 亿的窟窿谁填的？现金流量表写得明明白白：**净借新债 +25.86 亿，发新股 +4.01 亿。** 换句话说——

> **你收到的每一分钱分红，都不是公司赚出来给你的，是公司借钱借出来给你的、外加发新股稀释你自己发给你的。**

这句话听起来很吓人，但对受监管的公用事业来说，它其实是**行业常态而不是财务丑闻**。逻辑是：监管机构允许公司把这 46.5 亿加进费率基数，未来几十年从电费里连本带利收回来，回报率约 10%。所以"借钱修电网"在监管框架下是**有担保的、被批准的、几乎稳赚的**。这不是庞氏，是重资产受监管行业的运转方式。

但股东要清醒的是三件事：**第一，这套模式只在利率不高的时候好用**——2021 年 PPL 总债务 113 亿，现在 204 亿，TTM 付出的现金利息 7.45 亿；利率每高 1 个百分点，将来再融资就多吃掉一大块。**第二，它的利息保障倍数只有 2.59 倍**，经营利润只够付 2.6 倍的利息，在美股里属于薄的。**第三，也是最刺眼的一项：PPL 的投入资本回报率 ROIC 是 4.20%，而它自己的加权平均资本成本 WACC 是 5.76%。** 用最直白的话讲：**它每投一块钱进去，创造的回报低于这一块钱的融资成本——从纯财务的角度看，它每年在毁灭价值。**（要给它说句公道话：ROIC 分母里含了收购罗德岛付的溢价和商誉，压低了这个数；不含商誉的费率基数回报会好看一些。但即便如此，两者的差距是真实存在的。）

## 第三部分：市盈率，多口径

| 口径 | 怎么算 | 倍数 | 投 100 块的年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 271.1 亿 ÷ 12.64 亿 | **21.4 倍** | **4.66 元** |
| 公司自己吹的 Non-GAAP | PPL 用"持续经营每股收益"口径 | 财报页未提供，不编 | — |
| **剔除障眼法后的真实市盈率** | 本期无真一次性损益，SBC 已按 GAAP 扣除 | **21.4 倍** | **4.66 元** |
| 自由现金流口径 | 271.1 亿 ÷ (−19.92 亿) | **不适用（FCF 为负）** | **负数** |
| 企业价值口径 EV/EBIT | 471.5 亿 ÷ 22.70 亿 | **20.8 倍** | **4.81 元**（这是整个企业的回报，债主先拿走大头） |
| **三年平均利润口径** | 271.1 亿 ÷ (12.64+11.79+8.86)/3 = 11.10 亿 | **24.4 倍** | **4.09 元** |

**三年平均口径比当期高了 3 倍市盈率，说明当前的 12.64 亿利润是三年里的高点，不是常态。** 但和 NVDA 那种"当期 34 倍、三年平均 73.5 倍"的悬崖不一样——PPL 的差距来自于利润在稳步爬坡（8.86 → 11.79 → 12.64），是费率基数增长的正常结果，不是周期高点。这个爬坡大概率还会继续。

**说人话的结论：**

> **你今天投 100 块进 PPL，按最保守的三年平均口径，公司一年替你赚 4.09 块；按当期口径，赚 4.66 块。**

这 4.66 块里，有多少真的回到你口袋？

- **分红 3.17 块**（每股股息 1.14 美元 ÷ 股价 36.02 美元），派息率 65%。这部分是真钱，一个季度打一次到你账上。
- **回购 0 块。** 一股没回购。
- **反向减去稀释约 1.31 块**：股本一年增加 1.31%，你的所有权被摊薄，这相当于从你的回报里扣掉约 1.3%。
- **剩下的约 1.5 块留在公司里**——但严格说它没"留下"，公司的自由现金流是负的，这 1.5 块只是账面利润，实际是拿去抵了资本开支缺口的一部分，剩下的缺口靠借债。

所以**扣掉稀释之后，实实在在的现金回报大约是 3.17% − 1.31% ≈ 1.9%，加上留存利润带来的费率基数增长（约每年 6%–8% 的每股收益增长目标）。** 长期总回报的合理预期是 **7%–9% 出头**，前提是：利率不再大幅上行、三个州的监管机构继续按当前的允许回报率批费率、罗德岛能把回报追上来。

**这个 4.66 块未来大概率变大还是变小？** **变大，但速度是被监管封顶的。** 变大的理由很硬：数据中心正在推高肯塔基和宾州的用电负荷，电网老化带来强制性更换开支，这些都往费率基数里加钱，而费率基数增长几乎是自动兑换成利润的。PPL 官方给的每股收益年增长目标在 6%–8%。变小的风险也很实：利率再上一台阶会直接压缩利差，罗德岛如果一直追不上允许回报就要一直拖后腿，燃煤机组退役如果被判定为"不审慎"、监管机构不让全额进费率基数，会一次性减值。

## 第四部分：一句话结论

**PPL 是一张 4.7% 收益率、每年增长 6%–8% 的"准债券"，但你得接受两件不舒服的事：它给你的分红是借钱发的，它每年还稀释你 1.3%。**

值不值这个价？21.4 倍市盈率买一家利润增长 6%–8%、ROIC(4.2%) 低于 WACC(5.8%)、利息保障只有 2.6 倍、自由现金流常年为负的公司——**不便宜，但也没到离谱**。它的定价本质上是在和长期国债收益率比：只要 10 年期美债收益率不显著往上走，PPL 3.2% 的股息 + 6%–8% 的增长就说得过去；一旦利率再上一个台阶，这类股票会被同时打击两次（估值倍数下压 + 融资成本上升），2022–2023 年已经演过一遍。

**适合谁：** 需要稳定现金分红、能接受长期低个位数总回报、把它当债券替代品的人。**不适合谁：** 想赚资本利得的人——过去 52 周它跌了 3.28%，这不是意外，这就是它该有的样子。三门生意里，宾州那块（纯输配电、无发电风险）是最值钱的资产，罗德岛是目前最大的拖累和最大的翻身机会。
