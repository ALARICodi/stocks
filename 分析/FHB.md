# FHB · First Hawaiian（第一夏威夷银行）

市值 31.4 亿美元 / 股价 25.79 美元 / 行业：金融·区域银行 / TTM 截止 2026-06-30（任务2 · 市盈率 0–15 倍段 · 榜内第 277 名）

> **这是银行，用市净率 + ROE 口径。** 本会话第六家银行，重点讲它跟大陆同行不一样的地方：**它不是在跟几千家银行卷，是在一个太平洋孤岛上跟一个对手分市场**。

---

## 第一部分：它到底做几件事

1858 年开业，夏威夷最老、规模最大的银行，总资产约 240 亿美元，网点覆盖夏威夷全部主要岛屿外加关岛、塞班。**一门生意：在夏威夷吸存款放贷款**，分部只是零售（TTM 收入 6.33 亿，占 72%）和对公（2.49 亿，占 28%）的记账拆分。

真正值得写的是它的**市场结构**。夏威夷银行业实质是双寡头：First Hawaiian 和 Bank of Hawaii 两家合计吃掉全州过半存款，第三名以后不成气候。岛屿经济给了这个格局天然的护城河——大陆银行跨海来开分行不划算，本地居民和企业换银行的意愿极低（夏威夷人的账户往往是祖辈传下来的），结果就是**全美国最便宜、最稳的存款基础之一**：几乎不用付高息抢存款，2023 年硅谷银行挤兑潮席卷大陆区域银行时，这两家的存款纹丝不动。

资产端同样是岛屿画风：本地商业地产（购物中心、酒店）、住房按揭、给丰田/本田经销商的汽车库存融资（它是夏威夷汽车经销金融的老大）、消费贷。保守到什么程度——**总债务只有 1500 万美元**（不是亿），基本靠存款运营，TTM 拨备 0.23 亿、占贷款约 0.16%，坏账干净。

阴影面也来自同一座岛：**夏威夷经济=旅游业单一引擎**（外加军费），游客量决定全岛生意的水位；人口停滞、企业外迁加州，**这个市场几乎没有增长**——它的贷款盘子五年只微增。所以这家银行的剧本不是成长，是「垄断收租 + 高分红」。

**钱（TTM）**：营收 8.81 亿（+9.5%，利差重定价驱动）、净利润 2.85 亿、ROE 10.3%、ROA 1.20%、实际税率 23%。

## 第二部分：把会计障眼法剥掉（银行版）

- **拨备**：TTM 0.23 亿，太平年景水平，与它的资产结构相称，无垫利润痕迹。
- **一次性项目**：FY2024 有 0.26 亿证券组合重摆亏损（压低当年利润），已消化；TTM 干净。
- **股权激励**：银行惯例的小量级，忽略。
- **回购与稀释**：TTM 回购 0.88 亿 + 分红 1.29 亿，**股本一年实缩 3.0%（本会话六家银行里唯一在真回购的）**；股息率 4.0%、派息率 45%——**分红 + 回购合计把约 7% 的市值每年还给股东，银行组里最高**。
- **资本**：CET1 约 13%（估算），过剩——这正是它能一边分 4% 一边回购 3% 的底气。资本过剩的另一面是 ROE 被压在 10%：它的钱多到在岛上放不出去。

## 第三部分：估值（银行口径）

| 口径 | 数值 | 投100块年回报 |
|---|---|---|
| 市净率 PB | 1.11 倍 | ROE÷PB = 10.3÷1.11 ≈ **9.3 元** |
| 有形市净率 P/TBV | 1.71 倍 | ROTCE 约 16%÷1.71 ≈ 9.4 元 |
| 市盈率（参考） | 11.2 倍，预期 10.8 倍 | 8.9–9.2 元 |
| 三年平均利润口径 | (2.35+2.30+2.76)÷3 = 2.47 亿 → 12.7 倍 | 7.9 元 |
| 股息 | 4.0% | 其中 4.0 元现金到手 |

本会话六家银行终极对比（投 100 块年回报 / 股息率 / 股本增减）：**FHB 9.3 / 4.0% / -3.0%**，FFBC 9.0 / 3.2% / +5.4%，FULT 8.9 / 3.2% / +0.6%，VLY 8.8 / 3.2% / +3.1%，TOWN 6–7 / 3.0% / +12.4%。**FHB 是唯一「高分红 + 真回购 + 零债务」三样齐的**；FFBC 赢在赚钱效率（ROA 1.39 vs 1.20），FHB 赢在市场结构和股东回馈。

大白话：**你投 100 块进去，一年赚 9.3 块，其中 4 块分红到手、3 块回购注销，七成利润真金白银回到你身上**——剩下的留在一个不增长但也几乎不会被抢走的垄断市场里。风险两条：夏威夷旅游业一旦被衰退或天灾（火山、山火）打击，全行贷款跟着感冒；以及永远别指望它长大。52 周股价原地踏步（-0.9%），估值也在自己历史区间中位，没有被炒过。

## 第四部分：一句话结论

一台孤岛上的收租机：双寡头市场、祖传存款、总债务只有一千五百万美元、每年把 7% 市值还给股东——它把「银行」这门生意做成了最接近公用事业的形态，代价是永远没有成长。1.11 倍净资产买 10% ROE 加 4% 股息，价格不惊艳但诚实，而且没有像 VLY/FULT 那样刚涨完一波。**要收息就选它，要效率选 FFBC，两家是本段位银行里仅有的两个「买得下手」**。公道，生意一般偏好。
