# ACM · AECOM（艾奕康）

市值 79.3 亿美元 ｜ 股价 $61.72（2026-08-18 收盘）｜ 行业：工业服务 / 基建工程咨询 ｜ TTM 截至 2026-06-30（财年 10 月–9 月）

---

## 第一部分：它到底做几件事

AECOM 的分部只有三个，而且第三个已经名存实亡，所以实质上是**一门生意做两个地区**。

### 生意 A：美洲的基建设计与项目管理（FY2025 营收 125.26 亿美元，占 77.6%）

**这是一家卖工程师工时的公司，不是盖房子的公司。**

具体怎么运作：某个州的交通厅要修一条 30 公里的轻轨。它自己没有养一支能画图的队伍，于是招标找 AECOM。AECOM 派几十上百个工程师进场，做的事情是：先做可行性研究（这条线该从哪走、地质行不行、拆迁多少钱、客流预测多少），然后做初步设计和施工图（桥怎么架、隧道怎么打、轨道怎么排、信号系统怎么配），再然后在整个施工期里替业主做**项目管理**——盯着承包商有没有按图施工、进度有没有拖、变更单该不该批、钱该不该付。

收钱方式主要是两种：
- **成本加成（cost-plus）**：AECOM 报出每个岗位的小时费率（比如资深结构工程师 $220/小时、绘图员 $95/小时），把实际投入的工时乘费率报账，业主按月付款，另加一层管理费。这类合同占大头，风险低——加班了就多收钱。
- **固定总价（fixed-price）**：整个设计包一口价，比如"这段高架桥的全套施工图 4,800 万美元"。做超了自己承担。这类合同利润率高，但**这次爆雷就出在这里**（下面第二部分详述）。

典型客户和单子长什么样：美国联邦机构（陆军工程兵团的军事基地设施、环保署的污染场地修复、FEMA 的飓风灾后重建管理）、州和市政府（交通厅、水务局、机场管理局）、以及大企业（半导体厂、数据中心、能源公司的厂区建设）。一个大型机场航站楼扩建的设计+管理合同，合同额可以是 3–8 亿美元、跨 5–7 年慢慢确认收入。

**必须搞懂的一件事：AECOM 的"营收"里有一大半不是它自己的钱。** 很多合同 AECOM 是总包方，要把岩土勘察、环境检测、专业软件这些分包出去，分包商的费用先走 AECOM 的账再付出去（业内叫 pass-through）。所以它报出来的 154 亿美元营收里，扣掉转付给分包商的部分，真正属于自己的"净服务收入"大概只有六成左右。这就是为什么它的毛利率只有 5.68%——**不是生意差，是分母被灌水了**。看这家公司的盈利能力，要看经营利润率对净服务收入的比值，或者干脆看 ROIC（12.4%，还可以）。

客户为什么非用它不可：一是牌照和资质——大型公共工程要求设计方有对应州的执照工程师签字盖章，还要有类似项目的业绩记录，新公司进不来；二是**责任承担**——设计出错桥塌了要有人赔，业主要找一家赔得起的、买了巨额职业责任险的公司；三是政府项目的采购流程本身就是护城河，一个联邦长期采购合同（IDIQ）一签五到十年，期间的任务单直接派给已入围的几家。

### 生意 B：国际业务（FY2025 营收 36.13 亿美元，占 22.4%）

同样的生意，换到英国、中东、澳大利亚、加拿大、香港。典型项目是英国的高铁与水务升级、沙特和阿联酋的新城与场馆、澳大利亚的公路和铁路。国际这块 FY2025 基本零增长（36.13 亿 vs 36.18 亿），是拖后腿的一半。

### 生意 C：AECOM Capital（FY2025 营收 50 万美元）

这是过去做房地产开发跟投的自营投资平台，公司几年前就决定退出，现在只剩清算尾巴，营收 50 万美元，可以直接忽略。

### 各生意的钱（FY2025 全年，分部只披露到营收）

| 生意 | 营收（百万美元） | 同比 | 占比 | 说明 |
|---|---|---|---|---|
| 美洲 | 12,526 | +0.3% | 77.6% | 主力，增速已经停滞 |
| 国际 | 3,613 | -0.1% | 22.4% | 零增长 |
| AECOM Capital | 0.5 | -64% | 0.0% | 清算中 |
| 合计 | 16,140 | +0.2% | 100% | |

财报只按分部披露营收，不披露分部经营利润，所以上面没有利润列。按整体口径推算，FY2025 经营利润率 6.60%；TTM 掉到 4.70%——**这 1.9 个百分点全是最近一个季度砸出来的**。

TTM 营收 153.93 亿美元，同比 **-4.24%**，是过去五年第一次负增长。

## 第二部分：把会计障眼法剥掉

### 一、最近一个季度出了大事——这是全篇最重要的一段

看这四个季度的毛利润（百万美元，从近到远）：

| 季度 | 2026年6月 | 2026年3月 | 2025年12月 | 2025年9月 |
|---|---|---|---|---|
| 毛利润 | **-34.04** | 296.50 | 280.99 | 330.60 |
| 经营利润 | **-66.11** | 254.70 | 242.45 | 293.13 |
| 归母净利润 | **-86.71** | 179.86 | 74.52 | 120.37 |
| 营收同比 | -14.18% | +0.78% | -4.57% | +1.58% |

**2026 年 6 月这个季度，毛利润是负的。** 一家服务公司做出负毛利，意味着这一期确认的成本超过了收入——按会计准则，固定总价合同一旦预计要亏，必须**当期一次性把整个合同的预计亏损全部计提**，不能分摊到以后。从正常季度约 +295 到 -34，落差约 3.3 亿美元，这就是那笔计提的规模。

关键细节：**这笔钱是计在"成本"里的，不在"重组费用"里**（当季重组费用只有 1,208 万）。这个位置很要命——重组费用是公司自己主动做的动作，成本里的亏损计提是**项目干砸了**。同时营收同比 -14.18%，说明还伴随着项目停工或收入冲回。

按分析口径的规矩：**只看这一期，我判断不了这是"真一次性"还是"每隔几年就来一次"。** 但下面第二条给了一个不太好的旁证。

### 二、连亏六年的"已终止经营"

AECOM 几年前把自营施工业务（Civil Construction、电力建设）划成"已终止经营"准备卖掉/关掉。看这一行的历史：

| 财年 | FY2021 | FY2022 | FY2023 | FY2024 | FY2025 | TTM |
|---|---|---|---|---|---|---|
| 已终止经营损益（百万） | -121.5 | -78.5 | -58.75 | -103.66 | -76.49 | **-84.64** |

**连续六年、每年亏 6,000 万到 1.2 亿美元，一年不落。** 这是教科书级的"年年都有的一次性"。公司在讲故事时会说"请看我们持续经营业务的调整后每股收益"，把这一行整个抹掉；但这是真金白银流出去的，六年累计亏了 5.2 亿美元。**在算真实盈利能力时，这笔钱必须留在里面。**

它同时也说明一件事：AECOM 处理陈年工程合同的历史记录并不干净。这让人对上面那笔 3.3 亿的项目计提是否"绝无仅有"打个问号。

### 三、少数股东每年拿走一块

| 财年 | FY2021 | FY2023 | FY2025 | TTM |
|---|---|---|---|---|
| 少数股东损益（百万） | -25.11 | -43.26 | -73.29 | **-50.58** |

AECOM 很多大项目是和别人组合资联营体（joint venture）做的，合并报表时把联营体 100% 的利润并进来，再把不属于自己的部分扣掉。这一行也是年年都有、还在变大。它已经在 GAAP 净利润里扣掉了，没问题，但要知道：**报表上的"经营利润 7.24 亿"里，有约 5,000 万从来就不是股东的。**

### 四、股权激励（SBC）

TTM 4,186 万美元，占 GAAP 净利润 288.04 万美元的 **14.5%**。这个比例在美股里算低的——AECOM 是家工程公司，主要成本是工程师工资，不是股票。SBC 已在 GAAP 里扣除，这里不加回。

### 五、回购与稀释——这一项是全篇最亮的

TTM 回购 **6.919 亿美元**，同期 SBC 只有 4,186 万。**回购 / SBC = 16.5 倍。**

按分析口径的标准：这个比值接近 1 说明回购只是在抵消员工发股（假回馈），大于 3 才算真回购。**16.5 倍是真回购里的真回购。** 印证：股本一年实际减少 2.14%（1.32 亿股 → 1.285 亿股），而且这是连续第五年缩股（FY2021 -7.20%、FY2022 -4.66%、FY2023 -1.81%、FY2024 -2.61%、FY2025 -2.30%）。五年下来股本从 1.47 亿股缩到 1.285 亿股，缩了 12.6%。

另外 TTM 分红 1.499 亿美元，每股 1.19 美元，股息率约 1.9%，而且股息五年里每年提升 18–22%。

回购+分红合计 8.42 亿美元，是同期自由现金流（2.03 亿）的 4.1 倍——**这一年它是靠借钱和账上现金在回购**（净新增债务 1.53 亿，现金减少 7.81 亿）。这在股价腰斩时买入是聪明的做法，但也说明这个力度不可持续。

### 六、资本化的支出

AECOM 是人力服务公司，没有软件资本化、没有内容制作费。资本开支 TTM 1.62 亿美元，只占营收 1.05%，基本是办公和 IT 设备。**这一项：没有。**

### 七、利润和现金流的差——逐项对账

TTM 净利润 2.88 亿，经营现金流只有 3.65 亿，自由现金流 2.03 亿。而 FY2025 的自由现金流是 6.85 亿。**现金流一年掉了 70%**，钱去哪了：

| 项目 | 金额（百万美元） | 说明 |
|---|---|---|
| 归母净利润 | 288.04 | 起点 |
| + 少数股东损益 | +50.58 | 加回（现金流表从含少数股东的口径起算） |
| + 折旧摊销 | +207.59 | 非现金 |
| + 其他摊销 | +7.40 | 非现金 |
| + 资产处置损失 | +64.55 | 非现金损失，加回 |
| − 资产减值/重组冲回 | -22.07 | |
| + 权益投资损失 | +1.30 | |
| + 股权激励 SBC | +41.86 | 非现金（但真实稀释） |
| + 其他经营项 | +98.28 | |
| + 应收账款减少 | +12.82 | 收回了一点钱 |
| − **应付账款减少** | **-110.29** | **付给分包商的钱变多了** |
| − **预收账款减少** | **-37.57** | **客户预付的钱在消耗** |
| − **其他经营性资产变化** | **-186.55** | **主要是未开票的在建工程款堆积** |
| = 经营现金流 | **365.36** | |
| − 资本开支 | -161.92 | |
| = 自由现金流 | **203.45** | |

三个负数加起来 -3.34 亿，这就是现金流塌方的全部原因：**营运资金反噬。** 应付款下降+预收款下降+未收工程款上升，是"项目出问题"的典型现金流特征——活干完了钱收不回来（存在争议/索赔中），同时还得先把分包商的钱付掉。

这三项都是营运资金的时间差，理论上会回补；但如果背后是应收账款在打官司，就可能永远回不来。**FY2025 那 6.85 亿的自由现金流是这家公司的正常水平，TTM 的 2.03 亿是异常。** 下面估值时两个数都会用。

## 第三部分：市盈率，多口径

市值 79.32 亿，企业价值 102.41 亿（净负债 23.09 亿）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 7,932 ÷ 288.04 | **27.5 倍** | **3.63 元** |
| 公司自己吹的 Non-GAAP（估算） | 剔除已终止经营、重组费用后约 4.64 亿 | 17.1 倍 | 5.85 元 |
| **剔除障眼法后·保守** | 把项目计提当经常性，已终止经营和少数股东照扣 = 288.04 | **27.5 倍** | **3.63 元** |
| 剔除障眼法后·正常化 | 加回本季项目计提税后约 2.64 亿 → 5.52 亿 | 14.4 倍 | 6.95 元 |
| 自由现金流口径（TTM 实际） | 7,932 ÷ 203.45 | 39.0 倍 | 2.56 元 |
| 自由现金流口径（正常年份 6.85 亿） | 7,932 ÷ 684.93 | 11.6 倍 | 8.63 元 |
| 企业价值口径 EV/EBIT | 10,241 ÷ 724.17 | 14.1 倍 | 7.07 元 |
| **三年平均利润口径** | 7,932 ÷（288.04+561.77+402.27）/3 | **19.0 倍** | **5.26 元** |

（公司口径那一行是估算：以持续经营利润 4.23 亿为基础，扣少数股东 0.51 亿、加回税后重组费用约 0.92 亿。AECOM 官方调整口径的具体项目未逐项核对。）

**说人话：**

你现在投 100 块进 AECOM，会得到两个差得离谱的答案：

- **如果那 3.3 亿的项目亏损是真·一次性**（这一年倒霉，明年回到正常）：公司一年替你赚 **6.95 元到 8.63 元**，相当于 12–14 倍市盈率。这在美股是明显便宜的价格，市场给的 forward PE 只有 10.08 倍也是这个意思——分析师普遍认为明年利润会翻回去。
- **如果这是常态**（工程公司隔几年爆一次，六年连亏的已终止经营就是前科）：**一年只赚 3.63 元**，27.5 倍市盈率，一点不便宜。

**三年平均口径给出的 5.26 元（19.0 倍）是最诚实的答案。** 它把 FY2025 的好年景（5.62 亿）、FY2024 的普通年景（4.02 亿）和 TTM 的爆雷年（2.88 亿）平均起来，正好抹平了工程公司的项目周期。19 倍对一家营收零增长、毛利率 6%、ROIC 12.4% 的服务公司，是**公道偏贵一点**的价，谈不上捡便宜。

这 5.26 元里有多少真回到你口袋？TTM 回购 6.92 亿 + 分红 1.50 亿 = 8.42 亿，占市值的 **10.6%**——账面上股东回报率极高。但这一年它是**动用现金储备和借款**在做（现金从 15.95 亿掉到 10.23 亿，净负债从 17.7 亿升到 23.1 亿）。可持续的水平应该看正常年份：FY2025 回购 3.88 亿 + 分红 1.34 亿 = 5.22 亿，对当时 172.8 亿的市值是 3.0%，对现在 79.3 亿的市值是 6.6%。**按现价，正常年份的回购+分红能给你约 6.6% 的现金回报率**，这个数字是站得住的。

留在公司里再投资的部分：TTM 投资活动流出 4.27 亿，其中并购 2.10 亿、资本开支 1.62 亿。AECOM 在买小的专业设计公司做补强，规模不大。

X（每年赚的钱）未来会变大还是变小？两股力量：往上的是基建需求本身——美国的桥梁、水厂、电网都在老化，各国政府的基建预算在增加，AECOM 手上的在手订单（backlog）是这类公司的护城河；往下的是营收已经连续两个季度负增长（-4.57%、-14.18%），说明订单转化在放缓，同时它 78% 的收入来自美洲、其中相当部分是联邦和州政府预算，**政府支出一旦收紧，这门生意是直接挨刀的**。

## 第四部分：一句话结论

**股价跌 48% 是因为一个季度砸出了一笔约 3.3 亿的项目亏损计提，而这家公司过去六年已终止经营每年都在亏钱——所以"一次性"这个说法要打折听；按三年平均利润的 19 倍看，现在这个价是公道偏贵，不是便宜货，真正的赌注是"明年利润能不能弹回 5 亿以上"，赌对了 14 倍、赌错了 27 倍。**

值得放进观察名单，但不是那种闭着眼睛买的价格：它的加分项是极其扎实的回购（16.5 倍于股权激励、连续五年缩股）和不高的债务，减分项是营收已经在负增长、毛利率本来就薄、以及那本翻不完的陈年项目烂账。等下一个季度确认利润率是否回到 6% 以上再动手，比现在猜要划算。
