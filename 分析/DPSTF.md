# DPSTF · DHL 集团（德国邮政 DHL Group）

市值 609 亿欧元（约 716 亿美元，按 1 欧元 = 1.17 美元）/ 法兰克福主板股价 55.02 欧元（场外代号 DPSTF 是同一股票，64 美元）/ 运输·物流 / TTM 截止 2026 年 6 月 30 日（财年 = 自然年）

**先说清楚数据口径**：财报是欧元、IFRS 准则；用的是法兰克福主上市页，市值和财报同一货币，倍数直接算，不用换汇。场外代号 DPSTF 的页面没有财报。

## 第一部分：它到底做几件事

DHL 集团是全球最大的物流公司，57.7 万名员工，一年营收 856 亿欧元，但**利润率只有 4.3%**——这是一门"搬东西"的苦生意，靠规模吃饭。它实质上做五件事，重要程度差别极大：

### 生意 A：国际快递（DHL Express）——真正的印钞机

这是 DHL 的核心，全球跨境限时快递的第一名。具体是这样运作的：一家深圳的电子元件厂要把一箱样品 48 小时内送到慕尼黑的客户手上，打电话给 DHL，DHL 的货车上门取件，当晚送到香港的中转枢纽，装上 DHL 自己的波音 777 货机飞到莱比锡（DHL 在那里有欧洲最大的航空枢纽，一晚上能分拣几十万件），第二天早上莱比锡到慕尼黑的车队送到客户门口。全程一个条码追踪，海关清关 DHL 代办。这样一票 10 公斤的国际快件收费 150–300 欧元，而且**客户不会为了省 20 欧元换一家**，因为样品晚到一天可能丢掉一笔百万订单。

这门生意的护城河是**"全球网络 + 自有机队"**：DHL 在 220 个国家和地区都有清关和派送能力，自有和租赁的货机三百多架。想复制这个网络要几百亿美元和几十年——所以全球跨境快递就三家：DHL、FedEx、UPS，而 DHL 在美国以外的国际件市场份额第一。营业利润率常年 12–14%，是集团其他业务的两到三倍。

### 生意 B：货代（DHL Global Forwarding, Freight）——赚差价的中间商

货代不自己开船开飞机，是个"批发商"：一家德国机械厂要把 40 个集装箱的设备从汉堡运到上海，DHL 货代帮它找船公司（马士基、达飞）订舱、报关、买保险、安排两端的陆运，收全包价。DHL 一年从船公司和航空公司批量买舱位，价格比单个客户自己订便宜，中间赚个差价加服务费。**2022 年海运费涨到天上时这门生意营收冲到 302 亿欧元，运费一回落就跌回 190 亿**——它的营收跟着运价走，自己没有定价权。利润率 5% 左右。

### 生意 C：合同物流（DHL Supply Chain）——替大公司管仓库

这是"外包仓储部门"。比如一家英国连锁超市不想自己建配送中心，DHL 替它建一个 10 万平米的自动化仓库、雇 2000 名员工、管理从进货到门店补货的全流程，签 5 年合同，按处理量收费，一年几千万到上亿欧元。客户包括汽车厂（管零部件入厂）、药企（冷链仓储）、电商（退货处理）。合同一签几年，客户换供应商成本很高（整个仓库要搬），所以营收很稳，但利润率只有 5–6%，因为本质上是替人打工，仓库和人工都是成本。

### 生意 D：德国邮政（Post & Parcel Germany）——躺着萎缩的垄断

这是 DHL 的出身：德国全境的信件和包裹。德国法律规定的普遍服务义务，每一个村子每天都要送信。信件量每年跌 5–8%（没人写信了），包裹量靠电商在涨，一进一出营收基本不动，180 亿欧元。这是个**受监管的低利润业务**，邮资涨价要联邦网络局批，2025 年才批了一轮涨价。利润率 4–5%，而且 2025 年公司宣布在德国裁 8000 人（"Fit for Growth"降本计划），就是为了保住这点利润。

### 生意 E：电商包裹（DHL eCommerce）——各国的本地包裹网

在美国、英国、荷兰、波兰、印度等国跑非限时的本地电商包裹，跟本地邮政和亚马逊自建物流抢生意。这是五块里唯一在萎缩的（−3.7%），利润率最薄，3–4%。

## 第二部分：把会计障眼法剥掉

**股权激励（SBC）**：标准化现金流量表里没有单列，年报口径的股份激励费用大约 1–1.5 亿欧元（估算），占净利润不到 4%。德国公司发股很克制，这项可以忽略。

**一次性项目**：TTM 资产处置收益 1.51 亿（税后约 1 亿，要从利润里扣）；重组和减值只有 400 万。但注意，标准化报表里看不到的是 2025 年"Fit for Growth"裁员计划的一次性费用（公司口径几亿欧元）——**单期看不清这种重组是不是年年都有，物流公司"年年重组"很常见，我不加回。**

**资本化的支出**：没有。物流公司没有资本化研发或内容成本，资本开支 28.7 亿全是飞机、仓库、分拣设备。

**回购与稀释**：TTM 回购 10.8 亿欧元，除以 SBC 约 1.2 亿 = **9 倍**，是真回购；股本一年实际减少 3.93%。加上分红 21.2 亿，一年回馈股东 32 亿欧元，占市值 5.2%。

**利润和现金流的差**——净利润 37 亿，经营现金流 99 亿，差了 62 亿，值得逐项对账：

| 项目 | 亿欧元 | 说明 |
|---|---|---|
| 净利润 | 37.2 | |
| + 折旧摊销 | 48.3 | 其中约 19 亿是 IFRS 16 租赁资产（租来的飞机、仓库）的折旧 |
| + 其他摊销 | 1.1 | |
| − 资产处置收益 | −1.5 | |
| + 其他非现金项目 | 16.8 | 养老金、拨备、递延税，账上计了费用但没付现金 |
| − 应收账款增加 | −21.6 | 营收涨得少但应收涨得多，客户付款变慢了，要盯 |
| − 存货增加 | −1.4 | |
| + 其他营运项目 | 20.4 | 应付账款和应计费用增加，大致抵掉上面的应收 |
| **= 经营现金流** | **99.3** | |
| − 资本开支 | −28.7 | |
| = 报表自由现金流 | 70.6 | stockanalysis 的数字，**虚高** |
| − 租赁本金偿还（藏在融资活动里） | −14.2 | IFRS 16 把租金搬到了融资项，但租飞机租仓库是实打实的经营开支 |
| **= 股东真正能拿的自由现金流** | **≈ 56** | 再扣 2.5 亿并购，约 54 亿 |

**这张表的核心结论**：自由现金流（56 亿）比净利润（37 亿）高 50%，不是因为利润造假，而是折旧（48 亿）比资本开支加租赁付款（43 亿）多——换句话说 DHL 现在每年花在维护和更新网络上的钱比账面折旧少 5 亿，加上养老金等非现金费用 17 亿。这个差额是真的，但不能指望它扩大：飞机和分拣中心该换还是要换。

**债务**：总债务 280 亿（含约 150 亿租赁负债），现金 43 亿，净负债 237 亿，是净利润的 6 倍多、EBITDA 的 2.8 倍。利息保障倍数 4.9 倍，一年付现金利息 10.8 亿。不危险，但这不是一张干净的资产负债表——有形账面价值的市净率 8.3 倍，说明 228 亿净资产里一大半是商誉。

## 第三部分：市盈率，多口径

市值 609.3 亿欧元。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 609 ÷ 37.2 亿净利润 | 16.4 倍 | 6.1 块 |
| 公司自己的口径 | 公司只讲 EBIT（含其他营业收入，比标准化口径高几亿）和"扣租赁扣并购后的自由现金流"约 33 亿（估算）；市值 ÷ 33 | 18.5 倍 | 5.4 块 |
| **剔除障眼法后的真实市盈率** | 609 ÷（37.2 − 1.0 亿处置收益税后）= 36.2 亿 | **16.8 倍** | **5.9 块** |
| 自由现金流口径 | 609 ÷ 56 亿（扣租赁付款后） | 10.9 倍 | 9.2 块 |
| 企业价值口径 EV/EBIT | （609 + 237 净负债）= 851 ÷ 60.4 亿经营利润 | 14.1 倍 | 7.1 块 |
| 三年平均利润口径 | 609 ÷（35.0 + 33.3 + 36.8）÷ 3 = 35.0 亿 | 17.4 倍 | 5.7 块 |

三年平均和当期几乎一样（17.4 倍 vs 16.8 倍），说明**现在的 37 亿不是周期高点**——2022 年海运费暴涨时它赚过 54 亿，那才是高点，早就回落完了。当前利润是正常水平，甚至偏保守（货代业务在运价低位）。

**大白话**：你现在投 100 块进去，按最保守的真实口径，公司一年替你赚 5.9 块；按股东真正拿到手的现金算，是 9.2 块。这 9.2 块里，**3.5 块以分红形式打到你账上（股息率 3.46%），3.9 块以回购形式注销股份（一年少 3.9% 的股本），加起来 7.4 块直接回到你口袋**——这是全场少见的、分红加回购都由真金白银的现金流覆盖的公司（回馈 32 亿 < 自由现金流 56 亿）。剩下的 2 块左右留在公司还债（TTM 净还债 14 亿）和小额并购。

这个 X 未来会变大还是变小？**大概率缓慢变大，但别指望快**：营收一年只涨 0.9%，利润靠降本（德国裁 8000 人）和快递的价格上调撑着；分析师给未来三年 EPS 增速 10.6%，一半来自回购缩股本。往下的风险是全球贸易量——DHL 是全球贸易的温度计，关税战、经济衰退直接打它的快递件量和货代运价。

## 第四部分：一句话结论

**值这个价，公道，但没有便宜可占。** 16.8 倍真实市盈率、11 倍现金流、7.4% 的真实股东回报率，买的是一门世界级的国际快递生意（贡献一半利润）外加四门利润率 5% 上下的搬运生意。账不算干净（237 亿净负债、商誉占净资产一大半），但现金流真实、回购真实、分红有覆盖。股价一年涨了 43%，从 2024 年底 11.8 倍涨到现在 16.8 倍，**便宜的窗口已经关了**——这个价格买进去，长期年回报大概率就是 7–9%，跟它的自由现金流收益率一样，不多不少。适合放在观察名单里，等下一次贸易恐慌把它打回 12 倍时再看。
