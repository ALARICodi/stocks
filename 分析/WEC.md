# WEC · 威斯康星电力集团（WEC Energy Group）

市值 $360.1 亿 / 股价约 $110.5 / 行业：公用事业（受监管电力与天然气）/ 数据口径：TTM，截止 2026 年 6 月 30 日

---

## 第一部分：它到底做几件事

WEC 是美国中西部的一家**受监管公用事业**。理解这家公司，先得理解"受监管"这三个字到底意味着什么——因为它决定了这门生意的一切。

### 这门生意的底层规则：花钱就是赚钱

普通公司想多赚钱，得多卖货或者提价。**受监管的电力公司不能自己定价**——威斯康星州公用事业委员会（PSCW）说了算。规则是这样运作的：

1. 公司把自己投在电网、发电厂、天然气管道上的**净资产**报给委员会，这叫 **费率基数（rate base）**。假设是 300 亿美元。
2. 委员会审核后批准一个**允许回报率**，通常在 9.5%–10% 之间，假设 9.8%。
3. 于是委员会允许公司从电费里赚 300 亿 × 9.8% = **29.4 亿的税前利润**。
4. 电价 = （燃料成本 + 运维成本 + 折旧 + 税）÷ 用电量 + 上面那笔允许利润 ÷ 用电量。

**这个规则的后果非常反直觉：公司多埋一根电线杆、多建一座变电站，费率基数就变大一块，委员会就允许它多收一块电费。** 也就是说，只要监管机构批准，**花钱本身就是这家公司的增长引擎**。这跟正常企业"花钱是成本"完全相反。

这也解释了后面财报上一个吓人的数字：TTM 资本开支 49.48 亿，是经营现金流 35.74 亿的 1.4 倍，自由现金流是 **负 13.73 亿**。对一般公司这是危险信号，对受监管公用事业这是**增长最快的时候**。

**一个普通家庭的账单长什么样**：密尔沃基一户人家一个月用 700 度电，账单大约 115 美元。其中大约 40 美元是燃料成本（天然气、煤炭）——这部分是**原样转嫁**的，涨了直接加到你账单上，公司一分钱不赚也不亏；剩下约 75 美元是输配电和固定成本，公司的允许利润就藏在这 75 块里。

按财报分部，是四门生意：

### 1）威斯康星（Wisconsin）—— 占四分之三

旗下 We Energies（密尔沃基一带）和 Wisconsin Public Service（格林湾一带），服务约 **220 万电力客户 + 110 万天然气客户**。这是绝对的主业。

**为什么这块 FY2025 猛涨 15.2%**：威斯康星东南部正在建**数据中心集群**。微软在 Mount Pleasant（拉辛县）买了 1,300 多英亩地建超大数据中心，Cloverleaf/Vantage 在 Port Washington 也在建。一个 300 兆瓦的数据中心，用电量相当于 20 万户家庭——而且它是 24 小时满载，不像家庭有峰谷。对 WEC 来说这意味着两件事：卖电量涨，以及**必须建新的发电和输电设施来供这些电，费率基数跟着膨胀**。公司已经宣布了一个 2026–2030 年 **280 亿美元**的资本开支计划，主要就是为这个。

### 2）伊利诺伊（Illinois）

Peoples Gas（芝加哥市区天然气）+ North Shore Gas，约 **100 万天然气客户**。

这块有一个持续几十年的工程：芝加哥地下埋着大量 19 世纪末、20 世纪初铺的**铸铁天然气管**，年久漏气，必须换成塑料管。这个工程叫 SMP（System Modernization Program），每年花 3–5 亿美元，全部计入费率基数——换句话说，**每换一米管子，芝加哥居民未来的燃气费里就多一点点利润给 WEC**。这个工程因为成本超支多次被伊利诺伊监管机构和消费者团体质疑，2025 年被要求重新审核节奏，是这块业务的主要监管风险。

### 3）其他州（Other States）

密歇根州上半岛（UPPCO 服务区）和明尼苏达的电力与天然气业务，规模小，约占 5.5%。

### 4）非监管能源基础设施（Non-Utility Energy Infrastructure）

这是**唯一一门不受费率监管的生意**，也是增速最快的（FY2025 +35.1%）。

具体做什么：WEC Infrastructure 出钱买风电场和太阳能电站的股权（通常买 80%–90%），比如德州的 Blooming Grove 风电场、伊利诺伊的 Sapphire Sky 风电场。这些电站发的电通过**长期购电协议（PPA）**卖给别的公用事业或大企业，一签 15–20 年、价格锁定。

**这块生意真正赚钱的地方不是电费，是税**。美国联邦政府给可再生能源发电提供**生产税抵免（PTC）**和**投资税抵免（ITC）**——每发一度风电可以抵掉一笔联邦所得税。WEC 把这些抵免拿来冲抵整个集团的税单，结果就是下面这个惊人的数字：

**TTM 有效税率只有 6.51%。** 一家税前赚 18.1 亿的公司，只交了 1.18 亿的税。正常美国企业的综合税率（联邦 21% + 州）在 24%–26%。

### 四门生意的钱（TTM，截止 2026-06-30）

| 生意 | TTM 营收（百万） | 增速（FY25 vs FY24） | 占比 | 特点 |
|---|---|---|---|---|
| 威斯康星 | 7,608 | +15.2% | 75.1% | 电+气，数据中心驱动 |
| 伊利诺伊 | 1,637 | +5.1% | 16.1% | 芝加哥燃气，换管工程 |
| 其他州 | 560 | +17.3% | 5.5% | 密歇根、明尼苏达 |
| 非监管基础设施 | 333 | +35.1% | 3.3% | 风电太阳能，**税抵免的来源** |
| **合计** | **10,137** | **+8.9%（TTM 口径）** | 100% | 整体经营利润率 **24.2%** |

四个分部加起来正好等于总营收，没有内部抵消。**财报不披露分部利润**，但公用事业的利润基本按费率基数比例分布，威斯康星占大头是确定的。

## 第二部分：把会计障眼法剥掉

公用事业有一套**独有的会计游戏**，跟科技公司完全不是一回事。

### 股权激励（SBC）：财报未单独披露

现金流量表上没有单列 SBC 行（被归进了"其他经营活动"）。公用事业公司的股权激励通常极小，估计在 3,000–5,000 万量级，占净利润 2%–3%，**可以忽略**。这不是粉饰点。

### 有效税率 6.51%：不是障眼法，但是个必须理解的杠杆

如前所述，这来自可再生能源的 PTC/ITC 抵免。三点判断：

1. **它是真实的、持续的**——不是一次性的会计花招，是税法给的，只要公司持续投风电就持续有。
2. **但它有法定期限**。PTC 通常在项目投运后享受 10 年，ITC 是一次性的。要维持低税率，公司必须**不停地建新的可再生项目**。
3. **它是政策风险的集中点**。联邦对可再生能源税收优惠的任何调整，都会直接、立刻打在 WEC 的净利润上。如果税率回到正常的 25%，TTM 净利润会从 16.92 亿掉到 **13.58 亿，少掉 20%**。

**下面第三部分的"真实口径"，我按正常税率重算了一遍，这是全文最重要的调整。**

### 一次性项目：资产减值 1.3 亿

TTM 计提了 1.3 亿的资产减值，大概率是某座煤电厂提前退役（WEC 在推进 2030 年前关停全部燃煤机组）。

**单期口径无法判断这是不是年年发生的项目**——但翻一下历史就有答案：FY2023 减值 1.789 亿，FY2024 减值 0.121 亿，TTM 1.3 亿。**这类减值在能源转型期间属于"经常性的一次性"**，公司在 Non-GAAP 里会把它剔掉，但你不该跟着剔——未来五年关停剩下的煤电机组，还会年年计提。

### 资本化的支出：公用事业最大的会计特色

两个必须知道的名词：

**AFUDC**（建设期资金成本资本化）：一座变电站建三年，这三年里投进去的钱本来该产生利息费用，但会计准则允许公用事业**把这笔利息记成资产而不是费用**，等电站投运后再通过折旧慢慢摊。效果是：**在建工程越多，当期利润看起来越好看**。WEC 现在正处在 280 亿资本开支计划的起点，这个数字只会变大。

**监管资产（Regulatory Assets）**：公司先垫付了某笔成本（比如一场风暴的抢修费、某个环保改造），监管机构承诺允许以后从电费里收回，于是这笔钱不记成当期费用，而是记成一项**资产**挂在账上。现金流量表上"其他经营活动 +2.979 亿"里，很大一部分就是这类递延项目的变动。

**这两样合起来，是公用事业行业最大的利润平滑器。** 它们不是造假——监管机构确实会批准回收——但它们让当期利润和当期真实的现金消耗严重脱节。

### 回购与稀释：这一项是明确的负分

| 项目 | TTM 金额（百万） |
|---|---|
| 回购股票 | 1.3（基本等于零） |
| **发行新股** | **410.4** |
| 股本变化（同比） | **+2.81%** |

按判断标准，回购 ÷ SBC 要大于 3 才算真回馈股东。WEC 是**反过来的**：它不回购，它**发股**。为了给 280 亿的资本开支计划筹钱，公司在持续增发。

**这件事的杀伤力有一个完美的实证**：

> FY2024 净利润 15.27 亿 → FY2025 净利润 15.58 亿，**涨了 2.0%**。
> FY2024 每股收益 $4.83 → FY2025 每股收益 $4.81，**跌了 0.4%**。

公司赚的钱变多了，你手上每股分到的钱反而变少了。中间那 2.4 个百分点，就是新发的股票吃掉的。**这是本文最该记住的一个事实。**

### 利润和现金流的差：逐项对账

净利润 16.92 亿，经营现金流 35.74 亿——差了 18.82 亿，差额比净利润本身还大。差在哪：

| 步骤 | 金额（百万） | 说明 |
|---|---|---|
| 净利润 | 1,692.0 | |
| + 折旧摊销 | **+1,514.0** | **差额主体**：电网、电厂、管道的折旧 |
| + 资产减值 | +130.0 | 煤电提前退役 |
| − 股权投资收益 | −53.6 | 参股风电项目的账面收益，非现金 |
| + 其他经营活动 | **+297.9** | **递延税 + 监管资产的变动** |
| − 应收账款增加 | −68.7 | |
| − 存货增加 | −41.6 | |
| + 应付账款增加 | +116.4 | |
| + 所得税项变动 | +36.1 | |
| − 其他净经营资产 | −48.2 | |
| **= 经营现金流** | **3,574.3**（实际 3,574） | **完全对上** |

差额结构很干净：**80% 是折旧（15.14 亿），16% 是递延税和监管资产（2.98 亿）**。没有猫腻。

### 但真正的问题在下一步：钱花到哪去了

| 项目 | TTM 金额（百万） |
|---|---|
| 经营现金流 | +3,574 |
| **资本开支** | **−4,948** |
| **= 自由现金流** | **−1,373（负的）** |
| 付股息 | −1,199 |
| 回购 | −1.3 |
| **缺口合计** | **−2,573** |
| 补缺口：净增借款 | +2,396 |
| 补缺口：发行新股 | +410 |
| 其他（收购、投资、卖资产等） | −206 |
| 净现金变动 | +27 |

**把这张表读一遍，你会得到一个必须知道的结论：你收到的 3.45% 股息，一分钱都不是从自由现金流里出来的——它是借来的，加上新股东交进来的钱。**

这不是庞氏骗局，理由是：那 49.48 亿的资本开支变成了实实在在的电网资产，进了费率基数，未来会通过电费一年一年收回来，并附带 9.8% 的允许回报。这是这个行业的正常商业模式。**但作为股东你必须清楚：这家公司现在处在"用未来的电费抵押今天的股息"的阶段，而且这个状态至少要持续到 2030 年。**

财务杠杆的量级：总债务 **230.23 亿**，是市值的 64%；债务/EBITDA = **5.79 倍**；利息保障倍数只有 **2.69 倍**（税前利润只够付 2.69 次利息）；TTM 现金支付利息 **8.73 亿**。这个杠杆在受监管公用事业里属于偏高但不异常——监管机构默认允许约 50/50 的债股结构。

## 第三部分：市盈率，多口径

市值 360.1 亿美元，企业价值 589.9 亿（因为背了 229.7 亿净负债，**EV 比市值高出 64%**）。

| 口径 | 怎么算 | 倍数 | 投 100 块年回报 |
|---|---|---|---|
| GAAP TTM 市盈率 | 360.1 亿 ÷ 16.92 亿净利润 | **21.3 倍** | 4.70 元 |
| 公司自己吹的 Non-GAAP | 剔除 1.3 亿减值（按 6.5% 税率约 1.22 亿）→ 18.14 亿 | 19.9 倍 | 5.03 元 |
| **剔除障眼法后的真实市盈率** | 360.1 亿 ÷（税前 18.1 亿 × 75% 正常税率 = 13.58 亿）；减值不剔，因为它年年发生 | **26.5 倍** | **3.77 元** |
| 自由现金流口径 | FCF 为 **−13.73 亿** | **无意义** | 负数 |
| 企业价值口径 EV/EBIT | 589.9 亿 ÷ 24.50 亿经营利润 | **24.1 倍** | 4.15 元 |
| 三年平均利润口径 | 360.1 亿 ÷ 三年均值 15.92 亿（TTM 16.92、FY25 15.58、FY24 15.27） | **22.6 倍** | 4.42 元 |

三年平均（22.6 倍）只比当期（21.3 倍）贵 6%，说明**这家公司的利润非常稳定，当期不在高点也不在低点**——这正是受监管公用事业该有的样子，利润由监管公式决定，不受经济周期影响。

但要盯住两行：

**自由现金流那一行是负的。** 这不是暂时的：FY2022 −2.54 亿、FY2025 −10.19 亿、TTM −13.73 亿，而且随着 280 亿的资本计划推进只会更负。**任何一个用"市值/自由现金流"来判断估值的框架，对这家公司都是失效的。**

**真实口径的 26.5 倍是全表最重要的数字。** 它假设有一天可再生能源税收抵免消失、公司按正常税率交税。这个假设不一定成真，但如果你按 21.3 倍买入而这件事发生了，你等于是按 26.5 倍买的。

### 说人话

**你现在投 100 块进 WEC，按最保守的真实口径（按正常税率纳税、减值算经常性成本）算，公司一年替你赚 3 块 77。**

这 3 块 77 里，回到你口袋的部分：

- **分红 3 块 45**（股息率 3.45%，每股 $3.81，**已连续 22 年增长**，派息率 73.76%）——几乎全额发出来了。
- **回购：0**。
- **但股本每年增加 2.81%**，你的持股比例在稀释。粗略算，你真正净得到的接近 **3.45 − 2.81 ≈ 0.6 元 + 每股收益随费率基数增长的部分**。

留在公司里再投资的：资本开支 49.48 亿远超折旧 15.14 亿，超出的 34 亿全是新增费率基数。**按 9.8% 的允许回报，这 34 亿理论上未来能带来约 3.3 亿的新增税前利润**——这是这家公司增长的全部来源，非常机械、非常可预测。

这个数字未来会变大还是变小？**会稳定地小幅变大，年化 6%–7%**，理由是：
1. 费率基数从现在的约 300 亿，按 280 亿资本计划推进，2030 年会到 450 亿以上，允许利润按比例增长；
2. 威斯康星的数据中心用电需求给了监管机构批准这些投资的正当理由；
3. 但**每年 2.8% 的股本稀释会吃掉其中很大一块**，落到每股上的增长可能只有 3%–4%。

风险清单（短且明确）：
- **利率**。230 亿债务，利率每涨 1 个百分点，长期看多付 2.3 亿利息，直接砍掉 14% 的净利润。这也是公用事业股票走势跟长期国债收益率高度反向的原因。
- **监管**。委员会不批准某笔投资进费率基数，或者压低允许回报率，利润立刻受损。芝加哥换管工程已经被质疑过。
- **可再生能源税收政策**。见上面 6.51% 有效税率那一段。

## 第四部分：一句话结论

**WEC 本质上是一张 3.45% 收益率、22 年没断过、还能每年涨 6% 的债券——不是股票。它的确定性来自监管公式而不是竞争力，它的股息来自借款和增发而不是自由现金流，它的低税率来自一项可能变的政策。21 倍的表面市盈率在按正常税率还原后是 26.5 倍，对一个每年真实每股增长只有 3%–4% 的生意来说，这个价格谈不上便宜，但也不荒谬。**

买它的唯一正当理由：你想要一份比国债多一点、每年会涨的现金流，并且能接受"公司账面赚的 4 块 7 里，有 2 块 8 被新发的股票吃掉"这件事。想赚股价的钱，找别家。
