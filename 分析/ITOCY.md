## 第一部分：它到底做几件事

"综合商社"这个词在日本以外没有对应物。它的祖先是**贸易中间商**（伊藤忠 1858 年从卖麻布起家），一百多年下来，靠贸易攒下的关系和钱，把上下游的公司一家一家买下来，变成了**一个装着几百家公司的控股平台**。伊藤忠在五大商社（三菱商事、三井物产、伊藤忠、住友商事、丸红）里的特点是：**最不靠矿，最靠消费。** 巴菲特 2020 年买了五大商社各 5%，之后加到 10%，伊藤忠是其中之一。

它的财报按八个部门分（TTM 收入 15.14 万亿，比 2026 财年 +3.1%）。挑重要的讲：

### 1. 食品——全家便利店 + 食品批发（收入 5.12 万亿，占 34%，2026 财年口径）

**这是伊藤忠跟其他商社最大的不同：它拥有全家（FamilyMart）。** 2020 年把全家全部私有化，日本 1.6 万家店，每天 1,500 万人进店买饭团、咖啡、交水电费、取快递。便利店的钱不是从卖东西上赚的（毛利率 30%，扣掉房租人工所剩无几），是从**加盟费**上赚的——加盟主出人出力，全家收营业毛利的 40–60% 当加盟费，另外还有 FamiPay 支付、店内广告屏、自有品牌"FamilyMart 收藏"（毛利率比可口可乐高一倍）。

食品这块还包括：**Dole 亚洲**（菲律宾香蕉、菠萝，亚洲鲜果第一），**日本 Access**（日本最大的食品批发商，全家的货一半从它走），Prima 火腿，不二制油（巧克力用油脂全球第一）。

**这门生意的逻辑是垂直整合**：不二制油的油脂→Prima 的火腿→日本 Access 的配送车→全家的货架→FamiPay 扫码。每一环伊藤忠都抽一道。

### 2. 能源化工（收入 3.18 万亿，占 21%，+5%）

进口原油和 LNG 卖给日本的炼厂和电力公司，进口石脑油、甲醇、合成树脂卖给日本的化工厂和汽车厂，出口日本的精细化工品。**收入大、利润薄**，赚的是贸易价差和物流费，另外持有阿塞拜疆 ACG 油田、卡塔尔 LNG 的少量权益。近几年往储能电池（跟宁德时代合作在日本卖储能）、可再生燃料上转。

### 3. 机械（收入 1.53 万亿，占 10%，+1.7%）

三块：**Yanase**（日本最大的进口车经销商，卖奔驰、宝马、奥迪），**汽车出口**（把五十铃、马自达、铃木的车卖到东南亚、非洲、中东，在当地做总代理），**基建**（船舶、飞机租赁、电站、海水淡化）。持有日立建机 26%（2022 年从日立手里买的）。

### 4. 金属矿产（收入 1.28 万亿，占 8.5%，+4%）

跟必和必拓合伙的西澳铁矿（伊藤忠占 8%）、巴西 CSN 铁矿、澳大利亚煤矿、铝。**这是利润最大头之一，但完全看铁矿石价格**——2021 年铁矿 200 美元/吨时这块一年赚 2,000 亿，现在铁矿 100 美元出头，赚 1,200 亿左右。伊藤忠这块比三菱、三井小得多，所以它的利润比同行稳。

### 5. 生活资材和不动产（收入 1.55 万亿，占 10%，+1.6%）

北美的建材生意（Master-Halco 是美国最大的围栏批发商，Alta Forest Products 造木栅栏），芬兰 Metsä 的纸浆，橡胶轮胎贸易，日本的物流地产和公寓开发。

### 6. IT 和金融（收入 1.14 万亿，占 7.5%，+3.6%）

CTC（伊藤忠科技，日本 IT 集成商第一梯队，2023 年私有化），Bell System24（呼叫中心外包），"保险窗口"（日本最大的保险代理连锁），Orient Corporation 消费信贷 20%，Pocket Card 信用卡，以及 2024 年接盘丑闻缠身的 Big Motor 改名 **WECARS**（日本最大的二手车连锁）。

### 7. 纺织（收入 6,920 亿，占 4.6%，+2%）

伊藤忠的老本行，今天是**品牌授权公司**：Converse 日本、Hunting World、LeSportsac、Paul Smith 日本、Descente（2024 年私有化）。它买下品牌在日本或亚洲的权利，找工厂生产，通过百货和自己的渠道卖。利润率是全公司最高的部门之一。

### 8. "第 8 公司"（收入 5,120 亿，占 3.4%）

2019 年专门为全家成立的部门，做全家周边的新生意：店内广告网络、会员数据、FamiPay 金融。

### 藏在利润表下面的：中信集团 10%

2015 年伊藤忠花 6,000 亿日元买了中国中信股份 10%，按权益法记利润，**每年贡献约 1,000 亿日元的权益法收益**，是集团单一最大的利润来源之一——它不在上面任何一个部门的收入里，直接进净利润。TTM 权益法收益合计 3,713 亿，占净利润 41%。

### 钱的分布

公司披露各部门的**归属净利润**，不披露经营利润。下表用公司最近年报的部门净利润比例估算（食品和第 8 公司 TTM 收入缺失，用 2026 财年数）：

| 部门 | 收入（亿） | 占比 | 归属净利润（估算） | 占净利润 |
|---|---|---|---|---|
| 食品（全家等） | 51,217 | 34% | 约 900 | 10% |
| 能源化工 | 31,796 | 21% | 约 1,200 | 13% |
| 机械 | 15,265 | 10% | 约 1,500 | 16% |
| 金属矿产 | 12,833 | 8.5% | 约 1,200 | 13% |
| 生活资材不动产 | 15,534 | 10% | 约 800 | 9% |
| IT 金融 | 11,428 | 7.5% | 约 1,200 | 13% |
| 纺织 | 6,920 | 4.6% | 约 400 | 4% |
| 第 8 公司 | 5,124 | 3.4% | 约 350 | 4% |

一句话：**没有一个部门超过 17%，这是它最大的优点——也是它最大的问题：你买的是一篮子平均水平的日本生意。**

## 第二部分：把会计障眼法剥掉

**股权激励 SBC**：日本商社几乎没有，财报未单列，忽略。

**一次性项目（TTM）**：出售投资收益 828 亿（2026 财年 1,752 亿、2025 财年 832 亿、2024 财年 348 亿）。**商社年年都在卖资产、买资产（他们叫"资产循环"），这笔收益单期看是一次性，多年看是常态**。本文按一半算作真实利润的一部分：真实净利润 = 9,101 − 828 × 70%（税后）× 50% ≈ 8,810 亿。

**资本化的支出**：没有值得一提的。

**回购与稀释**：TTM 回购 1,300 亿，SBC 为零，是**真回购**，股本一年减 1.54%。加分红 2,947 亿，合计回馈股东 4,247 亿，占净利润 47%。

**利润和现金流的差**：净利润 9,101 亿，经营现金流 9,929 亿，自由现金流 7,079 亿——看起来很健康，**但有两件事被 IFRS 藏起来了**：

| 项目 | TTM 金额（亿） | 说明 |
|---|---|---|
| 净利润 | 9,101 | |
| + 折旧摊销 | 4,623 | **其中约 2,600 亿是全家店铺的租赁折旧**（IFRS 16 把房租变成了折旧） |
| − 权益法收益 | −3,713 | 中信、日立建机这些按比例记的利润，不是现金 |
| − 出售投资收益 | −828 | |
| + 其他非现金项（含从权益法公司收到的分红约 2,000 亿） | 2,857 | |
| − 营运资金增加 | −2,115 | |
| = 经营现金流 | 9,929 | |
| − 资本开支 | −2,850 | |
| = 表上的自由现金流 | 7,079 | |
| − **租赁付款（记在筹资活动里）** | **−2,636** | **全家 1.6 万家店的房租** |
| = **真正的自由现金流** | **约 4,440** | |

**第一件事**：全家的房租 2,636 亿在 IFRS 下记在筹资活动，不在经营活动。房租不是可选的，不付就得关店。所以真正能自由支配的现金是 4,440 亿，不是 7,079 亿。**这个数刚好等于分红加回购的 4,247 亿**——伊藤忠把真正的自由现金流全部分给了股东，一分不剩。

**第二件事**：那它每年买资产的钱从哪来？TTM 投资证券 2,098 亿，靠**净新增借款 1,821 亿**。有息负债 5.24 万亿加租赁负债 1.08 万亿，合计 6.3 万亿，是净资产（7.19 万亿）的 88%。**14% 的 ROE 里有一半是杠杆撑出来的**——ROIC 只有 5.2%，这才是这堆生意真正的赚钱能力。

## 第三部分：市盈率，多口径

市值 **152,303 亿日元**，企业价值 200,357 亿（净负债 43,850 亿 + 租赁负债约 10,800 亿）。

| 口径 | 怎么算 | 倍数 | 投100块年回报 |
|---|---|---|---|
| GAAP（IFRS）TTM 市盈率 | 152,303 ÷ 9,101 | **16.7 倍** | 5.98 元 |
| 公司自己吹的 | 商社不报调整口径，公司口径就是"归属净利润"，同 GAAP | 16.7 倍 | 5.98 元 |
| **剔除障眼法后的真实市盈率** | 152,303 ÷ 8,810（出售收益按一半算作经常性） | **17.3 倍** | **5.78 元** |
| 自由现金流口径（表上） | 152,303 ÷ 7,079 | 21.5 倍 | 4.65 元 |
| **自由现金流口径（扣掉全家房租）** | 152,303 ÷ 4,440 | **34.3 倍** | **2.9 元** |
| 企业价值口径 EV/EBIT | 200,357 ÷ 7,366（不含权益法收益） | 27.2 倍 | 3.7 元 |
| 企业价值口径 EV/（EBIT + 权益法收益） | 200,357 ÷ 11,079 | 18.1 倍 | 5.5 元 |
| **三年平均真实利润口径** | 152,303 ÷ 8,300（2025 财年约 8,510、2026 财年约 8,390、TTM 8,810 的平均） | **18.4 倍** | **5.4 元** |

三年平均那一行说明：**利润三年基本没动（8,000 亿上下），但市值从 2024 年 3 月的 9.3 万亿涨到 15.2 万亿，涨了 64%。** 同一家公司，2023 年 7.8 倍市盈率、市净率 1.15；现在 16.7 倍、市净率 2.12。**这三年的股价涨幅，全部是估值抬升，没有一分是利润增长。** 巴菲特买的时候是 0.7 倍市净率下面捡便宜，现在是 2.1 倍。

**大白话**：你投 100 块进去，按剔除障眼法的真实口径，公司一年替你赚 5.78 块。这 5.78 块里：

- **1.98 块以分红打到你账上，0.85 块用来回购**，合计 2.8 块。
- 剩下的 3 块**名义上留在公司再投资**——但看现金流，公司每年的真自由现金流只够付分红和回购，再投资的钱全是借的。留在公司里的 3 块，一部分是中信那种"记了利润没拿到现金"的权益法收益，一部分变成了新买的公司股权。
- 这个 5.78 块未来会**缓慢变大，一年 3–5%**：全家在提价、纺织和 IT 在稳步增长，铁矿和能源看行情。它没有爆发的引擎，也没有崩盘的风险——就是一台年化 5% 慢慢转的机器。

## 第四部分：一句话结论

**17 倍市盈率、2.1 倍市净率、真正的自由现金流只够付分红——这个价格偏贵了。** 伊藤忠是五大商社里最稳的一家（不靠矿、靠全家和一堆日本消费生意），ROE 14% 稳了六年，管理层对股东也真诚（分红加回购占利润一半）。但它的生意本质是"一篮子 ROIC 5% 的平庸生意加上一倍杠杆"，值 10–12 倍，不值 17 倍。过去三年 64% 的涨幅全是估值抬升，利润一分没涨，**这是巴菲特效应和日本股市热钱把它抬上来的**。等它回到 12 倍以下、市净率 1.5 倍以下再看。
