ROA1.39%的优等生银行卖平庸价，本会话四家银行里首选

FFBC · First Financial Bancorp（第一金融，辛辛那提银行）

市值 34.5 亿美元 / 股价 32.82 美元 / 行业：金融·区域银行 / TTM 截止 2026-06-30（任务2 · 市盈率 0–15 倍段 · 榜内第 260 名）

这是银行，用市净率 + ROE 口径（理由同前几家银行：利润建立在十倍杠杆上，市盈率藏杠杆）。这是本会话第五家银行，直接说它跟前四家（VLY、FULT、TOWN、以及任务2段里成片的同行）比有什么不同。

第一部分：它到底做几件事

总部俄亥俄州辛辛那提，1863 年拿的国民银行牌照（美国最老的一批），总资产约 200 亿美元，网点在俄亥俄、印第安纳、肯塔基、伊利诺伊四州。一门生意加三个「利差放大器」——它是本会话见过的银行里赚钱效率最高的一家（ROA 1.39%，同行普遍 1.0–1.2%），高出来的部分全靠特色业务：

主体：中西部社区商业银行

标准剧本不重复：给辛辛那提周边的制造业中小企业放贷吸储。值得说的是它的存款质地——四州小城镇的散户和企业存款，成本低、粘性高，是利差的地基。

三个利差放大器（它和平庸同行的差别所在）

  • 设备融资（Summit Funding Group）：给全美的中小企业做机床、卡车、医疗设备的融资租赁——收益率比普通商业贷款高好几个点，全国展业不受本地网点限制。
  • 保费金融（Agile Premium Finance）：企业买商业保险时保费一次交不起，它垫付、按月收回，短周期高周转的小额贷款。
  • 外汇经纪（Bannockburn Global Forex）：给中型企业做跨境收付的外汇对冲和兑换，赚点差和佣金——纯手续费收入，不占资本，是同行少有的现金奶牛。

这三块合起来把它的净息差推到 4% 上下（估算，行业平均约 3%），这就是 ROA 1.39% 的来源。代价是设备融资和保费金融的坏账率天然比房贷高，衰退年份拨备会比纯房贷银行难看——高收益从来不是白来的。

TTM 动作：收购了俄亥俄同城的 Westfield Bancorp（保险集团旗下银行，现金+换股，股本因此一年 +5.4%），继续在四州版图里补密度。

钱（TTM）：营收 9.53 亿（+21.9%，并购+利差双驱动）、净利润 2.85 亿、ROE 10.3%、ROA 1.39%、拨备 0.36 亿（正常水平）、实际税率 20%。

第二部分：把会计障眼法剥掉（银行版）

  • 拨备：TTM 0.36 亿，占贷款约 0.3%，比纯房贷行高是业务结构使然，处于它自己的正常区间，无垫利润迹象。
  • 一次性项目：并购 Westfield 的整合费用压着当期利润（方向是压低），FY2024 有证券组合重摆的 0.26 亿亏损——都不改变量级。
  • 稀释：股本一年 +5.4%（并购换股），无回购。分红 TTM 1.01 亿，股息率 3.2%，派息率 37%，健康。
  • 有形净资产被商誉吃掉一截：PB 1.15 但 P/TBV 1.95——连年并购攒的商誉。按有形口径 ROTCE 约 18%（估算），效率确实高，但你为这份效率付了近两倍有形净资产的价。
  • 资本：CET1 约 12%（估算），充裕。

第三部分：估值（银行口径）

和本会话其他银行摆在一起（投 100 块年回报口径）：FFBC 9.0 / FULT 8.9 / VLY 8.8 / TOWN 6–7。FFBC 的生意质量最高（ROA 1.39 vs 同行 1.0–1.2），价格却和平庸同行一个价——同样的钱买到更好的银行。

大白话：你投 100 块进去，一年赚 9 块，3.2 块分红到手，剩下的留在行里滚资产。未来看点：Westfield 并表增厚 + 设备融资全国扩张（正面），衰退时特色贷款的坏账弹性（负面）。52 周涨了 22.5%、PB 从 0.89 回到 1.15，便宜段同样已被买走一截，但它是四家银行里唯一「质量配得上价格」的。

第四部分：一句话结论

本会话见过的最会赚钱的区域银行：一百六十年老牌照 + 三个高收益特色业务把 ROA 做到 1.39%，同行里排前列，股息 3.2%、派息保守、资本充裕。1.15 倍 PB 是区域银行的普通标价，但它不是普通银行——质量高一档、价格没多收，公道里最接近便宜的一家。要在这个段位配一家银行，选它优先于 VLY/FULT/TOWN。公道，生意一般偏好。
