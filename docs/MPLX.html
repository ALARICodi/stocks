收费站生意账最干净,但MLP分红中国人预扣37%

MPLX · MPLX LP（马拉松石油旗下管道合伙企业）

市值 $600.7亿 / 股价约 $59.5 / 能源中游（管道与集输，MLP 结构）/ TTM 截至 2026-06-30

先说清一个身份问题：MPLX 不是普通公司，是一家 MLP（业主有限合伙）。它的"股票"其实叫合伙单位，母公司马拉松石油（MPC，美国最大炼油商之一）握着约 64% 的份额并且是总管理人。这个结构决定了它几乎不交企业所得税（TTM 只交了 900 万美元，税率 0.19%），赚的钱几乎全额往外分——TTM 分红 42.6 亿美元，股息率约 7.1%。这既是它市盈率低的原因之一，也是后面结论里那个大坑的来源。

第一部分：它到底做几件事

生意一：原油与成品油物流（约占营收 55%）

这门生意说白了就是给炼油厂当"血管"。马拉松石油在全美有十几座炼油厂，原油要从油田、港口运进去，汽油柴油要从炼油厂运出来送到各地油库，这些管道、储罐、码头、驳船大部分不是炼油厂自己的，是 MPLX 的。

怎么收钱：按量收过路费。一桶原油走一段管道收几十美分到一美元多的运费，存进储罐按月收租，码头装卸按吞吐量计费。合同是长期的，而且普遍带最低运量承诺——就算马拉松今年少炼了油，没走够合同量也得按承诺量付钱。举个具体例子：马拉松位于德州加尔维斯顿湾的炼油厂每天要"吃"几十万桶原油，这些油从墨西哥湾码头卸下来、走 MPLX 的管道进厂，炼成汽油后再走 MPLX 的成品油管道发往内陆油库——一进一出，MPLX 两头收费，一年从母公司身上收走几十亿美元。

关键点：它最大的客户就是自己的老板。这段收入的大头来自与马拉松石油的关联交易，运费费率是母子公司之间谈出来的。好处是收入极稳（炼油厂只要开工就得用），坏处后面结论里说。

TTM 营收构成：服务费 48.7 亿 + 储罐租金 10.1 亿 + 融资租赁 4.0 亿 + 合资管道分红 2.4 亿 + 其他约 1.3 亿。

生意二：天然气与 NGL 服务（约占营收 45%）

这门生意在产业链更上游：去气田井口收气、加工、拆分、再卖掉。美国页岩气田（MPLX 主战场是阿巴拉契亚的 Marcellus 气田和西部的二叠纪盆地）打出来的天然气是"湿气"，里面混着乙烷、丙烷、丁烷这些天然气凝析液（NGL）。MPLX 的小口径集输管道像毛细血管一样接到几千个井口，把湿气收进处理厂，分离出干气（送进州际管网卖给电厂、城市燃气公司）和 NGL（拆分成乙烷卖给化工厂做塑料、丙烷装罐卖给取暖经销商）。

怎么收钱：一部分按处理量收固定加工费，一部分是"卖产品"——TTM 里有 24.8 亿美元营收是直接卖 NGL 产品的钱，这部分随丙烷、乙烷价格波动，是全公司唯一明显吃商品价格的环节。2025 年公司还花 33 亿美元把 BANGL 管道（把二叠纪的 NGL 运到墨西哥湾出口码头）剩余股权全部买下，赌的是美国 NGL 出口继续涨。

TTM 营收构成：服务费 25.1 亿 + 产品销售 24.8 亿 + 合资项目分红 4.6 亿 + 租金与其他约 11.2 亿。

第二部分：把会计障眼法剥掉

  • 股权激励（SBC）：现金流量表里根本没有这一行。MLP 的员工编制和高管薪酬大都挂在母公司马拉松石油那边，MPLX 自身 SBC 约等于零。这是少数"不用担心 SBC 骗局"的公司。
  • 一次性项目：TTM 净利里藏着约 1.6 亿美元资产出售收益 + 约 2.65 亿股权投资重估收益（把 BANGL 剩余股权买下时，原持有部分按新价重估出的账面利得，不是现金），合计约 4.2 亿，占净利润约 9%。单期口径无法判断是否年年发生——但 2022 年也有 4.75 亿出售收益，这家公司隔三差五就腾挪资产，把它当成"经常性的一次性"更稳妥，下面真实市盈率把它剔掉。
  • 资本化的支出：管道公司的资本开支天然全部资本化，没有软件/内容资本化的猫腻。要注意的是 capex 从 2023 年的 9.4 亿飙到 TTM 的 26.4 亿，公司口径里维护性开支只占约 2 亿，其余都是扩建（新处理厂、BANGL 扩容）——钱是真花了，但花在长大上，不是维持现状的成本。
  • 回购与稀释：TTM 回购 3 亿美元，SBC 为零，所以回购是纯回馈；股本一年降 0.54%。不过回购在这里是配角，主角是 42.6 亿分红。
  • 利润和现金流的差：净利 47.2 亿 vs 经营现金流 59.8 亿 vs 自由现金流 33.4 亿。对账很干净：净利 47.2 → 加折旧摊销 14.5 → 减资产出售收益 1.6 → 减股权重估收益 2.7 → 加合资分红与营运资金等约 2.4 → 经营现金流 59.8。FCF 比净利低不是利润造假，是 26.4 亿 capex 里大头是主动扩建。这是一份罕见地干净的账：利润基本就是现金。

三年平均 13.9 倍和当期 14.0 倍几乎一样——当前利润不是周期高点，是一路稳步爬上来的，这点比大多数能源股干净。

大白话：你投 100 块进去，按剔除一次性利得的真实口径，公司一年替你赚约 7.2 块。这 7.2 块里约 7.1 块当年就以现金分红打到你账上（42.6 亿分红 ÷ 600 亿市值），MLP 就是这么设计的：不留钱、全上缴。扩建的钱哪来？发债——TTM 净新增借款 38 亿，扩张全靠加杠杆。所以这 7.2 块的回报是踩在 4.2 倍 Debt/EBITDA 的杠杆上的，利息保障倍数 4.1 倍，中游行业算正常水位，但利率再上一个台阶它的分红增速就得慢下来。

但是——中国投资者请先看这段再看结论：MLP 的分红在美国税法里不是"股息"，是"合伙经营收入分配"。外国人持有 MLP，分红按最高边际税率 37% 预扣（不是中美协定下普通股息的 10%），卖出时券商还要按成交额再扣 10%（IRS 1446(f) 条款）。上面那 7.1 块分红，到你手里只剩约 4.5 块，卖出时还要被啃一口本金。这不是理论风险，是每一笔分红都会实际发生的扣款。

第四部分：一句话结论

生意本身是教科书级的收费站：管道建好了没人能再建第二条，客户（也是老板）的炼油厂离了它转不动，账干净得罕见，利润全是真现金而且几乎全分给你。12.75 倍的标价里含着三个折价——税表麻烦（美国人拿 K-1 报税头疼）、母公司既当客户又当老板（运费定价你说了不算，将来低价私有化你也挡不住）、4 倍杠杆。对能正常拿分红的美国投资者，这个价算公道，7% 现金股息拿着很舒服；对中国投资者，37% 的预扣税直接把回报砍掉三分之一，7.2 块变 4.5 块，等于把公道价买成了贵价——这家公司好，但不适合你买。
