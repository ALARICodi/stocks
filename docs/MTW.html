股价翻倍后35倍赌周期反转,利息吃半数利润,股东零回报

MTW · 马尼托瓦克（The Manitowoc Company）

市值 $7.06 亿 / 股价 $19.59 / 工程起重机制造 / TTM 截止 2026-06-30

第一部分：它到底做几件事

一家 1902 年成立的威斯康星老牌制造商，如今就做一件事：造起重机（造船和餐饮设备业务早年都剥离了）。虽然财报按地区分部（美洲/欧非/中东亚太），实质上是一门生意的四个品种：

塔式起重机（Potain 品牌，法国血统，全球第一）

城市里盖高楼时，楼顶上那台横臂缓缓转动的塔吊，全球最大的牌子就是它家的 Potain。一台中型塔吊几十万到几百万美元。买家主要是设备租赁公司和大承包商——迪拜盖塔、巴黎改造、东南亚修地铁，工地上林立的 Potain 往往不是开发商买的，是租赁商买了按月出租。塔吊是订单制生意，跟着全球房建和基建开工量走，利率一高、开工一停，订单立刻断崖。

移动式起重机（Grove 品牌，美国主力）

装在轮式底盘上、开到现场把吊臂伸出去的那种伸缩臂起重机。北美数据中心工地吊装钢结构、电力公司换变压器、修桥换梁，用的就是这类。一台百吨级全地形起重机报价一百多万美元。这块是它美洲收入的主力，眼下最大的需求来自数据中心建设潮和美国基建法案的钱。

履带式起重机（Manitowoc 品牌，重型旗舰)

几百上千吨级的巨型履带吊，装风电风机、吊核电站模块用的。单台几百万到上千万美元，一年卖不了多少台，但单价高、波动最猛。

后市场（增长重心，利润质量最好的一块）

卖出去的每台起重机都要用二三十年，配件、维修、翻新、旧机翻卖、短租——公司这几年战略就是把这块"不看天吃饭"的收入做大（2021 年花 $1.86 亿收购了几家起重机服务商），目前约占收入四分之一强（公司披露口径，占比为估算）。一台服役十年的 Grove 换一套吊臂钢丝绳加大修，一单几十万美元，利润率比卖新机高得多。

第二部分：把会计障眼法剥掉

  • 股权激励（SBC）：TTM $8.5M，占净利润 42%——不是 SBC 特别多，是净利润太薄，衬得它扎眼。照扣。
  • 一次性项目：TTM 窗口内没有大额减值（FY2022 那笔 $171.9M 商誉减值把当年砸成 -$123.6M 巨亏，已是历史）。但 TTM 有效税率高达 36.9%（正常应约 25%），有海外亏损抵扣不了的结构性因素，单期口径无法判断是否年年如此。
  • 资本化的支出：无重大资本化花招，CapEx 一年 $43M，与折旧 $62M 相比是收着花的。
  • 回购与稀释：TTM 回购 $0，SBC $8.5M，比值为零；股本一年膨胀 3.6%。也不分红。股东从这家公司拿到手的现金回报是零，还每年被稀释。
  • 利润和现金流的差：TTM 经营现金流 $112.4M，比净利润 $20.2M 高 5 倍多。对账：净利 $20.2M → 加折旧摊销 $63.3M → 加 SBC $8.5M → 应付款增加 +$14.4M → 其他营运资金净释放 +$25.3M → 存货应收合计 −$11.7M → ≈ $112.4M。看着漂亮，但别当真——大头是折旧和这一期恰好释放的营运资金。拉长看真相残酷：FY2023 自由现金流 −$14.4M、FY2024 +$3.5M、FY2025 −$28.2M，过去三个完整财年 FCF 合计约为负，TTM 的 $69.4M 是营运资金摆动出来的一期性好看。
  • 杠杆：净债务 $442M，Debt/EBITDA 3.3，利息保障倍数只有 1.99——经营利润的一半拿去付了利息。这是净利润被压得只剩 $20M 的直接原因之一。

大白话：你现在投 100 块进去，按真实口径公司一年替你赚 2.8 块，而且一分钱都不给你——不分红、不回购，赚的钱先付银行利息、再补工厂，剩下的留在这台周期机器里等下一轮景气。三年平均口径 20.7 倍稍好看些，但那三年里最好的一年也只赚了 $55.8M——这家公司过去十年横跨牛熊，从来没有哪一年配得上 7 亿以上的市值贴 20 倍。真正让股价一年翻倍（+94%）的不是利润，是故事：数据中心和基建撑起的订单预期、美国制造的关税叙事、以及"周期股买在利润最烂的时候"的博弈逻辑。这个故事可能成真——但 35 倍买的是别人已经替你抢跑了一倍之后的入场券。

第四部分：一句话结论

全球数一数二的起重机品牌，却是门利润薄如纸、半数经营利润交给债主、五年攒不下自由现金、对股东零回报的苦生意，股价一年翻倍后 35 倍买它等于高价赌周期反转——贵得没道理，真想赌周期也该在没人要它的时候买。
