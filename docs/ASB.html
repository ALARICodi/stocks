9%ROE银行卖出史上最高1.06倍PB,还叠一笔用途不明的14%增发

ASB · 联合银行（Associated Banc-Corp）

市值 $57.7 亿 / 股价 $30.92 / 银行（威斯康星） / TTM 截止 2026-06-30 / 任务2（0–15倍段）第 187 名

这是金融企业，下面用 市净率 PB + ROE 口径而不是市盈率，原因同业：银行利润是杠杆撬出来的利差，要看「按几倍净资产买入、净资产每年生多少利」。

一、它到底做几件事

一门生意：威斯康星州最大的本土银行，总部绿湾（就是橄榄球包装工队那个绿湾），总资产约 470 亿美元，网点铺满威斯康星，延伸到明尼苏达和伊利诺伊。按分部拆是两块：企业与商业专营（TTM 营收 6.43 亿——给中西部的奶制品厂、造纸厂、设备制造商做贷款和现金管理，还有商业地产）、社区与消费（10.5 亿——个人账户、房贷、小微企业），另有资金管理条线的抵销项。

生意本体是标准的中西部存贷手艺，不用赘述。看懂 ASB 要看它这三年干的两件大事：

第一件：两轮「割肉换血」。 2023 年末和 2024 年末，它两次把账上低收益的老债券和低息房贷亏本卖掉，把回笼的钱转投高收益资产。代价直接打在利润表上：FY2023 净利润 1.70 亿、FY2024 只剩 1.11 亿（资金管理分部当年营收 -5.88 亿，就是卖资产的亏损计在这里），两年 ROE 被压到 4.5% 和 2.8%。这属于「早疼早利索」的自残式手术——把过去低利率时代的错误一次认掉。TTM 净利润 4.92 亿（ROE 回到 9.7%）就是手术后的成绩：确实见效了。

第二件：刚刚大幅增发。 股本同比 +7.2%，其中最近一个季度就增了 14%——这是一笔大额增发，数据源没写用途（银行增发通常为并购或补资本）。不管用途是什么，对现有股东就是实打实的稀释：手术刚见效，蛋糕先切走一块。单期口径无法判断这笔增发换回了什么，这是本篇最大的未知数。

真实速度看五年 ROE：8.7% → 9.1% → 4.5% → 2.8% → 9.9% → 现在 9.7%——剔掉手术两年，这就是一家常年 9% 上下的银行，和 FNB 同一档。

二、把会计障眼法剥掉（银行版）

  • 一次性项目：TTM 里已无大额卖资产亏损（手术完成），当前利润是干净的运营利润；但同比增速（EPS +264%）全是低基数幻觉，别当真。
  • 稀释与回购：上面说的增发是主角：FY2025 稀释 8.7%、过去一年再稀释 7.2%（其中最近一季 +14%）。分红每股 $0.96，股息率 3.10%，派息率 34%——分红是真的，但一边分红一边增发，等于左手发钱右手收回去一部分。
  • 商誉：PB 1.06 vs P/TBV 1.38，差了 30%——有商誉但比 FNB/UBSI 轻。
  • 现金流：银行口径无异常。
  • 数据源未提供 NIM、CET1、拨备覆盖率，不编数。定性：两轮重组后资产端收益率已修复，这正是 ROE 从 2.8% 回到 9.7% 的引擎。

大白话：你投 100 块进去，按 1.06 倍买了 94 块净资产，每年生出约 9.2 块，其中 3.1 块分红到手。 三年平均口径 23 倍难看是因为把手术费算进去了，不必按字面理解；但它提醒你一件事：这家银行上一次犯错（低利率时代囤长债）的账单就值两年利润，而你没有办法确认它以后不再犯。

真正扎手的是价格坐标：五年来市场从来只给它 0.76–0.85 倍净资产——比 FNB 还低半档——现在手术成功加银行板块行情，一口气给到了 1.06 倍，历史上从没这么贵过。而它手术后的 ROE（9.7%）和手术前（9.1%）其实只差半个点：资产端修好了，商业模式没变。叠加刚发生的 14% 增发悬案，现在买它，等于按史上最高估值买一家刚证明过自己会犯大错、且正在稀释你的 9% ROE 银行。

四、一句话结论

割肉换血的手术做得果断、也确实见效，但市场把功劳簿写得太满：一家常年 9% ROE 的威斯康星银行，五年里从没值过 0.9 倍净资产，现在卖 1.06 倍，还叠着一笔用途不明的 14% 大增发——手术成功≠脱胎换骨，史上最贵的价格买史上同一家银行，偏贵，等增发用途揭晓、估值回到 0.9 倍以下再看。
