第一部分:它到底做几件事

LivaNova 是 2015 年美国 Cyberonics 和意大利 Sorin 合并出来的公司,总部注册在伦敦。砍掉心脏瓣膜、人工循环支持等杂项后,现在实质上就剩两门生意,而且两门都是各自细分领域的全球第一。

生意一:心肺机及耗材(Cardiopulmonary)——心脏手术时替你"活着"的机器

做心脏搭桥、换瓣膜这类开胸手术时,外科医生要把心脏停下来才能下刀。心脏停了人怎么活?靠 LivaNova 的体外循环心肺机:血液从静脉引出体外,机器代替肺给血液充氧、代替心脏把血泵回动脉,病人靠这台机器"活"两三个小时,直到手术做完心脏重新起跳。LivaNova 的 S5 和新一代 Essenz 是全球用得最多的心肺机,装在全球几千家心脏中心的手术室里,一台卖十几万到三十万美元。

但真正的赚钱机器不是机器,是一次性耗材:每做一台手术,都要用一个全新的氧合器(血液在里面完成氧气交换的"人工肺",用完即扔,一个几百到上千美元),外加插管、管路套件。全球每年上百万台体外循环手术,台台都要消耗一套。这是标准的"剃须刀+刀片"模式:机器铺进医院,后面几十年源源不断卖刀片。医院为什么不换牌子?人命关天的设备,灌注师(操作心肺机的技师)全是按这套系统训练的,换品牌要重新验证整条流程,没人愿意为省几百块冒这个险。

生意二:迷走神经刺激器(Neuromodulation)——治癫痫的"脖子起搏器"

针对耐药性癫痫:全球几百万癫痫患者里约三分之一吃两三种药仍控制不住发作。LivaNova 的 VNS 疗法是给这些人做一个小手术:锁骨下埋一个火柴盒大小的脉冲发生器(长得像心脏起搏器),导线绕在颈部的迷走神经上,每隔几分钟放一阵微电流刺激大脑,把发作频率砍掉一半左右。一套植入物加手术费几万美元,保险覆盖。电池 5-10 年耗尽,患者回来换新机——存量患者变成循环收入。

这门生意接近垄断:VNS 治癫痫领域 LivaNova 是唯一成规模的玩家,几十年积累了十几万植入患者。弱点是增长平缓(+7% 左右):适应症拓展不顺,抑郁症方向做了多年临床,医保报销始终没铺开,等于第二增长曲线迟迟点不着。

第二部分:把会计障眼法剥掉

这家公司报表上的疤痕比一般医疗器械公司多得多,逐项来:

  • 税收收益注水(TTM 最大的障眼法):TTM 税前利润只有 1.07 亿,净利润却报 1.89 亿——中间是一笔 +8200 万的所得税收益(不是交税,是"收税")。这是递延税资产确认之类的一次性会计动作,不是经营赚来的。看这家公司必须看税前,净利润被注水了 77%。
  • 一次性项目(历史大坑):FY2025 净亏损 2.42 亿,主因是意大利 SNIA 环保诉讼——Sorin 前身公司留下的化工污染责任,意大利法院终审判赔约数亿欧元,一次计提打穿全年利润。TTM 税前利润与经营利润之间还有约 1.1 亿的缺口(经营利润 2.15 亿 → 税前 1.07 亿),除了约 3100 万利息,剩下是诉讼计提利息、汇兑等杂项。单期口径无法判断诉讼相关支出是否还有后续,但主体赔偿已计提在 FY2025。
  • 股权激励(SBC):TTM 4450 万,占净利润 23.6%,占税前利润 42%——这个比例在传统医疗器械公司里算高的,是真实成本。GAAP 已扣,不加回。
  • 资本化的支出:资本开支 TTM 1.01 亿(翻倍于两年前),主要是 Essenz 产线和 IT,无明显研发资本化把戏。没有。
  • 回购与稀释:TTM 回购仅 440 万 ÷ SBC 4450 万 = 0.1 倍——回购连员工发股的零头都盖不住,股本一年净增 1.77%,不分红。股东回报字面意义上为负(-1.77%)。
  • 利润和现金流的差:净利润 1.89 亿 vs 经营现金流 2.49 亿 vs FCF 1.48 亿。对账(TTM,百万美元):净利润 188.6 → +折旧摊销 85.1 → +SBC 44.5 → −出售资产/投资收益 15.5 → −其他 2.3 → −营运资金占用 51.1 → = 经营现金流 249.3;−资本开支 101.0 → = FCF 148.3。现金流是真的,但注意:税收收益是非现金的,所以 FCF(1.48 亿)反而比净利润更接近真实盈利能力。

三年平均这行必须多说一句:过去三年 LivaNova 加起来净亏 1.62 亿——诉讼把三年利润全吞了。当期 23.5 倍的表面市盈率,是站在"疤痕刚结痂、税收收益又化了妆"的这一年上算出来的。

说人话:你现在投 100 块进去,按剔除税收注水后的真实口径,公司一年替你赚 3.3 块。 这 3.3 块一分钱都不回你口袋:不分红,回购忽略不计,股本还在每年稀释你 1.8%。钱留在公司里投了 Essenz 产线和研发——好消息是这两门垄断生意的再投资回报不差(ROIC 19.8%),Essenz 换装潮+耗材粘性能让这个 3.3 块继续变大;坏消息是你只能指望股价,拿不到现金。

第四部分:一句话结论

两门全球第一的好生意(心肺机是剃须刀+刀片,VNS 是准垄断),但报表被三样东西弄脏:税收收益给净利润注水 77%、SBC 吃掉税前利润四成、股本连年稀释;剔完之后真实市盈率约 30 倍,而股价过去一年已涨 49%——生意配得上好价钱,但现在这个价把未来两三年的修复都预支了,等它跌回来再看。
