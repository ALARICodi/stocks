VREX · Varex Imaging（万睿视影像）

市值 $7.80 亿 / 股价约 $18.5 / 行业：医疗科技（X 光影像部件） / TTM 截止 2026-07-03

第一部分：它到底做几件事

Varex 是 2017 年从瓦里安医疗（Varian）拆出来的独立公司，做的东西一句话能说清：X 光机里最核心的那两个零件——发射 X 光的球管，和接收 X 光的平板探测器。它自己不造整机，是给造整机的厂商供货的"军火商"。按分部报表，它做两门生意。

生意一：医疗（Medical）——给 CT 机和 X 光机厂商供"灯泡"和"底片"

这门生意最好懂的比喻：X 光球管就是 X 光机里的"灯泡"，平板探测器就是"数码底片"。

具体怎么做的：西门子医疗、佳能医疗、联影这类造 CT 机的公司，自己不生产球管（或产能不够），就找 Varex 买。一台 CT 机里的球管是消耗品——高压电子轰击钨靶产生 X 光，靶面会烧蚀，用两三年就得换，一根 CT 球管卖几万到十几万美元。所以这门生意有两块收入：新整机出厂时装的（OEM），和存量机器换管子的（替换市场）。全球几十万台在用的 CT 和 X 光设备，每年都在产生替换需求，这是 Varex 最稳的现金来源。除球管外还卖数字化平板探测器（把 X 光直接转成数字图像的那块板，用在 DR 拍片机、乳腺机、C 臂上）、高压连接器和图像处理软件。

客户为什么非买不可：全球能批量造高端 CT 球管的独立厂商基本只剩 Varex 一家（另一家主要对手是佳能旗下的电子管事业部，但那是自用为主）。整机厂要么花十年自建球管产线，要么找 Varex——大部分选后者。这就是它的护城河：不宽，但真实。

生意二：工业（Industrial）——集装箱安检和工业探伤

同样的 X 光技术，换个场景卖：

  • 口岸安检：海关要扫描整个集装箱卡车，得用直线加速器产生的高能 X 光打穿几十厘米钢板。Varex 卖这套系统里的加速器和探测器阵列，一套设备里它的部件值几十万美元。买家是给各国海关做安检门架的集成商（如 Smiths Detection、Nuctech 的海外对手们）。
  • 工业探伤：飞机发动机叶片、锂电池、汽车焊缝出厂前要用 X 光/CT 检查内部缺陷，Varex 卖探测器和源。锂电池检测这几年是个真实的增量市场——每条电池产线都要装在线 X 光检测。

工业是全公司唯一的增长引擎，五年从 $174M 涨到 $278M（+60%），主要靠全球口岸安检更新和电池检测。

第二部分：把会计障眼法剥掉

  • 股权激励（SBC）：TTM $15.0M，是净利润（$22.1M）的 68%。GAAP 里已扣，这里不加回。要注意的是它对这种低利润公司的杀伤力：利润基数太小，发股票的成本就显得格外重。股本一年增加 2.55%，稀释是实打实的。

  • 一次性项目：TTM 这四个季度里没有大额一次性项目。但往前看一年就有大的：FY2025 计提了 $93.9M 资产减值和重组费（这就是 FY2025 亏损 $70.3M、FY2024 亏损 $48.8M 的主因之一）。单期口径无法判断这类减值是否还会再来，但连续两个财年亏损说明这家公司的"正常利润"本身就不稳。

  • 资本化的支出：没有明显的开发费资本化问题，资本开支 TTM $31.5M，超过折旧 $27.3M，属于正常偏重。

  • 回购与稀释：TTM 回购 $1.5M ÷ SBC $15.0M = 0.1。回购连员工发股的零头都抵不掉，同期还发新股融了 $3.3M。股东在被持续稀释，没有任何回馈可言。

  • 利润和现金流的差：这是全篇最要命的地方。净利润 +$22.1M，但自由现金流是 -$20.2M。逐项对账：

项目 金额
净利润 +$22.1M
加：折旧摊销 +$28.8M
加：SBC +$15.0M
加：股权投资亏损等 +$4.5M
加：其他经营项目 +$18.3M
减：营运资金变化（其中压库存 -$55.7M） -$77.4M
= 经营现金流 +$11.3M
减：资本开支 -$31.5M
= 自由现金流 -$20.2M

一年赚的 2200 万利润，全部变成了仓库里的存货还倒贴。公司解释通常是"为关税和新品备货"——存货最终能不能按账面价值卖出去，决定了这 2200 万利润是真是假。FY2025 刚减值过 9400 万，这个疑问不是杞人忧天。

  • 债务：账上现金 $100.1M、总债务 $379.3M，净债务 $279.2M。TTM 付现金利息 $33.7M，而经营利润才 $72.2M——利息吃掉近一半经营利润，利息覆盖率 1.86 倍。这是典型的"股东排在债主后面吃剩饭"的资本结构。

大白话：你现在投 100 块进去，按真实口径公司一年替你赚 2 块 8；按现金流算，今年一分钱没赚还倒贴。 这 2 块 8 里没有一分钱回到你口袋——不分红，回购形同虚设，钱全压进了存货。三年平均利润是负的，说明当前这点利润不是"低谷"，而是这公司近年的较好状态。

多头的全部指望在"修复"：远期 PE 18 倍，赌的是医疗市场（尤其中国）回暖 + 工业安检继续涨 + 去年重组见效。可能成，但注意：股价过去 52 周已经涨了 61.6%，RSI 89 严重超买——修复的故事已经被抢跑定价了大半。

第四部分：一句话结论

生意本身站得住（球管独立供应商全球就它一家，工业安检在真增长），但财务结构很难看：利息吃掉半数经营利润、利润全压成存货、现金流为负、股东只被稀释不被回馈。35 倍买的不是现在这家公司，是"明年利润翻倍"的剧本，而这个剧本的票价已经先涨了 61%。不值得现在买，偏贵——真想要它的人应该等修复证实、或等超买回落，而不是在 RSI 89 的位置追。
