13.5倍FFO股息5.4%连涨37年,公道价的收租机器

NNN · NNN REIT（全美净租赁地产信托）

市值 $88.0亿 / 股价约 $45.9 / 零售地产 REIT / TTM 截止 2026-06-30

这是地产信托（REIT），下面用 FFO/AFFO 口径而不是市盈率。 原因：会计上房子每年要计提折旧当费用，但地段好的商业地产实际上不掉价甚至升值，所以 REIT 的"净利润"被假成本压低了，22.6 倍的账面市盈率没有意义；行业通用的口径是 FFO（净利润加回房产折旧、剔除卖楼损益），它才近似"房租真正剩下的钱"。

一、它到底做几件事

严格说只做一件事：买下临街商铺，整栋出租给连锁品牌，收租。但这个模式有三个关键词要讲透——"单一租户""净租赁""长约"。

具体是这么运作的：7-Eleven 想在佛罗里达开 20 家带加油站的便利店，每家店地皮加建筑要 300 万美元，20 家就是 6000 万——它不想把钱压在房子上，想拿去铺货开新店。于是 NNN 出钱把这 20 家店买下来（或者直接出钱替它建好），然后签一份 15–20 年的长租约租回给 7-Eleven，年租金约为房价的 7%–8%（每家店一年 20 多万美元），租约里写好每年租金自动涨 1.5% 左右。

"净租赁"（Triple Net，公司代号 NNN 就是这个意思）是灵魂：房产税、保险、维修全归租户掏，NNN 只管收租。所以这家公司只有 85 名员工，却管着约 3,600 处物业、一年收 9.3 亿租金——人均"创收"1100 万美元，本质是一家披着地产外衣的收租机器，几乎没有运营。

租给谁：全是"电商杀不死"的街边生意——便利店（7-Eleven、Wawa，约占租金 17%）、汽修轮胎店（Mavis）、洗车行、快餐（Taco Bell、Wendy's 的加盟商）、健身房。这类租户的共同点：生意离不开那个具体位置，搬家等于重开一家店，所以到期续约率高，出租率长年 99% 左右（公司披露口径）。

钱怎么滚大：REIT 按法律要求把利润几乎全分红，留不下钱，扩张靠"发新股 + 借债 → 买新楼 → 租金差价归股东"。TTM 买楼花了 9.1 亿，卖旧楼回收 2 亿，股本增发 1.6%。只要买楼的租金回报率（约 7.5%）高于融资成本，每股分红就能一年比一年多——这套循环 NNN 玩了三十多年。

二、把会计障眼法剥掉

  • 最大的"障眼法"是行业自带的：折旧。 TTM 计提房产折旧摊销 $2.77亿，把净利润压到 $3.84亿。这笔"费用"一分钱现金都不花，而且对应的是大概率不掉价的临街地皮。这是 GAAP 冤枉它，不是它骗你——所以才要用 FFO。
  • 股权激励（SBC）：TTM 仅 $1,412万，占净利润 3.7%。85 个人的公司，克制得很，忽略不计。
  • 一次性项目：TTM 卖楼赚了 $4,950万（要从 FFO 里剔掉，不是经常性房租），同时计提了 $4,130万资产减值——这个数字比往年偏大（FY2024 只有 660 万），说明有一批租户出了问题（餐饮和洗车行租户破产、退租），两者基本对冲。减值连续两年放大是唯一值得盯的坏苗头。
  • 回购与稀释：REIT 模式决定了不回购、只增发（TTM 增发 1.58%）。这不是掏股东腰包，增发的钱拿去买了新楼，看每股 FFO 有没有涨就行——有涨（约 +2%/年），及格。
  • 利润 vs 现金流：净利润 $3.84亿 + 折旧 $2.77亿 − 卖楼收益 $0.50亿 + 减值 $0.41亿 ≈ 经营现金流 $6.73亿，完全对得上，房租是真金白银。统计页显示"自由现金流 −2.4亿"是把买楼当资本开支算的，对收租模式没有意义——净租赁模式下维护性开支归租户，NNN 自己的维护资本开支近乎为零。

三、估值：FFO/AFFO 口径

市值 $88.0亿，带息债务 $50.0亿，企业价值 $137.9亿。

FFO 计算（据财报组件推算）：净利润 3.84 + 房产折旧 2.77 − 卖楼收益 0.50 + 减值 0.41 ≈ $6.53亿，每股约 $3.40（与公司披露的 Core FFO 基本一致；AFFO 与之相差不大，净租赁模式两者很接近）。

大白话：你投 100 块进去，房租扣掉利息和开销后一年真实剩下约 7.4 块，其中 5.4 块以季度分红直接打到你账上，剩下 2 块留在公司凑首付买下一批楼。这个分红已经连续涨了 37 年——全美股 REIT 里只有两三家做到过，穿越了 2008 金融危机和 2020 疫情。未来这 7.4 块大概率以每年 1%–3% 的速度缓慢变大：租约里写死的涨租条款托底，上行空间则取决于利率——它借新钱的成本降下来，买楼利差才能重新拉开；债务/EBITDA 5.8 倍比它历史习惯的 5.5 倍略高，利息覆盖 2.75 倍也在缓慢变薄，这是增长引擎当前偏紧的信号。

四、一句话结论

一台运转了三十七年的收租机器：租户付税付保险付维修、出租率常年 99%、85 个人管 3600 栋楼、分红连涨 37 年——生意简单到无聊，但无聊得可靠。13.5 倍 FFO、到手 5.4% 股息率，在它自己的历史区间里处在偏低一段，价格算公道，当收息股拿是合格的；别指望它涨出花来——它的天花板就是"分红 5.4% + 每年涨 2%"，租户减值连续两年放大和 5.8 倍的杠杆是要每季度瞄一眼的两处暗角。
