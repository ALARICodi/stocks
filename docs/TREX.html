好生意真回购，但28倍买的是利润率回升的期望

TREX · Trex 木塑地板

市值 $48.6 亿 / 股价 $47.73 / 行业：建筑材料（户外地板） / TTM 截止 2026-06-30

一、它到底做几件事

就一门生意：用回收垃圾做户外露台地板，替代木头。 2021 年卖掉商用工程业务后，财报只剩一个分部（Trex Residential）。

这门生意具体是这么回事：美国人家后院普遍有一块木头露台（deck），全美存量大约 6000 万个。木头露台的痛点是每一两年就要打磨、刷漆、防腐，十几年就烂穿。Trex 发明的替代品是"木塑复合材料"：约 95% 的原料是回收货——锯木厂的木屑加超市里回收的塑料袋、缠货盘的塑料膜，加热挤压成型，外面包一层耐磨防褪色的塑料壳。卖点直白：不烂、不长刺、不用刷漆，质保 25–50 年。

钱是这么收的：一个典型场景，房主找承包商把 20 年的旧木露台换掉，整个工程 1.5 万美元左右，其中 Trex 的板材和栏杆大概 6000–8000 美元——比用防腐木贵 30%–50%，但省掉此后二十年的维护，承包商也乐意推（好施工、不吃保修投诉）。销售走两级分销：Trex 卖给建材分销商，分销商供给全美几千家专业木材行，同时家得宝、劳氏的货架上也摆着零售款。收入约九成来自翻新改造而不是新房——所以它跟的是"美国人愿不愿意为后院花一万多块"的消费周期，不完全跟新房开工走。

行业格局是这门生意最值钱的部分：户外地板里木头仍占约四分之三,复合材料每年从木头那里抢走约一个百分点的份额,这是一条能走十几年的替换曲线;而复合材料阵营里 Trex 约占一半,是品牌代名词(像"邦迪"之于创可贴)。主要对手 TimberTech（AZEK）2025 年被 James Hardie 收购后火力变强。Trex 的成本护城河在原料端：别人买新塑料，它收废塑料膜，一年吃掉几亿磅垃圾，原料成本天然便宜一截。

二、把会计障眼法剥掉

  • 股权激励（SBC）：TTM 仅 $930 万，占净利润 5%——制造业公司的正常水平，干净。
  • 一次性项目：TTM 处置资产损失 $520 万，可忽略。没有减值、没有重组、没有大额诉讼。这张利润表基本没有妆可卸。
  • 资本化的支出：资本开支 TTM $1.5 亿（占营收 12.4%），前两年高达 $2.2–2.3 亿——在阿肯色州建第三座工厂。工厂建完开支正在回落，这是 FCF 好转的主因，不是经营变好那么简单。
  • 回购与稀释：TTM 回购 $2.04 亿，是 SBC 的 22 倍——教科书级的真回购，股本一年实缩 2.1%。不派股息，股东回报全走回购。
  • 利润 vs 现金流：净利润 $1.77 亿 vs 经营现金流 $3.58 亿，差额很大，对账：净利润 1.77 → 加折旧摊销 0.71 → 加 SBC 0.09 → 加营运资金释放 0.79（应收账款回收 + 去库存，这是"早买计划"发货节奏造成的单年现象）→ 加其他 0.22 ≈ 3.58。翻译：今年现金流里有约 8000 万是把去年压在渠道里的钱收回来了，明年不会再有，看常态化 FCF 应该按净利润附近（$1.8–2 亿）估，别被 P/FCF 23 倍骗到。

真正要盯的不是会计，是利润率本身：毛利率从 FY2024 的 43.6% 掉到 TTM 的 38.2%，经营利润率从 28.0% 掉到 20.2%——需求疲软 + 新厂爬坡吃产能利用率 + 入门款占比升高，三个原因叠在一起。营收还在涨、利润在缩，这是这家公司眼下的全部矛盾。

大白话：你现在投 100 块进去,按真实口径公司一年替你赚 3 块半。这 3 块半基本全数以回购形式还给你了（TTM 回购金额甚至超过净利润）,公司账上净债务不到 1 倍 EBITDA,不欠着你什么。三年平均口径 23 倍比当期 28 倍低,说明当前利润是被压着的（利润率在低位）,不是顶点——这点和多数 28 倍的股票相反,算一个安慰。

未来这 3 块半变大还是变小？两股力在拔河：往上的力是木头换复合材料的长期渗透 + 新厂产能利用率回升 + 每年 2% 的股本收缩；往下的力是美国高利率下万元级后院消费持续疲软 + James Hardie 加持的对手打价格战。过去 52 周股价跌 24%、10.4% 的流通盘被做空，市场押的是后一股力。

四、一句话结论

好生意、干净账、真回购,但 28 倍买的是"利润率会回到 25% 以上"的期望——在需求还没回暖、对手刚换了有钱爸爸的当口,这个价不便宜,合理偏贵;它 2025 年底跌到 20 倍以下时才是给耐心人的价格,现在这个位置买,赚的钱主要得靠周期回暖来兑现。
