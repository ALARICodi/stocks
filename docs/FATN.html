FATN · FatPipe（法派管网络）

市值 $8675 万 / 股价约 $6.1 / 行业：科技服务（SD-WAN 网络软件） / TTM 截止 2026-06-30

第一部分：它到底做几件事

FatPipe 实质上只做一门生意：卖「网络不断线」的设备和软件。财报没有按业务分部披露，只按地区分（美国 + 海外），所以下面按一门生意讲。

这门生意是什么

想象一家有 200 家分行的银行。每家分行都要连总部的核心系统——柜员转账、ATM 吐钱、风控审批，全走网络。分行一般同时拉两三条线：一条贵的专线（MPLS，运营商保证质量）、一条便宜的普通宽带、再备一张 4G/5G 卡。问题是：专线一断，传统路由器切到备用线路要几秒到几十秒，切换瞬间所有连接全掉——柜台交易失败、ATM 卡单。

FatPipe 卖的盒子（加软件）装在分行和总部两头，把这两三条线捆成一条虚拟的线。它的专利技术能把同一个数据流拆到多条物理线路上同时走，任何一条线断了，流量瞬间从其他线走，连接不掉、用户无感知，而且不需要运营商配合（这是它 1990 年代末申请的一批专利的核心）。这个品类后来被行业叫做 SD-WAN（软件定义广域网）。

具体怎么收钱：客户按点位买设备/软件许可（每个分支一台，总部一对做冗余），再按年付维保和订阅。一家 200 个网点的客户，初次部署几十万美元量级，之后每年付 15–20% 的维保费——这部分是可以年年收的。产品线叫 MPVPN、WARP、XTREME，上面还有一层集中管理软件 SYMPHONY，网管坐在总部就能给全国网点改配置。

卖给谁：对「断网一分钟就出事故」的行业最有吸引力——银行、医院、保险、连锁零售、呼叫中心、政府机构。公司总部在盐湖城，研发很大一块在印度，客户也集中在这两个市场。

第二部分：把会计障眼法剥掉

这家公司的报表问题非常严重，是全篇重点。

① 净利润是靠「负所得税」撑出来的。 TTM 税前利润只有 $339 万，净利润却有 $544 万——中间差的 $207 万是所得税收益（税是负的，很可能是递延税资产确认之类的账面调整）。也就是说，净利润里有 38% 不是生意赚来的，是税务科目送的。单期口径无法判断这是否年年发生，但正常缴税的公司不可能长期税率为负。

② 利润从来没有变成过现金——五年全负。 经营现金流：FY2022 -$19 万、FY2023 -$184 万、FY2024 -$36 万、FY2025 -$50 万、FY2026 -$78 万、TTM -$95 万。账面五年累计净赚约 $1470 万，同期经营现金流累计约 -$370 万。钱去哪了，对账表一目了然：

净利润 → 经营现金流（TTM） 金额

一年 $2030 万的收入，应收账款一年就多压了 $709 万——新增收入的钱基本都停在「客户还没付」这一栏。而且这不是一年的事，近三个财年应收变动累计约 -$1800 万，跟同期收入规模一个量级。

③ 坏账计提在加速。 FY2024 计提 $21 万、FY2025 $77 万、FY2026 $111 万、TTM $123 万——公司自己也在承认，挂在账上的应收有一部分收不回来了。收入确认了、利润确认了、钱没来、然后开始一年比一年多地认赔。

④ 股权激励与稀释：TTM SBC $97 万，占税前利润 29%。回购为零，回购/SBC = 0。股本一年增加 6.59%（2025 年刚上市，IPO 增发 + 发股）。股东每年被稀释，没有任何回馈。

⑤ 资本化支出：没有，资本开支仅 $1.5 万，可忽略。

⑥ 一次性项目：除上述税务收益外无其他大额一次性项目。

大白话：你投 100 块进去，账面说一年替你赚 6.3 块；把送的税务收益剥掉，只剩 2.9 块；而按真金白银算，公司一年倒贴你 1.1 块——它不但没收到钱，还得靠借债和增发新股来维持运转（FY2025 借了 $551 万、FY2026 增发募了 $374 万）。分红没有、回购没有，赚的「利润」全变成了应收账款躺在账上，其中一部分正在按年被确认为坏账。这个 6.3 块和 2.9 块的差距未来会怎么走，取决于那座应收账款山能不能收回来——目前的坏账计提趋势指向的方向不乐观。

第四部分：一句话结论

表面 15.8 倍的便宜是假的：利润里 38% 是税务科目送的，剩下的部分五年来一分钱现金都没变成，全堆在收不回来的应收账款里，坏账计提一年比一年多——这不是便宜，是报表失真，不值得碰。
